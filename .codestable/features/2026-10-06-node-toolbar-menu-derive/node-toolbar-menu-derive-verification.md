# V6-007 验证记录

设计：[node-toolbar-menu-derive-design.md](node-toolbar-menu-derive-design.md)。本条只改前端。

## 实现取舍

- 节点右键菜单在 PRD 列出的菜单项之外，还保留了「替换媒体 / 上传媒体」和「从资产库添加参考」。工具条按 CV-70 去掉了替换按钮，所以菜单是替换媒体的唯一入口；「从资产库添加参考」是 V6-057 已经验收过的入口。两项都放在「复制」之前，PRD 规定的菜单项顺序不变。
- 链接、文档节点的工具条暂时只有主要动作和「更多」，链接与音频完整的工具条由 V6-009/010 补齐。
- 「生成图片」只在文本节点有正文时显示。空文本作为参考没有意义，这与之前的行为一致。
- V6-001 移交过来的「编辑节点」已改为「编辑文字」，只对文本节点显示。有内容的媒体节点另外保留「编辑说明」：PRD CV-80 没有列这一项，但它是修改媒体说明的唯一入口，去掉就会回退（`creative-media` e2e 依赖它）。

## 门禁

- `npm run lint` 退出码 0；`npm run build` 通过；`make test-frontend` 404/404。
- mock e2e：新增的 `creative-node-toolbar` AC-01–04 全部通过。另外 11 个纯 mock 的创意空间 e2e 也全部通过：node-create、canvas-viewport、node-resize、node-label、save-status、canvas-interaction、canvas-baseline、composer-baseline、library、library-baseline、generation。
- 回归有效性：把 `CanvasView`、`WorkspacePage` 换回 HEAD 后，AC-01、03、04 失败。AC-02（派生一次撤销还原整批）仍然通过，因为改动前节点和连线就在同一个 `act` 里，本条只是补上验收。AC-04 在 HEAD 上失败的原因是工具条按钮名称不同，「复制、删除按子树处理」本身改动前就成立。

修改的既有断言（都是文案或入口按 PRD 调整导致的）：
- `creative-canvas-interaction`：「编辑节点」改为「编辑文字」；「复制选中节点」「复制节点」改为「复制」；「移除节点」改为「删除」。文本节点的工具条按 CV-70 不再有复制按钮，原来两处「点工具条复制」改为「更多 → 复制」，仍然不经过画布键盘处理。空媒体工具条的「上传媒体」图标按钮改为「上传」文字按钮。
- `creative-library-baseline` AC-07：「存入个人资产库」改为「存入资产库…」。

e2e 的写法：在线时 mock 会确认派生节点，生成面板才会解锁并获得焦点。但 mock 没有服务端变更历史，确认之后就不能撤销，所以需要撤销的场景（AC-02、AC-04）放到离线 context 里跑，改动留在本机。

## 验收对应

| AC | 证据 |
|---|---|
| AC-01 文本→图片、图片→视频、多选→参考图片，都新建下游节点并逐个连线 | e2e AC-01：三种派生都只新建一个对应类型的节点（image / video / image）；每个来源都有 `connect_reference` 指向新节点，并且和 `add_node` 在同一条命令里发出 |
| AC-02 预填引用和视频前缀，聚焦新节点，不自动生成，一次撤销还原整批 | e2e AC-01：提示词输入框里的引用 chip 按来源顺序排列；文本→图片和多选只有引用，图片→视频后面跟着「镜头缓慢推进，」；焦点在「提示词」上；没有调用 `/executions`。e2e AC-02（离线）：三种派生各撤销一次后，节点和新连线都消失，撤销栈清空 |
| AC-03 各类选区的工具条符合 CV-70；多选含组时可解组、可批量入库；组可适应视图；「更多」与右键菜单一致 | e2e AC-03：多选为「已选 3 项 / 打组 / 解组 / 合并为参考生成 / 复制 / 删除」；单个组为「重命名 / 解组 / 复制整组 / 更多」；文本为「编辑 / 生成图片 / 更多」；空媒体为「上传 / 更多」；图片为「生成视频 / 全屏查看 / 存入资产库 / 下载 / 更多」；视频为「全屏查看 / 存入资产库 / 下载 / 更多」。视频节点上「更多」打开的菜单与右键菜单完全相同，并符合 CV-80 的顺序；文本节点菜单含「编辑文字」；组菜单为 CV-82 的 5 项，「适应到分组」后组铺满视口；多选含组时菜单为 CV-81 的 5 项；批量入库只保存有内容的 2 个节点；空白处菜单末尾为「撤销 / 重做 / 全选 / 适应画布」，「全选」选中全部根节点。e2e AC-04：多选含组时的解组可以一步撤销 |
| AC-04 撤销/重做不可用时禁用；删除和复制遵守子树规则 | e2e AC-04：没有可撤销的操作时，空白处菜单和缩放条上的撤销、重做都是禁用状态；同时选中组和组内节点后复制，只多出 2 个节点（组和子节点各一个，没有重复）；「删除分组及内容」把子节点一起删掉，撤销后恢复，重做变为可用 |
| AC-05 派生节点为 1:1，放在所有来源右侧 120 处，垂直方向取来源中心的平均值 | e2e AC-01：三种派生的新节点宽高相等；左边缘等于所有来源最右端再加 120 × 缩放倍率；垂直中心等于各来源中心的平均值 |
