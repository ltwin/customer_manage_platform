# 创意空间 v6 · PRD 全量追踪

[返回需求总表](README.md)

PRD v0.2 共 222 个编号（§2–§9），每个编号都有且只有一个**主责条目**。主责条目负责按 PRD 原条目的全部验收要点完成验收；协作条目只交付其中与自身范围相关的部分，不能代替主责关闭。

- 「已实现」的需求同样有主责条目（基线回归验收 V6-055/056/057 等），不因差距分析未列为 GAP 而豁免验收。
- **证据**列在主责条目验收通过后填写验证记录链接；条目 AC 与 PRD 验收要点的逐项对应写在该条目的验证记录里。
- 新增或调整 PRD 编号、改变主责时，同步修改本表与条目「需求来源」，并用总表「维护检查」重跑覆盖校验。
- 优先级取自 PRD 原文；UF 为验收流程，NF 未标优先级的保留「质量要求」，不自行归为 P0/P1。
