## 目标与范围

资产库成为独立页面，方向是 Eagle 式的素材管理。布局是应用侧栏、资料库树、浏览区和检查器四栏。本条负责页面骨架、浏览、选择与整理、导入和回收站入口。体量较大，预拆三个子项：067.1 页面骨架、浏览与筛选；067.2 选择与整理（拖放、检查器、批量条、右键菜单）；067.3 导入与回收站。

范围外：与已有条目的分工：计数与中文排序见 V6-016，删除分组撤销见 V6-018，类型分段与缩略形态见 V6-060，回收站到期清理验收见 V6-020。这些在各自条目里定义，本条只把它们放进新页面。「最近添加」不同于 V6-014 的「最近使用」，两者不合并。画布内的资产库抽屉不在本条范围：它继续负责在画布里取用素材（V6-057 已验收的入口：工具轨、添加菜单「从资产库添加」、空节点填充、`@` 添加参考），本条不改变这些行为。整理模式此前是候选（V6-054、D-02），2026-10-11 owner 拍板资产库独立成页后由本条承接。**手机上暂不提供资料库树**（2026-10-11 倾向不做，owner 未要求；如需要再另立条目）。

## 当前基础

2026-10-11 拆分时复核的代码基础；开工时再核对一次。

- `/creative/library` 渲染 `WorkspacePage`，资产库是画布内的面板（`LibraryPanel.tsx` / `LibraryEditor.tsx`）。
- 资产列表接口已支持 view（all / favorites / unclassified / trash）、group_id、include_descendants、kind、q、tag_ids + tag_mode、sort（recent / oldest / name），资产带 purge_after。
- 分组、标签、标签分类、资料库设置已有接口。
- 回收站期限由账号设置决定（`CreativeLibrarySettings.retention_days`：7 / 30 / 90 天，或为空表示不自动清除），每项素材带 `purge_after`；基础需求 LIB-05 要求期限可配置。原型里写的「30 天」只是示例。
- 搜索已有服务端投影（`creative_asset_search`），覆盖范围按基础需求：标题、描述、文字内容、来源 URL 和标签。
- 内容归属约定：资产库不记录、也不展示素材是否进了画布（owner 2026-10-07）。

## 验收标准

- [x] **AC-01**：`/creative/library` 是独立页面，不加载任何画布；侧栏与首页一致。宽度大于 1100px 时四栏全部显示；≤1100px 收起检查器，并隐藏检查器开关；≤760px 只保留浏览区，侧栏变成顶栏。各宽度下都没有横向滚动。
- [x] **AC-02**：资料库树包含固定视图（全部、未归类、最爱、最近添加、回收站；「最近添加」是最近 7 天内添加的素材，按添加时间倒序）、最多两层的分组（计数包含子组）、按分类列出的标签；点标签即加入筛选；底部显示用量。
- [x] **AC-03**：浏览区：类型分段带数量，数量为 0 的类型不出现；关键词搜索覆盖标题、描述、文字内容、来源 URL 和标签（与基础需求一致）；标签可选「同时满足 / 满足任一」；生效的条件以 pill 列出，可以逐个移除；可以排序；瀑布流 / 方格切换和缩略图大小记在本机；换视图时清空筛选；进入分组后显示面包屑和子分组 chip。
- [x] **AC-04**：选择：单击选中，⌘ 加选，Shift 连选，在空白处拖动框选，⌘A 全选，Esc 取消。把素材拖到左侧分组上即归入，一份素材可以同时在多个组；进入分组后右键菜单有「移出这个分组」。
- [x] **AC-05**：检查器：单选时可以编辑标题和备注，就地增删分组和标签，也可以新建标签；多选时显示叠放预览，只属于部分素材的分组和标签显示为半透明。检查器可见时不出现批量条；检查器收起或放不下时出现批量条。批量条、检查器和右键菜单提供同一组操作。
- [x] **AC-06**：「放入项目…」：可以选择已有项目，也可以「新建项目并放入」（没有项目的账号也能完成）；单选、多选都适用，生成记录复用同一个菜单。放入时把内容复制一份，在目标画布现有内容的右侧横排摆开（间距与 V6-057 AC-05 一致）；整批要么全部放入，要么失败并说明原因、可以重试，不会静默地只放进一部分；完成后 toast 提供「打开画布」。资产库不记录、不展示被哪个项目用过。
- [ ] **AC-07**：导入：菜单可以上传文件、添加链接、新建文字；文件拖进浏览区时导入到当前分组；⌘V 可以粘贴文件、网址或文字；被跳过的项在 toast 里逐项说明原因。
- [ ] **AC-08**：回收站：每项按自己的 `purge_after` 显示剩余天数，可以恢复或永久删除；顶部提示按账号设置的期限书写（如「7 天后自动清除」），设置为不自动清除时提示不会自动清除，提示与实际清理时间始终一致；旁边是「清空回收站」，执行前确认，并说明画布里已有的节点不受影响。
- [x] **AC-09**：卡片下方只放标题（仅图片和视频）和只读星级；文字、链接、音频卡片各有自己的样式，不用通用图标代替。
