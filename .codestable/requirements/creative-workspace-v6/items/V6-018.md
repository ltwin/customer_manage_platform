# V6-018 · 删除资产分组的可恢复撤销

## 目标与范围

在已有删除保留资产/提升子组之上增加真实服务端撤销。

范围外：不扩展到本条未列出的相邻能力。

## 当前基础

以下是 2026-10-05 的分析依据，只取与本条相关部分；开工时复核，不将同一 GAP 内其他子需求一并带入。

- **GAP-20**：新建分组在校验重名前先关闭编辑，重名输入没有保留；删除会保留资产并提升子组，但无 toast 撤销入口。

## 验收标准

- [x] **AC-01**：删除后资产保留、子组上提，并显示可用撤销入口。
- [x] **AC-02**：撤销恢复分组与归类，刷新后结果一致。
- [x] **AC-03**：期间有新变更时提示冲突或保留新变更，不能覆盖他人/其他窗口操作。
- [x] **AC-04**：重复回执/重试不会创建重复组或成员关系。
