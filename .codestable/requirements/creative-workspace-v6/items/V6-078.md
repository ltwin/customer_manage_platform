# V6-078 · 助手整理资产库

[返回需求总表](../README.md) · 优先级：P1 · 类型：交付

**需求来源**：2026-10-13 owner 讨论助手资产工具时拍板。PRD v0.2 之外的新增范围，没有 PRD 编号。

**推进状态与产物链接以总表本条记录为准**，本文件只维护需求，不重复记录执行状态。

## 目标与范围

助手帮摄影师整理资产库：看图后写标题和描述、打标签、归入分组，新建、改名、移动、删除分组、分类和标签，把素材移入回收站或从回收站恢复。整理写出的标题、描述和标签进入现有搜索，没有文字信息的图片从此能被找到，也是以后知识库的基础。

owner 2026-10-13 拍板：

- **何时整理**：摄影师指派，或助手在创作中觉得有必要时先询问摄影师，同意后再做。助手不自行发起整理。
- **允许的操作**：删除分组、分类、标签属于正常整理操作，纳入范围。
- **禁止的操作**：彻底删除素材、清空回收站，任何模式都不开放。
- **改写与入库**（owner 2026-10-13 design 评审）：可以改写已有标题和描述，但改写前先在对话里列出原值和新值，摄影师同意后再写；新入库素材必须有标题和描述，存入前列出标题、描述、分组、标签，摄影师同意后再存。这两条写在基础提示词里。
- **恢复**：助手可以把素材从回收站恢复；库内移入回收站不撤销已有显式、画布和会话引用的内容读取权。仅凭回收站搜索不能新增内容读取权。
- **完整读取**（owner 2026-10-13 审查修正）：素材搜索、归类结构和整理结果明细都要能筛选或分页读全；条数、字节限制不能造成无继续入口的缺失。计数来自完整数据，不能把本页条数当作总数；数据变化导致游标失效时明确提示。
- **描述长度**（owner 2026-10-13 审查修正）：新建、提交更新的资产库描述统一最多 1000 个 Unicode 码点，前端、HTTP 和 Agent 写入保持一致；搜索返回完整描述，通过双预算分页控制大小。已有 1001–2000 字描述保留，不因修改其他字段被截断或拒绝。
- **执行与汇报**：批量允许逐项部分成功；中断恢复先核对已提交回执，不能把自己的版本递增误判为冲突。写前保存恢复所需原值和计划，完整结果可独立分页读取，读取不能重新执行写入；结果保留窗口到期要明确告知。若工具已报告提交状态未知，剩余写入停止，后续结果查询只核对回执并收口，不暗中继续修改；补做须重新明确指派或同意。
- **基础提示词**：助手要有一套基础提示词，Skill 只在其上增加能力。本条整理基础提示词的内容与存放方式，补上 V6-035/077 新工具的说明，并加测试防止工具与提示词再次脱节。
- **确认**：目前只有自动执行模式，危险操作没有确认框；确认交互随手动模式（[V6-033](V6-033.md)）补上，本条不等它。

范围外：评分、收藏、标签颜色（摄影师的判断或审美，助手不改）；合并标签、多分类等资产库页本身也没有的能力；语义检索。

## 当前基础

2026-10-13 核对的代码基础：

- 资产库后端已有整理（`Organize`）、元数据（`Metadata`）、分组 / 分类 / 标签的增改删、移入回收站与恢复，都走 `creativeops` 执行器，带幂等和库级修订号；能力类别目前都是 `manual_write`。
- 删除分组可以恢复（`RestoreGroup`），删除标签和分类不能恢复。
- V6-035 已提供 `save_to_library`；助手尚无素材整理、归类结构管理和回收站写工具。

## 依赖与设计前置

依赖 [V6-035](V6-035.md)：查找、`read_library` 和读取素材在那里定义，整理在其上叠加写操作。

design 时需要定：

- 工具形状。建议按对象分：`organize_assets`（标题、描述、标签、分组的批量增改）、`manage_library`（分组、分类、标签的增改删与移动）、`trash_assets` / `restore_assets`（回收站），另提供只读的整理结果明细分页入口。
- 单次上限与汇报。建议每次调用最多改 50 个素材，结果列出改了什么、影响多少素材，助手在对话里如实汇报。
- 成本控制。看图打标签要把图片发给模型；整理范围由摄影师指定（如「未打标签的 30 张」），工具一次返回的缩略图数量有界。
- 改写摄影师手写的标题和描述时是否需要限制（已定：允许改写，改写前先确认，见上文 owner 拍板）。
- 助手写操作沿用哪个能力类别、记哪种调用方。

## 验收标准

- [x] **AC-01**：摄影师指派整理时，助手能改标题和描述、加减标签、归入或移出分组，结果与资产库页一致，并在对话里列出改动。
- [x] **AC-02**：能新建、改名、移动、删除分组、分类和标签；删除前按真实操作口径预览，执行后报告实际影响。标签统计全部关联素材，分组统计全部直接成员（两者含回收站），分类统计受影响标签；父分组删除另说明子组上提，不误报子组成员被移除。
- [x] **AC-03**：能把素材移入回收站，助手和资产库页都能恢复；彻底删除和清空回收站没有对应工具，模型无法发起。
- [x] **AC-04**：创作中助手认为需要整理时先询问，未经同意不写资产库；改写已有标题和描述、存入新素材前先列出内容并询问。
- [x] **AC-05**：批量有上限；并发修改冲突时不覆盖摄影师的改动，如实报告；文字提交后、归类提交后、工具结果登记前中断均可按回执恢复，不重复提交，原值和实际改动仍准确。
- [x] **AC-06**：真实模型完成一次看图打标签与归类，之后按新标签能搜到这些素材；保留工具调用记录。
- [x] **AC-07**：素材、完整描述、完整归类关系及第 501 项以后的结构对象都可继续读取。每页实际 JSON 大小有界；同版本遍历无漏项、无重复，总数准确；并发变化明确返回游标失效，不伪装成查询完成。
- [x] **AC-08**：合法的大批量写入返回有界摘要，完整前后值和关系明细分页可读且不重复写入；描述写入 1000 字成功、1001 字明确拒绝，不静默截断；已有长描述可读，修改标题/收藏/归类和恢复仍可进行。
