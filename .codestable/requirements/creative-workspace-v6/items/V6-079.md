## 目标与范围

拍摄策划有一个承载它的地方：一份独立的策划文档，加上画布上的策划节点。摄影师可以手写，也可以由助手（[V6-081](V6-081.md)）起草，两条路径得到同一种可编辑内容。

- **存储**：策划文档存在 `creative_documents`，由现有 `internal.document` 骨架转正（owner 2026-10-15 拍板，不复用旧 `shootplanning`）。字段可以借鉴旧模块：创作 brief（作品名、角色名、主题、情绪、视觉关键词）、镜头字段（场景、动作、表情、构图、光线）及景别 / 光向 / 光质 / 色调标签。
- **画布节点**：卡片显示方案名、角色与作品、选定方向一句话、几张关键参考、镜头数、各章节状态。双击最大化，进入策划编辑视图；关闭后回到原画布。
- **章节模板固定**：章节对应 cosplay 摄影领域头部摄影师的经验 SOP（前期策划 / 拍摄 / 后期合成 / AI 辅助 / 商业交付标准），另加准备清单（妆造、服装、道具、场地、灯具；合成片场地一般为无影棚），首版不允许摄影师修改模板（owner 2026-10-15）。章节可以留空或标「本次不适用」，不阻断使用。
- **镜头表**：按交付阵列（2 张主视觉全身大场景 + 4 张半身动态 + 3 张特写）分组。每个镜头可引用分镜图和参考图，引用的是内容修订，不是画布节点。删除、替换画布上的图片节点不影响策划。
- **版本**：每次保存形成不可变修订。摄影师手改和助手修改走同一条版本链，可以查看、恢复旧版本，互不静默覆盖。
- **助手工具**：读取策划（全文或指定章节）、按章节修改（带预期版本，冲突时重读再改）。
- **视觉设定**：分镜之前先定人设三视图与场景设定图（由助手基于角色资料生成，策划阶段没有定妆照）；镜头关联设定，分镜记录生成时的设定版本，设定更新后提示分镜过时（owner 2026-10-15）。
- **正文编辑器**：所见即所得，存储仍是 Markdown 子集（owner 2026-10-15）。
- **退出路径**：文档回收站与彻底删除。
- **助手面板**：编辑视图里嵌入画布的同一个助手面板与会话，不另做章节级 AI；章节、镜头、参考图和选中文字上的「请助手修改」只起草消息，带上这一处（含摘录或图号）的标签；画布面板与编辑视图共用一份面板状态，打开策划不切换会话；文档按画布记住工作会话，从编辑视图发消息默认带策划类型对应的 Skill（owner 2026-10-15）。

- **协作审核**（2026-10-15 交互走查后加入）：助手直接写入，摄影师事后审核，不设待批准的建议层。「看改动」在原位显示自确认以来的差异；每轮写入后对话里给出改动清单，逐处对照「本轮之前 → 现在」，确认或恢复这一处；冲突时可以编辑出合并结果。
- **镜头表体验**：完成度分开显示已规划数与可用分镜图数；有一屏比较整组分镜的紧凑总览；「补齐镜头方案」与「生成分镜图」分成两个入口，后者先选范围和风格。

范围外：PDF 导出（owner 2026-10-15：目前报告只给摄影师看，将来可能导出 PDF；本期的文档结构要能支撑以后导出）、发布到订单、现场模式、分享给客户、复制为新方案、摄影师自定义模板。

## 当前基础

2026-10-15 静态核对的代码基础，开工时复测：

- `creative_documents` 只有 6 列：id、账号、`type_key`、标题、`content_revision_id`、`revision`（迁移 0040）。正文只能是一条 `text` 内容修订，没有章节结构。
- 创建（`CreateInternalDocument`）和放上画布（`ReferenceInternalDocument`）只在集成测试夹具里注册，生产没有入口。生产只开放了只读的 `GET /documents/:id`。
- 前端 `DocumentView.tsx` 能只读地最大化显示文档；`internal.document` 在节点定义里 `CreationSupported: false`，不在创建菜单。
- 节点引用文档、删节点不删文档的关系已经由夹具验证过。
- 旧 `shootplanning`（迁移 0016–0029）的 `CreativeBrief`、`Shot` 字段可以借鉴；它的媒体走 `planningmedia`，与创意空间的内容修订不通，不直接复用。

## 依赖与设计前置

无硬依赖。[V6-081](V6-081.md) 依赖本条。

design 时需要定：

- **文档内容的形状**：新增结构化内容类型 `plan`，还是 Markdown 加约定。建议结构化：节点摘要、助手按章节修改、将来的 PDF 导出都要按章节和镜头读取。
- **章节清单**：与截图 SOP 逐项对应，确定每章的字段（自由文本还是结构化）与章节状态（空 / 草稿 / 已确认）。
- **镜头字段**：在旧 `Shot` 基础上加交付阵列位置、分镜引用、参考引用。
- **节点类型**：命名（如 `photo.shoot_plan`）与在节点定义目录中的位置，摄影业务扩展不进 `core.*`。
- **撤销边界**：画布撤销只管节点的增删移动；文档编辑走文档自己的版本，不进画布撤销栈。需要说明两者同时发生时的表现。
- **并发**：摄影师在编辑视图里改的同时助手按章节写入，冲突时谁让谁、界面怎么提示。
- **找回**：删掉最后一个策划节点后，文档从哪里找回（如「引用已有策划」放回画布）。本期做不做文档删除。

## 验收标准

- [ ] **AC-01**：摄影师能在画布上新建空白策划，助手也能创建策划；节点显示摘要，双击最大化进入编辑视图，关闭后回到原画布位置。
- [ ] **AC-02**：编辑视图按固定章节展示和编辑；空章节可以留空；每章状态可见。
- [ ] **AC-03**：镜头表按 2+4+3 交付阵列分组，每个镜头可引用分镜图和参考图；删除画布上的对应图片节点后，策划里的图仍然可见。
- [ ] **AC-04**：每次保存形成新修订，可以查看并恢复旧版本；摄影师与助手的修改在同一条版本链上，版本冲突时提示，不静默覆盖。
- [ ] **AC-05**：助手能读取策划全文或指定章节、按章节修改；修改后节点摘要和打开中的编辑视图随之更新。
- [ ] **AC-06**：删除策划节点不删除文档，且可撤销；所有读写限定在账号范围内。
- [ ] **AC-08**：可以维护人设与场景设定（多视角图、确认）；镜头能关联设定；设定更新或删除后，基于旧设定的分镜显示「设定已更新」。
- [ ] **AC-07**：策划可移入回收站、恢复、彻底删除；彻底删除后它独占的图片可被回收。
- [ ] **AC-10**：「确认后有修改」的章节和设定点「看改动」时，在原位显示自确认以来的差异（文字、图片、关键字段），可直接重新确认或恢复到确认时的内容；助手一轮写入多处后，对话里列出本轮改动，每处可跳转查看「本轮之前 → 现在」并确认或恢复这一处。
- [ ] **AC-11**：冲突时除整份择一外，可以编辑出合并后的最终内容并逐张决定参考图去留；断网时关掉再打开策划，看到的是本机未保存的内容，顶栏如实显示未保存。
- [ ] **AC-12**：可以选中正文或镜头字段里的一段文字、或某张参考图，请助手只改那一处；镜头表分开显示已规划数与可用分镜图数，有紧凑总览，「补齐镜头方案」与「生成分镜图」是两个入口，后者先选镜头与风格；空白策划首屏是基本信息与起草入口；窄窗口下目录仍有章节名。
- [ ] **AC-09**：编辑视图里能直接和助手对话，与画布助手面板共用同一份面板状态（当前会话、草稿、运行状态），两边互通：画布上发起的修改在编辑视图里可见，反之亦然；打开或关闭策划不打断当前会话；从章节入口起草的消息带上该单元的标签；画布面板能 `@` 策划节点；面板没有当前会话时，打开策划进入它在这张画布上的工作会话。
