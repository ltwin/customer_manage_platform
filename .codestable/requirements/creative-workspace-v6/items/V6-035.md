## 目标与范围

助手在创作时按需到摄影师的资产库里找素材，用来补充创意：参考过往作品、借用积累的优秀素材快速出方向、取特效素材做合成。找到的素材可以读、可以放上画布、可以连为生成参考；画布节点的结果可以存入资产库。

与 [V6-077](V6-077.md) 分开对待（owner 2026-10-13）：

- 会话内容是本次对话里出现过的东西，找回它是为了接着用，已在对话授权范围内。
- 资产库是摄影师的全部积累，助手主动去翻，属于超出当前消息的外发，需要单独授权。

范围外：整理资产库（改名、打标签、分组、删除）归 [V6-078](V6-078.md)；语义检索、向量索引等知识库能力另行立项，本条是精确检索。

## 当前基础

2026-10-13 核对的代码基础：

- 资产库后端已有完整查询：关键词、类型、分组（含子分组）、标签（全部 / 任一）、评分、主色、画幅、排序与游标分页（`creativelibrary.SearchAssets`），以及分组树、分类与标签列表。
- 关键词只对标题、正文和标签名做 `LIKE` 匹配；没有标题、描述和标签的图片基本搜不到。打标签、写描述由 V6-078 补。
- 助手现有 `read_asset` 只读当前画布节点和本轮引用的素材，看不到资产库。
- `edit_canvas` 的 `add_node` 不能带内容，助手没法把一个素材放上画布。
- 授权记录已预留 `account_library` 模式（「助手自己搜到的库内容可以外发」），但前端从未授予，后端 `coversRun` 也只认 `selected_revisions`。

## 依赖与设计前置

实现与完整验收依赖 [V6-029](V6-029.md)（已完成）。放上画布扩展 [V6-034](V6-034.md) 已交付的 `edit_canvas`。

design 时需要定：

- 授权方式。建议在对话里提供「允许助手查找资产库」开关，打开时授予 `account_library`，首次打开说明会外发什么；不做每次搜索都确认。
- 工具形状。建议 `search_assets`（条件同资产库页，每页有上限，只返回身份与元数据，不带图片）、`read_library`（分组树和「分类 → 标签」，带数量）、`read_asset` 放宽到授权内的资产、`add_node` 支持素材、`save_to_library`。
- 搜索结果接口为以后的语义检索留位置：换检索方式时不改工具契约。

## 验收标准

- [ ] **AC-01**：按关键词、类型、分组、标签、评分、主色、画幅查真实资产，结果带资产 ID 和固定的内容修订 ID。
- [ ] **AC-02**：无匹配如实返回，不伪造素材；分页和单次结果大小有界。
- [ ] **AC-03**：未授权查找资产库时拒绝并说明；授权只在本条定的范围内生效，读内容和图片前仍检查可展示与可外发，搜索不能绕过授权。
- [ ] **AC-04**：找到的素材能放上画布、连为生成参考；画布节点的当前内容能存入指定分组和标签。都走既有命令，可撤销的照常可撤销。
- [ ] **AC-05**：真实模型在创作任务中按需查库、读图并用于后续创作，保留工具调用记录。
- [ ] **AC-06**：资产库不记录、也不展示素材被哪个画布或对话用过（内容归属约定）。

## Design 交付要求

设计按本条范围说明交互、授权、工具契约、边界与异常；涉及 API 和数据时说明版本、幂等、权限及恢复，复用既有模块并列出契约变更。与 V6-077、V6-078 共用的工具（`read_asset`、`read_library`）在本条定义，兄弟条目引用，不重复定义。
