## 验收标准

- [x] **AC-01**：左侧抽屉宽 344、默认收起；工具轨、添加菜单「从资产库添加」、空节点「资产库」、`@`「从资产库添加参考」均可打开；Esc 依次清空关键词、清空多选、关闭抽屉。
- [x] **AC-02**：（2026-10-12 按 PRD §11.3 #15 修订，原「按分组平铺」作废）抽屉与独立资产库页共用浏览区，始终是一张结果网格；窄抽屉用顶部「视图」下拉切换视图与分组（子组缩进紧跟父组），加宽后左侧是资料库树。
- [x] **AC-03**：进组后顶部为面包屑和「N 项」，下面是子组 chip 与保持原比例的两列瀑布流；点面包屑里的父组名回父组，从「视图」下拉或资料库树回「全部」（2026-10-12 修订，原「返回」按钮取消）。分组计数包含子组内容，一项资产可属多个分组。
- [x] **AC-04**：单击选中（2026-10-12 起与独立页一致），⌘/Ctrl 单击或选择勾切换选中，Shift 单击按列表顺序选范围；底部显示「已选 N 项 · 取消 · 放入画布」；库内选中不改变画布选区。
- [x] **AC-05**：整批拖入或「放入画布」以落点或视口中心横排、间距 40，整批一步撤销并选中这些节点；同一资产多次放入不重复上传。（2026-10-07 修订：owner 决定节点不记录来源资产，删去原「节点记录来源资产」。）
- [x] **AC-06**：从空节点进入填充模式：标题按类型改为「选择图片」等，只列与节点类型匹配的媒体，点一张即填入（规则同 V6-008 AC-05）；目标节点已有内容时不做任何修改。
- [x] **AC-07**：「存入资产库…」分组选择第一项为「不归类，只存入」，子组缩进并紧跟父组（AL-61）；重复存入只追加归类，toast 区分「已存入 N 项」与「已归入」，无内容节点给出提示。
- [x] **AC-08**：（2026-10-12 按 PRD §11.3 #15 修订）分组菜单在加宽抽屉的资料库树里右键打开（与独立页同一组件），含重命名/新建子分组（最多两层）/删除；视图（含「未归类」）没有分组菜单。
- [x] **AC-09**：上传到资产库只写入资产库，不在画布上新建节点（AL-67）；批量上传逐项显示进度，失败项可重试。
