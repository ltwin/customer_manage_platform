## 验收标准

- [x] **AC-01**：缩放为 10%–400%，指针缩放与屏幕中心 ⌘± 的 1.2 倍行为正确。
- [x] **AC-02**：适应画布包含标题区，避开已打开面板，限制 20%–110%。
- [x] **AC-03**：视口按账号/画布恢复；非法值回退适应；视口变化不进撤销栈。
- [x] **AC-04**：中键拖动、平移工具下左键拖动、未选中时按住 Space、触控板/滚轮滚动四种平移均可用；选中单个有内容节点时 Space 交给全屏预览；滚轮等视口变化关闭当前菜单。
