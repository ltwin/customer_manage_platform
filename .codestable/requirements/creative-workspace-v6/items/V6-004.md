## 验收标准

- [x] **AC-01**：只有单选普通节点显示缩放入口，组不能手动缩放。
- [x] **AC-02**：图片/视频等比；文本/链接/音频自由缩放；拖动实时显示尺寸。
- [x] **AC-03**：一次调整一次撤销，尺寸随画布保存，刷新后保持。
- [x] **AC-04**：前后端采用相同尺寸约束，越界有明确处理。
- [ ] **AC-05**：图片/视频有内容后保持当前宽度（默认 300 或手动值），高度跟随当前显示内容的真实宽高比；生成、上传、填充、切换预览版本后都更新，尺寸未读到时保持原高度；空媒体改比例 chip 时按当前宽度重算高度。
