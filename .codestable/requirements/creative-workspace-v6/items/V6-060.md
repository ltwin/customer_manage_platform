范围外：音频节点卡片由 V6-010；链接节点卡片由 V6-009。

以下是 2026-10-05 的分析依据，只取与本条相关部分；开工时复核，不将同一 GAP 内其他子需求一并带入。

- [x] **AC-01**：类型分段全部 / 图片 / 视频 / 音频 / 文字 / 链接均可筛选，结果与类型一致。
- [ ] **AC-02**：视频卡片显示封面，音频卡片显示波形（或经走查确认的等效形态），链接卡片显示域名。
