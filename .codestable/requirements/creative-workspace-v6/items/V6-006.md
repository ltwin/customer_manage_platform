## 验收标准

- [x] **AC-01**：工具轨、空白双击/右键、端口入口打开同一菜单；从端口进入时标题为「生成下游节点」或「添加上游参考」，从文本输出端口进入时「图片」项附「以上游文本为提示词」。
- [x] **AC-02**：新建后只选中新节点：新文本立即编辑，新图片/视频把焦点交给生成输入框；新节点不自动加入所在位置的组。
- [x] **AC-03**：T/I/O 在屏幕中心创建，输入聚焦或按下修饰键时不触发；A/L 复用同一机制，分别在 V6-010、V6-009 验收。
- [x] **AC-04**：双击按位置区分：标题重命名、文本编辑、有内容媒体全屏、空媒体聚焦生成输入（不启动上传或自动生成）、空白处打开添加菜单。
