## 目标与范围

素材评分采用五星制，最小单位半颗星。可以筛选、排序、批量评分，也可以作为智能分组的条件。

范围外：智能分组条件的存储由 V6-072 负责。

## 当前基础

2026-10-11 拆分时复核的代码基础；开工时再核对一次。

- 资产没有评分字段；排序只有 recent / oldest / name。

## 依赖与设计前置

后端补以下能力：评分取值 0.5–5、步长 0.5，未评分存为空值，不使用 0；清除评分即写回空值，按评分筛选、按评分排序，批量评分。批量评分沿用现有资产批量操作（`CreativeAssetBatchPayload`）的幂等与版本规则。

依赖项尚未完成时可以做设计；共享接口与语义必须对齐，不能把依赖未就绪写成验收通过。

## 验收标准

- [x] **AC-01**：五星制，最小单位 0.5：点星星左半边是半星，点右半边是整星；再点一次当前分数则清零；悬停时预览；方向键每次 ±0.5。
- [x] **AC-02**：选中素材后按数字键 1–5 打整星，按 0 清除；多选时批量评分，可以在 toast 里撤销。
- [x] **AC-03**：检查器、批量条、右键菜单和查看浮窗里都可以改分；卡片上的星级只读；星星用白色。
- [x] **AC-04**：筛选项有「5 星 / 4.5 星以上 / 4 星以上 / 3 星以上 / 未评分」，「未评分」就是评分为空；可以按评分排序（未评分排在最后），同分时按添加时间排；筛选和排序都在服务端执行，跨分页结果正确。
- [x] **AC-05**：评分写入有版本校验，并发冲突按现有资产 revision 规则处理；跨账号隔离。
