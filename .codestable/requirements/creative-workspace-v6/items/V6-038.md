# V6-038 · 本轮改动归属与保留人工修改的撤销

## 目标与范围

将一次运行的多个真实画布 change 聚合为一次可撤销操作，并提供改动卡。

范围外：不扩展到本条未列出的相邻能力。

以下是 2026-10-05 的分析依据，只取与本条相关部分；开工时复核，不将同一 GAP 内其他子需求一并带入。

- **GAP-28**：普通画布 change 撤销已有，但没有 Agent run 与多次 change 聚合、改动卡和保留人工修改的部分撤销流程。

## 验收标准

- [ ] **AC-01**：汇总新增节点/连线/提示词/组织变化与费用，列出生成结果缩略图，提供「在画布上查看」与「撤销本轮」；中途失败/停止也汇总。
- [ ] **AC-02**：撤销本轮与 ⌘Z 同一效果，一轮一步，其他人工编辑不被回滚。
- [ ] **AC-03**：内容/标题/分组冲突先列出并确认，跳过冲突节点，其他部分正常撤销；单纯位置变化不算该冲突。
- [ ] **AC-04**：重复撤销/回执恢复幂等，记录已撤销；撤销删除本轮新建节点（含组）及相关连线、恢复改写的提示词和已有节点的位置与分组；toast 说明已消耗点数不退回。
- [ ] **AC-05**：先用真实画布命令形成不同 run 的测试改动，证明聚合机制，再接模型工具。
