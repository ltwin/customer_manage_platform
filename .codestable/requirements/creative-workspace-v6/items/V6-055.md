## 验收标准

- [x] **AC-01**：缩放条撤销/重做栈为空时置灰；点击百分比回到 100%，屏幕中心对应的画布点保持不动。
- [x] **AC-02**：单击选中；Shift/⌘/Ctrl 单击切换；单击多选集合中的节点不打散多选；单击空白清空；选中节点与选中连线互斥。
- [x] **AC-03**：组只能点击标题栏选中；⌘A 全选；Esc 依次关闭浮层、关闭全屏、清空选中。
- [x] **AC-04**：方向键移动 1px、Shift 加方向键移动 10px，输入状态下不生效，每次移动可撤销。
- [x] **AC-05**：拖线到空白松手弹出添加菜单且虚线保留：选择类型后新节点端口落在虚线终点并变实线，取消则虚线消失；只点击端口或键盘 Enter/Space 打开菜单，新节点放在源节点旁 120 处、垂直居中并自动连线。
- [x] **AC-06**：文本节点保留输入端口、可作为下游（CV-36）；拒绝引用环（CV-37）、自环、重复连线、以组为端点，提示说明原因（「指向链接」随 V6-009 链接节点改为只输出一并验收）。
- [x] **AC-07**：选中连线后中点上方「断开连线」浮条、双击连线、Backspace/Delete 三种断线方式均可撤销，双击断开时 toast 提示「⌘Z 可撤销」（断开后 chip 同步由 V6-012 AC-02 验收）。
- [x] **AC-08**：⌫/Delete 删除连线或节点子树并删除相关连线，不弹确认，可撤销。
