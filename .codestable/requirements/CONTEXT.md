# 摄影师私域客户经营系统

面向私域流量（微信 / QQ / Telegram）摄影师的客户经营系统：把客户、订单、档期、套系连成一张网，替代散落在聊天软件、系统日历和备忘录里的客户资产。

## Language

### 经营对象

**客户（Customer）**:
与摄影师建立过联系、可能产生订单的个人。一个客户可挂多个社交身份。
_Avoid_: 粉丝、好友、用户

**社交身份（Social Identity）**:
客户在某个社交平台（微信 / QQ / Telegram 等）上的账号。多个社交身份可归属同一客户，是"多平台身份合并"的载体。
_Avoid_: 联系方式、社媒账号

**渠道（Channel）**:
客户的获客来源分类（小红书 / 抖音 / 微博 / 客户介绍 / 其他），建档时标记。注意与「平台」区分：平台指社交身份所在的 IM（微信 / QQ / Telegram），渠道指客户从哪里被吸引来。
_Avoid_: 来源、获客平台

**线索（Lead）**:
已建档但尚无成交订单（无 delivered / closed 订单）的客户。不是独立实体，是客户的一种状态视图——咨询即建档，成交后自然脱离线索范畴。
_Avoid_: 潜客、意向客户

**客户头像（Customer Avatar）**:
客户档案上的可选视觉标识；每个客户最多一个当前头像，用于列表、详情与客户选择面辅助识别。未设置或读取失败时以昵称首字（首个 Unicode grapheme）色块代替。
_Avoid_: 作品、相册、拍摄回顾、交付照片、原图、头像文件（勿与业务 pointer 混称）

### 账号与认证

**账号（Account）**:
系统使用者的稳定身份与 CRM 数据归属单位；一个账号代表一个可独立认证和隔离访问的经营空间。
_Avoid_: 租户、用户、登录身份

**登录身份（Account Identity）**:
可验证且全局唯一地指向某个账号的外部登录标识；首期为邮箱，后续手机号作为新的 identity kind 接入。
_Avoid_: 账号、邮箱字段、客户社交身份、联系方式

**密码凭证（Password Credential）**:
归属于账号、用于密码认证的受保护材料，与登录身份及账号实体分别建模；该术语不指用户输入的原始密码。
_Avoid_: 登录身份、密码明文、账号

**认证动作令牌（Auth Action Token）**:
只服务于一种认证动作、具有有效期且只能成功消费一次的持有者证明，例如邮箱验证、密码重置或旧账号认领。
_Avoid_: Access Token、Refresh Token、验证码

**刷新会话族（Refresh Session Family）**:
从一次设备登录开始、由连续轮换的 refresh generation 组成，并共享绝对生命周期与撤销边界的一组服务端会话记录。
_Avoid_: Access Token、Cookie Session、设备账号

**旧账号认领（Legacy Account Claim）**:
为既有 seed 账号绑定并验证 owner 登录身份、同时保留原 `account_id` 与全部 CRM 数据归属的受信迁移过程。
_Avoid_: 新账号导入、租户搬迁、全库数据迁移、公开注册

### 交易与交付

**订单（Order）**:
一次拍摄服务的完整记录，关联客户与套系，携带状态（咨询 / 定档 / 已拍摄 / 已选片 / 精修中 / 已交付 / 完结 / 取消）、金额事实（已收现金 / 待收尾款 / 收款时刻）与定金、尾款收讫标记、应交付日，以及下单时固化的归因快照。
_Avoid_: 约单、预约记录

**已收现金（amount_paid）**:
一笔订单实际已收到的款项金额，与价格、待收尾款共同构成订单金额事实；标记收讫而未显式给金额时按推定取结清金额，不降低既有值。
_Avoid_: 定金（deposit_paid 是布尔标记）、营收（已确认收入按 delivered_at 落窗口径）

**待收尾款（outstanding_amount）**:
订单尚未收清的余额部分；未定价订单为空且不计入待收合计，已收讫订单恒为 0。
_Avoid_: 尾款收讫标记（balance_paid 是布尔）、欠款

**在途（Pipeline）**:
已定档进入执行链（定档 / 已拍摄 / 已选片 / 精修中）但尚未交付确认的收入承诺；已交付未结清归待收段、不属在途。
_Avoid_: 进行中订单的泛称、待收

**归因快照（Attribution Snapshot）**:
订单创建时固化的客户渠道与套系拍摄类型；此后客户渠道或套系类型变更、客户合并都不改历史订单归因。
_Avoid_: 客户当前渠道的动态读取

**应交付日（delivery_due_at）**:
拍摄后承诺交片的日期（仅有日期、无时刻），由账号级 SLA 默认天数自拍摄日派生、可按订单覆盖；修改 SLA 默认值不重写历史订单。
_Avoid_: 交付完成日（delivered_at 是实际交付时刻）

**套系（Package）**:
预定义的拍摄服务商品：拍摄类型（写真 / cosplay 等）、定价方式（按时间 / 按张）、交付参数（张数、时长、底片数量范围、精修张数）。
_Avoid_: 套餐、价目、产品

**档期（Schedule Slot）**:
日历上一段半开的占用时间区间，可跨账号本地自然日。类型为拍摄、预留或个人占用：拍摄档期关联且只关联一笔订单，预留和个人占用不关联订单。
_Avoid_: 日程、计划

### 创作策划

**拍摄策划（Shoot Plan）**:
一次创作型拍摄从创作意图、镜头、拍前准备到现场执行的独立方案；它可以不关联客户、订单或档期。
_Avoid_: 档期计划、日程、拍摄订单

**创作 brief（Creative Brief）**:
拍摄策划中对作品、角色、主题、情绪和视觉关键词的创作意图描述，不包含价格、成本或经营预估。
_Avoid_: 报价说明、经营草稿

**镜头（Shot）**:
拍摄策划中具有稳定身份和明确顺序的现场执行单元；一条镜头不等同于一张最终照片。
_Avoid_: 照片、成片

**准备项（Readiness Item）**:
拍摄前需要核对的策划级事实，可以关联多个镜头；它不等同于提醒、客户认领或现场缺失事件。
_Avoid_: 提醒、待办、认领项

**执行会话（Run Mode Session）**:
摄影师进入独立现场执行模式时形成的服务端事实，记录该次进入及其现场判定上下文。
_Avoid_: 拍摄档期、在线状态

**执行结果事件（Shot Execution Event）**:
镜头被记录为已拍、跳过或清除的不可变历史事实；镜头当前结果由有效事件序列投影得到。
_Avoid_: 可编辑结果行、完成勾选

**误记作废（Shot Execution Event Void）**:
指向一条执行结果事件的不可变纠错事实；它保留原事件，并使当前结果按剩余有效事件重新投影。
_Avoid_: 删除执行记录、撤回作废

**完成快照（Plan Finalization Snapshot）**:
拍摄策划每次完成时冻结的当前镜头、有效结果引用、准备缺失引用和事实版本集合；重新打开再完成会产生新快照。
_Avoid_: 当前策划副本、可变完成记录

### 经营配置

**设置（Settings）**:
归属于账号的业务配置集合，包含账号时区、提醒规则参数、摘要小时与触达绑定标识。它属于业务数据，不是部署环境变量。
_Avoid_: 系统配置、平台配置、运行配置

### 经营动作

**提醒（Reminder）**:
系统按客户与订单数据主动生成、供摄影师处理的经营事件，如客户生日、拍后回访、流失预警；也可手工创建自定义提醒。当前由提醒页和客户详情管理，Telegram Bot 摘要与 dashboard 今日待办属于后续消费能力。
_Avoid_: 通知、待办

**流失预警（Churn Alert）**:
客户超过阈值时长未产生新订单时触发的提醒。阈值按拍摄类型可配置。

**转介绍（Referral）**:
一个客户介绍另一个客户成交的关系记录，用于识别高价值节点客户。
_Avoid_: 拉新、裂变
