# 摄影师私域客户经营系统

面向私域流量（微信 / QQ / Telegram）摄影师的客户经营系统：把客户、订单、档期、套系连成一张网，替代散落在聊天软件、系统日历和备忘录里的客户资产。

## Language

### 经营对象

**客户（Customer）**:
与摄影师建立过联系、可能产生订单的个人。一个客户可挂多个社交身份。
_Avoid_: 粉丝、好友、用户

**社交身份（Social Identity）**:
客户在某个社交平台（微信 / QQ / Telegram 等）上的账号。多个社交身份可归属同一客户，是"多平台身份合并"的载体。
_Avoid_: 联系方式、社媒账号

**账号（Account）**:
系统使用者（摄影师）的身份与数据归属单位。所有业务数据挂在某个账号下。首版单账号运行。
_Avoid_: 租户、用户

**渠道（Channel）**:
客户的获客来源分类（小红书 / 抖音 / 微博 / 客户介绍 / 其他），建档时标记。注意与「平台」区分：平台指社交身份所在的 IM（微信 / QQ / Telegram），渠道指客户从哪里被吸引来。
_Avoid_: 来源、获客平台

**线索（Lead）**:
已建档但尚无成交订单（无 delivered / closed 订单）的客户。不是独立实体，是客户的一种状态视图——咨询即建档，成交后自然脱离线索范畴。
_Avoid_: 潜客、意向客户

### 交易与交付

**订单（Order）**:
一次拍摄服务的完整记录，关联客户与套系，携带状态（咨询 / 定档 / 已拍摄 / 已选片 / 已交付等）与定金、尾款收讫标记。
_Avoid_: 约单、预约记录

**套系（Package）**:
预定义的拍摄服务商品：拍摄类型（写真 / cosplay 等）、定价方式（按时间 / 按张）、交付参数（张数、时长、底片数量范围、精修张数）。
_Avoid_: 套餐、价目、产品

**档期（Schedule Slot）**:
日历上被订单占用或预留的时间段，关联到具体订单（从而关联客户与套系）。
_Avoid_: 日程、计划

### 经营动作

**提醒（Reminder）**:
系统主动推送给摄影师的待办事件，如客户生日、拍后回访、流失预警。触达渠道为 Telegram Bot 与 dashboard 今日待办。
_Avoid_: 通知、待办

**流失预警（Churn Alert）**:
客户超过阈值时长未产生新订单时触发的提醒。阈值按拍摄类型可配置。

**转介绍（Referral）**:
一个客户介绍另一个客户成交的关系记录，用于识别高价值节点客户。
_Avoid_: 拉新、裂变
