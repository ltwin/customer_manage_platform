# 资产库浏览与入库基线回归验收记录

## 1. 范围与结论

[V6-057](../../requirements/creative-workspace-v6/items/V6-057.md) 是验证项，对应 PRD 中 AL-01/05/06/07/20/21/22/51/61/62/64/67 这几个差距分析没有列为 GAP 的编号。

结论：9 条 AC 全部满足（AC-05 拆成两个检查，共 10 个），业务代码不需要修改。本条只新增一个浏览器回归脚本，另有一项不属于本条范围的文案问题已移交 V6-045。

## 2. 验收方法

新增 `frontend/scripts/creative-library-baseline.e2e.mjs`：
- 全量 mock API，每条 AC 使用新的 browser context。
- 上传流程按真实接口顺序 mock：创建会话、分片授权、分片 PUT、完成、轮询到 ready。第一次创建返回 503，用来验证失败后重试。
- AC-05 的整批撤销在离线状态下验证，这时改动留在本机，⌘Z 直接取消。
- `ONLY=AC-0x` 只跑指定 AC，`DEBUG=1` 打印完整的 Playwright 调用日志。

首轮有 4 个检查失败，逐一排查后都是测试写法问题，业务代码本身符合要求：
- 进组入口要先悬停段标题才会出现「查看全部」。
- 底栏取消按钮的名称是「取消选择」。
- 选中节点后出现的生成输入框挡住了拖放落点和点击位置。
- 填充模式下每个分组段只显示前几格，测试点了不在可见范围内的资产。

修正测试后连续两次 10/10 通过。

## 3. 与 PRD 文字的差异（不算缺陷）

- **底栏多两个批量动作**：底栏是「已选 N 项 · 整理 · 移入回收站 · 取消选择（图标）· 放入画布」。「整理」和「移入回收站」来自基础需求 LIB-03/05 的批量能力。PRD AL-20 要求的计数、取消、放入画布三项都在，所以只验这三项。
- **无内容节点的提示方式**：单个无内容节点的右键菜单和工具条直接不提供「存入个人资产库」；把无内容节点拖进资产库时，会提示「这些节点还没有内容，无法存入资产库」。PRD AL-62 要求的是「没有内容的节点给出提示」，现在的做法是不提供入口加上拖入时提示，没有误存的可能，判定为满足。
- **入口名称**：存入资产库的入口叫「存入个人资产库」，弹出的是对话框，里面用下拉框选择分组。PRD 写的是「存入资产库…」并弹出分组选择。行为一致，名称不同，不影响验收。
