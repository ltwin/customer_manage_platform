## creative/scene: ADD 实时 GI 的屏幕外反射

渲染器为实时 GI 时，在支持的 WebGPU 设备上，镜面、金属和光滑表面除了映出画面里看得到的物体，也映出画面外和被挡住的物体，例如摄像机背后的家具和墙：屏幕空间反射没找到的方向，改为对整个场景发光线，命中的表面按它自己的材质和灯光着色。被反射的物体离开画面时，反射不变暗、不消失，屏幕边缘也没有接缝。粗糙表面在视口里只补较光滑的部分（粗糙度 0.5 以下），导出时全部补上。间接光（物体之间的反弹光）仍只计算画面里可见的表面。

打开场景后，屏幕外的反射在后台准备，视口不等待：准备好之前只画屏幕上找得到的反射，准备好后自动接上；导出和助手的回看会等它准备好再开始画，同一场景两次导出完全相同。兼容模式、设备不支持或场景太大时，实时 GI 照常可用，只是不画屏幕外的反射，渲染选项卡说明原因；场景较大时，屏幕外的反射改用简化几何。这些都只取决于本机，不改写场景。

### Scenario: 镜面映出摄像机背后的物体
- GIVEN 光滑地板上放着镜面柜和金属球，摄像机背后有红、绿、黄三个方块，渲染器为实时 GI
- WHEN 切到最终渲染，或导出材质光照
- THEN 镜面柜和金属球里映出背后的三个方块和地板

### Scenario: 物体离开画面时反射还在
- GIVEN 金属球在光滑地板上的倒影在画面里
- WHEN 摄像机下压，让金属球从画面上沿移出
- THEN 地板上仍是球的倒影，亮度几乎不变，屏幕边缘没有接缝

### Scenario: 打开场景时先画屏幕空间
- GIVEN 一个面数很多、第一次在这台电脑上打开的场景，渲染器为实时 GI
- WHEN 打开场景并切到最终渲染
- THEN 视口立即可以操作，渲染选项卡显示「正在准备屏幕外的反射」；准备好后提示消失，反射里出现画面外的物体，期间编辑不卡顿；第二次打开时很快就准备好

### Scenario: 导出等准备好再画
- GIVEN 屏幕外的反射还在准备
- WHEN 导出材质光照，或助手回看材质光照
- THEN 导出等准备好再开始画，导出图里有屏幕外的反射；等了 15 秒仍没准备好时，这张图失败并提示「屏幕外的反射还在准备，请稍后重试」，画布上没有半成品

### Scenario: 编辑后反射跟上
- GIVEN 镜子里映着摄像机背后的一把椅子
- WHEN 拖动椅子、换它的材质，或删除它
- THEN 镜子里的椅子随之移动、变色或消失

### Scenario: 兼容模式与设备不支持
- GIVEN 渲染后端是兼容模式，或当前 WebGPU 设备不满足要求
- WHEN 渲染器为实时 GI
- THEN 画面与只有屏幕空间反射时相同；渲染选项卡在「渲染后端」旁说明「兼容模式：未绘制屏幕外的反射」或「当前设备不支持屏幕外的反射」，没有技术错误信息

### Scenario: 场景较大与过大
- GIVEN 渲染器为实时 GI
- WHEN 场景的几何多到本机装不下完整的数据
- THEN 屏幕外的反射改用简化几何，渲染选项卡提示「场景较大：屏幕外的反射使用简化几何」；简化几何也装不下时不画屏幕外的反射，提示「场景过大：未绘制屏幕外的反射」；编辑和导出都照常

## creative/scene: MODIFY 渲染器与输出分辨率

属性区参照 Blender 分成「渲染」「环境」「物件」三个选项卡。「渲染」里可以选渲染器和输出分辨率，调曝光，并看到当前的渲染后端。曝光在程序化天空和纯色天空下是曝光补偿，在物理天空下是默认摄像机的曝光（只用于视口的自由视角和助手的临时视点）：自动或手动，自动时调补偿，手动时调默认曝光值（EV100）。渲染器有工作台、实时 GI，以及还不能选的「路径追踪 · 规划中」：工作台是标准的光栅化渲染；实时 GI 在它之上加入物体之间的间接光反弹、反射和接触阴影：间接光只计算画面里可见的表面，反射在支持的 WebGPU 设备上还包括画面外的物体（见「实时 GI 的屏幕外反射」）。渲染器决定编辑器的最终渲染、助手的材质光照回看和材质光照导出的画面；白模、线框、材质预览和线稿总按工作台画，正交视图也按工作台显示。灯光图标、摄像机视锥、空物体等辅助对象在视口里照常显示，但不参与光照：不遮挡、不压暗周围。输出分辨率只决定导出图的长边。这些都是场景的设置，静默保存，可以撤销，其他标签页和助手看到的一样。

### Scenario: 打开渲染选项卡
- GIVEN 摄影师在场景编辑视图里
- WHEN 点属性区的「渲染」
- THEN 看到渲染器（工作台、实时 GI、灰掉的「路径追踪 · 规划中」）、输出分辨率（1K、2K、4K、8K，注明长边像素）、曝光和渲染后端（「WebGPU」或「兼容模式」）；渲染器是实时 GI 且本机没有画屏幕外的反射时，渲染后端旁说明原因；天空是物理天空时，曝光一栏是默认摄像机的曝光：自动（缺省）显示补偿，手动显示「默认曝光（EV100）」并列出常见场景的参考值；否则是曝光补偿

### Scenario: 选中物件时切到物件属性
- GIVEN 摄影师停在「渲染」选项卡
- WHEN 在视口里选中一个物件，再取消选中
- THEN 选中时属性区切到「物件」，取消后回到「渲染」

### Scenario: 换成实时 GI
- GIVEN 一个红墙、白地面、金属球的房间，渲染器是工作台，摄影师在最终渲染模式下
- WHEN 把渲染器换成实时 GI
- THEN 停止操作后画面逐渐变干净然后停止刷新；靠近红墙的白地面被染红，金属球和光滑地板映出房间里的其他物体；白模模式下画面不变；Cmd+Z 回到工作台；另一个标签页同步显示

### Scenario: 正交视图按工作台显示
- GIVEN 渲染器是实时 GI
- WHEN 切到正交视图
- THEN 画面按工作台显示，视口角落提示「正交视图按工作台显示」；回到透视视图后恢复实时 GI

### Scenario: 按 4K 导出
- GIVEN 场景里有一台 3:2 的摄像机，输出分辨率选 4K
- WHEN 导出白模、线稿和材质光照
- THEN 三张图长边都是 4096 px、短边 2731 px；导出对话框写明长边 4096

### Scenario: 设备画不了所选分辨率
- GIVEN 输出分辨率选 8K，当前设备的显存不够
- WHEN 导出
- THEN 导出失败并说明当前设备可能画不了这个分辨率、可以换低一档，画布上没有半成品；不会悄悄按更低的分辨率导出

### Scenario: 请助手换渲染器并按 4K 导出
- GIVEN 摄影师在助手面板里
- WHEN 请助手「换成实时 GI，按 4K 导出」
- THEN 助手把渲染器和输出分辨率改掉，回看一次实时 GI 的画面，再导出长边 4096 的图；两项修改出现在这一轮的改动清单里

### Scenario: 路径追踪还不能选
- GIVEN 摄影师或助手想用路径追踪
- WHEN 打开渲染器下拉，或助手写入路径追踪
- THEN 下拉里这一项不能选；助手的写入被拒绝并说明还不支持

## creative/scene: MODIFY 渲染设备不可用与丢失

编辑器、助手的截图和导出、缩略图和资产预览都用 WebGPU 渲染；浏览器拿不到 WebGPU 时自动改用兼容模式（WebGL2），编辑和导出照常可用，画面一致，只有实时 GI 不画屏幕外的反射（见「实时 GI 的屏幕外反射」）。渲染设备在使用中丢失（显卡驱动重置、GPU 进程崩溃等）时，编辑视图自动恢复；助手的任务不报失败，由页面重新领取后完成。

### Scenario: 没有 WebGPU 时照常使用
- GIVEN 浏览器拿不到 WebGPU，但支持 WebGL2
- WHEN 摄影师打开场景编辑视图，编辑并导出
- THEN 编辑和导出照常完成，导出图与 WebGPU 下的同一张图看不出区别，渲染器为实时 GI 的材质光照图除外：兼容模式下其中没有屏幕外的反射，渲染选项卡有说明；页面不出现技术错误信息

### Scenario: 两种都拿不到
- GIVEN 浏览器既拿不到 WebGPU，也拿不到 WebGL2
- WHEN 摄影师打开场景编辑视图
- THEN 显示「当前浏览器无法显示 3D 场景，请使用最新版 Chrome、Edge 或 Safari」；这个页面不领取助手的场景任务

### Scenario: 编辑时设备丢失
- GIVEN 摄影师在编辑视图里选中了物件，刚做过还没保存完的修改，正在拖动另一个物件
- WHEN 渲染设备丢失
- THEN 视口自动恢复显示场景，视角、选中和已做完的修改都还在（照常保存）；正在拖的那一下被取消，物件回到拖动前的位置；短时间内反复丢失时停止自动恢复，提示刷新页面

### Scenario: 执行助手任务时设备丢失
- GIVEN 本页正在为助手截图或导出
- WHEN 渲染设备丢失
- THEN 任务不报失败，已经画好的图一张都不交出；租约到期后任务重新排队，由一个页面重新领取并完成，助手拿到正常结果

### Scenario: 设备一直恢复不了
- GIVEN 本页执行助手任务时设备丢失，之后一直无法重新建立渲染设备
- WHEN 助手的任务重新排队
- THEN 本页不再领取场景任务，任务由其他能渲染的页面完成；没有这样的页面时，按「没有页面时任务过期」处理

### Scenario: 手动导出时设备丢失
- GIVEN 摄影师在导出分镜
- WHEN 渲染设备丢失
- THEN 导出失败并提示「渲染设备暂时不可用，请重试」，画布上不出现半成品；重试后正常导出
