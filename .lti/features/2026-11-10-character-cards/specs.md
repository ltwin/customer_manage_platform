## creative/library: ADD 角色卡

资产库可以存放角色卡：一个虚构角色的几张参考图（带视角）、一段外貌描述、原始素材，加上所属 IP、作品、版本说明、别名和可选的来源备注。建卡没有版权确认或授权步骤。角色卡和其他资产一样可以分组、打标签、评分、进回收站。修改角色卡会产生新版本。

### Scenario: 从几张图建卡
- GIVEN 资产库里有某角色的三张图片
- WHEN 摄影师多选它们，选「创建角色卡」，填上名字和外貌描述，并给每张图指定视角
- THEN 资产库出现这张角色卡，封面是第一张参考图；查看浮窗里能看到参考图（带视角）和外貌描述；来源字段都可以不填

### Scenario: IP 从候选里选
- GIVEN 摄影师在建卡对话框里
- WHEN 在「所属 IP」里输入「Genshin」并直接保存
- THEN 角色卡归到内置的「原神」下，按「原神」筛选能找到它

### Scenario: 自建 IP 成为候选
- GIVEN 摄影师保存过一张所属 IP 为自己原创系列的角色卡
- WHEN 下次建卡时打开「所属 IP」
- THEN 这个系列出现在候选里，并显示已有几张角色卡

### Scenario: 同名角色靠 IP 和作品区分
- GIVEN 资产库里有两张「阿尔托莉雅」，作品分别是 Fate/stay night 和 Fate/Grand Order，都没填版本说明
- WHEN 摄影师浏览资产库，或在生成节点上选参考
- THEN 两张卡标题相同，但标题下分别显示「Fate · Fate/stay night」「Fate · Fate/Grand Order」

### Scenario: 作品简称也能筛
- GIVEN 同上
- WHEN 摄影师按作品筛选，输入「FGO」或「Fate/Grand Order」
- THEN 都只出现 Fate/Grand Order 那张；输入在多个 IP 下都是作品简称的词时，提示有歧义并列出候选

### Scenario: 内置目录收录了自建 IP 之后
- GIVEN 摄影师用自建 IP「某系列」建过角色卡
- WHEN 之后版本更新，内置目录收录了「某系列」，摄影师再用「某系列」筛选
- THEN 旧卡仍然能筛到

### Scenario: 不能用作生成参考的图
- GIVEN 某张图片不能用作生成参考
- WHEN 摄影师把它放进参考图并保存
- THEN 保存不成功，提示是哪一张；把它放进原始素材则可以保存

### Scenario: 改出新版本
- GIVEN 画布上放着某张角色卡
- WHEN 摄影师在资产库里改了它的外貌描述并保存
- THEN 角色卡变成新版本；画布上的节点仍是原版本，提示有新版本；点「更新」后换成新版本，可以撤销

### Scenario: 两处同时保存
- GIVEN 两个标签页打开着同一张角色卡的同一版本
- WHEN 先后保存
- THEN 后保存的提示冲突、需要重新读取，不覆盖前一次保存

## creative/library: ADD 用角色卡生成

角色卡放进画布后，可以连到生成节点做参考，在提示词里 `@` 它。生成时角色卡展开成它的全部参考图，外貌描述附在提示词后面；摄影师不用逐张连图。

### Scenario: 连一个角色卡节点生成
- GIVEN 画布上有角色卡「芙宁娜」（3 张参考图）和一张场景图，都连到一个生成节点
- WHEN 摄影师写「@芙宁娜 站在 @场景 的台阶上」并生成
- THEN 生成用上了芙宁娜的 3 张参考图和场景图，提示词附了芙宁娜的外貌描述；生成结果的信息里能看到用的是哪张角色卡的哪个版本

### Scenario: 参考图超出上限
- GIVEN 一个生成节点连了三张角色卡，展开后的参考图超过所选模型的上限
- WHEN 摄影师点生成
- THEN 不生成也不扣费，提示上限、展开后的总数和每张角色卡各占几张

### Scenario: 只能做生成参考
- GIVEN 画布上有一个角色卡节点
- WHEN 摄影师把它连到文本节点，或连到生成节点的数据输入
- THEN 连线被拒绝

### Scenario: 删掉角色卡之后
- GIVEN 画布上放着某张角色卡
- WHEN 摄影师在资产库里把它移进回收站或彻底删除
- THEN 画布上的节点照常能用来生成，只是不再提示新版本

### Scenario: 生成结果的溯源不会丢
- GIVEN 用某张角色卡生成过一张图
- WHEN 摄影师删掉角色卡节点、彻底删除角色卡资产，后台随后清理了无人引用的内容
- THEN 那张生成结果仍能显示用的是哪张角色卡的哪个版本，并能读出它的参考图和外貌描述

### Scenario: 提示词里没有 @ 也能用
- GIVEN 角色卡只是连到生成节点，提示词里没有 @ 它
- WHEN 摄影师生成
- THEN 照样带上角色卡的全部参考图和外貌描述

## creative/library: ADD 助手使用角色卡

助手可以按名字、别名、IP、作品找到角色卡，读取它的参考图和外貌描述，把它放到画布上连到生成节点。外部助手经 MCP 用同样的只读工具。

### Scenario: 按名字用角色卡出图
- GIVEN 资产库里有角色卡「芙宁娜 · 常服」
- WHEN 摄影师在对话里说「用芙宁娜的角色卡出一张正面半身」
- THEN 助手找到这张角色卡，放到画布上、连到生成节点并生成，不逐张连它的参考图

### Scenario: 有多张符合时让摄影师选
- GIVEN 资产库里有两张 Fate/Grand Order 的 Saber 角色卡
- WHEN 摄影师说「用 FGO 里的 Saber」
- THEN 助手列出这两张让摄影师选，不自行挑一张

### Scenario: 外部助手拿到全部参考图
- GIVEN 外部助手已经连接
- WHEN 它读取一张有 3 张参考图的角色卡
- THEN 按参考图顺序拿到 3 张图和全部文字；某张图压缩不到可发送的大小时只省略这一张，并说明原因

### Scenario: 内置助手的模型不能看图
- GIVEN 内置助手当前用的模型不能看图，或本次对话没有授权图片预览
- WHEN 它读取一张角色卡
- THEN 只得到文字内容，并被告知参考图因此没有附上
