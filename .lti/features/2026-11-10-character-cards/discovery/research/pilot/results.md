# 参考图一致性小样结果

2026-11-10，24 张均通过现有画布生成并保存为作品版本。两款模型都跑通了原立绘、单图、三图、四图和拼版。每张按发色、瞳色、夹克及口袋、胸针四项各 0–2 分评分。Codex 对隐藏组别和模型的编号图做了一轮目视复核。

| 对照组 | GPT Image 2.5 Sunburst 两次 | Nano Banana 2.1 两次 | 平均（满分 8） |
|---|---|---|---:|
| B 原立绘、正文描述 | 8、8 | 8、8 | 8.00 |
| V1 正面 | 8、7 | 6、8 | 7.25 |
| V3 正侧背分图 | 8、8 | 8、4 | 7.00 |
| V4 增加脸部特写 | 8、8 | 8、8 | 8.00 |
| S1 正侧背拼版 | 8、8 | 8、6 | 7.50 |
| V3 无描述 | 8、8 | 8、8 | 8.00 |

20 张四项均匹配。四张发生局部偏差，分别为多了一枚胸针、发色偏灰且胸袋只剩浅色翻盖、发色偏灰且胸针多了吊链，以及瞳色偏蓝绿同时发色与胸袋变化。基线已达评分上限，小样无法测量原判据要求的 1 分提升。两次重复和单一镜头也无法确定分图与拼版的优劣或外貌描述的稳定增益。

按 owner 确认的范围通过可行性验证并继续实施。保留设计中的 1–4 张参考图、现有视角枚举和「角色设定」段。双人镜头和两人独立盲评未执行。

结果在 [实验画布](http://localhost:5173/creative/canvases/cccv_a8676c74-3d46-4bb7-8c73-0995ff002826) 的「作品版本」中。基线按模型各有独立节点。V1 的版本 1、3 是 Sunburst，版本 2、4 是 Nano Banana。其余各组的版本 1、2 是 Sunburst，版本 3、4 是 Nano Banana。
