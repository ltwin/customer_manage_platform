# Epic: creative-image-editor — 创意空间的分层图像编辑器（类 Photoshop）

永久需求文档：本 Epic 的目标、边界和交付计划。整体方案见 design.md，目标契约见 contracts.md。项目 `.lti/contracts/` 记录当前已交付事实。探索记录见 `discovery/brainstorm.md`，选型证据见 `discovery/research/editor-and-ai-options.md`。

## 目标

拍摄后期有两类像素级工作：人像精修，以及 CG 合成（抠图 → 白模搭景 → 构图 → 精修）。现在这两类工作都要离开平台去 Photoshop 做。创意空间目前只有图片节点的裁切和压缩（V6-076），3D 场景导出的分镜底图也没有地方做后期。

本 Epic 完成后，摄影师和专业创作者可以在创意空间里打通后期全流程：

1. **分层图像文档**：画布上可以新建「图像文档」节点，双击进入全屏编辑器。分层工程可以反复打开，有版本历史，多个标签页之间同步。
   - 从图片节点打开时，以这张图为底层新建文档。
   - 可以从本机、资产库或画布置入图片作为新图层，3D 场景的导出图也能这样进来。
2. **接近 Photoshop 核心能力的编辑**，交互按 Photoshop 的惯例（键位、工具行为、面板结构）：
   - 图层：混合模式、蒙版、剪贴蒙版、图层样式与混合颜色带、锁定、调整图层；新建图层时可以填充中性色。
   - 工具：选区、画笔、加深 / 减淡、调色、变形、滤镜、修复、钢笔、渐变、文字。
3. **AI 能力**：
   - 智能选区：选择主体、点选分割、边缘细化。
   - 生成式填充：画选区并写提示词，用 gpt-image-2.5 局部重绘，结果落成新图层。
4. **画笔资产**：可以导入 Photoshop `.abr` 画笔，存进资产库的新类型「画笔包」，在编辑器里选用。
5. **导出回画布**：
   - 导出的平面图落成画布图片节点，记录来源；文档改了以后，节点提示过时。
   - 从图片节点打开的文档，可以选择把导出写回原节点，作为它的新版本。
6. **创作助手参与**：
   - 读取：看图层结构和预览图。
   - 参数化操作：图层属性、调整图层、用智能选区建蒙版、生成式填充、导出。
   - 用代码作画：助手写绘画代码，在沙箱里执行，生成结构化的笔触指令，由编辑器的画笔引擎画到图层上。

## 范围与非目标

- **范围**（每项归哪个子项见 roadmap.md）：
  - **文档与图层**：
    - 图像文档类型与画布节点、全屏编辑器。
    - 像素图层与图层组；不透明度与填充不透明度；Photoshop 的 27 种混合模式；显示/隐藏、排序、复制、合并、栅格化。
    - 透明度锁定、像素锁定、位置锁定、全部锁定。
    - **新建图层对话框**（Photoshop 的 `Ctrl+Shift+N` / Alt 点新建图层按钮）：名称、颜色标记、模式、不透明度、使用前一图层创建剪贴蒙版。选中有中性色的模式时，可以勾选「填充中性色」，例如柔光、叠加、强光、线性光填 50% 灰。这是中性灰修图的常用起手（owner 2026-10-22）。
    - 置入图片；画布尺寸与裁切。
    - 保存、历史版本、多标签页同步、撤销（只撤销自己的）。
  - **选区与蒙版**：
    - 选区工具：矩形、椭圆、套索、多边形套索、魔棒、快速选择。
    - 选区运算：加、减、交叉、反选、扩展/收缩、羽化。
    - 蒙版：图层蒙版、剪贴蒙版、快速蒙版。
    - 填充：油漆桶、填充命令。
  - **画笔**：
    - 画笔引擎：柔边圆、硬边圆等内置画笔；大小、硬度、不透明度、流量、间距、平滑；压感控制大小和不透明度。
    - 橡皮擦、吸管。
    - **加深 / 减淡工具**：范围（阴影 / 中间调 / 高光）、曝光度、保护色调，用于中性灰修图（owner 2026-10-22）。
    - `.abr` 导入，资产库「画笔包」类型。
  - **调整图层**：曲线、色阶、色相/饱和度、亮度/对比度、色调分离、色彩平衡、可选颜色。可以带蒙版，可以剪贴到下方图层。
  - **钢笔与渐变**：
    - 钢笔路径：绘制、编辑锚点；路径面板；路径转选区、填充路径、描边路径。
    - 渐变工具：线性、径向，渐变编辑器。
  - **文字图层**：点文字和段落文字，横排；字体、字号、颜色、行距、字距、对齐；可以再编辑，可以栅格化。
  - **变形**：自由变换（缩放、旋转、斜切）、透视、扭曲、变形网格、操控变形。
  - **滤镜**：
    - 高斯模糊、高反差保留、USM 锐化、添加杂色。
    - 液化：向前变形、重建、平滑、顺时针旋转扭曲、褶皱、膨胀、冻结/解冻蒙版。
  - **修复**：污点修复画笔、修复画笔、仿制图章。
  - **智能选区**：选择主体、点选/框选分割、边缘细化（选择并遮住的基础能力）。
  - **生成式填充**：选区 + 提示词局部重绘，结果为带蒙版的新图层，按现有积分规则扣费。
  - **图层样式与混合选项**：
    - 图层样式：投影、内阴影、外发光、内发光、描边、颜色叠加。
    - **混合颜色带**：本图层 / 下一图层，灰色与红、绿、蓝通道，按住 Alt 拆分滑块做平滑过渡。这是合成溶图的常用手段（owner 2026-10-22）。
  - **导出**：PNG / JPEG / WebP；落成新图片节点，或写回原图片节点作为新版本；过时提示。
  - **助手**：读取、参数化操作、代码作画；每个能力子项同时交付助手对应的操作。
- **非目标**（显式排除）：
  - **PSD / PSB 读写**：后续再做。图层模型按 PSD 的概念和取值对齐（混合模式、蒙版、剪贴、样式、调整图层），届时不用改模型（owner 2026-10-22）。
  - **高位深与其他色彩模式**：16 / 32 位、CMYK、Lab、非 sRGB 工作空间。首版是 8 位 sRGB，导入时转换到 sRGB（owner 2026-10-22）。
  - **智能对象与智能滤镜**：滤镜和变形直接作用于像素。
  - **矢量形状**：矢量形状图层（矩形、椭圆等形状工具）、矢量蒙版、填充图层（owner 2026-10-22：钢笔首版只做路径）。
  - **通道与竖排**：通道面板、存储选区、色彩范围、竖排文字。
  - **其他修饰工具**：海绵、涂抹、模糊/锐化画笔、历史记录画笔、修补工具、内容识别填充。去除杂物由生成式填充和修复工具承担。
  - **部分图层样式、混合选项和调整**：
    - 图层样式：斜面和浮雕、光泽、渐变叠加、图案叠加。
    - 混合选项：挖空、通道勾选。
    - 调整：自然饱和度、黑白、渐变映射、照片滤镜等。
    - 首版之后按使用反馈再加。
  - **人脸感知液化**、SAM 3 一类的概念文字分割。
  - **服务端渲染**：合成、导出、预览都在浏览器完成，沿用 3D 场景的决定。
  - **使用环境**：移动端和触屏界面；多人实时协同（协同只有摄影师和助手两方，沿用通用文档底座的并发机制）。
  - **扩展能力**：动作、脚本、插件；Camera Raw；视频与时间轴。

## 验收标准

全部子项完成后做整体验收。参考设备、基准文档和性能数值由 I0 确定，经 Epic 修订写入 design「验证与交付」。

- **AC-1 文档与编辑闭环**：
  - **WHEN** 摄影师在画布上新建图像文档，或从图片节点选「在编辑器中精修」，**THEN** 进入全屏编辑器；从图片节点打开时，这张图是底层。
  - **WHEN** 编辑后关闭，在另一个标签页或第二天重新打开，**THEN** 图层、蒙版、调整、文字、路径都和关闭前一致。
  - **WHEN** 打开历史版本列表，**THEN** 能只读预览旧版本，也能恢复为新版本。
- **AC-2 撤销与协同**：
  - **WHEN** 助手和摄影师先后修改同一文档，**THEN** 摄影师的 Cmd+Z 只撤销自己的操作；要撤销的那一步之后，同一图层被助手改过时跳过并提示，不覆盖助手的改动。
  - **WHEN** 摄影师想回退助手的改动，**THEN** 可以在历史版本里恢复，或在对话里让助手撤回。
- **AC-3 图层模型**：
  - **WHEN** 用参考文档逐一检查 27 种混合模式、不透明度与填充不透明度、图层蒙版、剪贴蒙版、透明度锁定、调整图层（含蒙版和剪贴）、图层样式、混合颜色带（含拆分滑块），**THEN** 编辑器显示和导出结果都与 Photoshop 参考图一致，误差在 design 定的阈值内。
- **AC-4 精修工具**：
  - **WHEN** 摄影师按新建图层的快捷键（或 Alt 点新建图层按钮），在对话框里选柔光并勾选「填充中性色」，**THEN** 得到一个填满 50% 灰的柔光图层，画面不变。
  - **WHEN** 在这个图层上用减淡和加深（中间调、低曝光）涂抹，**THEN** 只改变明暗，不改变颜色，效果与 Photoshop 一致。
  - **WHEN** 摄影师用修复画笔、仿制图章、污点修复、液化、高反差保留（锐化和频率分离两种用法）、曲线等完成一张人像精修，**THEN** 每个工具的行为符合 Photoshop 惯例，结果可以导出。
- **AC-5 合成工具**：**WHEN** 摄影师把 3D 场景导出图和人像置入同一文档，依次完成以下步骤，**THEN** 每一步都能在编辑器内完成，生成式填充的结果是带蒙版的新图层，并按积分规则扣费：
  - 用选择主体抠出人物，并做边缘细化；
  - 用自由变换、透视、操控变形调整人物；
  - 用混合模式、混合颜色带和调整图层溶图、匹配光色；
  - 用生成式填充补背景。
- **AC-6 画笔与画笔资产**：
  - **WHEN** 导入一个包含采样笔尖和计算笔尖的 `.abr` 文件，**THEN** 资产库多了一份画笔包，可以分组、打标签、评分、进回收站。
  - **WHEN** 在编辑器的画笔面板中选用包里的画笔作画，**THEN** 笔尖形状、间距、角度、圆度等支持的属性与 Photoshop 一致；不支持的属性在导入时列出，不静默丢弃。
- **AC-7 钢笔、渐变与文字**：
  - **WHEN** 用钢笔勾出主体轮廓转为选区，**THEN** 得到与路径一致的选区，可以羽化后建蒙版。
  - **WHEN** 用渐变工具在蒙版上做过渡，**THEN** 结果符合 Photoshop 惯例。
  - **WHEN** 添加中文和英文文字图层，**THEN** 文字可以再编辑，换设备打开后显示一致。
- **AC-8 导出与过时**：
  - **WHEN** 导出为新节点，**THEN** 画布上多一个图片节点，长宽与文档一致，格式可选。
  - **WHEN** 从图片节点打开的文档选择写回，**THEN** 原节点多一个版本，可以撤销。
  - **WHEN** 文档之后又被修改，**THEN** 导出得到的节点提示「文档已更新」；改动后又改回原样不算过时。
  - **WHEN** 导出超过当前设备或媒体上限，**THEN** 明确失败并说明原因，不悄悄降低分辨率或质量。
- **AC-9 助手**：
  - **WHEN** 摄影师请助手「把背景压暗一点、肤色调暖」，**THEN** 助手读取文档，新建带蒙版的调整图层完成修改。
  - **WHEN** 摄影师请助手「在左上角画几笔光斑」，**THEN** 助手写绘画代码，用指定的画笔（可以是导入的画笔）画到新图层上；保留代码和参数，可以调参数重画。
  - **WHEN** 助手修改文档，**THEN** 摄影师能在本轮改动清单和历史里看到这些改动。
- **AC-10 大图性能**：**WHEN** 在参考设备上编辑 60MP 原片、10 层以上的文档，**THEN** 笔触跟手，图层属性和调整参数的拖动实时预览，打开、保存和导出在 I0 定的目标时间内完成。不满足时不宣称支持该规格。
- **AC-11 端到端样张**（只能由 owner 判断）：**WHEN** 用编辑器分别完成一张人像精修和一张 CG 合成并导出，**THEN** owner 认为这两张图可以不经 Photoshop 交付；保留样张和过程记录。

## 交付路线

见 roadmap.md：14 个串行子项。

1. **I0 穿刺**：验证分块存储与 GPU 合成，对照 PhotoCraft 引擎，定性能指标和存储方案。
2. **I1–I4**：基础编辑器（文档外壳、选区与蒙版、画笔与画笔资产、调整图层）。
3. **I5 助手接入**：读取、参数化操作、代码作画。此后的每个子项同时交付助手对应的操作。
4. **I6–I13**：钢笔与渐变、变形、滤镜与液化、修复、智能选区、生成式填充、文字、图层样式。
