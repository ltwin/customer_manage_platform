## creative/agent-context: ADD 长任务不因自身工具结果超限

内置助手在一次运行里可以连续调用很多工具。本次运行累积的消息超过单次请求上限时，助手先截短较早步骤的工具结果，再整步省略最早的步骤，让运行继续；最近一步、创作者的提交与补充、上下文摘要始终保留。只有最近一步本身放不下时，运行才以「内容超过本次运行的长度上限」结束。

### Scenario: 截短较早的工具结果
- GIVEN 一次运行已调用多次工具，本次运行的消息超过单次请求上限
- WHEN 助手准备下一次调用模型
- THEN 较早步骤的工具结果只保留开头，并提示按来源重新读取；最近一步完整；运行继续

### Scenario: 省略最早的步骤
- GIVEN 截短之后仍超过上限
- WHEN 助手准备下一次调用模型
- THEN 从最早的步骤起整步省略（工具调用与结果一起），模型输入里有一条说明写明省略了几步，并列出每步的工具和结果定位符；运行继续

### Scenario: 取回被省略的结果
- GIVEN 本次运行较早的步骤已被省略
- WHEN 助手需要其中某个结果
- THEN 用说明里的定位符读取原结果，或用 read_history 查看本次运行较早的消息

### Scenario: 最近一步本身超限
- GIVEN 最近一步的工具结果本身就超过单次请求上限
- WHEN 助手准备下一次调用模型
- THEN 运行结束，提示「内容超过本次运行的长度上限」，并说明可以压缩上下文后继续

## creative/agent-context: ADD 压缩覆盖放不下的最近一轮

压缩通常保留最近 2 轮原文。最近的轮次超出单次请求的历史预算时，保留的轮数减少到放得下的数量，放不下的轮次也写进摘要。

### Scenario: 长任务失败后手动压缩
- GIVEN 会话只有一轮，这一轮超出单次请求的历史预算
- WHEN 创作者发 `/compact`
- THEN 生成摘要，覆盖到这一轮的最后一条消息

### Scenario: 长任务失败后继续对话
- GIVEN 上一轮超出单次请求的历史预算
- WHEN 创作者发下一句话
- THEN 先自动压缩，摘要包含上一轮，再回答

### Scenario: 短会话手动压缩
- GIVEN 会话只有一轮，且放得进预算
- WHEN 创作者发 `/compact`
- THEN 提示「暂无可压缩的内容」，不调用模型
