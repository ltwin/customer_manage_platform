## creative/scene: ADD 助手提交局部场景修改

助手可以新增物件并让服务端分配内部身份、默认显示状态和同级顺序。只传部分变换时只改变指定属性。

### Scenario: 省略常用新增字段

- GIVEN 助手已用 read_scene 读到场景的当前修订
- WHEN 助手以这个修订为基线新增物件，省略 ID、顺序、父级及显示状态
- THEN 新增物件按输入顺序追加到根级并返回分配的 ID，物件默认可见且未锁定

### Scenario: 移动单个分镜中的物件

- GIVEN 场景有多个分镜，物件在各分镜里有各自的状态
- WHEN 助手对其中一个分镜提交仅包含位置的变换
- THEN 只更新该分镜的位置，保留其余变换通道和其他分镜的状态

### Scenario: 建模来源错误

- GIVEN 助手已用 read_scene 读到场景的当前修订
- WHEN 助手调用 write_model 时遗漏建模来源或提供互斥来源
- THEN 工具提示需要修正的参数且不创建烘焙任务
