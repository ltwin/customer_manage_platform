# 场景助手参数错误诊断

新建场景用脚本化模型调用真实的场景工具，可以复现八类拒绝。最小输入是省略新增物件的父级或可见性，传非单位旋转、重复同级顺序、把朝向放进摄像机属性、同时给两种朝向、只传部分变换，或不给建模来源。另有首写修订号漏传与手拼 ID 超长两类复现。

新增工具直接接收完整物件。排序值由模型提供，详细场景结果却不返回该值。普通移动解码为完整变换，朝向和分镜另有预处理。建模来源和场景基线在工具 schema 里缺少执行端的约束。入口在 `backend/internal/creativeagent/scene_tools.go`，归并、变换和命令校验分别在 `backend/internal/creativescene/{agent,lookat,agent_shots,ops,model,jobs}.go`。手动编辑器共用下层完整命令，修复限定在助手入口。保持已有的并发冲突和异步烘焙检查。
