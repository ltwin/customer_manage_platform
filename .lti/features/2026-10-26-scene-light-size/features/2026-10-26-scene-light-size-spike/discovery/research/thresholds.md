# 第 10 组：阈值与 U1–U8 的建议

> 状态：owner 2026-10-26 按建议选定，待写回 Epic（任务 5.3）。数据都来自参考设备（`baseline/baseline.md`），出处见各行。

## 阈值

| AC | 建议阈值 | 依据（原型实测） |
|---|---|---|
| AC-1 半影 | ① 宽半影（参考解 ≥ 5 cm）：10%–90% 宽度与参考解相差不超过 20%；② 窄半影（< 5 cm）：不超过该处阴影图 2 个 texel；③ 每块板两条剖面上，阴影系数与参考解的差：均值 ≤ 0.02，最大 ≤ 0.12 | 聚光、点光、平行光、面光源，宽半影的偏差都在 −19% 到 +11% 之间（平行光 10° 最大）；0.5 m 板偏宽 1–2 cm，等于 1024 图上约 1 个 texel；剖面均值 ≤ 0.016，最大 ≤ 0.08，叠放遮挡时最大 0.12（`soft-shadow-candidates.md`） |
| AC-3 包裹 | 明暗交界线（降到峰值 1%）与参考解相差不超过 2° | Snyder 在半径 0.5 m、1 m 时都在 1° 以内（`sphere-horizon-sheen.md`） |
| AC-4 高光 | 与参考解比，高光板上：总能量偏差 ≤ 10%，高光面积（半峰值以上）偏差 ≤ 20%，峰值偏差 ≤ 25% | 混合模型，半径 0.1–1 m：能量 0.92–0.99，面积 0.97–1.15，峰值 −3% 到 −20%（`integration.md`「高光模型」）。Epic 原文写的是「与点光源相比」，但大光源下参考解本身就比点光源少约 30% 的能量，所以改为与参考解比 |
| AC-5 面光源 | ① 不带阴影：墙面漫反射与高光板的能量与参考解相差不超过 5%；② 阴影：全图阴影系数误差均值 ≤ 0.005；每块板剖面均值 ≤ 0.02（边长 ≤ 1 m）、≤ 0.05（细长或 2 m 级的光源） | 矩形面光源比参考解整体亮 4%，不随尺寸变化，像是 three 的 LTC 拟合带来的固定偏差；阴影 1×1 m 时全图 0.0014，2×2 m 时剖面 0.009，2×0.5 m 时 0.049（`area-shadow.md`） |
| AC-8 性能 | 参考设备，1200 × 800，4 盏有尺寸的投影光源（含 1 个面光源）：① 视口每帧增量 ≤ 8 ms；② 场景第一次构建（编译）增量 ≤ 1 s；③ 导出时长增量 ≤ 50% | 每盏聚光或点光的 PCSS 约 +0.3–0.45 ms；面光源（视口档，16 + 32 次采样）约 +5 ms；合计约 6.5 ms。导出（冷启动，`frame-two-lights`，两盏有尺寸的灯）：采样循环改用 TSL 的 `Loop` 后，`workbench` 3.1 → 4.1 s（+30%），`realtime_gi` 11.3 → 12.9 s（+14%）；构建编译 +0.5 s，首帧 +0.4–1.0 s。最初逐次展开时是 +190% 和 +89%（`soft-shadow-candidates.md`「反应舱」）。S1 在 4 盏灯的场景上复测 |

另外两点：

- **AC-2（尺寸为 0 不变）**：尺寸为 0 的灯不挂滤波函数，与基线逐像素一致（`integration.md`「尺寸为 0」）。owner 2026-10-26 决定：聚光和点光 `bias` 为 0 的条纹放进 S1 一起修，所以 AC-2 改为「与修复条纹后的基线一致」。
- **AC-5 的椭圆**：参考解用椭圆、光栅用矩形时，亮度差 1.32 倍，约等于面积比 4/π 再乘以 1.04。S2 的椭圆面光源不能直接借用矩形的 LTC，要单独处理；阈值沿用矩形的。

## U1–U8

| 项 | 建议 | 依据 |
|---|---|---|
| U1 软阴影的做法 | **PCSS**（owner 2026-10-26 已确认）。聚光和点光：16 次搜索加 32 次滤波，半影上限 48 texel；面光源见 U5。阴影图去掉比较模式、改为最近点过滤，全部手动比较（U7）。接收面偏置的上限按坡度表达（≤ 20 倍，约 87°）。`smtrace` 不进产品；`vsm-pcss`、`msm-pcss`、`mip-pcss` 不做 | `soft-shadow-candidates.md` |
| U2 `workbench` 的颗粒 | 给 `workbench` 的最终导出加时域累积（例如 16 帧，逐帧旋转核），不做预滤波。现在只有 `realtime_gi` 累积（`sceneRenderer.ts:717`） | 对比视图里多帧平均相当于加了累积：半径 0.3 m 时，3 m 板剖面最大差从单帧的 0.193 降到 0.080，半影外缘的亮点被平均掉。`workbench` 每帧约 2 ms，16 帧只多几十毫秒；预滤波要另做一套 |
| U3 面光源阴影 | 中心的立方体阴影图，滤波核与面光源的轴对齐（矩形核） | 立方体与参考解几乎一样；前半球 150° 透视图半影只有一半（`area-shadow.md`） |
| U4 接触阴影 | 主光有尺寸时，关掉屏幕空间接触阴影；尺寸为 0 时保持现状 | 有尺寸时它只叠出硬暗带和颗粒虚线，抖动方向也没有改善（`contact-shadow.md`） |
| U5 尺寸上限与半影上限 | 字段上限维持 Epic 暂定（`radius_m` ≤ 10、`angular_diameter_deg` ≤ 30、`width`/`height` 0.01–20）。半影上限：点光、聚光、平行光 48 texel；面光源 128 texel，出图 32 + 64 次采样，视口 16 + 32 次、48 texel。超出上限时，半影偏窄但画面连续，可以接受 | 平行光 10°、面光源 2 m 时，宽半影受上限影响最大偏窄 19%；上限放到 256 反而变差（`area-shadow.md`、`soft-shadow-candidates.md`） |
| U6 地平线以下的漫反射 | Snyder 的精确照度；sheen 随漫反射走，不做定量验收 | 交界线与参考解相差 ≤ 1°，代表点包裹过头 7–10°（`sphere-horizon-sheen.md`） |
| U7 原始深度读取 | 两个后端统一：去掉比较、最近点过滤、全部手动比较。WebGPU 和 WebGL2 各绕开一个 three r186 的缺陷，并各有一个 e2e 防回退。不需要额外输出线性深度 | `depth-read-backends.md` |
| U8 半径是否随缩放 | 暂按 Epic「不随缩放」推进，等 Blender 对照核对 | `blender-cycles.md`「U8 的核对」，owner 在另一台机器上做 |

## 其他交给 S1 的事项

都在 `integration.md`「给 S1 的清单」里，这里只列和阈值有关的：

- 采样循环用 TSL 的 `Loop`，并照原型的做法每份阴影一个 `Fn`（`soft-shadow-candidates.md`「反应舱」的 `Loop` 的坑），在 4 盏灯的场景上复测 AC-8。
- 平行光级联的 `ownNames` 后缀改为按序号，复测 standIn。
- 高光的混合模型参数（1.5 与 0.6）是在一块 0.15 粗糙度的板上拟合的，S1 在另一档粗糙度上复核 AC-4。
