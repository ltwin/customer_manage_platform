## creative/scene: ADD 光源尺寸与软阴影

点光和聚光有半径，平行光有角径，与 Blender 的 Radius 和 Angle 相同。新建的灯默认带尺寸：点光和聚光半径 0.1 m，平行光角径 0.545°。

- **阴影**：光源越大、遮挡物离受光面越远，影子边缘越软；贴着遮挡物的地方仍然是实的。
- **高光**：光源越大，光滑表面上的高光越大、越柔和。
- **照度**：离光源足够远时，照度与同强度的点光源相同；靠近光源时照度不会无限变亮。
- **尺寸为 0**：半径或角径写成 0，就是理想的点光源或平行光，影子是硬的。
- **天空的太阳和月亮**：同样投出软边的影子。物理天空的太阳按画出的太阳盘大小计算，月亮按 0.52°，程序化天空的太阳按 0.545°。
- **生效范围**：与其他灯光字段一样，只在最终渲染和材质光照导出里生效，工作台和实时 GI 都是如此；改动静默保存，可以撤销。

### Scenario: 调大半径，影子变软
- GIVEN 最终渲染模式下，一盏聚光隔着框架照墙，框架离墙 1 m
- WHEN 在属性面板把聚光的「半径」从 0.1 m 调到 0.5 m
- THEN 墙上框架的影子边缘明显变宽变软，贴墙的那条边仍然清楚；墙面整体亮度基本不变；Cmd+Z 回到 0.1 m

### Scenario: 半径为 0 时是硬影子
- GIVEN 一盏点光
- WHEN 把「半径」改成 0
- THEN 影子边缘是硬的，与点光源一样；墙面上没有细密的自阴影条纹

### Scenario: 图标画出光源大小
- GIVEN 一盏半径 0.3 m 的点光，所在物件缩放了 2 倍
- WHEN 在视口里查看这盏灯
- THEN 图标画出一个半径 0.3 m 的球，不随物件缩放变大

### Scenario: 太阳盘变大，影子变软
- GIVEN 天空是物理天空，地上有一根 2 m 高的柱子
- WHEN 把太阳的视直径从默认值调到 5°
- THEN 太阳盘变大，柱子影子的边缘随之变软

### Scenario: 助手写错类型的字段
- GIVEN 助手在调一盏点光
- WHEN 给点光写了平行光才有的 `angular_diameter_deg`
- THEN 修改被拒绝，结果指出是这个字段；场景不变

### Scenario: 旧场景打开后带上缺省尺寸
- GIVEN 加入光源尺寸之前保存的场景，里面有一盏聚光
- WHEN 打开这个场景
- THEN 聚光的属性面板显示半径 0.1 m，影子比以前软；把半径改成 0 可以回到以前的硬影子

## creative/scene: MODIFY 导出图提示场景已更新

导出之后场景被修改，并且修改会改变这张图时，画布上的导出图显示「场景已更新」；改回原样后不再显示。只是提示，不改图片。哪些修改算数按导出方式区分：线稿只看几何和这台摄像机，白模另看景深，材质光照再看环境、灯光、材质、曝光和渲染器。物理天空下，材质光照的曝光是这台摄像机自己的曝光：自动时是模式和补偿，手动时是 ISO、快门和光圈；「渲染」选项卡里默认摄像机的曝光不算；其他天空下是曝光补偿。输出分辨率不算。实时 GI 的画面因渲染器本身的改进而明显变化时（例如加入屏幕外的间接光），已有的实时 GI 材质光照图各提示一次，重新导出后恢复；工作台的材质光照图、白模和线稿不受影响。灯光的画法本身改变时（例如加入光源尺寸），有灯光对象、或天空的太阳会投影的场景，已有的材质光照图各提示一次，工作台和实时 GI 都是如此；其余场景的材质光照图，以及白模和线稿，不受影响。

### Scenario: 几何变化让导出图过时
- GIVEN 画布上有某台摄像机的白模图和线稿
- WHEN 摄影师移动了场景里的一根柱子
- THEN 两张图都显示「场景已更新」

### Scenario: 改挂分组也算几何变化
- GIVEN 画布上有某台摄像机的白模图和线稿
- WHEN 助手在同一次修改里把两根柱子移进一个旋转过的分组，并新增了一台摄像机
- THEN 两张图都显示「场景已更新」，即使柱子在画面中的位置没变

### Scenario: 改回原样不再提示
- GIVEN 导出后摄影师移动了一根柱子，导出图显示「场景已更新」
- WHEN 把柱子移回原位
- THEN 导出图不再显示「场景已更新」

### Scenario: 摄像机被删除
- GIVEN 画布上有某台摄像机的导出图
- WHEN 摄影师删除了这台摄像机
- THEN 导出图显示「场景已更新」

### Scenario: 环境只影响材质光照图
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图
- WHEN 摄影师改了太阳高度，打开了雾，或在物理天空下改了地点、时刻、大气参数或太阳的亮度和色温
- THEN 只有材质光照图显示「场景已更新」

### Scenario: 灯光和材质只影响材质光照图
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图
- WHEN 摄影师改了一盏灯的颜色或半径，或换了一个槽位的材质
- THEN 只有材质光照图显示「场景已更新」

### Scenario: 曝光只影响材质光照图
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图，天空是程序化天空
- WHEN 摄影师调了曝光补偿
- THEN 只有材质光照图显示「场景已更新」；调回原值后不再显示

### Scenario: 物理天空下改摄像机曝光
- GIVEN 物理天空，画布上有摄像机 A 和摄像机 B 的材质光照图
- WHEN 摄影师改了摄像机 A 的快门，或把 A 切成环境测光、改了 A 的补偿
- THEN 只有 A 的材质光照图显示「场景已更新」；改「渲染」选项卡里默认摄像机的曝光（模式、补偿、默认曝光值）时，两张图都不显示

### Scenario: 景深参数不影响线稿
- GIVEN 一台打开了景深的摄像机，画布上有它的白模图、线稿和材质光照图
- WHEN 摄影师改了光圈，或移动了对焦物件
- THEN 白模图和材质光照图显示「场景已更新」，线稿不显示；景深关闭时改光圈，天空不是物理天空则三张图都不显示，是物理天空则只有材质光照图显示

### Scenario: 渲染器只影响材质光照图
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图，场景一直用工作台
- WHEN 摄影师把渲染器换成实时 GI
- THEN 只有材质光照图显示「场景已更新」；换回工作台后不再显示

### Scenario: 改输出分辨率不提示
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图
- WHEN 摄影师把输出分辨率从 2K 改成 4K
- THEN 三张图都不显示「场景已更新」

### Scenario: 不影响画面的修改不提示
- GIVEN 画布上有某台摄像机的白模图和线稿
- WHEN 只新加、删除或调了另一台摄像机，加了或删除一盏灯光，改了场景标题、显示模式、曝光补偿、默认摄像机的曝光，或者某个槽位的材质
- THEN 导出图不显示「场景已更新」

### Scenario: 换了图或场景没了就不再提示
- GIVEN 一张导出图之后场景有过几何修改
- WHEN 摄影师换掉了这个节点的图片内容，或场景已被删除
- THEN 不显示「场景已更新」

### Scenario: 实时 GI 加入屏幕外间接光后提示一次
- GIVEN 画布上有渲染器为实时 GI 的材质光照图，以及同一场景的白模图、线稿和另一个工作台场景的材质光照图，都是加入屏幕外间接光之前导出的
- WHEN 加入屏幕外间接光的版本上线后打开画布
- THEN 只有实时 GI 的材质光照图显示「场景已更新」；重新导出后不再显示；其余的图都不显示

### Scenario: 加入光源尺寸后提示一次
- GIVEN 加入光源尺寸之前导出的三张材质光照图：场景 A 有一盏聚光，场景 B 没有灯、天空是程序化天空，场景 C 没有灯、天空是 HDRI；另有场景 A 的白模图和线稿
- WHEN 加入光源尺寸的版本上线后打开画布
- THEN 场景 A 和场景 B 的材质光照图显示「场景已更新」，工作台和实时 GI 都是如此；重新导出后不再显示；场景 C 的材质光照图、场景 A 的白模图和线稿都不显示
