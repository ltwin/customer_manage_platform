## creative/scene: ADD 渲染设备不可用与丢失

编辑器、助手的截图和导出、缩略图和资产预览都用 WebGPU 渲染；浏览器拿不到 WebGPU 时自动改用兼容模式（WebGL2），编辑和导出照常可用，画面一致。渲染设备在使用中丢失（显卡驱动重置、GPU 进程崩溃等）时，编辑视图自动恢复；助手的任务不报失败，由页面重新领取后完成。

### Scenario: 没有 WebGPU 时照常使用
- GIVEN 浏览器拿不到 WebGPU，但支持 WebGL2
- WHEN 摄影师打开场景编辑视图，编辑并导出
- THEN 编辑和导出照常完成，导出图与 WebGPU 下的同一张图看不出区别；页面不出现技术错误信息

### Scenario: 两种都拿不到
- GIVEN 浏览器既拿不到 WebGPU，也拿不到 WebGL2
- WHEN 摄影师打开场景编辑视图
- THEN 显示「当前浏览器无法显示 3D 场景，请使用最新版 Chrome、Edge 或 Safari」；这个页面不领取助手的场景任务

### Scenario: 编辑时设备丢失
- GIVEN 摄影师在编辑视图里选中了物件，刚做过还没保存完的修改，正在拖动另一个物件
- WHEN 渲染设备丢失
- THEN 视口自动恢复显示场景，视角、选中和已做完的修改都还在（照常保存）；正在拖的那一下被取消，物件回到拖动前的位置；短时间内反复丢失时停止自动恢复，提示刷新页面

### Scenario: 执行助手任务时设备丢失
- GIVEN 本页正在为助手截图或导出
- WHEN 渲染设备丢失
- THEN 任务不报失败，已经画好的图一张都不交出；租约到期后任务重新排队，由一个页面重新领取并完成，助手拿到正常结果

### Scenario: 设备一直恢复不了
- GIVEN 本页执行助手任务时设备丢失，之后一直无法重新建立渲染设备
- WHEN 助手的任务重新排队
- THEN 本页不再领取场景任务，任务由其他能渲染的页面完成；没有这样的页面时，按「没有页面时任务过期」处理

### Scenario: 手动导出时设备丢失
- GIVEN 摄影师在导出分镜
- WHEN 渲染设备丢失
- THEN 导出失败并提示「渲染设备暂时不可用，请重试」，画布上不出现半成品；重试后正常导出
