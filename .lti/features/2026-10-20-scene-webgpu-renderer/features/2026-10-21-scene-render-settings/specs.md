## creative/scene: ADD 渲染器与输出分辨率

属性区参照 Blender 分成「渲染」「环境」「物件」三个选项卡。「渲染」里可以选渲染器和输出分辨率，调曝光补偿，并看到当前的渲染后端。渲染器有工作台、实时 GI，以及还不能选的「路径追踪 · 规划中」：工作台是标准的光栅化渲染；实时 GI 在它之上加入物体之间的间接光反弹、反射和接触阴影，只计算画面里可见的表面。渲染器决定编辑器的白模和最终渲染、助手回看和白模、材质光照导出的画面；线框、材质预览和线稿不受影响，正交视图按工作台显示。输出分辨率只决定导出图的长边。两项都是场景的设置，静默保存，可以撤销，其他标签页和助手看到的一样。

### Scenario: 打开渲染选项卡
- GIVEN 摄影师在场景编辑视图里
- WHEN 点属性区的「渲染」
- THEN 看到渲染器（工作台、实时 GI、灰掉的「路径追踪 · 规划中」）、输出分辨率（1K、2K、4K、8K，注明长边像素）、曝光补偿和渲染后端（「WebGPU」或「兼容模式」）

### Scenario: 选中物件时切到物件属性
- GIVEN 摄影师停在「渲染」选项卡
- WHEN 在视口里选中一个物件，再取消选中
- THEN 选中时属性区切到「物件」，取消后回到「渲染」

### Scenario: 换成实时 GI
- GIVEN 一个红墙、白地面、金属球的房间，渲染器是工作台，摄影师在最终渲染模式下
- WHEN 把渲染器换成实时 GI
- THEN 停止操作后画面逐渐变干净然后停止刷新；靠近红墙的白地面被染红，金属球和光滑地板映出房间里的其他物体；白模模式下同样有染色和接触处的暗部，但没有反射；Cmd+Z 回到工作台；另一个标签页同步显示

### Scenario: 正交视图按工作台显示
- GIVEN 渲染器是实时 GI
- WHEN 切到正交视图
- THEN 画面按工作台显示，视口角落提示「正交视图按工作台显示」；回到透视视图后恢复实时 GI

### Scenario: 按 4K 导出
- GIVEN 场景里有一台 3:2 的摄像机，输出分辨率选 4K
- WHEN 导出白模、线稿和材质光照
- THEN 三张图长边都是 4096 px、短边 2731 px；导出对话框写明长边 4096

### Scenario: 设备画不了所选分辨率
- GIVEN 输出分辨率选 8K，当前设备的显存不够
- WHEN 导出
- THEN 导出失败并说明当前设备可能画不了这个分辨率、可以换低一档，画布上没有半成品；不会悄悄按更低的分辨率导出

### Scenario: 请助手换渲染器并按 4K 导出
- GIVEN 摄影师在助手面板里
- WHEN 请助手「换成实时 GI，按 4K 导出」
- THEN 助手把渲染器和输出分辨率改掉，回看一次实时 GI 的画面，再导出长边 4096 的图；两项修改出现在这一轮的改动清单里

### Scenario: 路径追踪还不能选
- GIVEN 摄影师或助手想用路径追踪
- WHEN 打开渲染器下拉，或助手写入路径追踪
- THEN 下拉里这一项不能选；助手的写入被拒绝并说明还不支持

## creative/scene: MODIFY 导出分镜到画布

摄影师或助手可以把场景按摄像机导出成图，落成画布上的图片节点。导出方式有白模（`clay`）、线稿和材质光照（`lit`）；每张图按摄像机画幅出图，长边按场景的输出分辨率（1K、2K、4K、8K 分别为 1024、2048、4096、8192 px，缺省 2K）。白模与编辑器的白模一致，材质光照与编辑器的最终渲染一致，两者都按场景所选的渲染器出图。图片节点记录来源场景、修订、摄像机和导出方式。

### Scenario: 导出 3 台摄像机
- GIVEN 场景里有 3 台摄像机
- WHEN 摄影师在编辑视图里点「导出」，选全部摄像机和白模、线稿两种方式
- THEN 画布上场景节点右侧出现 6 个图片节点，每台摄像机一行、白模和线稿各一列；在画布上撤销一次，6 个节点一起移除

### Scenario: 导出材质光照
- GIVEN 场景里有 3 台摄像机，摄影师在最终渲染模式下
- WHEN 打开「导出」
- THEN 白模、线稿、材质光照默认都勾选；导出后得到 3 行 3 列 9 个节点，材质光照图与相机视图里最终渲染的画面一致，摄像机打开景深时同样虚化

### Scenario: 白模模式下默认不带材质光照
- GIVEN 摄影师在白模模式下
- WHEN 打开「导出」
- THEN 默认只勾选白模和线稿，可以手动勾选材质光照

### Scenario: 先保存再导出
- GIVEN 摄影师刚移动了一个物件，修改还没保存完
- WHEN 点「导出」
- THEN 先完成保存，再按保存后的场景出图；导出图记录的修订包含这次移动

### Scenario: 再次导出不叠在旧图上
- GIVEN 场景节点右侧已经有一组导出图
- WHEN 再导出一次
- THEN 新的一组排在旧图下方，不重叠，旧图保留

### Scenario: 不能导出时说明原因
- GIVEN 场景里没有摄像机，或选择的组合超过 48 张图
- WHEN 打开导出
- THEN 「导出」不可用，分别提示先添加摄像机、分次导出

### Scenario: 提交时断网不重复
- GIVEN 摄影师点了导出，图片已经上传，提交时网络中断，而服务端其实已经建好节点
- WHEN 页面重试提交
- THEN 拿到的是同一组节点，画布上不会出现第二组

### Scenario: 助手导出
- GIVEN 摄影师请助手导出分镜，只开着画布页
- WHEN 助手调用导出
- THEN 画布页在后台完成导出，任务完成时图片出现在这次对话所在画布的场景节点旁；助手得到每张图的节点、摄像机和方式；助手可以要求材质光照图，不指定时导出白模和线稿

### Scenario: 助手知道导出图怎么拍的
- GIVEN 一台对焦在人物上、光圈 f/1.8、打开景深的摄像机已导出白模和线稿
- WHEN 助手读取画布，准备拿这两张图做参考重绘
- THEN 两个导出图节点都给出来源：哪台摄像机、哪种导出方式、导出时的焦距、景深开关、光圈、对焦距离和对焦物件「人物」，以及场景之后是否改过；助手按此在白模的重绘提示词里写明对焦在人物上、焦外虚化，线稿的提示词要求全清晰

### Scenario: 导出中途换页面不重复
- GIVEN 执行助手导出的页面已经出完图，但在完成任务前被关闭
- WHEN 另一个页面接手这个任务
- THEN 画布上只出现接手页面导出的一组节点；助手照常得到结果

### Scenario: 助手导出时场景节点已被移走
- GIVEN 助手的导出任务正在执行
- WHEN 摄影师在任务完成前把场景节点从画布上删掉
- THEN 一个节点也不建，助手得到失败原因

## creative/scene: MODIFY 导出图提示场景已更新

导出之后场景被修改，并且修改会改变这张图时，画布上的导出图显示「场景已更新」；改回原样后不再显示。只是提示，不改图片。哪些修改算数按导出方式区分：线稿只看几何和这台摄像机，白模另看环境、景深和渲染器，材质光照再看灯光、材质和曝光。输出分辨率不算。

### Scenario: 几何变化让导出图过时
- GIVEN 画布上有某台摄像机的白模图和线稿
- WHEN 摄影师移动了场景里的一根柱子
- THEN 两张图都显示「场景已更新」

### Scenario: 改挂分组也算几何变化
- GIVEN 画布上有某台摄像机的白模图和线稿
- WHEN 助手在同一次修改里把两根柱子移进一个旋转过的分组，并新增了一台摄像机
- THEN 两张图都显示「场景已更新」，即使柱子在画面中的位置没变

### Scenario: 改回原样不再提示
- GIVEN 导出后摄影师移动了一根柱子，导出图显示「场景已更新」
- WHEN 把柱子移回原位
- THEN 导出图不再显示「场景已更新」

### Scenario: 摄像机被删除
- GIVEN 画布上有某台摄像机的导出图
- WHEN 摄影师删除了这台摄像机
- THEN 导出图显示「场景已更新」

### Scenario: 环境不影响线稿
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图
- WHEN 摄影师改了太阳高度
- THEN 白模图和材质光照图显示「场景已更新」，线稿不显示

### Scenario: 灯光和材质只影响材质光照图
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图
- WHEN 摄影师改了一盏灯的颜色，或换了一个槽位的材质
- THEN 只有材质光照图显示「场景已更新」

### Scenario: 曝光只影响材质光照图
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图
- WHEN 摄影师调了曝光补偿
- THEN 只有材质光照图显示「场景已更新」；调回原值后不再显示

### Scenario: 景深参数不影响线稿
- GIVEN 一台打开了景深的摄像机，画布上有它的白模图、线稿和材质光照图
- WHEN 摄影师改了光圈，或移动了对焦物件
- THEN 白模图和材质光照图显示「场景已更新」，线稿不显示；景深关闭时改光圈，三张图都不显示

### Scenario: 渲染器只影响白模和材质光照图
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图，场景一直用工作台
- WHEN 摄影师把渲染器换成实时 GI
- THEN 白模图和材质光照图显示「场景已更新」，线稿不显示；换回工作台后不再显示

### Scenario: 改输出分辨率不提示
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图
- WHEN 摄影师把输出分辨率从 2K 改成 4K
- THEN 三张图都不显示「场景已更新」

### Scenario: 不影响画面的修改不提示
- GIVEN 画布上有某台摄像机的白模图和线稿
- WHEN 只新加、删除或调了另一台摄像机，加了或删除一盏灯光，改了场景标题、显示模式、曝光补偿，或者某个槽位的材质
- THEN 导出图不显示「场景已更新」

### Scenario: 换了图或场景没了就不再提示
- GIVEN 一张导出图之后场景有过几何修改
- WHEN 摄影师换掉了这个节点的图片内容，或场景已被删除
- THEN 不显示「场景已更新」

## creative/scene: MODIFY 编辑灯光与环境

摄影师可以添加平行光、点光、聚光，编辑它们的颜色、强度、阴影和光锥；天空、环境光和雾在属性区的「环境」选项卡里编辑，曝光补偿在「渲染」选项卡里。灯光和曝光补偿只在最终渲染和材质光照导出里生效；太阳方向、天空、环境光和雾在白模里也生效。改动静默保存，可以撤销。

### Scenario: 加一盏聚光
- GIVEN 摄影师在最终渲染模式下
- WHEN 用 Shift + A 加一盏聚光，把光锥角调到 30°，打开「投射阴影」
- THEN 光照范围和图标的光锥一致，物件在地面投下阴影；存储的光锥角为 π/12 弧度

### Scenario: 换灯光类型
- GIVEN 一盏聚光
- WHEN 把类型改成点光
- THEN 光锥角和柔化消失，颜色、强度、阴影设置保留

### Scenario: 白模里灯光不生效
- GIVEN 摄影师在白模模式下选中一盏灯
- WHEN 查看属性栏
- THEN 提示灯光在最终渲染模式下生效

### Scenario: 调太阳高度
- GIVEN 天空是程序化天空
- WHEN 在「环境」选项卡里把太阳高度从 35° 调到 5°
- THEN 白模和最终渲染里影子都变长，天空变成黄昏色调；Cmd+Z 回到 35°

### Scenario: 调曝光补偿
- GIVEN 一个只有两盏壁灯的室内场景，最终渲染偏暗
- WHEN 在「渲染」选项卡里把「曝光补偿」调到 +2
- THEN 最终渲染变亮；白模不变；Cmd+Z 回到 0

### Scenario: 纯色天空和雾
- GIVEN 摄影师在「环境」选项卡里
- WHEN 把天空改成纯色，打开雾并设置起止距离
- THEN 背景和雾按设置显示，导出图一致
