## creative/library: MODIFY 导入外部模型


摄影师可以把外部的 `.glb` 模型导入资产库，之后像其他模型资产一样放进场景。模型可以是静态的，也可以是绑好骨骼的角色。只收资源全部内嵌的 `.glb`。导入在浏览器里完成换算：材质换成槽位分配，贴图拆成账号的图片，压缩或量化过的几何先还原；对话框列出换算结果和被忽略的部分，摄影师确认后才上传。

- **入口**：资产库页面和资产库抽屉的「导入」（也可以把 `.glb` 拖进去）、编辑器资产面板的「导入模型」、编辑器「添加 > 导入模型…」（导入后直接放进场景）。
- **换算**：基础色、ORM、法线、自发光贴图和透明方式都按 glTF 的含义换算；只用顶点色上色的模型打开「顶点色」；贴图的平移、缩放、旋转烘进 UV。第二套 UV 的贴图、形态键、动画、灯光和相机丢掉并提示；镜像或钳制寻址的贴图在 UV 越界时按重复显示并提示。超出上传上限的图片会缩小，透明图片和法线等数据贴图保持无损。
- **带骨骼的角色**：保留蒙皮；每个顶点最多保留 4 个影响（多出的去掉并提示）。导入时自动把骨骼对应到标准人形骨骼，依次看 VRM 扩展、Mixamo 和 UE 小白人的骨骼名；对话框显示对应上了多少根骨骼、是否带手指、有几条 VRM 约束。对应不上（缺必需骨骼，或骨骼层级与人形不符）时说明原因，可以手动指定，也可以按非人形骨架导入。放进场景后按静止姿势显示。
- **拒绝**：引用外部文件的模型（提示重新导出为内嵌资源的 GLB）、骨骼超过 512 根、KTX2 贴图、超过 32 个材质、超过 64 张图片、超出模型的面数和大小上限时，对话框说明原因，不上传。
- **原点**：缺省保留文件里的原点；可以勾选「原点移到底面中心」。
- **来源与授权**：记录原文件名，以及摄影师填写的授权说明（用文件里的版权信息预填）和来源页面；导入后在资产查看浮窗和场景属性栏里显示。
- **导入的模型没有代码**：不能改参数和代码，可以换材质、做面级材质分配（带骨骼的模型暂不能做面级材质分配）；放进场景后的修改不影响资产库里的资产。助手可以找到、放置和换材质，不能改代码。
- **保存到资产库**：上传期间可以取消，取消后资产库不变、已上传的文件被丢弃。开始保存后不能取消；网络中断时自动重试同一次保存，不会建出两份。同一个文件导入两次是两份资产。

### Scenario: 导入带贴图的道具
- GIVEN 一个带基础色、ORM、法线和自发光贴图的 `.glb`
- WHEN 在资产库页面点「导入」选中它，确认换算结果并填写标题
- THEN 资产库出现这个模型，缩略图带贴图；拖进场景后，材质预览和最终渲染里贴图和发光正确

### Scenario: 换算结果可见
- GIVEN 一个带动画和形态键、有一张贴图用第二套 UV 的 `.glb`
- WHEN 选中它导入
- THEN 对话框列出被丢掉的动画、形态键和那张贴图；确认后照常导入

### Scenario: 压缩过的模型
- GIVEN 一个用 Draco 压缩的 `.glb`
- WHEN 导入
- THEN 导入成功，画面与未压缩的版本相同

### Scenario: 导入 VRM 角色
- GIVEN 一个从 VRM 转出的带骨骼角色 `.glb`
- WHEN 选中它导入
- THEN 对话框显示骨骼按 VRM 对应好了，列出骨骼数和约束数；导入后放进场景，角色按静止姿势站在地面上，贴图正确

### Scenario: 按骨骼名识别
- GIVEN 一个 Mixamo 导出的角色 `.glb`
- WHEN 选中它导入
- THEN 骨骼按名字自动对应到人形骨骼，带手指

### Scenario: 骨骼对应不上
- GIVEN 一个脚挂在 IK 控制骨下面的角色
- WHEN 选中它导入
- THEN 对话框说明哪根骨骼的层级不对；摄影师可以手动改对应关系后导入，也可以按非人形骨架导入

### Scenario: 来源与授权
- GIVEN 一个 `asset.copyright` 写着作者和许可的 `.glb`
- WHEN 导入
- THEN 授权说明已预填；导入后在查看浮窗和属性栏里能看到原文件名、授权说明和来源页面，看不到参数和代码

### Scenario: 放进场景后修改
- GIVEN 场景里放着一个导入的模型
- WHEN 给它做面级材质分配
- THEN 场景里的模型变了，资产库里的资产和缩略图不变

### Scenario: 助手不能改导入模型的代码
- GIVEN 场景里有一个导入的模型
- WHEN 助手对它调用 `write_model`
- THEN 工具返回「导入的模型没有代码，只能换材质或摆放」，场景不变

### Scenario: 取消导入
- GIVEN 导入正在上传
- WHEN 摄影师点取消
- THEN 资产库不变，已上传的文件被丢弃

### Scenario: 保存时网络中断
- GIVEN 服务端已经建好资产，但响应没有回到浏览器
- WHEN 导入自动重试
- THEN 拿到同一个资产，资产库里只有一份

### Scenario: 引用外部文件
- GIVEN 一个图片放在 `.glb` 旁边另一个文件里的模型
- WHEN 选中它导入
- THEN 对话框提示「模型引用了外部文件，请在 Blender 里重新导出为内嵌资源的 GLB」，不上传任何文件

## creative/scene: ADD 内置素体

编辑器内置一男一女两个素体，所有账号都能直接放进场景。素体本身不能修改，场景里的实例可以移动、缩放、换材质，以后可以摆姿态。

- **放入**：「添加 > 素体」或资产面板的「素体」。放入时带上素体自己的皮肤、眼睛和眉毛贴图。
- **在场景里**：属性栏显示「素体」和来源（Quaternius，CC0）。没有参数和代码，不能做面级材质分配，不能存入资产库；可以把女素体换成男素体，反之亦然。
- **换材质**：给素体的槽位换材质只改这个实例；撤销照常。
- **助手**：助手能在内置来源里搜到素体，读取它的要点和缩略图，放进场景；没写材质时自动带上素体自己的材质。
- **文件缺失**：素体文件暂时读不到时，视口显示占位并提示，导出失败并说明原因，其他物件照常。

### Scenario: 放入女素体
- GIVEN 任意账号打开一个场景
- WHEN 选「添加 > 素体 > 女素体」
- THEN 女素体站在地面上，材质预览、最终渲染和导出里皮肤、眼睛、眉毛的贴图都正确

### Scenario: 素体只读
- GIVEN 场景里放着一个女素体
- WHEN 查看它的属性栏
- THEN 能看到「素体」和来源，看不到参数、面级材质分配和「存入资产库」；可以缩放、换材质

### Scenario: 换成男素体
- GIVEN 场景里放着一个女素体
- WHEN 在属性栏把模型换成男素体
- THEN 原位置换成男素体，带男素体的材质（之前给女素体换过的材质不保留）；撤销后回到女素体和原来的材质

### Scenario: 助手放入素体
- GIVEN 助手在为一个场景搭布景
- WHEN 它在内置来源里搜「女」，把结果放进场景
- THEN 场景里出现带贴图的女素体，回看图里能看到它

## creative/scene: ADD 带骨骼的角色

带骨骼的角色（导入的角色和内置素体）在视口的三种显示模式、最终渲染、实时 GI、回看和导出里都画成蒙皮网格。现在还不能摆姿态，角色按静止姿势显示。

- **一致**：镜中的倒影、墙上的间接光、包围盒、贴地吸附和线稿都按角色当前的姿态计算，与视口里看到的相同。
- **VRM 约束**：VRM 角色里由约束驱动的扭转骨，随手的转动一起转。
- **代码模型不带骨骼**：用代码生成的模型不能带骨骼，提交时被拒绝。
- **暂不做面级材质分配**：带骨骼的角色可以给整个槽位换材质，但还不能把一部分面分到别的槽位。
- **已知局限**：没有扭转骨的角色（包括内置素体），以后摆姿态时手绕前臂大角度转动，手腕会收窄。

### Scenario: 角色在 GI 下的倒影
- GIVEN 场景里一面镜子前站着一个导入的角色
- WHEN 切到最终渲染（实时 GI）
- THEN 镜中能看到角色，导出图与视口一致

### Scenario: 角色贴地
- GIVEN 一个导出时根节点带旋转的角色
- WHEN 把它放进场景
- THEN 角色的脚贴在地面上，选中框与可见的网格一致

### Scenario: 旧场景不变
- GIVEN 本次上线前建的场景，里面没有带骨骼的角色
- WHEN 打开它
- THEN 画面和导出图的过时状态都不变
