## creative/scene: ADD 分镜与关键帧

一个场景可以有多个分镜。分镜是时间线上的一个标记，有名称、帧号和绑定的摄像机；切到一个分镜，就是跳到这一帧并从它的摄像机取景。物件的位置、旋转、缩放、可见性，以及摄像机的焦距、传感器、画幅、景深、光圈、对焦和曝光可以打关键帧；有关键帧的属性按帧变化，没有关键帧的属性所有分镜共用，所以布景在各分镜里天然一致。交互参照 Blender 的时间线：I 插入关键帧，自动关键帧开关默认关闭，属性栏用颜色区分有关键帧、本帧是关键帧和已改未记录。

- **分镜互不影响**：有关键帧的属性在每个分镜的帧上都有关键帧，所以改一个分镜不会带动别的分镜。第一次给某个属性插关键帧时（在哪一帧都一样），其他分镜自动记下修改前的值，这个值也是这个属性的默认状态；挪动分镜时关键帧跟着走；删除分镜时删掉它那一帧的关键帧。
- **新建与复制分镜**：新建分镜从默认状态开始，只属于别的分镜的物件不出现；复制分镜与被复制的分镜完全相同。
- **改基础值还是改这一镜**：没有关键帧的属性改了就是所有分镜都变；有关键帧的属性改了但没插关键帧，切到别的分镜时改动丢弃。
- **只在当前分镜显示**：物件可以设成只在当前分镜可见，其他分镜和之后新建的分镜里都隐藏。
- **清除动画**：删掉一个属性的全部关键帧，属性保持当前帧的值，所有分镜共用。
- 以上都是普通的场景修改：静默保存，Cmd+Z 只撤销自己的操作，其他标签页同步出现。撤销或恢复历史版本后若有分镜缺少关键帧，时间线上会标出来。
- 不做动画播放、曲线编辑和视频导出；灯光、天空、雾不能打关键帧。

### Scenario: 建分镜
- GIVEN 一个有 2 台摄像机的场景
- WHEN 摄影师在时间线上新建 3 个分镜，分别绑定摄像机
- THEN 时间线上出现 3 个标记，按帧序编号；点击任一个，视口跳到这一帧并从它的摄像机取景；刷新后保持

### Scenario: 先建镜头、后加动画
- GIVEN 3 个分镜已经建好，主体的位置没有关键帧
- WHEN 摄影师切到分镜 2，移动主体并按 I
- THEN 只有分镜 2 的主体在新位置；切到分镜 1、3，主体在原位

### Scenario: 复制分镜
- GIVEN 主体在分镜 2 有位置关键帧
- WHEN 复制分镜 2 得到分镜 4
- THEN 分镜 4 的主体与分镜 2 相同；之后改分镜 4 不影响分镜 2

### Scenario: 新建分镜从默认状态开始
- GIVEN 主体原在门口，在分镜 2 里被移到窗边并插了关键帧；分镜 3 里有一个只在当前分镜显示的人片
- WHEN 新建分镜 4
- THEN 分镜 4 的主体在门口，人片不出现

### Scenario: 先移动再按 I
- GIVEN 3 个分镜，主体的位置没有关键帧，自动关键帧关闭
- WHEN 摄影师在分镜 2 移动主体
- THEN 3 个分镜里的主体都跟着动（这是在改布景）
- WHEN 接着按 I
- THEN 分镜 1、3 的主体回到原位，只有分镜 2 在新位置

### Scenario: 在两个分镜之间插帧
- GIVEN 分镜在第 0、10 帧，主体的位置没有关键帧
- WHEN 把帧指针拖到第 5 帧，移动主体并按 I
- THEN 写入成功；两个分镜的主体都在原位

### Scenario: 挪动和删除分镜
- GIVEN 3 个分镜，主体在分镜 2 的位置与其他分镜不同
- WHEN 把分镜 2 拖到另一帧
- THEN 分镜 2 的画面不变
- WHEN 删除分镜 2
- THEN 分镜 1、3 的画面不变

### Scenario: 只在当前分镜显示
- GIVEN 3 个分镜
- WHEN 在分镜 3 里添加一个物件，选「只在当前分镜显示」
- THEN 它只出现在分镜 3；之后新建、挪动或删除别的分镜，它仍然只在分镜 3；复制分镜 3 得到的分镜会带上它

### Scenario: 摄像机参数按分镜
- GIVEN 分镜 1、2 共用一台 35 mm 的摄像机
- WHEN 在分镜 1 把焦距改成 85 mm 并插入关键帧
- THEN 分镜 1 是 85 mm，分镜 2 仍是 35 mm

### Scenario: 已改未记录
- GIVEN 主体的位置有关键帧
- WHEN 摄影师移动主体但不按 I
- THEN 属性栏的位置显示「已改未记录」的颜色
- WHEN 切到别的分镜再切回来
- THEN 主体回到关键帧的位置

### Scenario: 改布景
- GIVEN 3 个分镜，桌子没有关键帧
- WHEN 摄影师移动桌子
- THEN 3 个分镜里的桌子都在新位置

### Scenario: 清除动画
- GIVEN 主体的位置在 3 个分镜里各不相同
- WHEN 在分镜 2 对位置「清除动画」
- THEN 主体在 3 个分镜里都停在分镜 2 的位置

### Scenario: 有未记录的改动时导出
- GIVEN 主体的位置有关键帧，摄影师移动了主体但没按 I
- WHEN 点「导出」
- THEN 先提示有未记录的改动，可以插入关键帧后导出、放弃改动后导出或取消；选插入关键帧时，导出图里主体在新位置

### Scenario: 撤销分镜操作
- GIVEN 摄影师刚删除了分镜 2
- WHEN 按 Cmd+Z
- THEN 分镜 2 和它那一帧的关键帧都回来

### Scenario: 缺少关键帧的写入被拒绝
- GIVEN 主体的位置有关键帧
- WHEN 一次修改让分镜 2 的帧上没有这个属性的关键帧（例如外部客户端只删了这一个关键帧）
- THEN 修改被拒绝，场景不变，错误指出缺口

## creative/scene: ADD 助手按分镜搭镜头

助手可以读写分镜和关键帧：读场景时看到分镜列表和各物件哪些属性有关键帧，可以按分镜读出这一帧的状态；修改时指明分镜，就写成这一镜的关键帧，补齐其他分镜的规则与编辑器相同；按分镜回看和导出。

### Scenario: 按要求建多个分镜
- GIVEN 场景里有人物和一台摄像机
- WHEN 摄影师请助手「建 3 个分镜，第 2 镜人物往前走两步、换 85 mm」
- THEN 助手建出 3 个分镜；只有第 2 镜的人物位置和焦距不同；助手按分镜回看确认

### Scenario: 不指明分镜改有关键帧的属性
- GIVEN 人物的位置有关键帧
- WHEN 助手修改人物位置时没有指明分镜
- THEN 工具返回错误，提示指定分镜或先清除动画；场景不变

### Scenario: 读到缺口
- GIVEN 摄影师恢复历史版本后，分镜 2 缺少人物位置的关键帧
- WHEN 助手读取场景
- THEN 结果列出这个缺口；助手下一次写这个属性时一并补齐

## creative/scene: MODIFY 导出分镜到画布

摄影师或助手可以把场景按分镜导出成图，落成画布上的图片节点；没有分镜的场景按摄像机导出。每个分镜先按它的帧求出整个场景的状态，再用它绑定的摄像机出图。导出方式有白模（`clay`）、线稿和材质光照（`lit`）；每张图按摄像机（在这一帧的）画幅出图，长边按场景的输出分辨率（1K、2K、4K、8K 分别为 1024、2048、4096、8192 px，缺省 2K）。白模与编辑器的白模一致，按工作台出图；材质光照与编辑器的最终渲染一致，按场景所选的渲染器出图。图片节点记录来源场景、修订、分镜和帧号（按摄像机导出时没有分镜）、摄像机和导出方式。

### Scenario: 导出 3 台摄像机
- GIVEN 场景里有 3 台摄像机
- WHEN 摄影师在编辑视图里点「导出」，选全部摄像机和白模、线稿两种方式
- THEN 画布上场景节点右侧出现 6 个图片节点，每台摄像机一行、白模和线稿各一列；在画布上撤销一次，6 个节点一起移除

### Scenario: 导出材质光照
- GIVEN 场景里有 3 台摄像机，摄影师在最终渲染模式下
- WHEN 打开「导出」
- THEN 白模、线稿、材质光照默认都勾选；导出后得到 3 行 3 列 9 个节点，材质光照图与相机视图里最终渲染的画面一致，摄像机打开景深时同样虚化

### Scenario: 白模模式下默认不带材质光照
- GIVEN 摄影师在白模模式下
- WHEN 打开「导出」
- THEN 默认只勾选白模和线稿，可以手动勾选材质光照

### Scenario: 先保存再导出
- GIVEN 摄影师刚移动了一个物件，修改还没保存完
- WHEN 点「导出」
- THEN 先完成保存，再按保存后的场景出图；导出图记录的修订包含这次移动

### Scenario: 再次导出不叠在旧图上
- GIVEN 场景节点右侧已经有一组导出图
- WHEN 再导出一次
- THEN 新的一组排在旧图下方，不重叠，旧图保留

### Scenario: 不能导出时说明原因
- GIVEN 场景里没有摄像机，或选择的组合超过 48 张图，或选中的分镜没有绑定摄像机（摄像机已被删除）
- WHEN 打开导出
- THEN 「导出」不可用，分别提示先添加摄像机、分次导出、给分镜绑定摄像机

### Scenario: 提交时断网不重复
- GIVEN 摄影师点了导出，图片已经上传，提交时网络中断，而服务端其实已经建好节点
- WHEN 页面重试提交
- THEN 拿到的是同一组节点，画布上不会出现第二组

### Scenario: 助手导出
- GIVEN 摄影师请助手导出分镜，只开着画布页
- WHEN 助手调用导出
- THEN 画布页在后台完成导出，任务完成时图片出现在这次对话所在画布的场景节点旁；助手得到每张图的节点、分镜、摄像机和方式；助手可以要求材质光照图，不指定时导出白模和线稿；场景有分镜时默认导出全部分镜，没有分镜时导出全部摄像机

### Scenario: 助手知道导出图怎么拍的
- GIVEN 一台对焦在人物上、光圈 f/1.8、打开景深的摄像机已导出白模和线稿
- WHEN 助手读取画布，准备拿这两张图做参考重绘
- THEN 两个导出图节点都给出来源：哪台摄像机、哪种导出方式、导出时的焦距、景深开关、光圈、对焦距离和对焦物件「人物」，以及场景之后是否改过；助手按此在白模的重绘提示词里写明对焦在人物上、焦外虚化，线稿的提示词要求全清晰

### Scenario: 导出中途换页面不重复
- GIVEN 执行助手导出的页面已经出完图，但在完成任务前被关闭
- WHEN 另一个页面接手这个任务
- THEN 画布上只出现接手页面导出的一组节点；助手照常得到结果

### Scenario: 助手导出时场景节点已被移走
- GIVEN 助手的导出任务正在执行
- WHEN 摄影师在任务完成前把场景节点从画布上删掉
- THEN 一个节点也不建，助手得到失败原因

### Scenario: 按分镜导出
- GIVEN 场景里有 3 个分镜，分镜 1、2 共用摄像机 A，分镜 3 用摄像机 B；主体在分镜 2 往前走了一步
- WHEN 摄影师打开「导出」，选全部分镜和白模、线稿
- THEN 画布上出现 3 行 2 列 6 个节点，每行一个分镜，标题用分镜名（没有名字时为「分镜 N」）；分镜 2 的图里主体在前一步的位置，分镜 1 的图里在原位

### Scenario: 按分镜导出时摄像机参数按这一帧
- GIVEN 分镜 1 和分镜 2 共用一台摄像机，焦距在分镜 1 是 35 mm、在分镜 2 是 85 mm（关键帧）
- WHEN 导出这两个分镜
- THEN 分镜 1 的图按 35 mm 取景，分镜 2 按 85 mm；两张图的来源里镜头焦距分别是 35 和 85

### Scenario: 没有分镜的场景照旧按摄像机
- GIVEN 本次上线前建的场景，有 3 台摄像机、没有分镜
- WHEN 打开「导出」
- THEN 仍然按摄像机列出，导出结果与以前相同

## creative/scene: MODIFY 导出图提示场景已更新

导出之后场景被修改，并且修改会改变这张图时，画布上的导出图显示「场景已更新」；改回原样后不再显示。按分镜导出的图，只看这个分镜那一帧求出的场景：只改别的分镜的关键帧不算，分镜挪到别的帧但画面不变也不算；分镜被删除、没有绑定摄像机、或换绑了另一台摄像机（即使参数相同）都算。按摄像机导出的图（包括本次上线前的图）按第 0 帧求出的场景判断，没有关键帧的场景与以前完全相同。只是提示，不改图片。哪些修改算数按导出方式区分：线稿只看几何和这台摄像机，白模另看景深，材质光照再看环境、灯光、材质、曝光和渲染器。物理天空下，材质光照的曝光是这台摄像机自己的曝光：自动时是模式和补偿，手动时是 ISO、快门和光圈；「渲染」选项卡里默认摄像机的曝光不算；其他天空下是曝光补偿。输出分辨率不算。实时 GI 的画面因渲染器本身的改进而明显变化时（例如加入屏幕外的间接光），已有的实时 GI 材质光照图各提示一次，重新导出后恢复；工作台的材质光照图、白模和线稿不受影响。灯光的画法本身改变时（例如加入光源尺寸），有灯光对象、或天空的太阳会投影的场景，已有的材质光照图各提示一次，工作台和实时 GI 都是如此；其余场景的材质光照图，以及白模和线稿，不受影响。

### Scenario: 几何变化让导出图过时
- GIVEN 画布上有某台摄像机的白模图和线稿
- WHEN 摄影师移动了场景里的一根柱子
- THEN 两张图都显示「场景已更新」

### Scenario: 改挂分组也算几何变化
- GIVEN 画布上有某台摄像机的白模图和线稿
- WHEN 助手在同一次修改里把两根柱子移进一个旋转过的分组，并新增了一台摄像机
- THEN 两张图都显示「场景已更新」，即使柱子在画面中的位置没变

### Scenario: 改回原样不再提示
- GIVEN 导出后摄影师移动了一根柱子，导出图显示「场景已更新」
- WHEN 把柱子移回原位
- THEN 导出图不再显示「场景已更新」

### Scenario: 摄像机被删除
- GIVEN 画布上有某台摄像机的导出图
- WHEN 摄影师删除了这台摄像机
- THEN 导出图显示「场景已更新」

### Scenario: 环境只影响材质光照图
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图
- WHEN 摄影师改了太阳高度，打开了雾，或在物理天空下改了地点、时刻、大气参数或太阳的亮度和色温
- THEN 只有材质光照图显示「场景已更新」

### Scenario: 灯光和材质只影响材质光照图
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图
- WHEN 摄影师改了一盏灯的颜色或半径，或换了一个槽位的材质
- THEN 只有材质光照图显示「场景已更新」

### Scenario: 曝光只影响材质光照图
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图，天空是程序化天空
- WHEN 摄影师调了曝光补偿
- THEN 只有材质光照图显示「场景已更新」；调回原值后不再显示

### Scenario: 物理天空下改摄像机曝光
- GIVEN 物理天空，画布上有摄像机 A 和摄像机 B 的材质光照图
- WHEN 摄影师改了摄像机 A 的快门，或把 A 切成环境测光、改了 A 的补偿
- THEN 只有 A 的材质光照图显示「场景已更新」；改「渲染」选项卡里默认摄像机的曝光（模式、补偿、默认曝光值）时，两张图都不显示

### Scenario: 景深参数不影响线稿
- GIVEN 一台打开了景深的摄像机，画布上有它的白模图、线稿和材质光照图
- WHEN 摄影师改了光圈，或移动了对焦物件
- THEN 白模图和材质光照图显示「场景已更新」，线稿不显示；景深关闭时改光圈，天空不是物理天空则三张图都不显示，是物理天空则只有材质光照图显示

### Scenario: 渲染器只影响材质光照图
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图，场景一直用工作台
- WHEN 摄影师把渲染器换成实时 GI
- THEN 只有材质光照图显示「场景已更新」；换回工作台后不再显示

### Scenario: 改输出分辨率不提示
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图
- WHEN 摄影师把输出分辨率从 2K 改成 4K
- THEN 三张图都不显示「场景已更新」

### Scenario: 不影响画面的修改不提示
- GIVEN 画布上有某台摄像机的白模图和线稿
- WHEN 只新加、删除或调了另一台摄像机，加了或删除一盏灯光，改了场景标题、显示模式、曝光补偿、默认摄像机的曝光，或者某个槽位的材质
- THEN 导出图不显示「场景已更新」

### Scenario: 换了图或场景没了就不再提示
- GIVEN 一张导出图之后场景有过几何修改
- WHEN 摄影师换掉了这个节点的图片内容，或场景已被删除
- THEN 不显示「场景已更新」

### Scenario: 实时 GI 加入屏幕外间接光后提示一次
- GIVEN 画布上有渲染器为实时 GI 的材质光照图，以及同一场景的白模图、线稿和另一个工作台场景的材质光照图，都是加入屏幕外间接光之前导出的
- WHEN 加入屏幕外间接光的版本上线后打开画布
- THEN 只有实时 GI 的材质光照图显示「场景已更新」；重新导出后不再显示；其余的图都不显示

### Scenario: 加入光源尺寸后提示一次
- GIVEN 加入光源尺寸之前导出的三张材质光照图：场景 A 有一盏聚光，场景 B 没有灯、天空是程序化天空，场景 C 没有灯、天空是 HDRI；另有场景 A 的白模图和线稿
- WHEN 加入光源尺寸的版本上线后打开画布
- THEN 场景 A 和场景 B 的材质光照图显示「场景已更新」，工作台和实时 GI 都是如此；重新导出后不再显示；场景 C 的材质光照图、场景 A 的白模图和线稿都不显示

### Scenario: 只改一个分镜不影响其他分镜的图
- GIVEN 画布上有分镜 1、2、3 的白模图，主体的位置有关键帧
- WHEN 摄影师只在分镜 2 移动主体并插入关键帧
- THEN 只有分镜 2 的白模图显示「场景已更新」

### Scenario: 布景修改影响所有分镜
- GIVEN 画布上有分镜 1、2、3 的白模图
- WHEN 摄影师移动了一根没有关键帧的柱子
- THEN 三张图都显示「场景已更新」

### Scenario: 挪动分镜不提示
- GIVEN 画布上有分镜 2 的白模图
- WHEN 摄影师把分镜 2 拖到时间线的另一帧
- THEN 不显示「场景已更新」

### Scenario: 换绑摄像机提示
- GIVEN 画布上有分镜 2 的白模图，分镜 2 绑定摄像机 A
- WHEN 摄影师复制出一台参数和位置完全相同的摄像机 B，把分镜 2 换绑到 B
- THEN 分镜 2 的白模图显示「场景已更新」

### Scenario: 分镜被删除
- GIVEN 画布上有分镜 2 的白模图
- WHEN 摄影师删除分镜 2
- THEN 这张图显示「场景已更新」

### Scenario: 旧导出图不受影响
- GIVEN 本次上线前导出的白模图、线稿和材质光照图
- WHEN 上线后打开画布
- THEN 过时状态与上线前完全相同；之后给场景加分镜和关键帧，只有改变第 0 帧画面的修改才让它们显示「场景已更新」
