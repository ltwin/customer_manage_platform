## creative/library: ADD 导入外部模型

摄影师可以把外部的静态 `.glb` 模型导入资产库，之后像其他模型资产一样放进场景。只收资源全部内嵌的 `.glb`。导入在浏览器里完成换算：材质换成槽位分配，贴图拆成账号的图片，压缩或量化过的几何先还原；对话框列出换算结果和被忽略的部分，摄影师确认后才上传。

- **入口**：资产库页面和资产库抽屉的「导入」（也可以把 `.glb` 拖进去）、编辑器资产面板的「导入模型」、编辑器「添加 > 导入模型…」（导入后直接放进场景）。
- **换算**：基础色、ORM、法线、自发光贴图和透明方式都按 glTF 的含义换算；只用顶点色上色的模型打开「顶点色」；贴图的平移、缩放、旋转烘进 UV。第二套 UV 的贴图、形态键、动画、灯光和相机丢掉并提示；镜像或钳制寻址的贴图在 UV 越界时按重复显示并提示。超出上传上限的图片会缩小，透明图片和法线等数据贴图保持无损。
- **拒绝**：引用外部文件的模型（提示重新导出为内嵌资源的 GLB）、带骨骼蒙皮的模型（后续版本支持）、KTX2 贴图、超过 32 个材质、超过 64 张图片、超出模型的面数和大小上限时，对话框说明原因，不上传。
- **原点**：缺省保留文件里的原点；可以勾选「原点移到底面中心」。
- **来源与授权**：记录原文件名，以及摄影师填写的授权说明（用文件里的版权信息预填）和来源页面；导入后在资产查看浮窗和场景属性栏里显示。
- **导入的模型没有代码**：不能改参数和代码，可以换材质、做面级材质分配；放进场景后的修改不影响资产库里的资产。助手可以找到、放置和换材质，不能改代码。
- **保存到资产库**：上传期间可以取消，取消后资产库不变、已上传的文件被丢弃。开始保存后不能取消；网络中断时自动重试同一次保存，不会建出两份。同一个文件导入两次是两份资产。

### Scenario: 导入带贴图的道具
- GIVEN 一个带基础色、ORM、法线和自发光贴图的 `.glb`
- WHEN 在资产库页面点「导入」选中它，确认换算结果并填写标题
- THEN 资产库出现这个模型，缩略图带贴图；拖进场景后，材质预览和最终渲染里贴图和发光正确

### Scenario: 换算结果可见
- GIVEN 一个带动画和形态键、有一张贴图用第二套 UV 的 `.glb`
- WHEN 选中它导入
- THEN 对话框列出被丢掉的动画、形态键和那张贴图；确认后照常导入

### Scenario: 压缩过的模型
- GIVEN 一个用 Draco 压缩的 `.glb`
- WHEN 导入
- THEN 导入成功，画面与未压缩的版本相同

### Scenario: 带骨骼的模型
- GIVEN 一个带蒙皮的角色 `.glb`
- WHEN 选中它导入
- THEN 对话框说明「带骨骼的模型将在后续版本支持」，不上传任何文件

### Scenario: 来源与授权
- GIVEN 一个 `asset.copyright` 写着作者和许可的 `.glb`
- WHEN 导入
- THEN 授权说明已预填；导入后在查看浮窗和属性栏里能看到原文件名、授权说明和来源页面，看不到参数和代码

### Scenario: 放进场景后修改
- GIVEN 场景里放着一个导入的模型
- WHEN 给它做面级材质分配
- THEN 场景里的模型变了，资产库里的资产和缩略图不变

### Scenario: 助手不能改导入模型的代码
- GIVEN 场景里有一个导入的模型
- WHEN 助手对它调用 `write_model`
- THEN 工具返回「导入的模型没有代码，只能换材质或摆放」，场景不变

### Scenario: 取消导入
- GIVEN 导入正在上传
- WHEN 摄影师点取消
- THEN 资产库不变，已上传的文件被丢弃

### Scenario: 保存时网络中断
- GIVEN 服务端已经建好资产，但响应没有回到浏览器
- WHEN 导入自动重试
- THEN 拿到同一个资产，资产库里只有一份

### Scenario: 引用外部文件
- GIVEN 一个图片放在 `.glb` 旁边另一个文件里的模型
- WHEN 选中它导入
- THEN 对话框提示「模型引用了外部文件，请在 Blender 里重新导出为内嵌资源的 GLB」，不上传任何文件

## creative/scene: MODIFY 材质贴图

原理化 BSDF 的槽位可以配六种贴图：基础色、法线、糙度、金属度、AO、自发光，与 Blender 原理化 BSDF 的同名输入相同。图片来自资产库、场景所在的画布，或者当场上传（上传的图片进资产库，以后还能再用）。基础色和自发光按 sRGB 读，其余按线性读；糙度、金属度、AO 可以选读哪个通道。

- **映射**：六张贴图共用一种映射。缺省是三平面投影，按设定的米尺寸平铺，物件缩放时贴图不跟着拉伸；也可以选模型 UV，按重复次数平铺。旋转和法线强度两种映射都能调。
- **自发光**：自发光贴图乘自发光颜色和强度，与 glTF 相同；自发光颜色为黑色时贴图不起作用。
- **顶点色**：原理化材质有「顶点色」开关，打开时基础色再乘模型的顶点色，与基础色贴图同时生效；模型没有顶点色时开关不起作用。
- **透明**：不透明、透明裁切或半透明混合。透明裁切按基础色贴图的透明通道乘不透明度挖空，阈值可调，投下的影子同样挖空；半透明混合时透明度随贴图变化。
- **生效范围**：材质预览、最终渲染、`render_view`、`lit` 导出、屏幕外反射和探针 GI 都体现贴图；白模和线稿与以前一样不看材质。
- **场景持有图片**：场景引用的图片不会因为原图从画布或资产库删掉而失效，场景的所有修订都不再引用它之后才按现有规则回收。一个场景最多引用 64 张不同的图片。
- **等图片**：视口先按材质参数画，图片到了再重绘；离屏出图等图片加载完才渲染，有图片加载失败时这张图失败并写明是哪张。
- 配贴图、换映射、改透明方式都是普通的场景修改，静默保存，可以撤销；复制材质会连同贴图、映射和透明方式一起复制。

### Scenario: 给方块配一张基础色贴图
- GIVEN 一个原理化材质的方块
- WHEN 在属性栏的材质槽里点基础色的「选择」，从资产库选一张图片
- THEN 方块按三平面投影显示这张图，每 1 米一块；Cmd+Z 撤销后回到没有贴图的样子

### Scenario: 从画布选图或当场上传
- GIVEN 一个在画布上打开的场景
- WHEN 在选图框里切到「画布」选一张画布上的图片，或者切到「上传」选一个本机文件
- THEN 图片配到槽位上；上传的图片同时出现在资产库里

### Scenario: 缩放物件，贴图尺寸不变
- GIVEN 一个配了三平面贴图的方块
- WHEN 把方块放大两倍
- THEN 贴图块的大小不变，方块上的块数变多

### Scenario: 模型没有 UV
- GIVEN 一个不带 UV 的代码模型
- WHEN 把它的槽位映射方式改成「模型 UV」
- THEN 面板提示「这个模型没有 UV，按三平面显示」，视口按三平面投影显示，不出错图

### Scenario: 树叶面片挖空
- GIVEN 一个面片，基础色贴图带透明通道
- WHEN 透明方式选「透明裁切」
- THEN 透明的部分被挖空，地上的影子也有同样的镂空；从镜面反射里看也是挖空的

### Scenario: 没有贴图时选透明裁切
- GIVEN 一个没有基础色贴图的槽位
- WHEN 透明方式选「透明裁切」
- THEN 面板提示「没有透明贴图，裁切只看不透明度」

### Scenario: 原图删掉之后
- GIVEN 场景里一个槽位用了画布上的一张图片
- WHEN 摄影师把这张图片从画布和资产库都删掉
- THEN 场景照常显示这张贴图，再打开也一样

### Scenario: 图片不可用
- GIVEN 场景里一张贴图的图片已经不能读取
- WHEN 打开场景
- THEN 那个槽位的贴图旁显示「图片不可用」，悬停说明原因；渲染按没有这张贴图处理，其他贴图照常

### Scenario: 导出时有图片加载失败
- GIVEN 一个带贴图的场景，其中一张图片加载失败
- WHEN 导出 `lit` 图或执行 `render_view`
- THEN 这张图失败，原因写明是哪张图片，不出缺贴图的图

### Scenario: 自发光贴图
- GIVEN 一个原理化材质的方块，自发光颜色为白色
- WHEN 在材质槽的「自发光」里选一张图片
- THEN 图片亮的部分发光，最终渲染和 `lit` 导出里同样发光；把自发光颜色改成黑色后不再发光

### Scenario: 顶点色
- GIVEN 一个带顶点色的导入模型，槽位是原理化材质
- WHEN 打开「顶点色」
- THEN 模型按顶点色上色，最终渲染、镜面反射和探针 GI 里一致；关掉后回到纯色

### Scenario: 旧场景不变
- GIVEN 本次上线前保存的、带贴图的场景
- WHEN 打开它并导出 `lit` 图
- THEN 画面与上线前相同，已有导出图的过时状态不变
