## creative/scene: ADD 姿态模式

摄影师可以给带骨骼的角色（内置素体和导入的角色）摆姿态。操作照搬 Blender 的姿态模式：按 Tab 打开模式轮盘选「姿态模式」，视口画出骨骼，点选骨骼后用 R 旋转，拖动手或脚时手臂、腿用 IK 跟着解出来。姿态存进场景：骨骼没有关键帧时改的是所有分镜共用的姿态；按 I 给选中的骨骼插入关键帧后，姿态按分镜变化，规则与其他属性的关键帧相同。

- **模式轮盘**：Tab 打开轮盘，里面有物体模式、编辑模式（面编辑）和姿态模式。按住 Tab，指针指向某一项再松开，进入那一项；没有指向任何一项就松开，轮盘关闭、模式不变。轻按 Tab，轮盘常亮，用鼠标点选某一项才生效，再按 Tab 关闭。活动物件不支持的模式不显示：带骨骼的角色没有编辑模式，没有骨骼的物件没有姿态模式。视口顶栏也能切换模式。
- **选择**：单击骨骼选中，Shift + 单击加选或去掉，A 全选，Alt + A 全不选。姿态模式下其他物件不可选。属性栏列出选中的骨骼，用颜色标出有关键帧、本帧是关键帧和已改未记录。
- **旋转（FK）**：R 旋转选中的骨骼，X / Y / Z 锁轴（按两次是骨骼自己的轴），可以直接输入角度，回车或左键确认，右键或 Esc 取消。子骨骼跟着动。骨骼不能缩放；除了骨盆，骨骼也不能挪开。
- **IK**：对手或脚按 G，或直接拖动选中的手、脚，上臂与前臂（大腿与小腿）解出来让手（脚）跟着指针，肩、髋不动，肘、膝保持原来弯曲的方向；够不着时伸直指向目标。对骨盆按 G 是移动骨盆。
- **复制与镜像粘贴**：Ctrl + C 复制选中骨骼的姿态，Ctrl + V 粘贴到同名骨骼，Ctrl + Shift + V 镜像粘贴到对侧。剪贴板只在这个页面里有效，可以跨角色粘贴。
- **清除**：Alt + R 把选中骨骼的旋转清回静止姿势，Alt + G 清除骨盆的移动。
- **非人形骨架**：按非人形骨架导入的角色可以选骨骼、用 R 旋转、复制粘贴，没有 IK 和镜像粘贴。
- **保存**：每次确认是一条普通的场景修改：静默保存，Cmd+Z 只撤销自己的操作，其他标签页同步出现。
- **拖动时的画面**：拖动骨骼时镜中的倒影和墙上的间接光跟着当前姿态走，不会留下旧姿态的残影；面数很多的角色在拖动期间暂时不出现在倒影和间接光里，松手后回来。松手后几帧内画面与导出图一致。

## creative/scene: MODIFY 带骨骼的角色

带骨骼的角色（导入的角色和内置素体）在视口的三种显示模式、最终渲染、实时 GI、回看和导出里都画成蒙皮网格，并按当前帧的姿态显示（见「姿态模式」）；没摆过姿态的角色按静止姿势显示。

- **一致**：镜中的倒影、墙上的间接光、包围盒、贴地吸附和线稿都按角色当前的姿态计算，与视口里看到的相同。
- **VRM 约束**：VRM 角色里由约束驱动的扭转骨，随手的转动一起转。
- **代码模型不带骨骼**：用代码生成的模型不能带骨骼，提交时被拒绝。
- **暂不做面级材质分配**：带骨骼的角色可以给整个槽位换材质，但还不能把一部分面分到别的槽位；模式轮盘里没有「编辑模式」。
- **换模型**：男、女素体互换时姿态和骨骼关键帧都保留。换成没有人形骨骼的模型，或者骨架不同的模型时，对不上的姿态被去掉并提示，撤销可以找回。
- **助手**：助手读场景时能看到各角色的姿态和哪些骨骼有关键帧，指定分镜读取时看到的是这一帧的姿态。助手现在还不能摆姿态，只能清除骨骼的关键帧。
- **已知局限**：没有扭转骨的角色（包括内置素体），手绕前臂大角度转动时手腕会收窄。

### Scenario: 角色在 GI 下的倒影

## creative/scene: MODIFY 内置素体

编辑器内置一男一女两个素体，所有账号都能直接放进场景。素体本身不能修改，场景里的实例可以移动、缩放、换材质、摆姿态（见「姿态模式」）。

- **放入**：「添加 > 素体」或资产面板的「素体」。放入时带上素体自己的皮肤、眼睛和眉毛贴图。
- **在场景里**：属性栏显示「素体」和来源（Quaternius，CC0）。没有参数和代码，不能做面级材质分配，不能存入资产库；可以把女素体换成男素体，反之亦然，摆好的姿态保留。
- **换材质**：给素体的槽位换材质只改这个实例；撤销照常。
- **助手**：助手能在内置来源里搜到素体，读取它的要点和缩略图，放进场景；没写材质时自动带上素体自己的材质。
- **文件缺失**：素体文件暂时读不到时，视口显示占位并提示，导出失败并说明原因，其他物件照常。

### Scenario: 放入女素体
- GIVEN 任意账号打开一个场景
- WHEN 选「添加 > 素体 > 女素体」
- THEN 女素体站在地面上，材质预览、最终渲染和导出里皮肤、眼睛、眉毛的贴图都正确

### Scenario: 素体只读
- GIVEN 场景里放着一个女素体
- WHEN 查看它的属性栏
- THEN 能看到「素体」和来源，看不到参数、面级材质分配和「存入资产库」；可以缩放、换材质

### Scenario: 换成男素体
- GIVEN 场景里放着一个女素体
- WHEN 在属性栏把模型换成男素体
- THEN 原位置换成男素体，带男素体的材质（之前给女素体换过的材质不保留）；撤销后回到女素体和原来的材质

### Scenario: 助手放入素体
- GIVEN 助手在为一个场景搭布景
- WHEN 它在内置来源里搜「女」，把结果放进场景
- THEN 场景里出现带贴图的女素体，回看图里能看到它

## creative/scene: MODIFY 分镜与关键帧

一个场景可以有多个分镜。分镜是时间线上的一个标记，有名称、帧号和绑定的摄像机；切到一个分镜，就是跳到这一帧并从它的摄像机取景。物件的位置、旋转、缩放、可见性，摄像机的焦距、传感器、画幅、景深、光圈、对焦和曝光，以及带骨骼角色的每根骨骼（旋转，骨盆另有移动）可以打关键帧；有关键帧的属性按帧变化，没有关键帧的属性所有分镜共用，所以布景在各分镜里天然一致。交互参照 Blender 的时间线：I 插入关键帧，自动关键帧开关默认关闭，属性栏用颜色区分有关键帧、本帧是关键帧和已改未记录。

- **分镜互不影响**：有关键帧的属性在每个分镜的帧上都有关键帧，所以改一个分镜不会带动别的分镜。第一次给某个属性插关键帧时（在哪一帧都一样），其他分镜自动记下修改前的值，这个值也是这个属性的默认状态；挪动分镜时关键帧跟着走；删除分镜时删掉它那一帧的关键帧。
- **新建与复制分镜**：新建分镜从默认状态开始，只属于别的分镜的物件不出现；复制分镜与被复制的分镜完全相同。
- **改基础值还是改这一镜**：没有关键帧的属性改了就是所有分镜都变；有关键帧的属性改了但没插关键帧，切到别的分镜时改动丢弃。
- **只在当前分镜显示**：物件可以设成只在当前分镜可见，其他分镜和之后新建的分镜里都隐藏。
- **清除动画**：删掉一个属性的全部关键帧，属性保持当前帧的值，所有分镜共用。
- 以上都是普通的场景修改：静默保存，Cmd+Z 只撤销自己的操作，其他标签页同步出现。撤销或恢复历史版本后若有分镜缺少关键帧，时间线上会标出来。
- 不做动画播放、曲线编辑和视频导出；灯光、天空、雾不能打关键帧。

### Scenario: 建分镜
- GIVEN 一个有 2 台摄像机的场景
- WHEN 摄影师在时间线上新建 3 个分镜，分别绑定摄像机
- THEN 时间线上出现 3 个标记，按帧序编号；点击任一个，视口跳到这一帧并从它的摄像机取景；刷新后保持

### Scenario: 先建镜头、后加动画
- GIVEN 3 个分镜已经建好，主体的位置没有关键帧
- WHEN 摄影师切到分镜 2，移动主体并按 I
- THEN 只有分镜 2 的主体在新位置；切到分镜 1、3，主体在原位

### Scenario: 复制分镜
- GIVEN 主体在分镜 2 有位置关键帧
- WHEN 复制分镜 2 得到分镜 4
- THEN 分镜 4 的主体与分镜 2 相同；之后改分镜 4 不影响分镜 2

### Scenario: 新建分镜从默认状态开始
- GIVEN 主体原在门口，在分镜 2 里被移到窗边并插了关键帧；分镜 3 里有一个只在当前分镜显示的人片
- WHEN 新建分镜 4
- THEN 分镜 4 的主体在门口，人片不出现

### Scenario: 先移动再按 I
- GIVEN 3 个分镜，主体的位置没有关键帧，自动关键帧关闭
- WHEN 摄影师在分镜 2 移动主体
- THEN 3 个分镜里的主体都跟着动（这是在改布景）
- WHEN 接着按 I
- THEN 分镜 1、3 的主体回到原位，只有分镜 2 在新位置

### Scenario: 在两个分镜之间插帧
- GIVEN 分镜在第 0、10 帧，主体的位置没有关键帧
- WHEN 把帧指针拖到第 5 帧，移动主体并按 I
- THEN 写入成功；两个分镜的主体都在原位

### Scenario: 挪动和删除分镜
- GIVEN 3 个分镜，主体在分镜 2 的位置与其他分镜不同
- WHEN 把分镜 2 拖到另一帧
- THEN 分镜 2 的画面不变
- WHEN 删除分镜 2
- THEN 分镜 1、3 的画面不变

### Scenario: 只在当前分镜显示
- GIVEN 3 个分镜
- WHEN 在分镜 3 里添加一个物件，选「只在当前分镜显示」
- THEN 它只出现在分镜 3；之后新建、挪动或删除别的分镜，它仍然只在分镜 3；复制分镜 3 得到的分镜会带上它

### Scenario: 摄像机参数按分镜
- GIVEN 分镜 1、2 共用一台 35 mm 的摄像机
- WHEN 在分镜 1 把焦距改成 85 mm 并插入关键帧
- THEN 分镜 1 是 85 mm，分镜 2 仍是 35 mm

### Scenario: 骨骼按分镜
- GIVEN 分镜 1、2 里的素体都垂着手臂，骨骼没有关键帧
- WHEN 在姿态模式里选中左上臂，在分镜 1 抬起它并按 I
- THEN 分镜 1 抬着左臂，分镜 2 仍垂着；其他骨骼在两个分镜里仍然一致

### Scenario: 已改未记录
- GIVEN 主体的位置有关键帧
- WHEN 摄影师移动主体但不按 I
- THEN 属性栏的位置显示「已改未记录」的颜色
- WHEN 切到别的分镜再切回来
- THEN 主体回到关键帧的位置

### Scenario: 改布景
- GIVEN 3 个分镜，桌子没有关键帧
- WHEN 摄影师移动桌子
- THEN 3 个分镜里的桌子都在新位置

### Scenario: 清除动画
- GIVEN 主体的位置在 3 个分镜里各不相同
- WHEN 在分镜 2 对位置「清除动画」
- THEN 主体在 3 个分镜里都停在分镜 2 的位置

### Scenario: 有未记录的改动时导出
- GIVEN 主体的位置有关键帧，摄影师移动了主体但没按 I
- WHEN 点「导出」
- THEN 先提示有未记录的改动，可以插入关键帧后导出、放弃改动后导出或取消；选插入关键帧时，导出图里主体在新位置

### Scenario: 撤销分镜操作
- GIVEN 摄影师刚删除了分镜 2
- WHEN 按 Cmd+Z
- THEN 分镜 2 和它那一帧的关键帧都回来

### Scenario: 缺少关键帧的写入被拒绝
- GIVEN 主体的位置有关键帧
- WHEN 一次修改让分镜 2 的帧上没有这个属性的关键帧（例如外部客户端只删了这一个关键帧）
- THEN 修改被拒绝，场景不变，错误指出缺口
