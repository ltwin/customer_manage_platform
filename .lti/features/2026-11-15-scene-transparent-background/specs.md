## creative/scene: MODIFY 渲染器与输出分辨率

属性区参照 Blender 分成「渲染」「环境」「物件」三个选项卡。「渲染」里可以选渲染器和输出分辨率，开关「透明背景」（挂在输出分辨率旁，缺省关闭），调曝光，并看到当前的渲染后端。曝光在程序化天空和纯色天空下是曝光补偿，在物理天空下是默认摄像机的曝光（只用于视口的自由视角和助手的临时视点）：自动或手动，自动时调补偿，手动时调默认曝光值（EV100）。渲染器有工作台、实时 GI，以及还不能选的「路径追踪 · 规划中」：工作台是标准的光栅化渲染；实时 GI 在它之上加入物体之间的间接光反弹、反射和接触阴影：在支持的 WebGPU 设备上，间接光和反射都包括画面外的物体（见「实时 GI 的屏幕外反射」「实时 GI 的屏幕外间接光」），其余情况只计算画面里可见的表面。渲染器决定编辑器的最终渲染、助手的材质光照回看和材质光照导出的画面；白模、线框、材质预览和线稿总按工作台画，正交视图也按工作台显示。灯光图标、摄像机视锥、空物体等辅助对象在视口里照常显示，但不参与光照：不遮挡、不压暗周围。输出分辨率只决定导出图的长边；透明背景决定跟随场景设置的白模和材质光照导出里天空背景是否透明，以及编辑器的最终渲染视口是否显示棋盘格背景（线稿导出和助手回看始终不受影响；助手导出时也可按次单独指定是否使用透明背景，不改写场景设置）。这些都是场景的设置，静默保存，可以撤销，其他标签页和助手看到的一样。

### Scenario: 打开渲染选项卡
- GIVEN 摄影师在场景编辑视图里
- WHEN 点属性区的「渲染」
- THEN 看到渲染器（工作台、实时 GI、灰掉的「路径追踪 · 规划中」）、输出分辨率（1K、2K、4K、8K，注明长边像素）及旁边的「透明背景」开关、曝光和渲染后端（「WebGPU」或「兼容模式」）；渲染器是实时 GI 且本机没有画屏幕外的光照与反射时，渲染后端旁说明原因；天空是物理天空时，曝光一栏是默认摄像机的曝光：自动（缺省）显示补偿，手动显示「默认曝光（EV100）」并列出常见场景的参考值；否则是曝光补偿

### Scenario: 选中物件时切到物件属性
- GIVEN 摄影师停在「渲染」选项卡
- WHEN 在视口里选中一个物件，再取消选中
- THEN 选中时属性区切到「物件」，取消后回到「渲染」

### Scenario: 换成实时 GI

- GIVEN 渲染器是实时 GI
- WHEN 切到正交视图
- THEN 画面按工作台显示，视口角落提示「正交视图按工作台显示」；回到透视视图后恢复实时 GI

- WHEN 请助手「换成实时 GI，按 4K 导出」
- THEN 助手把渲染器和输出分辨率改掉，回看一次实时 GI 的画面，再导出长边 4096 的图；两项修改出现在这一轮的改动清单里

### Scenario: 路径追踪还不能选

- WHEN 打开渲染器下拉，或助手写入路径追踪
- THEN 下拉里这一项不能选；助手的写入被拒绝并说明还不支持

### Scenario: 开关透明背景可撤销并跨标签页同步

- WHEN 查看「透明背景」开关，将它打开后再按 Cmd+Z
- THEN 旧场景初始显示关闭；打开后静默保存，另一个标签页同步显示已打开；按 Cmd+Z 后回到关闭，另一个标签页随之同步

### Scenario: 请助手按透明背景导出或修改场景透明背景设置
- GIVEN 场景的「透明背景」开关处于关闭状态，摄影师在助手面板里
- WHEN 先请助手「导出透明背景的材质光照图」（即使导出期间另一个标签页切换了场景的「透明背景」开关），之后再请助手「把场景的透明背景打开」
- THEN 第一次请求时助手在导出工具里指定 `transparent_background: true`，导出透明背景的材质光照图并保留场景开关原值，另一标签页切换开关不触发这张图的过时提示。第二次请求时助手修改场景的透明背景设置，「渲染设置」出现在这一轮的改动清单里，可以撤回

### Scenario: 写入非布尔值的透明背景被拒绝
- GIVEN 客户端向场景命令接口提交透明背景修改
- WHEN 传入的值不是布尔值（如字符串、数字或空值）
- THEN 命令被拒绝（400），场景保持不变

## creative/scene: MODIFY 导出分镜到画布

摄影师或助手可以把场景按分镜导出成图，落成画布上的图片节点；没有分镜的场景按摄像机导出。每个分镜先按它的帧求出整个场景的状态，再用它绑定的摄像机出图。导出方式有白模（`clay`）、线稿和材质光照（`lit`）；每张图按摄像机（在这一帧的）画幅出图，长边按场景的输出分辨率（1K、2K、4K、8K 分别为 1024、2048、4096、8192 px，缺省 2K）。白模与编辑器的白模物体着色一致（开启透明背景时，白模导出为透明底，视口白模仍保留中性灰底），按工作台出图；材质光照与编辑器的最终渲染一致，按场景所选的渲染器出图。图片节点记录来源场景、修订、分镜和帧号（按摄像机导出时没有分镜）、摄像机和导出方式。

场景打开「透明背景」且导出方式勾选了白模或材质光照时，导出对话框在长边像素旁注明「白模、材质光照使用透明背景」（只勾选线稿时不显示）；助手调用导出工具（`export_shots`）时也可以按次显式指定 `transparent_background`，不改写场景文档且不受场景开关影响（省略时跟随导出时刻的场景设置）。透明背景导出时，白模和材质光照图里相机直接看到天空的像素（天空、纯色背景、太阳圆盘、夜空的星星和月亮）变为完全透明（`alpha = 0`），雾和空气透视只作用于物体、不在透明背景处残留雾色，而天空光、太阳、月光、环境反射和灯光对物体的照明以及金属、镜面映出的天空保持不变；抗锯齿边缘（含兼容模式无 MSAA 下的暗色剪影与实时 GI 运动前景边缘）、景深虚化边缘按覆盖率输出半透明，无历史残影，也不带天空色或黑色描边；玻璃等透射材质和体积物件保留场景内的物理透射、折射与反射，并对空背景输出供单通道 W3C `source-over` 合成使用的近似标量透明度（光滑玻璃后方完全落在不透明物体内部的区域照常显示后面的物体，磨砂玻璃跨越物体与天空轮廓的采样带平滑过渡为半透明，不对外部新背景做折射变形或分通道彩色吸收）。透明背景导出时，1K 至 8K 的白模与材质光照按选定分辨率编码为无损 PNG，解码保留透明度；线稿不受透明背景影响，始终是白底 PNG；不使用透明背景导出时，各导出方式的格式与画面不变。含透明像素的导出图（含服务端生成的大图展示图）在画布节点和大图预览里透出底色，不会变成黑底或白底。助手截图回看（`render_view`）不受透明背景影响，始终输出带背景的 JPEG。

### Scenario: 透明背景下导出白模、材质光照与线稿
- GIVEN 物理天空的院子场景，地面上有一个白色立方体和一个金属球，输出分辨率为 2K，打开「透明背景」
- WHEN 打开导出对话框查看勾选不同导出方式时的提示，并导出白模、材质光照和线稿

- THEN 背后只有天空的玻璃区域和有色体积区域均呈半透明（`0 < alpha < 255`），保留玻璃表面反射与体积散射色；光滑玻璃背后完全落在不透明物体内部的区域照常显示后面的物体（`alpha = 255`）；磨砂玻璃跨越后方物体与天空轮廓的过渡带呈平滑半透明（`0 < alpha < 255`），无天空色描边

### Scenario: 夜空不画出星星与月亮但保留月光

- WHEN 导出材质光照图
- THEN 星星和月亮不出现在导出图里（天空区域 `alpha = 0`），月光和夜空对地面与物体的照明照常保留

- WHEN 导出白模和材质光照

## creative/scene: MODIFY 导出图提示场景已更新

导出之后场景被修改，并且修改会改变这张图时，画布上的导出图显示「场景已更新」；改回原样后不再显示。按分镜导出的图，只看这个分镜那一帧求出的场景：只改别的分镜的关键帧不算，分镜挪到别的帧但画面不变也不算；分镜被删除、没有绑定摄像机、或换绑了另一台摄像机（即使参数相同）都算。按摄像机导出的图（包括本次上线前的图）按第 0 帧求出的场景判断，没有关键帧的场景与以前完全相同。只是提示，不改图片。哪些修改算数按导出方式区分：线稿只看几何和这台摄像机，白模另看景深和透明背景，材质光照再看环境、灯光、材质、曝光和渲染器。助手导出时若按次显式指定了 `transparent_background`，该节点的透明背景取值固定按导出时指定的值计算，不受之后切换场景「透明背景」开关影响（几何、摄像机、灯光、材质等其他相关修改仍照常提示）。物理天空下，材质光照的曝光是这台摄像机自己的曝光：自动时是模式和补偿，手动时是 ISO、快门和光圈；「渲染」选项卡里默认摄像机的曝光不算；其他天空下是曝光补偿。输出分辨率不算。透明背景的有效值为关闭状态时不改变已有指纹，本次上线前导出的图不会因上线变为过时。实时 GI 的画面因渲染器本身的改进而明显变化时（例如加入屏幕外的间接光），已有的实时 GI 材质光照图各提示一次，重新导出后恢复；工作台的材质光照图、白模和线稿不受影响。灯光的画法本身改变时（例如加入光源尺寸），有灯光对象、或天空的太阳会投影的场景，已有的材质光照图各提示一次，工作台和实时 GI 都是如此；其余场景的材质光照图，以及白模和线稿，不受影响。

## creative/scene: MODIFY 四种显示模式

编辑视图参照 Blender 的视口着色，提供线框、白模、材质预览、最终渲染四种显示模式。白模与白模导出的物体着色一致，最终渲染与材质光照导出一致。场景打开「透明背景」时，最终渲染模式下视口背景显示棋盘格（物体受天空、太阳和场景灯光的照明与反射不变），而白模、材质预览仍保留各自原有的中性灰背景（不显示棋盘格；白模导出在开启透明背景时为透明底），线框保持不变。白模用固定的工作室光，只用来看结构，不受场景的天空、太阳、环境光、雾和灯光影响。白模、材质预览和最终渲染按 AgX 色调映射：明亮的饱和色（落日、彩色灯光）越亮越接近白色，但不偏成别的颜色。显示模式是本机的查看状态，按场景记住，不写进场景，也不算一步编辑。

### Scenario: 切换显示模式
- GIVEN 场景里有分配了材质的物件和一盏投射阴影的点光
- WHEN 摄影师按 `Z`，在弹出的菜单里依次选线框、白模、材质预览、最终渲染
- THEN 线框只显示物件的轮廓边，能看到被挡住的物件，框选时被挡住的物件也会选中，点击仍选中最前面的表面；白模是统一的浅灰材质，背景是中性灰，看不到天空，灯光不影响画面；材质预览显示材质，光照是固定的中性室内光；最终渲染显示材质，点光照亮周围并投下阴影

- THEN 画面不变
