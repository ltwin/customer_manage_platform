## creative/scene: ADD 在助手里引用场景和物件

摄影师在助手输入框里用 @ 引用画布上的 3D 场景，也可以展开场景的物件列表，引用其中一个或多个物件，不必打开场景编辑器。引用按出现位置嵌在消息正文里；服务端冻结发送时的场景标题和物件名，助手据此直接定位到场景和物件。一条消息最多引用 5 个不同的场景；每个引用最多 50 个物件，同一个场景可以分成几个引用，各自不超过 50 个；整条消息还受消息长度上限约束。

### Scenario: 只引用场景
- GIVEN 画布上有「客厅」「卧室」两个场景，摄影师停在画布视图
- WHEN 输入 @，选中「卧室」并回车，然后发送「把灯光改成暖色」
- THEN 助手直接修改「卧室」的灯光，不需要按标题去查找；「客厅」不变

### Scenario: 在物件列表里多选
- GIVEN 摄影师在 @ 菜单里展开了「客厅」的物件列表
- WHEN 用单击、Cmd/Ctrl + 单击、Shift + 单击，或在列表里拖过连续多行，选中若干物件后确认
- THEN 正文里插入「客厅 · 物件名…」引用标签；发送后，助手改的正是这些物件

### Scenario: 按语序分批修改
- GIVEN 3D 编辑器打开着「客厅」
- WHEN 摄影师写下「把 @客厅·台灯、主光 改成金属，@客厅·沙发、茶几 改成胡桃木」并发送
- THEN 台灯和主光改成金属，沙发和茶几改成胡桃木，两批物件互不混淆

### Scenario: 引用的物件已被删除
- GIVEN 引用了「台灯」，发送前「台灯」已被删除
- WHEN 发送消息
- THEN 运行照常开始；助手得知引用中有一个物件（按物件 ID）发送时已不在场景里，先向摄影师确认，不猜替代对象；对话历史里这个物件显示为「已删除的物件」

### Scenario: 引用的场景已不可用
- GIVEN 引用的场景已进入回收站，或不属于当前账号
- WHEN 发送消息
- THEN 不创建运行；输入框保留草稿，提示「引用的场景已不可用，请重新选择」

### Scenario: 历史里显示发送时的名称
- GIVEN 一条消息引用了「客厅 · 台灯」
- WHEN 之后「台灯」被改名
- THEN 对话历史里这条消息仍显示「客厅 · 台灯」

## creative/scene: ADD 选中进入待选引用

选中的内容会在助手输入框的光标位置变成一个置灰的待选引用，有两种来源：

- 画布视图里，恰好点选了一个可引用的节点（文本、图片或场景）。
- 3D 编辑器里，当前选中的全部物件，合成一个引用。

摄影师点进输入框后，待选引用转为正式的 @ 引用。转正之前，如果选中发生变化，待选引用随之替换；取消选中时，它消失。待选引用只在选中发生变化时产生，即从未选中变为选中、或从选中 A 变为选中 B；点进输入框后再切出去，只要选中没变，就不会新增待选引用；在画布和 3D 编辑器之间切换时，待选引用会被移除。待选引用不会被保存，也不会被发送。3D 编辑器不再在输入框上方显示浮动的「选中物件」标签。

### Scenario: 点选后转正
- GIVEN 助手面板开着，摄影师停在画布视图
- WHEN 在画布上点选图片「参考图1」，再点进助手输入框
- THEN 输入框里先出现置灰的「参考图1」，点进输入框后变成正式引用，光标停在它后面

### Scenario: 待选时替换
- GIVEN 输入框里有一个尚未转正的待选引用「参考图1」
- WHEN 摄影师在画布上点选场景「客厅」
- THEN 待选引用变成「客厅」，输入框里不再有「参考图1」

### Scenario: 接在已输入的文字后面
- GIVEN 正文已有「把 @参考图1 的色调用在」，光标在末尾
- WHEN 摄影师在画布上点选「客厅」，再点回输入框
- THEN 「客厅」出现在「用在」后面，并转为正式引用；之前的引用和文字不变

### Scenario: 选中没变不新增
- GIVEN 摄影师点选「参考图1」后点进输入框，「参考图1」已转为正式引用
- WHEN 切出输入框，「参考图1」仍保持选中
- THEN 不新增待选引用；之后改为选中别的节点，才会产生新的待选引用

### Scenario: 不产生待选引用的情况
- GIVEN 点选的是视频、音频、链接或分组节点，或者助手面板是收起的
- WHEN 摄影师点选它
- THEN 不产生待选引用

## creative/scene: ADD 在 @ 菜单里搜索

助手输入框的 @ 菜单顶部有搜索框，可以按标题、节点类型和文本内容的开头搜索画布节点。结果按类型分组，画布上当前选中的节点排在最前面。场景的物件列表也可以按名称搜索。

### Scenario: 节点很多时搜到目标
- GIVEN 画布上有 200 个可引用的节点
- WHEN 摄影师打开 @ 菜单，在搜索框里输入几个字
- THEN 列表只剩下匹配的节点，按类型分组；按回车插入当前高亮的一项

### Scenario: 在物件列表里搜索
- GIVEN 场景「客厅」有上百个物件
- WHEN 在它的物件列表里输入「灯」
- THEN 只显示名称含「灯」的物件以及它们的上级；清空搜索后，之前选中的物件仍保持选中

### Scenario: 编辑器里分批选中
- GIVEN 3D 编辑器打开着「客厅」，正文里已有「把 @客厅·台灯、主光 改成金属，」
- WHEN 摄影师在视口里选中「沙发」和「茶几」，再点回输入框
- THEN 光标处出现「客厅 · 沙发、茶几」，并转为正式引用；前一个引用不变

### Scenario: 编辑器选中变化时替换待选引用
- GIVEN 3D 编辑器里有一个待选引用「客厅 · 台灯」，尚未转正
- WHEN 摄影师改为选中「主光」，或者按 Esc 清空选中
- THEN 待选引用变成「客厅 · 主光」，或者消失；只拖动物件、选中集合没有变化时，待选引用不变

## creative/scene: MODIFY 助手搭建和修改场景

助手可以读场景、改场景、用几何代码生成模型、截图回看。它可以在画布上新建场景节点，摄影师不打开场景也能让它搭建。需要页面完成的工作（烘焙模型、截图）由服务端派成任务，交给打开着的创意空间页面执行。

### Scenario: 在编辑视图里请助手搭景
- GIVEN 摄影师打开场景编辑视图
- WHEN 用一段描述请助手搭景
- THEN 助手写出若干程序化物件并摆放，过程中至少回看一次截图；物件陆续出现在编辑器里

### Scenario: 不打开场景也能搭建
- GIVEN 摄影师停在画布视图，没有打开任何场景
- WHEN 请助手搭一个场景
- THEN 助手在画布上新建场景节点并完成搭建，任务由画布页在后台执行；助手面板里能看到回看的截图；之后打开场景，看到搭好的结果

### Scenario: 编译失败由助手自己修
- GIVEN 助手写的几何代码有错误、超时或超出上限
- WHEN 页面执行烘焙任务
- THEN 助手收到错误信息和行号，运行不失败，场景不变；助手可以修改代码重试

### Scenario: 点选物件让助手改
- GIVEN 摄影师在编辑视图里选中了一根柱子，它和别的柱子共用同一个模型；点进助手输入框后，这根柱子成为正文里的引用
- WHEN 接着输入「改成断裂的」并发送
- THEN 只有这根柱子改变，先分叉出新模型；只改参数时助手不重写代码

### Scenario: 不能看图的模型没有截图工具
- GIVEN 当前选用的模型不支持图片输入
- WHEN 助手工作
- THEN 助手没有截图回看这个工具
