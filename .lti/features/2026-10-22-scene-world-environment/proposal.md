# Epic: scene-world-environment：3D 场景的世界环境（物理天空、曝光、夜空、空气透视与体积）

永久需求文档：本 Epic 的目标、边界和交付计划。
- 整体方案见 design.md，目标契约见 contracts.md。
- 项目 `.lti/contracts/` 记录当前已交付的事实。
- 探索共识见 `discovery/brainstorm.md`。
- 本 Epic 建在两个前序 Epic 之上：
  - `scene-editor-3d`：编辑器、导出、材质与光照。
  - `scene-webgpu-renderer`：WebGPU 渲染器与实时 GI。

## 目标

现在的天空是 Preetham 解析模型，只有 3 个参数：太阳高度、方位和浑浊度。它有几处做不到：
- 太阳接近地平线时色调失真，没有晨昏蒙影和夜晚。
- 场景亮度靠手动曝光补偿凑出来，正午和黄昏之间的亮度差并不真实。
- 雾只有全局的线性 `Fog`。

摄影师需要按实拍的地点和日期预演光线；专业创作者希望环境像 DCC 软件一样可信（owner 2026-10-22）。

本 Epic 完成后：

1. **白模只看结构，色调映射改用 AgX**：
   - 白模改用完全固定的工作室光，不画天空，不受太阳、环境光、雾和灯光影响，与传统 DCC 软件的实体视图一致。光影氛围交给最终渲染。
   - 色调映射从 ACES Filmic 换成 AgX（Blender 4 起的默认），明亮的饱和色（日落、灯光）不再偏色和褪色。
2. **物理天空**：天空新增「物理天空」模式，与现有的程序化天空、纯色并列。
   - 选地点（城市或经纬度）、日期和当地时刻，并设定场景的正北方向，太阳就落在真实位置上。也可以切换为手动调太阳角度。
   - 天空颜色、太阳光颜色与强度、天空光都由同一套物理大气模型算出，覆盖晨昏蒙影。
   - 海拔、空气密度、尘埃密度和臭氧可以调，并有「晴朗 / 雾霾 / 高原 / 沙尘」等预设。
   - 太阳的亮度和色温可以调，用来在不改曝光的情况下调整光线。
3. **物理为底、观感优先**：物理天空下场景按真实照度计算，曝光是摄像机的功能（owner 2026-10-23，修订 v5）。CG 的亮暗宽容度有限，本产品服务于 CG 制作而不是现实模拟，物理计算是基础，默认观感优先于完全仿真：
   - 每台摄像机可选自动或手动曝光。自动曝光按场景的照度测光，再按「夜间压暗曲线」少补一些：入夜后画面平滑变暗，但只比正午暗 2–4 档，切到夜晚不用调曝光，视口也不会一片黑。自动曝光可以加减补偿。
   - 手动曝光用 ISO、快门和已有的光圈，光圈同时决定景深和亮度，按真实照度成像。
   - 视口的自由视角和助手的临时视点是「默认摄像机」，缺省自动曝光，也可以切成手动、用场景的默认曝光值（EV100）。新建的摄像机缺省自动曝光。
   - 夜色：入夜后画面渐进偏蓝、降饱和（日拍夜的调色惯例），强度可调，调到 0 为纯物理颜色。
4. **夜空**：太阳落下后，月亮按真实位置和月相出现，月光按物理计算；星空和银河按地点和时刻旋转。月亮和星空的亮度、色温可以调。默认设置下，无月的夜空是深蓝而不是黑色，银河和亮星可见（修订 v5）。
5. **空气透视**：远处景物随距离变蓝变淡，颜色来自同一套大气模型。可以开关，距离倍率可调，与全局雾、体积物件共存。
6. **体积物件**：新增有范围的体积物件，参照 Blender 中带体积散射和体积吸收的物体。太阳、聚光和点光都会照亮它，形成光束和阴影。
7. **助手**能写入以上全部设置，并用材质光照回看。
8. **为后续能力打底**：
   - 云层、天气和地表效果的数据位置和渲染接入点已经预留。
   - 大气 LUT 和体积定义可以被将来的路径追踪渲染器复用。

## 范围与非目标

- **范围**：
  - 白模固定工作室光（对所有天空模式）。
  - 色调映射改用 AgX：所有现在经 ACES Filmic 出图的显示模式和导出，并重新标定现有场景的亮度。
  - 物理天空：
    - 地点、日期、时刻、时区和正北方向；
    - 太阳的天文计算与手动模式；
    - 物理大气（Hillaire 2020）；
    - 大气参数与预设；
    - 太阳盘；
    - 太阳的亮度倍率与色温；
    - 天空光照（环境贴图）。
  - 物理单位：只在物理天空下使用。程序化天空和纯色天空保持现有标定。
  - 摄像机曝光：
    - 自动曝光（场景测光、夜间压暗曲线、补偿）与手动曝光（ISO、快门、光圈）；
    - 默认摄像机的曝光模式、补偿和默认曝光值；
    - 导出结果确定。
  - 夜空：
    - 月亮的位置、月相与月光；
    - 星表中的亮星；
    - 银河；
    - 月亮和星空的亮度与色温；
    - 夜色与夜空的观感调整（修订 v5）。
  - 空气透视：开关与距离倍率。
  - 体积物件：
    - 立方体或球体范围；
    - 散射颜色与密度、吸收颜色与密度、各向异性、边缘柔化；
    - 受光照亮并接收阴影。
  - 环境选项卡和摄像机属性的编辑界面。
  - 助手工具说明。
  - 渲染指纹和过时判断随之调整。
  - 天空、夜空和空气透视在 WebGPU 和 WebGL2 两个后端下都能运行。
- **非目标**（显式排除）：
  - 云层（参数与云型预设，如积雨云、层积云）、天气（雨、雪等）、地表附加效果（积水、潮湿、积雪、雪地痕迹）：远期另行规划（见 roadmap「远期」）。本 Epic 只保证数据位置和渲染接入点不会堵住它们。
  - 把现有程序化天空、纯色天空迁移到物理单位：它们保持现有的标定方式（除了 W1 的 AgX 重新标定），不改成物理单位。
  - 全局雾的退役：全局 `Fog` 长期保留，作为快速的风格化手段（owner 2026-10-22）。
  - 太阳以外行星的位置、日食和月食、极光、大气折射造成的太阳变形。
  - 自动曝光的时间适应（人眼适应式的渐变）和按画面的反射式测光：自动曝光只由场景决定，转动视角时亮度不跳，导出结果确定（修订 v5）。
  - HDRI 天空：仍是 `scene-editor-3d` 的子项 C5c。
  - 路径追踪：仍属后续的路径追踪 Epic。

## 接口约定

目标契约在本 Epic 的 `contracts.md` 中定义：

- 数据：
  - `data: ADD 物理天空`
  - `data: MODIFY 摄像机曝光`（W2 以 ADD 交付手动曝光；修订 v5 加自动曝光，由 W3 交付）
  - `data: ADD 夜空`
  - `data: ADD 空气透视`
  - `data: ADD 体积物件`

  这几节都是对 `data: 场景文档` 的扩展，各由一个子项完整交付。
- 接口：`api: MODIFY 提交场景命令`。`add_objects` / `update_objects` 接受 `volume`。
- 架构与模式：
  - `architecture: MODIFY 场景模块`：世界环境的渲染组成、天文计算、曝光。
  - `patterns: MODIFY 场景着色写法`：预计算 LUT 的写法、物理单位与预曝光、只支持 WebGPU 时的统一规则。

其余接口外形不变：
- `set_environment` 仍是整体替换，`update_objects` 里的 `camera` 仍按键合并。新字段按上述数据契约校验。
- `render_view`、导出和客户端任务的请求与结果都不变。
- OpenAPI 的 `CreativeSceneEnvironment`、`CreativeSceneSky`、`CreativeSceneCamera` 和对象 schema 随数据契约加字段。每个子项运行 `make generate` 后，提交两份生成物。

## 验收标准

全部子项完成后做整体验收。参考场景、参考地点和参考设备由 W2 确定，记录在 evidence 中（design「验证与交付」）。

- **AC-1 白模只看结构**：
  - **WHEN** 改变太阳、天空类型、环境光、雾或灯光，**THEN** 白模视口、白模的 `render_view` 和白模导出都不变。
  - **WHEN** W1 上线，**THEN** 已有的白模导出图各显示一次「场景已更新」；之后改环境，白模导出不再过时。
  - 线稿不受影响。
- **AC-1b AgX**：
  - **WHEN** W1 上线后打开现有参考场景（正午、黄昏、室内灯光、材质板），**THEN** 最终渲染和 `lit` 导出都用 AgX 色调映射，整体亮度与改之前接近，日落和饱和色灯光不再偏色。前后对照图由 owner 判断。
  - **WHEN** 打开线稿或线框，**THEN** 画面与改之前相同。
  - **WHEN** W1 上线，**THEN** 已有的 `lit` 导出图各显示一次「场景已更新」；`line` 不提示。
- **AC-2 地点与时间**：
  - **WHEN** 物理天空设为上海、2026-06-21，时刻从 05:00 拖到 20:00，**THEN**：
    - 太阳的高度和方位与 NOAA 太阳计算器的结果相差不超过 0.5°；
    - 日出、日落时刻（太阳上缘过地平线）相差不超过 2 分钟；
    - 画面依次经过晨昏蒙影、日出、蓝天、黄昏和入夜，太阳光的颜色与强度随之连续变化；
    - 改正北方向后，太阳和影子随之绕场景转动。
  - **WHEN** 切到手动模式，**THEN** 可以直接调太阳高度和方位，与程序化天空的用法相同。
- **AC-3 物理亮度与曝光**：
  - **WHEN** 选晴朗预设，太阳高度不低于 60°，**THEN** 场景原点处的水平照度在 100–130 klux 之间。
  - **WHEN** 摄像机设为手动曝光，ISO 100、1/125 s、f/16（阳光 16 法则，EV100 ≈ 15），分别拍晴天正午和日落后 20 分钟，**THEN**：
    - 正午的画面曝光正常，EV100 与正午的入射式测光值（测试里按 C = 250 算出）相差不超过 1 档；
    - 日落后的画面明显变暗，测光值比正午低 5 档以上。
  - **WHEN** 手动曝光的摄像机改光圈，**THEN** 画面亮度和景深一起变化；自动曝光的摄像机改光圈只改变景深。
  - **WHEN** 调太阳的亮度或色温，**THEN** 太阳光、天空和天空光照一起变亮变暗、变暖变冷；缺省值下与物理计算一致。
  - **WHEN** 视口在自由视角下，**THEN** 按默认摄像机的曝光显示（缺省自动）；切到相机视图时，按这台摄像机的曝光显示。
  - **WHEN** 默认设置（自动曝光、补偿 0）下把时刻从正午拖到深夜，**THEN** 画面亮度连续变化，没有台阶；场景中灰的显示亮度比正午低：黄金时刻约 0.5 档，满月之夜 2–3 档，新月之夜 3–4 档（修订 v5）。正午、黄昏、满月之夜、新月之夜四张默认设置的对照图由 owner 判断。
  - **WHEN** 自动曝光加 1 档补偿，**THEN** 画面亮 1 档。
  - **WHEN** 场景里有一盏 40 cd 的台灯，**THEN** 正午时几乎看不出它的光，入夜后它成为主要光源。
  - **WHEN** 天空切回程序化或纯色，**THEN** 画面与 W2 之前（W1 的 AgX 标定后）一致；摄像机曝光、默认摄像机的曝光和夜色都不生效，界面说明原因。
- **AC-4 大气参数与预设**：
  - **WHEN** 选「晴朗」「雾霾」「高原」「沙尘」预设，或单独调尘埃密度和海拔，**THEN** 天空、太阳光和天空光一起变化（雾霾更白更暗、高原天顶更深蓝、沙尘偏黄）。owner 判断是否可信，保留样例。
- **AC-5 夜空**：
  - **WHEN** 物理天空设为北京、某个满月之夜的 22:00，**THEN**：
    - 月亮的位置与天文数据相差不超过 1°，月相正确；
    - 默认设置下（自动曝光、夜色缺省）不调曝光就能看清月光照亮的场景，画面略偏蓝（修订 v5）；
    - 改成手动曝光、调到月光的曝光值（EV100 约 −3）时，同样能看清；
    - 北极星位于正北，高度约等于纬度；
    - 拖动时刻，星空绕北天极旋转。
  - **WHEN** 换成新月之夜，**THEN** 没有月光；默认设置下天空是深蓝而不是黑色，银河和亮星可见，场景仍能分辨（修订 v5）。
  - **WHEN** 夜色调到 0，**THEN** 画面颜色与物理计算一致。
  - **WHEN** 调月亮或星空的亮度、色温，**THEN** 月光和星空随之变化。
- **AC-6 空气透视**：
  - **WHEN** 打开空气透视，场景里有远近排列的物体，**THEN** 远处的物体变蓝变淡，颜色随时刻和大气参数变化。
  - **WHEN** 调大距离倍率，**THEN** 小尺度的场景也能看出空气透视。
  - **WHEN** 关闭空气透视，**THEN** 效果消失。
  - **WHEN** 同时开着全局雾和体积物件，**THEN** 三者叠加生效。
  - 白模和线稿不受影响。
- **AC-7 体积物件**：
  - **WHEN** 在屋内放一个体积物件，太阳从窗口照进来，**THEN** 看到穿过窗口的光束，窗框投下阴影；聚光照进体积时能看到光锥。
  - **WHEN** 移动或缩放体积物件，**THEN** 只有它覆盖的范围受影响。
  - **WHEN** 调散射颜色、吸收颜色、密度和各向异性，**THEN** 画面像 Blender 里对应的体积散射和体积吸收一样变化。
  - **WHEN** 切到白模，**THEN** 体积物件只显示范围线框。
- **AC-8 两个后端**：
  - **WHEN** 在 WebGL2 后端（SwiftShader）下打开参考场景，**THEN** 物理天空、夜空和空气透视的画面与 WebGPU 后端一致（阈值由 W2 定）。
  - 体积物件按 W5 穿刺后的决定执行：要么两个后端一致，要么在兼容模式下按统一规则降级并明确提示（design 未决事项 2）。
- **AC-9 确定性与过时**：
  - **WHEN** 在隐藏的标签页里连续两次导出物理天空的场景，包括自动和手动曝光、夜空和体积物件，**THEN** 两次结果逐像素相同。
  - **WHEN** 改了地点、时刻、大气参数、空气透视、夜空设置、摄像机曝光或体积物件，**THEN** 相关的 `lit` 导出图提示「场景已更新」，`clay`、`line` 不提示。
  - **WHEN** 只改了一台摄像机的曝光，**THEN** 只有这台摄像机的 `lit` 导出图过时。
- **AC-10 助手**：
  - **WHEN** 摄影师请助手「改成成都 10 月 1 日傍晚的黄金时刻，加一点雾霾，在窗前放一团能看到光束的雾，用相机手动曝光」，**THEN** 助手：
    - 按读场景时给出的太阳参考选时刻，写入物理天空（地点、日期、时刻、时区、预设）；
    - 添加体积物件；
    - 把摄像机设为手动曝光；
    - 用 `render_view` 的 `lit` 回看。
  - 写错字段时，工具说明原因，场景不变。
- **AC-11 性能**：
  - **WHEN** 在参考设备上拖动时刻滑杆，**THEN** 视口不低于 30 fps，天空光照在 200 ms 内跟上（沿用现有的节流）。
  - **WHEN** 物理天空静止，**THEN** 视口帧时间比程序化天空多不超过 2 ms。
  - 体积物件的帧时间目标由 W5 穿刺确定，经 Epic 修订写入本条。
