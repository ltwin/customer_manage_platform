## creative/scene: ADD 体积物件

场景里可以放体积物件：一个立方体或球体范围内的雾、烟、薄雾，被灯照亮后能看到光束和光锥。从「添加」菜单选「体积（立方体）」或「体积（球体）」，新体积边长 2 m，放在视口中心看向的位置。属性栏可以调散射颜色与密度、各向异性、吸收颜色与密度、边缘柔化，以及是否投射阴影，含义与 Blender 的体积散射和体积吸收相同。太阳、月光、平行光、聚光和点光都会照亮体积，投影的灯照进来会被物件挡出暗带；环境光和天空让体积整体略亮。每个场景最多 8 个体积物件。

体积只在最终渲染、`lit` 导出和助手回看的 `lit` 里画出；白模、线框、材质预览里只显示范围线框，白模和线稿导出与没有体积时一样。点击体积内部会选中它后面的物件，点线框选中体积本身。打开「投射阴影」后，体积在被照亮的表面上投出半透明的影子；第一次打开时视口会先在后台准备好再显示阴影。改动静默保存，可以撤销；助手也能添加和修改体积物件。

已知局限：只计单次散射，浓的白烟比离线渲染器暗；体积之间不互相遮挡；天空照亮体积时不计遮挡，室内的雾会被均匀抬亮；全局线性雾和景深按表面深度作用，不作用于体积本身。

### Scenario: 窗口照进来的光束
- GIVEN 物理天空，太阳从窗口照进一间屋子
- WHEN 添加一个盖住整间屋子的体积物件，散射密度 0.1、各向异性 0.6，切到最终渲染
- THEN 看到穿过窗口的光束，窗棂在光束里留下暗带；`lit` 导出里同样有光束

### Scenario: 聚光照出光锥
- GIVEN 一盏聚光照进体积物件
- WHEN 切到最终渲染
- THEN 看到聚光的光锥，锥外没有这盏灯的散射

### Scenario: 只影响自己的范围
- GIVEN 场景里有一个体积物件
- WHEN 移动或缩放它
- THEN 画面只在它覆盖的范围内变化，范围外与没有体积时一致

### Scenario: 调参数
- GIVEN 逆光看一个体积物件
- WHEN 调大散射密度、把吸收颜色改成红色、把各向异性调到正值
- THEN 体积更亮更浓、透过的光偏向红色、逆光方向更亮

### Scenario: 投射阴影
- GIVEN 太阳照着地面，一团浓烟挡在太阳和地面之间
- WHEN 打开浓烟的「投射阴影」
- THEN 视口准备好后，烟后面的地面变暗；关闭后地面与没有烟时一致，Cmd+Z 恢复

### Scenario: 白模与线稿不受影响
- GIVEN 场景里有体积物件
- WHEN 切到白模或线框，或导出白模、线稿
- THEN 只显示体积的范围线框，导出图与没有体积时逐像素一致

### Scenario: 导出图提示场景已更新
- GIVEN 画布上有这个场景的 `lit`、白模和线稿导出图
- WHEN 修改体积物件的密度
- THEN 只有 `lit` 导出图提示「场景已更新」

### Scenario: 超过上限
- GIVEN 场景里已有 8 个体积物件
- WHEN 编辑器或助手再添加一个
- THEN 服务端拒绝这次修改（413，「体积物件不能超过 8 个」），场景保持原样

### Scenario: 请助手加雾
- GIVEN 一间有窗户的屋子
- WHEN 请助手「在窗前放一团能看到光束的雾」
- THEN 助手添加一个体积物件、写对字段，并用 `lit` 回看
