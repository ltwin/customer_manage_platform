## creative/scene: MODIFY 物理天空

「环境」选项卡的天空类型可以选「物理天空」，与程序化天空、纯色并列。物理天空按地点（城市或经纬度）、日期、当地时刻和场景的正北方向推算太阳的真实位置，也可以切到手动调太阳角度。天空颜色、太阳光和天空光照由同一套物理大气算出，覆盖晨昏蒙影；海拔、空气密度、尘埃密度和臭氧可调，有「晴朗」「雾霾」「高原」「沙尘」四个预设；太阳的亮度和色温可调。物理天空下场景按真实照度渲染：太阳和平行光按照度（lux），点光和聚光按坎德拉，自发光按亮度（cd/m²），环境光不生效。黄昏和夜里场景按真实照度变暗；默认的自动曝光让入夜平滑变暗，只比正午暗 2–4 档，夜里画面略偏蓝（见「摄像机曝光」「夜空」）；手动曝光按真实照度成像。太阳落下后天空经晨昏蒙影变暗，地点模式下夜空随之显现（见「夜空」）。白模不受物理天空影响。改动静默保存，可以撤销。

城市表离线可用，数据来自 GeoNames（CC BY 4.0），城市下拉的底部注明来源。已知局限：太阳在地平线以下 6°–9° 时，天空比实际亮 2–3 档。

## creative/scene: ADD 夜空

物理天空的地点模式下，太阳落下后天上出现月亮、星星、银河和夜天光，位置都按地点、日期和当地时刻算出，随时刻转动，正北方向同样作用于它们。月亮按真实的位置、月相和视直径绘制，带月面纹理，亮面朝向太阳；月光是第二个平行光源，经大气衰减，满月约 0.3 lux，月亮在地平线以上、太阳低于 −6° 时投射阴影；月亮也照亮天空。星星取自 BSC5 星表中视星等不超过 6.5 的 8404 颗亮星，颜色按星表的色指数，地平线附近变暗变红。银河由渲染端程序化生成，银心、银道和暗隙的位置真实，细部结构是近似的。无月的晴夜天空有一层很暗的夜天光。夜空的光计入天空光照、全局雾的亮度和自动曝光的测光。默认设置下无月的夜空是深蓝而不是黑色，银河和亮星可见。

入夜后画面渐进偏蓝、降饱和（夜色），模拟人眼的夜视和电影「日拍夜」的调色；「夜空」一组的「夜色」滑杆调强度，调到 0 为纯物理颜色。夜色属于场景，对所有摄像机和两种曝光模式都一样，地点和手动两种太阳模式下都生效，黄金时刻之前不起作用。

「环境」选项卡的「夜空」一组有月亮、星星（含夜天光）、银河三个开关，月亮、星空各自的亮度倍率和色温（6500 K 为物理计算的颜色），以及夜色强度；手动模式下除夜色外这一组置灰，月亮和星空不画。时间一组显示当天的月相与照亮比例、月出月落，以及前后最近的满月和新月日期，点日期即改成那一天。白天的天空盖过星星，月亮照样看得见。星表来自 Yale 亮星星表（Hoffleit & Warren 1991，经 CDS/VizieR），月面纹理来自 NASA SVS，「夜空」一组底部注明星表出处。白模不受夜空影响。改动静默保存，可以撤销。

已知局限：不画行星、日食和月食、地照、光污染；月面纹理不计天平动；星星不闪烁，不计自行。

## creative/scene: MODIFY 摄像机曝光

物理天空下，曝光是观看者的设置，可选自动或手动。每台摄像机的属性里有「曝光」：
- 自动（新建的摄像机缺省）：按场景的照度测光，入夜后按夜间压暗曲线少补一些，画面平滑变暗，满月之夜比正午暗约 2.5 档、新月之夜约 3.5 档，不用调曝光也看得清；可以加减补偿（±5 档）。转动视角、切换摄像机不改变曝光。测光看的是场景原点的天光，室内或浓荫下的取景会偏暗，用补偿调整。光圈只决定景深。
- 手动：ISO、快门和光圈，光圈与景深共用，同时决定亮度和景深，旁边显示 EV100，按真实照度成像。

视口的自由视角和助手的临时视点、预设视角是「默认摄像机」，在「渲染」选项卡里设置：缺省自动曝光，补偿可调；切成手动时用默认曝光值（EV100，缺省 15，约为晴天）。从摄像机取景、导出和按摄像机回看时用这台摄像机的曝光。夜色（见「夜空」）对两种曝光都生效。其他天空下这些设置保存但不生效，界面置灰并说明原因。

- THEN 视口亮一档

## creative/scene: MODIFY 导出图提示场景已更新

导出之后场景被修改，并且修改会改变这张图时，画布上的导出图显示「场景已更新」；改回原样后不再显示。只是提示，不改图片。哪些修改算数按导出方式区分：线稿只看几何和这台摄像机，白模另看景深，材质光照再看环境、灯光、材质、曝光和渲染器。物理天空下，材质光照的曝光是这台摄像机自己的曝光：自动时是模式和补偿，手动时是 ISO、快门和光圈；「渲染」选项卡里默认摄像机的曝光不算；其他天空下是曝光补偿。输出分辨率不算。

### Scenario: 几何变化让导出图过时

- WHEN 摄影师移动了场景里的一根柱子
- THEN 两张图都显示「场景已更新」

### Scenario: 改回原样不再提示

## creative/scene: MODIFY 渲染器与输出分辨率

属性区参照 Blender 分成「渲染」「环境」「物件」三个选项卡。「渲染」里可以选渲染器和输出分辨率，调曝光，并看到当前的渲染后端。曝光在程序化天空和纯色天空下是曝光补偿，在物理天空下是默认摄像机的曝光（只用于视口的自由视角和助手的临时视点）：自动或手动，自动时调补偿，手动时调默认曝光值（EV100）。渲染器有工作台、实时 GI，以及还不能选的「路径追踪 · 规划中」：工作台是标准的光栅化渲染；实时 GI 在它之上加入物体之间的间接光反弹、反射和接触阴影，只计算画面里可见的表面。渲染器决定编辑器的最终渲染、助手的材质光照回看和材质光照导出的画面；白模、线框、材质预览和线稿总按工作台画，正交视图也按工作台显示。灯光图标、摄像机视锥、空物体等辅助对象在视口里照常显示，但不参与光照：不遮挡、不压暗周围。输出分辨率只决定导出图的长边。这些都是场景的设置，静默保存，可以撤销，其他标签页和助手看到的一样。

### Scenario: 打开渲染选项卡
- GIVEN 摄影师在场景编辑视图里
- WHEN 点属性区的「渲染」
- THEN 看到渲染器（工作台、实时 GI、灰掉的「路径追踪 · 规划中」）、输出分辨率（1K、2K、4K、8K，注明长边像素）、曝光和渲染后端（「WebGPU」或「兼容模式」）；天空是物理天空时，曝光一栏是默认摄像机的曝光：自动（缺省）显示补偿，手动显示「默认曝光（EV100）」并列出常见场景的参考值；否则是曝光补偿

### Scenario: 选中物件时切到物件属性
- GIVEN 摄影师停在「渲染」选项卡
- WHEN 在视口里选中一个物件，再取消选中
- THEN 选中时属性区切到「物件」，取消后回到「渲染」

### Scenario: 换成实时 GI
- GIVEN 一个红墙、白地面、金属球的房间，渲染器是工作台，摄影师在最终渲染模式下
- WHEN 把渲染器换成实时 GI
- THEN 停止操作后画面逐渐变干净然后停止刷新；靠近红墙的白地面被染红，金属球和光滑地板映出房间里的其他物体；白模模式下画面不变；Cmd+Z 回到工作台；另一个标签页同步显示

### Scenario: 正交视图按工作台显示
- GIVEN 渲染器是实时 GI
- WHEN 切到正交视图
- THEN 画面按工作台显示，视口角落提示「正交视图按工作台显示」；回到透视视图后恢复实时 GI

### Scenario: 按 4K 导出
- GIVEN 场景里有一台 3:2 的摄像机，输出分辨率选 4K
- WHEN 导出白模、线稿和材质光照
- THEN 三张图长边都是 4096 px、短边 2731 px；导出对话框写明长边 4096

### Scenario: 设备画不了所选分辨率
- GIVEN 输出分辨率选 8K，当前设备的显存不够
- WHEN 导出
- THEN 导出失败并说明当前设备可能画不了这个分辨率、可以换低一档，画布上没有半成品；不会悄悄按更低的分辨率导出

### Scenario: 请助手换渲染器并按 4K 导出
- GIVEN 摄影师在助手面板里
- WHEN 请助手「换成实时 GI，按 4K 导出」
- THEN 助手把渲染器和输出分辨率改掉，回看一次实时 GI 的画面，再导出长边 4096 的图；两项修改出现在这一轮的改动清单里

### Scenario: 路径追踪还不能选
- GIVEN 摄影师或助手想用路径追踪
- WHEN 打开渲染器下拉，或助手写入路径追踪
- THEN 下拉里这一项不能选；助手的写入被拒绝并说明还不支持
