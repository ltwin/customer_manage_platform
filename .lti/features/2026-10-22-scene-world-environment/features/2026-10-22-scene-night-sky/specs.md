## creative/scene: MODIFY 物理天空

「环境」选项卡的天空类型可以选「物理天空」，与程序化天空、纯色并列。物理天空按地点（城市或经纬度）、日期、当地时刻和场景的正北方向推算太阳的真实位置，也可以切到手动调太阳角度。天空颜色、太阳光和天空光照由同一套物理大气算出，覆盖晨昏蒙影；海拔、空气密度、尘埃密度和臭氧可调，有「晴朗」「雾霾」「高原」「沙尘」四个预设；太阳的亮度和色温可调。物理天空下场景按真实照度渲染：太阳和平行光按照度（lux），点光和聚光按坎德拉，自发光按亮度（cd/m²），环境光不生效；黄昏和夜里画面真实变暗，亮度由摄像机的曝光决定。太阳落下后天空经晨昏蒙影变暗，地点模式下夜空随之显现（见「夜空」）。白模不受物理天空影响。改动静默保存，可以撤销。

城市表离线可用，数据来自 GeoNames（CC BY 4.0），城市下拉的底部注明来源。已知局限：太阳在地平线以下 6°–9° 时，天空比实际亮 2–3 档。

### Scenario: 选上海的夏至日拖动时刻
- GIVEN 摄影师把天空改成物理天空，城市选「上海」，日期 2026-06-21
- WHEN 把当地时刻从 05:00 拖到 20:00
- THEN 太阳从东北方升起、正午接近天顶、傍晚落向西北，位置与 NOAA 太阳计算器相差不超过 0.5°，日出日落时刻相差不超过 2 分钟；画面依次经过晨昏蒙影、日出、蓝天、黄昏和入夜，太阳光的颜色和强度连续变化

### Scenario: 查看当天的光线时段
- GIVEN 物理天空的地点模式，城市选「成都」，日期 2026-10-01
- WHEN 查看「环境」选项卡的时间一组
- THEN 显示当前太阳的高度和方位、日出日落时刻，以及早晚的黄金时刻（太阳高度 −4°…6°）和蓝调时刻（−6°…−4°）

### Scenario: 改场景的正北方向
- GIVEN 物理天空的地点模式下，影子朝向场景的 −X 方向
- WHEN 把正北方向转 90°
- THEN 太阳和影子一起绕场景转 90°

### Scenario: 南半球
- GIVEN 城市选「悉尼」
- WHEN 时刻设为当地正午
- THEN 太阳在正北方向的天空里

### Scenario: 切到手动角度
- GIVEN 物理天空的地点模式下，太阳高度 23°
- WHEN 把太阳位置改为「手动角度」
- THEN 太阳不动，高度和方位滑杆显示 23° 和当前方位，之后可以直接拖动；Cmd+Z 回到地点模式

### Scenario: 入夜后切到手动角度
- GIVEN 物理天空的地点模式下，太阳高度 −15°
- WHEN 把太阳位置改为「手动角度」
- THEN 太阳高度夹到手动角度的下限 −10°，天空随之变亮；Cmd+Z 回到地点模式

### Scenario: 夏令时跳过的时刻
- GIVEN 城市选「纽约」，日期 2026-03-08
- WHEN 当地时刻设为 02:30（这一天时钟从 02:00 直接跳到 03:00）
- THEN 按 03:30 夏令时计算太阳位置

### Scenario: 选预设
- GIVEN 物理天空，晴朗预设，正午
- WHEN 依次选「雾霾」「高原」「沙尘」
- THEN 雾霾时天空更白、画面更暗；高原时天顶更深蓝；沙尘时天空和光线偏黄；天空、太阳光和天空光照一起变化

### Scenario: 调太阳的亮度和色温
- GIVEN 物理天空，正午
- WHEN 把太阳亮度调到 2，或把色温调低
- THEN 太阳光、天空和天空光照一起变亮一档，或一起变暖；调回 1 和 6500 K 后与调之前相同

### Scenario: 物理天空下的台灯
- GIVEN 物理天空的院子里有一盏 40 cd 的台灯，摄像机设为阳光 16 法则（ISO 100、1/125 s、f/16）
- WHEN 在正午和入夜各拍一张材质光照图，入夜那张把摄像机改为 ISO 1600、1/30 s、f/2.8
- THEN 正午几乎看不出台灯的光；入夜后台灯照亮的区域清晰可见，成为主要光源

### Scenario: 物理天空下环境光不生效
- GIVEN 天空是物理天空
- WHEN 打开「环境」选项卡
- THEN 环境光一组置灰，提示物理天空下天空光由大气算出，环境光不生效

### Scenario: 按城市搜索
- GIVEN 物理天空的地点模式
- WHEN 在城市搜索框里输入「成都」「Chengdu」或「稻城」
- THEN 下拉的第一项就是要找的地点；选中后经纬度和时区随之填入，底部注明 GeoNames 的署名

### Scenario: 其他天空不变
- GIVEN 一个程序化天空或纯色天空的场景，画布上有它的导出图
- WHEN 打开最终渲染，或重新导出
- THEN 画面与物理天空上线之前相同，已有导出图不显示「场景已更新」

### Scenario: 请助手改成物理天空
- GIVEN 摄影师请助手「改成成都 10 月 1 日傍晚的黄金时刻，加一点雾霾，用相机手动曝光」
- WHEN 助手完成这一轮
- THEN 场景里写入了物理天空（成都的经纬度和 `Asia/Shanghai`、日期、雾霾的大气参数，时刻落在当天傍晚的黄金时刻里），摄像机设了 ISO 和快门；助手至少用一次材质光照回看。助手读场景和写入环境时能看到当天的太阳参考：当前太阳的高度和方位、日出日落、黄金时刻和蓝调时刻
- WHEN 助手只写了经度和纬度没写时区，写了无效或大小写不对的时区名，在物理天空里写了浑浊度，或在程序化天空里写了日期
- THEN 修改被拒绝，场景不变，助手得到原因

## creative/scene: ADD 夜空

物理天空的地点模式下，太阳落下后天上出现月亮、星星、银河和夜天光，位置都按地点、日期和当地时刻算出，随时刻转动，正北方向同样作用于它们。月亮按真实的位置、月相和视直径绘制，带月面纹理，亮面朝向太阳；月光是第二个平行光源，经大气衰减，满月约 0.3 lux，月亮在地平线以上、太阳低于 −6° 时投射阴影；月亮也照亮天空。星星取自 BSC5 星表中视星等不超过 6.5 的 8404 颗亮星，颜色按星表的色指数，地平线附近变暗变红。银河由渲染端程序化生成，银心、银道和暗隙的位置真实，细部结构是近似的。无月的晴夜天空有一层很暗的夜天光。夜空的光计入天空光照和全局雾的亮度。

「环境」选项卡的「夜空」一组有月亮、星星（含夜天光）、银河三个开关，以及月亮、星空各自的亮度倍率和色温（6500 K 为物理计算的颜色）；手动模式下这一组置灰，月亮和星空不画。时间一组显示当天的月相与照亮比例、月出月落，以及前后最近的满月和新月日期，点日期即改成那一天。白天的天空盖过星星，月亮照样看得见。星表来自 Yale 亮星星表（Hoffleit & Warren 1991，经 CDS/VizieR），月面纹理来自 NASA SVS，「夜空」一组底部注明星表出处。白模不受夜空影响。改动静默保存，可以撤销。

已知局限：不画行星、日食和月食、地照、光污染；月面纹理不计天平动；星星不闪烁，不计自行。

### Scenario: 北京的满月之夜
- GIVEN 物理天空的地点模式，城市选「北京」，日期是一个满月日，当地时刻 22:00
- WHEN 打开最终渲染，摄像机设为 ISO 3200、4 s、f/2.8（EV100 约 −3）
- THEN 月亮的位置与天文数据相差不超过 1°，是满月；月光照亮院子，影子朝向背离月亮的一侧；天空是很暗的蓝色，能看到较亮的星星

### Scenario: 月相
- GIVEN 物理天空的地点模式，日期是上弦月当天，时刻在日落后
- WHEN 查看天上的月亮
- THEN 月亮只亮一半，亮面朝向太阳落下的一侧；时间一组显示「上弦月」和照亮比例

### Scenario: 北极星与星空旋转
- GIVEN 城市选「北京」，太阳在地平线以下
- WHEN 朝正北看，再把时刻往后拖
- THEN 北极星在正北，高度约等于北京的纬度；星空绕北极星转动

### Scenario: 南半球的星空
- GIVEN 城市选「悉尼」，太阳在地平线以下
- WHEN 朝南看
- THEN 能看到南十字座和麦哲伦云，北极星在地平线以下

### Scenario: 新月之夜看银河
- GIVEN 北京的新月之夜，银河在天上
- WHEN 摄像机曝光调到 EV100 约 −7
- THEN 没有月光，能看清银河的亮带和暗隙，场景只由星光、银河、夜天光和灯光照亮

### Scenario: 调月亮和星空
- GIVEN 满月之夜
- WHEN 把月亮亮度调到 2，或把月亮色温调高
- THEN 月盘、月光和月光照亮的天空一起变亮一档，或一起变冷；调回 1 和 6500 K 后与调之前相同
- WHEN 调星空的亮度或色温
- THEN 星星、银河和夜天光一起变化

### Scenario: 开关夜空
- GIVEN 满月之夜
- WHEN 分别关闭月亮、星星、银河
- THEN 对应的部分从天空和光照里消失，其余不变；关闭月亮时月光和月光照亮的天空一起消失

### Scenario: 手动模式没有夜空
- GIVEN 物理天空的地点模式，满月之夜
- WHEN 把太阳位置改为「手动角度」
- THEN 月亮和星空不画，「夜空」一组置灰并说明夜空只在地点模式下生效

### Scenario: 跳到满月
- GIVEN 物理天空的地点模式
- WHEN 在时间一组点「下一个满月」的日期
- THEN 日期改成那一天，月亮按那天的位置和月相显示；Cmd+Z 回到原来的日期

### Scenario: 夜空上线后的旧导出
- GIVEN 夜空上线之前存的物理天空场景，画布上有它的材质光照导出图
- WHEN 夜空上线后打开画布
- THEN 这些导出图各显示一次「场景已更新」；程序化天空和纯色天空的导出不受影响
- WHEN 之后改夜空的任一字段
- THEN 材质光照导出显示「场景已更新」，白模和线稿导出不显示

### Scenario: 请助手安排满月之夜
- GIVEN 摄影师请助手「改成北京下一个满月的晚上十点，拍月光下的院子」
- WHEN 助手完成这一轮
- THEN 场景里写入了物理天空（北京、月亮参考给出的满月日期、22:00），摄像机设了夜景曝光；助手至少用一次材质光照回看。助手读场景和写入环境时能看到月亮参考：当前月亮的高度和方位、月相与照亮比例、月出月落、前后最近的满月和新月
- WHEN 助手在程序化天空里写 `night`，或写超出范围的亮度、色温
- THEN 修改被拒绝，场景不变，助手得到原因
