## creative/scene: MODIFY 四种显示模式

编辑视图参照 Blender 的视口着色，提供线框、白模、材质预览、最终渲染四种显示模式。白模与白模导出一致，最终渲染与材质光照导出一致。白模用固定的工作室光，只用来看结构，不受场景的天空、太阳、环境光、雾和灯光影响。白模、材质预览和最终渲染按 AgX 色调映射：明亮的饱和色（落日、彩色灯光）越亮越接近白色，但不偏成别的颜色。显示模式是本机的查看状态，按场景记住，不写进场景，也不算一步编辑。

### Scenario: 切换显示模式
- GIVEN 场景里有分配了材质的物件和一盏投射阴影的点光
- WHEN 摄影师按 `Z`，在弹出的菜单里依次选线框、白模、材质预览、最终渲染
- THEN 线框只显示物件的轮廓边，能看到被挡住的物件，框选时被挡住的物件也会选中，点击仍选中最前面的表面；白模是统一的浅灰材质，背景是中性灰，看不到天空，灯光不影响画面；材质预览显示材质，光照是固定的中性室内光；最终渲染显示材质，点光照亮周围并投下阴影

### Scenario: 材质预览不受打光影响
- GIVEN 摄影师在材质预览模式下
- WHEN 删除场景里全部灯光，或改变太阳方向
- THEN 画面不变

### Scenario: 白模不受环境影响
- GIVEN 摄影师在白模模式下，天空是程序化天空，太阳高度 35°
- WHEN 把太阳调到 5°，把天空换成纯色，打开雾，改环境光，或加一盏投射阴影的点光
- THEN 画面不变；转到另一个角度看，光仍从视角的左上方照来，物体不投影，接触处有 AO 的暗部

### Scenario: 线框切换
- GIVEN 摄影师在最终渲染模式下
- WHEN 按 `Shift + Z`
- THEN 切到线框；再按一次回到最终渲染

### Scenario: 显示模式记在本机
- GIVEN 摄影师把场景切到最终渲染后离开
- WHEN 重开这个场景
- THEN 仍是最终渲染；Cmd+Z 不会撤销显示模式的切换；同一场景在另一个标签页里的显示模式不受影响

### Scenario: 第一次打开按场景的建议方式
- GIVEN 本机从没打开过这个场景，助手把场景的显示方式设成了 `lit`
- WHEN 摄影师打开场景
- THEN 以最终渲染显示

## creative/scene: MODIFY 编辑灯光与环境

摄影师可以添加平行光、点光、聚光，编辑它们的颜色、强度、阴影和光锥；天空、环境光和雾在属性区的「环境」选项卡里编辑，曝光补偿在「渲染」选项卡里。灯光、太阳、天空、环境光、雾和曝光补偿只在最终渲染和材质光照导出里生效，白模用固定的工作室光；不在最终渲染模式时，「环境」选项卡提示环境在「最终渲染」里生效。改动静默保存，可以撤销。

### Scenario: 加一盏聚光
- GIVEN 摄影师在最终渲染模式下
- WHEN 用 Shift + A 加一盏聚光，把光锥角调到 30°，打开「投射阴影」
- THEN 光照范围和图标的光锥一致，物件在地面投下阴影；存储的光锥角为 π/12 弧度

### Scenario: 换灯光类型
- GIVEN 一盏聚光
- WHEN 把类型改成点光
- THEN 光锥角和柔化消失，颜色、强度、阴影设置保留

### Scenario: 白模里灯光不生效
- GIVEN 摄影师在白模模式下选中一盏灯
- WHEN 查看属性栏
- THEN 提示灯光在最终渲染模式下生效

### Scenario: 白模里打开环境选项卡
- GIVEN 摄影师在白模模式下
- WHEN 打开「环境」选项卡
- THEN 看到提示：环境在「最终渲染」里生效；仍可以编辑，改动静默保存

### Scenario: 调太阳高度
- GIVEN 天空是程序化天空
- WHEN 在「环境」选项卡里把太阳高度从 35° 调到 5°
- THEN 最终渲染里影子变长，天空变成黄昏色调；白模不变；Cmd+Z 回到 35°

### Scenario: 调曝光补偿
- GIVEN 一个只有两盏壁灯的室内场景，最终渲染偏暗
- WHEN 在「渲染」选项卡里把「曝光补偿」调到 +2
- THEN 最终渲染变亮；白模不变；Cmd+Z 回到 0

### Scenario: 纯色天空和雾
- GIVEN 摄影师在最终渲染模式下打开「环境」选项卡
- WHEN 把天空改成纯色，打开雾并设置起止距离
- THEN 背景和雾按设置显示，与材质光照导出一致

## creative/scene: MODIFY 导出图提示场景已更新

导出之后场景被修改，并且修改会改变这张图时，画布上的导出图显示「场景已更新」；改回原样后不再显示。只是提示，不改图片。哪些修改算数按导出方式区分：线稿只看几何和这台摄像机，白模另看景深，材质光照再看环境、灯光、材质、曝光和渲染器。输出分辨率不算。

### Scenario: 几何变化让导出图过时
- GIVEN 画布上有某台摄像机的白模图和线稿
- WHEN 摄影师移动了场景里的一根柱子
- THEN 两张图都显示「场景已更新」

### Scenario: 改挂分组也算几何变化
- GIVEN 画布上有某台摄像机的白模图和线稿
- WHEN 助手在同一次修改里把两根柱子移进一个旋转过的分组，并新增了一台摄像机
- THEN 两张图都显示「场景已更新」，即使柱子在画面中的位置没变

### Scenario: 改回原样不再提示
- GIVEN 导出后摄影师移动了一根柱子，导出图显示「场景已更新」
- WHEN 把柱子移回原位
- THEN 导出图不再显示「场景已更新」

### Scenario: 摄像机被删除
- GIVEN 画布上有某台摄像机的导出图
- WHEN 摄影师删除了这台摄像机
- THEN 导出图显示「场景已更新」

### Scenario: 环境只影响材质光照图
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图
- WHEN 摄影师改了太阳高度，或打开了雾
- THEN 只有材质光照图显示「场景已更新」

### Scenario: 灯光和材质只影响材质光照图
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图
- WHEN 摄影师改了一盏灯的颜色，或换了一个槽位的材质
- THEN 只有材质光照图显示「场景已更新」

### Scenario: 曝光只影响材质光照图
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图
- WHEN 摄影师调了曝光补偿
- THEN 只有材质光照图显示「场景已更新」；调回原值后不再显示

### Scenario: 景深参数不影响线稿
- GIVEN 一台打开了景深的摄像机，画布上有它的白模图、线稿和材质光照图
- WHEN 摄影师改了光圈，或移动了对焦物件
- THEN 白模图和材质光照图显示「场景已更新」，线稿不显示；景深关闭时改光圈，三张图都不显示

### Scenario: 渲染器只影响材质光照图
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图，场景一直用工作台
- WHEN 摄影师把渲染器换成实时 GI
- THEN 只有材质光照图显示「场景已更新」；换回工作台后不再显示

### Scenario: 改输出分辨率不提示
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图
- WHEN 摄影师把输出分辨率从 2K 改成 4K
- THEN 三张图都不显示「场景已更新」

### Scenario: 不影响画面的修改不提示
- GIVEN 画布上有某台摄像机的白模图和线稿
- WHEN 只新加、删除或调了另一台摄像机，加了或删除一盏灯光，改了场景标题、显示模式、曝光补偿，或者某个槽位的材质
- THEN 导出图不显示「场景已更新」

### Scenario: 换了图或场景没了就不再提示
- GIVEN 一张导出图之后场景有过几何修改
- WHEN 摄影师换掉了这个节点的图片内容，或场景已被删除
- THEN 不显示「场景已更新」

## creative/scene: MODIFY 渲染器与输出分辨率

属性区参照 Blender 分成「渲染」「环境」「物件」三个选项卡。「渲染」里可以选渲染器和输出分辨率，调曝光补偿，并看到当前的渲染后端。渲染器有工作台、实时 GI，以及还不能选的「路径追踪 · 规划中」：工作台是标准的光栅化渲染；实时 GI 在它之上加入物体之间的间接光反弹、反射和接触阴影，只计算画面里可见的表面。渲染器决定编辑器的最终渲染、助手的材质光照回看和材质光照导出的画面；白模、线框、材质预览和线稿总按工作台画，正交视图也按工作台显示。灯光图标、摄像机视锥、空物体等辅助对象在视口里照常显示，但不参与光照：不遮挡、不压暗周围。输出分辨率只决定导出图的长边。两项都是场景的设置，静默保存，可以撤销，其他标签页和助手看到的一样。

### Scenario: 打开渲染选项卡
- GIVEN 摄影师在场景编辑视图里
- WHEN 点属性区的「渲染」
- THEN 看到渲染器（工作台、实时 GI、灰掉的「路径追踪 · 规划中」）、输出分辨率（1K、2K、4K、8K，注明长边像素）、曝光补偿和渲染后端（「WebGPU」或「兼容模式」）

### Scenario: 选中物件时切到物件属性
- GIVEN 摄影师停在「渲染」选项卡
- WHEN 在视口里选中一个物件，再取消选中
- THEN 选中时属性区切到「物件」，取消后回到「渲染」

### Scenario: 换成实时 GI
- GIVEN 一个红墙、白地面、金属球的房间，渲染器是工作台，摄影师在最终渲染模式下
- WHEN 把渲染器换成实时 GI
- THEN 停止操作后画面逐渐变干净然后停止刷新；靠近红墙的白地面被染红，金属球和光滑地板映出房间里的其他物体；白模模式下画面不变；Cmd+Z 回到工作台；另一个标签页同步显示

### Scenario: 正交视图按工作台显示
- GIVEN 渲染器是实时 GI
- WHEN 切到正交视图
- THEN 画面按工作台显示，视口角落提示「正交视图按工作台显示」；回到透视视图后恢复实时 GI

### Scenario: 按 4K 导出
- GIVEN 场景里有一台 3:2 的摄像机，输出分辨率选 4K
- WHEN 导出白模、线稿和材质光照
- THEN 三张图长边都是 4096 px、短边 2731 px；导出对话框写明长边 4096

### Scenario: 设备画不了所选分辨率
- GIVEN 输出分辨率选 8K，当前设备的显存不够
- WHEN 导出
- THEN 导出失败并说明当前设备可能画不了这个分辨率、可以换低一档，画布上没有半成品；不会悄悄按更低的分辨率导出

### Scenario: 请助手换渲染器并按 4K 导出
- GIVEN 摄影师在助手面板里
- WHEN 请助手「换成实时 GI，按 4K 导出」
- THEN 助手把渲染器和输出分辨率改掉，回看一次实时 GI 的画面，再导出长边 4096 的图；两项修改出现在这一轮的改动清单里

### Scenario: 路径追踪还不能选
- GIVEN 摄影师或助手想用路径追踪
- WHEN 打开渲染器下拉，或助手写入路径追踪
- THEN 下拉里这一项不能选；助手的写入被拒绝并说明还不支持
