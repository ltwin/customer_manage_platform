# three 0.186.1 的 AgX 与 ACES Filmic 对比

为 W1 的重新标定提供依据：换成 AgX 后，哪些亮度会变、变多少。

## 方法

- 照搬 `node_modules/three/src/nodes/display/ToneMappingFunctions.js` 里的 `acesFilmicToneMapping` 和 `agxToneMapping`，用 numpy 逐通道计算。曝光取 1，输出再按 sRGB OETF 编码成 8 位。
- 矩阵按 GLSL 的列主序理解。ACES 输入矩阵每行之和为 1，所以灰色经过矩阵后仍是灰色。
- 只是函数层面的对比。实际画面还取决于场景里各处的亮度分布，以重新标定时的截图测量为准。

## 结果

灰阶（线性输入 → 8 位 sRGB 输出）：

| 线性输入 | ACES Filmic | AgX |
|---|---|---|
| 0.02 | 20 | 37 |
| 0.05 | 50 | 70 |
| 0.18（中灰） | 127 | 128 |
| 0.5 | 197 | 174 |
| 1 | 226 | 202 |
| 2 | 242 | 224 |
| 4 | 250 | 239 |
| 8 | 253 | 248 |

- 中灰几乎相同：让 AgX 的中灰与 ACES 一致所需的曝光倍数是 0.992（−0.01 EV）。three 的 ACES 在内部先除以 0.6，抵消了 ACES 本来偏暗的中灰。
- 差别在对比度。AgX 的暗部更亮（0.02 处 20 → 37），亮部更暗（1.0 处 226 → 202），整条曲线更平。
- 饱和色（线性输入 → 8 位 RGB）：

| 颜色 | 线性输入 | ACES Filmic | AgX |
|---|---|---|---|
| 落日橙 | (4, 1.2, 0.3) | (255, 234, 196) | (246, 211, 181) |
| 红色灯光 | (3, 0.2, 0.1) | (255, 179, 128) | (251, 168, 146) |
| 天空蓝 | (0.3, 0.5, 1.2) | (176, 197, 231) | (157, 180, 212) |

ACES 下落日橙接近浅黄白，红色灯光偏橙；AgX 保留了原来的色相，只是逐渐变亮变白。

## 对 W1 的含义

- 「整体亮度接近原来」不需要整体加曝光。要调的是对比度带来的差别：
  - 以亮面为主的画面会变暗，例如正午阳光下的浅色地面和白模的受光面；
  - 以暗部为主的画面会变亮，例如室内灯光场景的墙角。
- 重新标定以截图测量为准：看参考场景整幅画面和地面区域的平均亮度，以及有多少像素过曝。现有的 e2e「calibration」检查（`frontend/scripts/creative-scene.e2e.mjs`）已经量这几项。
- 线框的轮廓线和视口辅助对象（灯光图标、摄像机视锥）也经过色调映射，换成 AgX 后颜色会变灰一些。线框要求画面不变，因此单独处理（design「色调映射」）。

## 复算脚本

```python
import numpy as np
def colmat(*cols): return np.array(cols).T
ACESIn = np.array([[0.59719,0.35458,0.04823],[0.07600,0.90834,0.01566],[0.02840,0.13383,0.83777]])
ACESOut= np.array([[1.60475,-0.53108,-0.07367],[-0.10208,1.10813,-0.00605],[-0.00327,-0.07276,1.07602]])
def rrt(c): return (c*(c+0.0245786)-0.000090537)/(c*(0.983729*c+0.4329510)+0.238081)
def aces(c): c=np.array(c,float)/0.6; return np.clip(ACESOut@rrt(ACESIn@c),0,1)
S2R=colmat([0.6274,0.0691,0.0164],[0.3293,0.9195,0.0880],[0.0433,0.0113,0.8956])
R2S=colmat([1.6605,-0.1246,-0.0182],[-0.5876,1.1329,-0.1006],[-0.0728,-0.0083,1.1187])
Ins=colmat([0.856627153315983,0.137318972929847,0.11189821299995],[0.0951212405381588,0.761241990602591,0.0767994186031903],[0.0482516061458583,0.101439036467562,0.811302368396859])
Outs=colmat([1.1271005818144368,-0.1413297634984383,-0.14132976349843826],[-0.11060664309660323,1.157823702216272,-0.11060664309660294],[-0.016493938717834573,-0.016493938717834257,1.2519364065950405])
def cont(x): x2=x*x; x4=x2*x2; return 15.5*x4*x2-40.14*x4*x+31.96*x4-6.868*x2*x+0.4298*x2+0.1191*x-0.00232
def agx(c):
    c=np.maximum(Ins@(S2R@np.array(c,float)),1e-10)
    c=np.clip((np.log2(c)+12.47393)/(4.026069+12.47393),0,1)
    return np.clip(R2S@(np.maximum(Outs@cont(c),0)**2.2),0,1)
def srgb(x): return np.where(x<=0.0031308,12.92*x,1.055*np.power(np.maximum(x,0),1/2.4)-0.055)
```
