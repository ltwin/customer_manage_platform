| 文件 | 内容 |
|---|---|

## AC-W1-6

**两个后端**（`SCENE_E2E_GPU`，R1 的阈值）：
- 48 行里 46 行在阈值内：
  - 对 W1 新参照的 `clay`、`lit` 都是 0；
  - 线稿对 R0 基线在阈值内；
  - WebGL2 对 WebGPU 的白模、线稿都在阈值内。
- 两行超阈值，都是 WebGL2 对 WebGPU 的 `lit`：

| 图 | W1 | R1 记录 |
|---|---|---|
| `noon-shot-lit` | 0.185 / 1.215% | 0.221 / 1.294% |
| `materials-board-lit` | 0.228 / 0.942% | 0.251 / 0.968% |

  这是 R1 已交 owner 的混凝土气孔硬边（R1 `parity.md`：Metal 上 WGSL 的浮点差异让单个气孔边缘的像素在阈值两侧翻转）。W1 的数值比 R1 略低，不是本次引入。

**确定性**（`SCENE_E2E_HIDDEN`）：
- 工作台：隐藏标签页与前台逐像素相同，连续两次相同；WebGL2 后端在后台两次相同。
- 实时 GI：隐藏与前台、两次之间最大差都是 0。
- 用例里有一条断言自 R2 任务 7.4 起就不成立：它要求实时 GI 下的白模与工作台不同，而 7.4 已经规定白模总按工作台画。在 `develop` f48841a3 上同样失败。已改为「白模、线稿与工作台相同，`lit` 不同」，用例绿。

**视口帧时间**（R1 性能场景，1600 × 1000，2 倍像素比）：

| 模式 | W1 之前 平均 / p95 / 最大 | W1 |
|---|---|---|
| 线框 | 8.3 / 9.1 / 9.4 ms | 8.3 / 9.1 / 9.4 ms |
| 白模 | 8.4 / 9.2 / 17.1 ms | 8.3 / 9.2 / 9.4 ms |
| 材质预览 | 8.3 / 9.1 / 9.3 ms | 8.3 / 9.2 / 9.4 ms |
| 最终渲染 | 8.3 / 9.1 / 9.3 ms | 8.3 / 9.2 / 9.5 ms |

- 四种模式都贴着 120 Hz 的刷新上限，没有变慢。
- 白模的最长一帧从 17.1 ms 降到 9.4 ms，因为白模不再画阴影贴图。
- 加灯和删灯时的最长一帧：W1 之前 141 / 275 ms，W1 为 142 / 258 ms。
