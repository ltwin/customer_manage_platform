## creative/agent-run: ADD 停止运行

助手运行时，输入框的发送按钮就是停止按钮。点一次就停：面板立刻显示已停止，同一个对话可以马上发下一条消息。正在进行的模型请求会被中断；已经产生的费用由后台继续核实并入账，摄影师不需要等待，也看不到核实过程。已经交给生成服务的生成会跑完并计费，还没发出的生成会被撤回。

### Scenario: 运行中点停止
- GIVEN 助手正在输出回答
- WHEN 摄影师点击输入框右下角的停止按钮
- THEN 输出立刻停住、不再增长，并标为「已停止」，按钮变回发送；停止完成后显示已保存的内容（可能比点击时多出很短的一段）；可以马上发下一条消息

### Scenario: 等待补充时停止
- GIVEN 助手停下来等摄影师补充信息，输入框为空
- WHEN 摄影师点击停止按钮
- THEN 这次运行结束；如果在输入框里写了内容，按钮会变成「补充并继续」

### Scenario: 停止请求失败
- GIVEN 网络断开
- WHEN 摄影师点击停止
- THEN 面板先显示已停止，请求失败后恢复为运行中，并提示停止没有成功；再点一次可以重试

### Scenario: 停止后的费用
- GIVEN 停止时模型请求正在输出
- WHEN 后台随后核实了这次请求的用量
- THEN 费用照常入账，运行仍是已停止；面板上不出现费用核实的提示
