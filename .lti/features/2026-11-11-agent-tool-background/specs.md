## creative/agent-run: ADD 耗时工具的等待与后台运行

助手调用生成、图片压缩、场景建模、回看截图、导出分镜这类耗时工具时，默认等到结果再继续。等待期间释放会话槽位，等待时长受任务自身执行时限和运行的 6 小时上限约束。除回看截图外，助手也可以选择后台运行：工具立即返回，助手接着做别的事，任务完成时结果作为一条通知回到对话里。前台等待中的工具卡片有「转后台」按钮，摄影师点击后助手不再等它。后台任务独立于运行：停止对话不会停止后台任务，要停止就在任务卡片上取消。场景建模和导出分镜需要保持创意空间页面打开。后台任务完成时如果对话空闲，助手会自动开一轮新回复来处理结果，按用量计费；以下情况只写完成提示、不自动开始，等摄影师下次发消息时一并送达：发起任务的那一轮被停止或失败、摄影师没发消息期间已连续自动开始 5 轮、外发同意已撤回或说明已变化、积分不足、助手在等摄影师补充；项目已归档时不写提示。

### Scenario: 等到生成完成
- GIVEN 助手调用生成，没有选择后台
- WHEN 生成用了几分钟才完成
- THEN 助手拿到生成结果后才继续，回答里说的是最终结果，而不是「还在生成」

### Scenario: 助手选择后台生成
- GIVEN 助手要生成一张图，同时还有别的事要做
- WHEN 助手以后台方式调用生成
- THEN 工具卡片显示为后台任务，助手立即接着做别的事；生成完成时，对话里出现一行完成提示，助手在当前这一轮或新的一轮里读到结果

### Scenario: 摄影师让助手不再等
- GIVEN 助手正在等一个耗时较长的生成
- WHEN 摄影师点工具卡片上的「转后台」
- THEN 卡片立刻变为后台任务，助手不再等它，接着往下做；生成完成时结果作为通知回到对话

### Scenario: 对话空闲时后台任务完成
- GIVEN 这一轮已经结束，还有一个后台生成在进行
- WHEN 生成完成
- THEN 对话里出现完成提示，助手随即自动开始新的一轮来处理结果；同一模型和主 Skill 版本的任务在合并窗口内只开一轮，不同配置依次开轮

### Scenario: 连续自动回复有上限
- GIVEN 摄影师没有发消息，助手已经连续自动开始了 5 轮，第 5 轮里又以后台方式发起了生成
- WHEN 这个生成在对话空闲时完成
- THEN 对话里出现完成提示，但助手不会再自动开始；摄影师下次发消息时，助手会一并读到这条结果，连续计数从头算

### Scenario: 停止对话不停止后台任务
- GIVEN 有后台生成在进行
- WHEN 摄影师点停止
- THEN 助手停下，后台生成继续，完成时照常出现完成提示，但助手不会自动开始；摄影师下次发消息时，助手会一并读到这条结果

### Scenario: 取消后台任务
- GIVEN 有后台生成在进行
- WHEN 摄影师在任务卡片上点「取消」
- THEN 生成被取消，卡片显示已取消，助手收到「已取消」的通知

### Scenario: 积分不足时不自动开始
- GIVEN 账号积分不足以开始新的一轮
- WHEN 后台任务在对话空闲时完成
- THEN 对话里照常出现完成提示，但助手不会自动开始；摄影师下次发消息时，助手会一并读到这条结果

### Scenario: 停止先于前台压缩采用
- GIVEN 助手的前台压缩已编码，候选结果尚未采用
- WHEN 摄影师先停止来源运行
- THEN 候选被丢弃，画布保留原图

### Scenario: 快速压缩先转后台
- GIVEN 压缩已编码，工具任务尚未发布结果
- WHEN 摄影师先完成转后台操作
- THEN 原工具得到转后台结果，压缩结束后对话收到一条完成通知

### Scenario: 来源运行交付部分内容后失败
- GIVEN 来源运行已交付部分内容，随后以带错误码的 `partial` 结束
- WHEN 后台任务在对话空闲时完成
- THEN 对话出现完成通知，摄影师下次发消息时一并送达

### Scenario: 唤醒等待锁时通知已送达
- GIVEN 唤醒正等待锁，候选通知仍待送达
- WHEN 摄影师的运行先送达该通知，之后唤醒取得锁
- THEN 这条通知不会创建新运行或预留积分
