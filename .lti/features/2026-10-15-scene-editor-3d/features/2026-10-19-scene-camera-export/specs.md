## creative/scene: ADD 摆放摄像机

摄影师可以在场景里放多台摄像机，设置焦距、画幅和高度，从摄像机的视角取景，也可以让摄像机对齐当前视图。这些都是普通的场景修改：静默保存，Cmd+Z 可以撤销。视场角按画面长边对应传感器长边计算，与全画幅相机的经验一致。

### Scenario: 按当前视角添加摄像机
- GIVEN 摄影师在编辑视图里转到一个满意的视角
- WHEN 在「添加」菜单选「摄像机」
- THEN 新摄像机出现在当前视角的位置、朝当前视角的方向，焦距 35 mm、画幅 3:2；属性栏可以改标签、焦距、画幅和高度

### Scenario: 从摄像机取景
- GIVEN 场景里选中了一台画幅 16:9 的摄像机
- WHEN 按 `0`
- THEN 视口切到这台摄像机的视角，显示 16:9 的取景框，框外压暗；框内画面与这台摄像机的导出图一致
- WHEN 再按 `0`，或拖动环绕视图
- THEN 退出相机视图

### Scenario: 摄像机对齐当前视图
- GIVEN 场景里选中了一台摄像机，视口在另一个视角
- WHEN 按 `Ctrl + Alt + 0`（macOS 为 `Cmd + Alt + 0`）
- THEN 摄像机移到当前视图的位置和朝向，产生一个修订；Cmd+Z 撤销回原位

### Scenario: 竖拍与横拍同一焦距取景一致
- GIVEN 一台焦距 35 mm、画幅 3:2 的摄像机
- WHEN 把画幅改成 2:3
- THEN 画面长边方向的取景范围不变，与全画幅相机竖拍 35 mm 一致；改回 3:2 时画面与原来相同

### Scenario: 换传感器预设
- GIVEN 一台焦距 35 mm 的全画幅摄像机
- WHEN 在「更多」里把传感器预设改成 APS-C
- THEN 传感器变为 23.5 × 15.6 mm，属性栏显示等效焦距约 53.6 mm，取景随之变窄

### Scenario: 构图辅助线
- GIVEN 摄影师在相机视图里
- WHEN 打开三分线
- THEN 取景框内显示三分线；导出图里没有辅助线；重开编辑器后保持上次的选择

## creative/scene: ADD 摄像机景深与对焦

摄像机可以打开景深，设置光圈和对焦。对焦可以填距离，也可以选场景里的物件或空物体。打开景深后，白模导出按光圈和对焦虚化，相机视图打开「景深预览」时视口实时虚化；线稿始终清晰。景深默认关闭。助手和摄影师调的是同一组相机参数；助手回看的截图默认清晰，助手可以要求按景深回看。

### Scenario: 按光圈看清晰范围
- GIVEN 一台 50 mm 的全画幅摄像机
- WHEN 打开景深，光圈设为 f/2.8，对焦距离 3 m
- THEN 属性栏显示清晰范围约 2.74–3.32 m，线框在 3 m 处标出焦点

### Scenario: 对焦到物件
- GIVEN 场景里有一尊雕像
- WHEN 摄影师把对焦设为「物件」，在视口里拾取雕像
- THEN 焦点落在雕像上；之后移动雕像，焦点跟着它走

### Scenario: 对焦到空物体
- GIVEN 摄影师想把焦点放在两根柱子之间的空处
- WHEN 在「添加」菜单选「空物体」，把它移到那里，再让摄像机对焦到它
- THEN 视口里显示空物体的十字标记，焦点落在它的位置

### Scenario: 白模导出按光圈虚化
- GIVEN 一台打开了景深的摄像机，光圈 f/1.8，对焦到近处的物件
- WHEN 导出白模和线稿
- THEN 白模图里对焦物件清晰、远处背景虚化；线稿全清晰

### Scenario: 相机视图实时预览景深
- GIVEN 一台打开了景深的摄像机，摄影师在它的相机视图里
- WHEN 打开「景深预览」开关
- THEN 视口按这台摄像机的光圈和对焦实时虚化，与导出图一致；改动场景、对焦物件或光圈时虚化跟着更新，开关保持打开
- WHEN 再点一下关闭开关
- THEN 视口不再虚化，AO 与打开前相同

### Scenario: 视口与导出同一套白模画面
- GIVEN 任意场景
- WHEN 摄影师在编辑器里查看，或助手不带景深调用 `render_view`
- THEN 画面带与白模导出相同的 AO（接触阴影），不需要打开景深预览；网格和变换手柄不受 AO 影响

### Scenario: 对焦物件被删除
- GIVEN 一台摄像机对焦在一尊雕像上
- WHEN 摄影师删除了雕像
- THEN 摄像机改按对焦距离对焦，属性栏提示对焦物件已删除；删除、撤销都照常进行，撤销后焦点回到雕像

### Scenario: 助手设置相机参数
- GIVEN 助手在搭场景
- WHEN 助手给摄像机写焦距、画幅、传感器、景深开关、光圈和对焦物件
- THEN 写入成功，属性栏显示相同的设置；对焦物件不存在、是摄像机自己、灯光或另一台摄像机，或光圈超出 0.5–64 时，写入被拒绝并说明原因

### Scenario: 助手回看默认不带景深
- GIVEN 一台打开了景深的摄像机
- WHEN 助手按这台摄像机回看，不要求景深
- THEN 截图全清晰，助手看到的是场景结构

### Scenario: 助手按景深回看
- GIVEN 一台打开了景深的摄像机，光圈 f/1.8，对焦在近处的物件上
- WHEN 助手按这台摄像机回看，并要求带景深
- THEN 截图里对焦物件清晰、远处背景虚化，与这台摄像机的白模导出一致

### Scenario: 不能按景深回看时说明原因
- GIVEN 助手要求带景深回看
- WHEN 用的是临时视点或预设视角，或这台摄像机没有打开景深
- THEN 工具直接返回错误并说明原因，不发起回看

## creative/scene: ADD 导出分镜到画布

摄影师或助手可以把场景按摄像机导出成图，落成画布上的图片节点。导出方式有白模（`clay`）和线稿；每张图按摄像机画幅出图，长边 2048。图片节点记录来源场景、修订、摄像机和导出方式。

### Scenario: 导出 3 台摄像机
- GIVEN 场景里有 3 台摄像机
- WHEN 摄影师在编辑视图里点「导出」，选全部摄像机和两种方式
- THEN 画布上场景节点右侧出现 6 个图片节点，每台摄像机一行、白模和线稿各一列；在画布上撤销一次，6 个节点一起移除

### Scenario: 先保存再导出
- GIVEN 摄影师刚移动了一个物件，修改还没保存完
- WHEN 点「导出」
- THEN 先完成保存，再按保存后的场景出图；导出图记录的修订包含这次移动

### Scenario: 再次导出不叠在旧图上
- GIVEN 场景节点右侧已经有一组导出图
- WHEN 再导出一次
- THEN 新的一组排在旧图下方，不重叠，旧图保留

### Scenario: 不能导出时说明原因
- GIVEN 场景里没有摄像机，或选择的组合超过 48 张图
- WHEN 打开导出
- THEN 「导出」不可用，分别提示先添加摄像机、分次导出

### Scenario: 提交时断网不重复
- GIVEN 摄影师点了导出，图片已经上传，提交时网络中断，而服务端其实已经建好节点
- WHEN 页面重试提交
- THEN 拿到的是同一组节点，画布上不会出现第二组

### Scenario: 助手导出
- GIVEN 摄影师请助手导出分镜，只开着画布页
- WHEN 助手调用导出
- THEN 画布页在后台完成导出，任务完成时图片出现在这次对话所在画布的场景节点旁；助手得到每张图的节点、摄像机和方式

### Scenario: 导出中途换页面不重复
- GIVEN 执行助手导出的页面已经出完图，但在完成任务前被关闭
- WHEN 另一个页面接手这个任务
- THEN 画布上只出现接手页面导出的一组节点；助手照常得到结果

### Scenario: 助手导出时场景节点已被移走
- GIVEN 助手的导出任务正在执行
- WHEN 摄影师在任务完成前把场景节点从画布上删掉
- THEN 一个节点也不建，助手得到失败原因

## creative/scene: ADD 导出图提示场景已更新

导出之后场景被修改，并且修改会改变这张图时，画布上的导出图显示「场景已更新」；改回原样后不再显示。只是提示，不改图片。

### Scenario: 几何变化让导出图过时
- GIVEN 画布上有某台摄像机的白模图和线稿
- WHEN 摄影师移动了场景里的一根柱子
- THEN 两张图都显示「场景已更新」

### Scenario: 改挂分组也算几何变化
- GIVEN 画布上有某台摄像机的白模图和线稿
- WHEN 助手在同一次修改里把两根柱子移进一个旋转过的分组，并新增了一台摄像机
- THEN 两张图都显示「场景已更新」

### Scenario: 改回原样不再提示
- GIVEN 导出后摄影师移动了一根柱子，导出图显示「场景已更新」
- WHEN 把柱子移回原位
- THEN 导出图不再显示「场景已更新」

### Scenario: 摄像机被删除
- GIVEN 画布上有某台摄像机的导出图
- WHEN 摄影师删除了这台摄像机
- THEN 导出图显示「场景已更新」

### Scenario: 环境只影响白模
- GIVEN 画布上有某台摄像机的白模图和线稿
- WHEN 摄影师改了太阳高度
- THEN 白模图显示「场景已更新」，线稿不显示

### Scenario: 景深参数只影响白模
- GIVEN 一台打开了景深的摄像机，画布上有它的白模图和线稿
- WHEN 摄影师改了光圈，或移动了对焦物件
- THEN 白模图显示「场景已更新」，线稿不显示；景深关闭时改光圈，两张图都不显示

### Scenario: 不影响画面的修改不提示
- GIVEN 画布上有某台摄像机的导出图
- WHEN 只新加、删除或调了另一台摄像机，加了或删除一盏灯光，改了场景标题或编辑器显示模式
- THEN 导出图不显示「场景已更新」

### Scenario: 换了图或场景没了就不再提示
- GIVEN 一张导出图之后场景有过几何修改
- WHEN 摄影师换掉了这个节点的图片内容，或场景已被删除
- THEN 不显示「场景已更新」

## creative/scene: ADD 助手用目标点摆朝向

助手修改场景时可以给物件写一个目标点，服务端按 three.js `Object3D.lookAt` 的规则算出朝向：摄像机和灯光的 −Z、其余物件的 +Z 对准目标点，上方向为 +Y。

### Scenario: 摄像机对准物件
- GIVEN 场景里有一个石台，中心在 (0, 0.4, −3)
- WHEN 助手加一台摄像机，位置 (4, 1.6, 2)，目标点写石台中心，再按这台摄像机回看
- THEN 石台在截图的画面中心

### Scenario: 在分组里也对得准
- GIVEN 摄像机放在一个旋转过的分组里
- WHEN 助手给它写目标点
- THEN 摄像机在世界坐标里对准目标点，与 three.js 的结果一致

### Scenario: 写法冲突被拒绝
- GIVEN 助手在同一处修改里既写了目标点又写了旋转，目标点与物件位置重合，或者同一次修改里还移动或改挂了物件的父级
- WHEN 提交修改
- THEN 修改被拒绝并说明原因，场景不变
