## creative/scene: ADD 助手搭建和修改场景

助手可以读场景、改场景、用几何代码生成模型、截图回看。它可以在画布上新建场景节点，摄影师不打开场景也能让它搭建。需要页面完成的工作（烘焙模型、截图）由服务端派成任务，交给打开着的创意空间页面执行。

### Scenario: 在编辑视图里请助手搭景
- GIVEN 摄影师打开场景编辑视图
- WHEN 用一段描述请助手搭景
- THEN 助手写出若干程序化物件并摆放，过程中至少回看一次截图；物件陆续出现在编辑器里

### Scenario: 不打开场景也能搭建
- GIVEN 摄影师停在画布视图，没有打开任何场景
- WHEN 请助手搭一个场景
- THEN 助手在画布上新建场景节点并完成搭建，任务由画布页在后台执行；助手面板里能看到回看的截图；之后打开场景，看到搭好的结果

### Scenario: 编译失败由助手自己修
- GIVEN 助手写的几何代码有错误、超时或超出上限
- WHEN 页面执行烘焙任务
- THEN 助手收到错误信息和行号，运行不失败，场景不变；助手可以修改代码重试

### Scenario: 点选物件让助手改
- GIVEN 摄影师在编辑视图里选中了一根柱子，它和别的柱子共用同一个模型
- WHEN 对助手说「改成断裂的」
- THEN 只有这根柱子改变，先分叉出新模型；只改参数时助手不重写代码

### Scenario: 不能看图的模型没有截图工具
- GIVEN 当前选用的模型不支持图片输入
- WHEN 助手工作
- THEN 助手没有截图回看这个工具

## creative/scene: ADD 助手的任务由页面执行

### Scenario: 等待页面时不占助手槽位
- GIVEN 助手调用了需要页面执行的工具
- WHEN 任务还没完成
- THEN 运行处于「等待页面执行」，不占写入槽位；摄影师在对话里发消息不会让它提前继续

### Scenario: 同一任务只由一个页面执行
- GIVEN 同一账号开着两个创意空间标签页
- WHEN 服务端派出一个任务
- THEN 只有一个标签页执行它；执行中的标签页关闭后，另一个标签页在租约到期后接手；旧标签页迟到的提交被拒绝

### Scenario: 页面关闭提醒与继续
- GIVEN 本标签页正在执行助手的任务
- WHEN 摄影师想关闭页面
- THEN 页面常驻「关闭会中断」提示；本页是唯一的创意空间标签页时浏览器会拦截关闭；重新打开后任务被重新领取，运行从原步骤继续，不重复写入

### Scenario: 没有页面时任务过期
- GIVEN 所有创意空间页面都关着
- WHEN 任务等待超过 30 分钟
- THEN 任务过期，助手被告知页面未打开，并转告摄影师

### Scenario: 后台标签页照常执行
- GIVEN 执行任务的标签页切到了后台
- WHEN 助手继续派任务
- THEN 任务照常被领取和执行

## creative/scene: ADD 助手不覆盖摄影师的修改

### Scenario: 按过时视图写入会冲突
- GIVEN 助手读过场景之后，摄影师改了某个物件
- WHEN 助手改同一物件的同一类属性
- THEN 助手的写入冲突，摄影师的修改保留；助手得知冲突的物件、改动者和当前状态

### Scenario: 烘焙期间被改动
- GIVEN 助手正在为某个物件烘焙新模型
- WHEN 摄影师移动了它
- THEN 两边都成功
- WHEN 摄影师改了它的参数、换了模型或删除了它
- THEN 助手的写入冲突、不覆盖；助手重试时复用已经烘焙好的结果，不重新编译

### Scenario: 助手工作中的物件高亮
- GIVEN 助手正在为某个物件烘焙，或本次运行 60 秒内改过它
- WHEN 摄影师在编辑视图里看到或选中它
- THEN 它有描边和「助手正在修改」标注；摄影师编辑时显示不打断操作的提示，修改照常生效

## creative/scene: ADD 助手知道场景的变化

### Scenario: 变更摘要
- GIVEN 助手上次写入场景之后，摄影师手动改过物件、从历史恢复过，或用清单恢复过助手的改动
- WHEN 摄影师再和助手对话，或助手读场景
- THEN 助手得到「自你上次写入后的变化」摘要，说明谁改了哪些物件、恢复到了第几版

## creative/scene: ADD 本轮改动清单与撤回

### Scenario: 恢复这一处
- GIVEN 助手的一轮运行改过场景并已结束
- WHEN 摄影师在助手面板的本轮改动清单里点某一处的「恢复这一处」
- THEN 只有这一处回到本轮之前的样子，产生一个修订

### Scenario: 撤销本轮
- GIVEN 本轮改动清单里有多处可恢复
- WHEN 摄影师点「撤销本轮」
- THEN 这些地方一起回到本轮之前的样子，通常产生一个修订

### Scenario: 别人改过的不覆盖
- GIVEN 本轮改过的某一处之后又被摄影师或其他运行改过
- WHEN 摄影师恢复这一处或撤销本轮
- THEN 这一处标为不可恢复并说明原因，其余照常恢复

### Scenario: 助手撤回自己的改动
- GIVEN 摄影师在对话里要求助手撤回它之前的改动
- WHEN 助手执行撤回
- THEN 它改过的单元恢复到那次运行开始前的版本；被别人改过的跳过并告诉摄影师
