## creative/scene: ADD 模型存入资产库

摄影师可以把场景里的代码模型存进资产库。存进去的是摄影师当时看到的那一版模型、参数和材质；位置、旋转和缩放属于场景，不随资产保存。同一版模型配同样的材质，在库里只有一份，再存只追加分组。

### Scenario: 存入资产库
- GIVEN 场景里有一个已生成好的代码模型实例
- WHEN 摄影师选中它，在物件菜单里点「存入资产库」，确认标题并选一个分组
- THEN 资产库的该分组里出现这个模型，类型为「模型」，卡片缩略图显示它在场景里配的材质；标题默认是模型名；弹框里说明位置、旋转和缩放不随资产保存

### Scenario: 同一版模型再存一次
- GIVEN 某个模型已经存入资产库
- WHEN 摄影师对引用同一版模型、配同样材质的实例再点「存入资产库」，选另一个分组
- THEN 提示「已在资产库中」，不新建资产，只把它归入这个分组

### Scenario: 换了材质再存
- GIVEN 某个模型已经存入资产库
- WHEN 摄影师给场景里的这个实例换了一个槽位的材质，再点「存入资产库」
- THEN 资产库里多出一份资产，缩略图显示新的材质；原来那份不变

### Scenario: 不能存入的物件
- GIVEN 摄影师选中的是内置基础体、灯光、「模型不可用」的占位、还在生成中的模型，或改动还没保存完的模型实例
- WHEN 打开物件菜单
- THEN「存入资产库」不可点，并说明原因

### Scenario: 存入前模型被别人改了
- GIVEN 摄影师打开了存入弹框
- WHEN 助手在此期间改了这个实例的模型或材质，摄影师再点存入
- THEN 不存入，提示模型刚被修改；编辑器显示出新版后，弹框提示「模型已更新为最新版本」

### Scenario: 确认新版后再存
- GIVEN 弹框已提示「模型已更新为最新版本」
- WHEN 摄影师再点存入
- THEN 存进资产库的是新版模型和材质

## creative/scene: ADD 从资产库放入模型

摄影师可以把资产库里的模型放进任意场景，模型带着资产的材质进来。放进来的模型与库里的那份互不影响：之后调参数、换材质只改这个场景。

### Scenario: 从「添加」菜单放入
- GIVEN 资产库里有模型
- WHEN 摄影师在场景视图里按 Shift + A，选「从资产库添加…」，在打开的资产抽屉里点一个模型
- THEN 抽屉只列出模型；点击后模型按参考点吸附到打开菜单处光标下的表面并被选中，名称为资产标题，材质与资产相同，属性栏立即显示模型名、参数和尺寸；一次 Cmd+Z 撤销；抽屉收起

### Scenario: 拖进视口时吸附表面
- GIVEN 资产抽屉在场景视图里打开，场景里有地面和一个方块
- WHEN 摄影师把一个落地模型的卡片拖到方块顶面上
- THEN 光标下出现模型虚影，立在方块顶面上；松手后模型放在虚影的位置，一次 Cmd+Z 撤销；抽屉保持打开，可以接着拖下一个

### Scenario: 墙挂与吊顶模型
- GIVEN 场景里有墙面和顶面
- WHEN 摄影师把墙挂模型拖到墙面上，把吊顶模型拖到顶面下
- THEN 墙挂模型背面贴墙、正面朝外；吊顶模型顶面贴着顶面

### Scenario: 没有合适的表面
- GIVEN 场景里没有顶面
- WHEN 摄影师把吊顶模型拖进视口
- THEN 模型包围盒的底面落在地面上，不会埋进地下

### Scenario: 取消拖入
- GIVEN 摄影师正把模型卡片拖进视口
- WHEN 拖出视口或按 Esc
- THEN 虚影消失，场景不变

### Scenario: 放入后修改不影响库和原场景
- GIVEN 场景 A 里的模型存入了资产库，又放进了场景 B
- WHEN 摄影师在场景 B 里调这个模型的参数、给槽位换材质
- THEN 场景 B 里的模型随之变化；场景 A 的实例、资产库里的缩略图和预览都不变；再从资产库放入一次，仍是存入时的样子；刷新页面后再改，或者由助手来改，结果相同

### Scenario: 助手放入库里的模型
- GIVEN 资产库里有一个名为「哥特束柱」的模型
- WHEN 摄影师请助手把它放到门两边
- THEN 助手在资产库里找到这个模型，放入两个实例，两个实例引用同一版模型，材质与资产相同

## creative/library: ADD 资产库里的模型

资产库可以存放 3D 模型。模型和其他资产一样可以分组、打标签、评分、进回收站；它只能放进 3D 场景，不能放到画布上。

### Scenario: 浏览与筛选
- GIVEN 资产库里有图片和模型
- WHEN 摄影师在类型筛选里选「模型」
- THEN 只列出模型，每张卡片显示带材质的模型缩略图

### Scenario: 查看浮窗里转着看
- GIVEN 摄影师在资产库页或画布的资产抽屉里
- WHEN 打开一个模型
- THEN 查看浮窗显示 3D 预览，可以拖动旋转、滚轮缩放，在「白模」和「材质」之间切换，材质与存入时场景里配的一致；右侧显示尺寸、面数、材质槽及所配材质和参数；「下载」得到 `.glb` 文件

### Scenario: 没打开模型时不加载 3D 引擎
- GIVEN 摄影师打开资产库页或画布页
- WHEN 浏览包括模型在内的卡片，但没有打开模型的查看浮窗、也没有进入场景
- THEN 页面不加载 3D 引擎

### Scenario: 模型不能放到画布上
- GIVEN 画布的资产抽屉里有模型
- WHEN 摄影师查看它的菜单，或把它拖到画布上
- THEN 菜单里没有「放入画布」「填充」「选参考」；拖到画布上不新建节点，提示「模型只能放进 3D 场景」；资产库页的「放入项目…」也不包含模型

### Scenario: 助手查找模型时看到要点
- GIVEN 资产库里有几个模型
- WHEN 助手按类型「模型」查找资产
- THEN 每个结果带模型的名称、尺寸（米）、挂载方式、面数、材质槽、参数名和所配材质，助手不用逐个读取就能初步挑选

### Scenario: 助手读取模型
- GIVEN 助手查到了一个模型
- WHEN 助手读取这个模型
- THEN 助手拿到完整的模型信息（尺寸、挂载方式、面数、材质槽与所配材质、部件、挂点、参数定义与当前值）并看到它的缩略图；拿不到生成代码

### Scenario: 当前模型不能看图
- GIVEN 当前对话用的模型不能看图，或摄影师没有允许图片预览
- WHEN 助手读取一个模型资产
- THEN 助手只拿到模型信息，并被告知没有附缩略图的原因；读取不失败

### Scenario: 助手把模型往画布上放
- GIVEN 助手搜到了资产库里的模型
- WHEN 助手试图把它放进画布节点
- THEN 被拒绝，错误说明模型只能放进 3D 场景、应改用 `edit_scene`；画布不变
