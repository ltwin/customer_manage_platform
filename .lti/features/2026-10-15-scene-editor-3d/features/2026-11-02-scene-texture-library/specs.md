## creative/scene: ADD 内置贴图材质

材质槽可以选平台内置的贴图材质。每一种都是一套完整的 PBR 材质：基础色、法线、AO、糙度、金属度，2K，来自 Poly Haven 等站点的 CC0 贴图，约 24 种，分木材、石材、砖墙、混凝土与抹灰、金属、布料、地面、瓷砖、屋面与沥青、皮革 10 类。不需要自己找图上传。

- **浏览与选用**：资产库页面、场景编辑器的资产面板、材质槽的「从资产库选」，在材质下都可以在「我的」和「内置」之间切换，两边不混排。内置项按品类列出缩略图、名称和尺寸，可以按名称筛选，可以在查看浮窗里看 3D 材质球，可以拖到物件上或选进槽位。内置项只读，不能评分、打标签、分组、收藏。
- **助手**：用资产搜索的内置来源查找，按 ID 选用，例如 `wood_floor@1`；没有资产库授权的对话也能用。
- **可调的**：色调、糙度、金属度等原理化参数（与贴图相乘），映射方式（三平面尺寸和旋转，或模型 UV 的重复次数），法线强度，透明方式。缺省按来源标注的真实尺寸三平面铺开，物件缩放时贴图不拉伸。
- **不可调的**：其中的单张贴图不能替换。要换图，用原理化 BSDF 配自己的图片。
- **生效范围**：与账号图片做的贴图相同，材质预览、最终渲染、`render_view`、`lit` 导出、资产缩略图和 3D 预览、屏幕外反射和探针 GI 都体现；离屏出图等贴图就绪。
- **稳定**：已发布的内置贴图材质外观不变，改外观发布新版本，已有场景不受影响。
- **读不到时**：视口显示占位并提示「贴图加载失败」，离屏出图失败并说明原因，不显示接口错误。
- 选用、调整都是普通的场景修改，静默保存，可以撤销；复制材质、存成材质资产时只带 ID 和参数。

### Scenario: 给地面铺木地板
- GIVEN 一块 3.4 米宽的地面
- WHEN 在场景资产面板的材质页切到「内置」，把「木地板」拖到地面上
- THEN 地面按 1.7 米一块显示木地板，横向重复两次；Cmd+Z 撤销后回到原来的材质

### Scenario: 调尺寸和色调
- GIVEN 一个用了内置贴图材质的方块
- WHEN 把三平面尺寸改成 0.5 米，基础色调成浅灰
- THEN 贴图块变小，颜色按色调变化；刷新后与修改后一致

### Scenario: 助手选用内置贴图材质
- GIVEN 摄影师请助手「把墙面换成红砖」
- WHEN 助手修改场景
- THEN 助手在内置来源里查到红砖，墙面的槽位写入内置红砖材质，用 `render_view` 回看时看得到红砖贴图

### Scenario: 在资产库里浏览内置材质
- GIVEN 资产库页面
- WHEN 在左侧选「内置材质」，输入「砖」
- THEN 只显示砖墙类的内置材质；打开其中一项能看到可拖动旋转的材质球；评分、标签、分组等整理操作不可用

### Scenario: 内置贴图没有部署好
- GIVEN 服务端读不到某种内置贴图的文件
- WHEN 打开用了它的场景，并导出 `lit` 图
- THEN 视口显示占位并提示「贴图加载失败」，导出失败并说明原因，界面上没有接口错误原文
