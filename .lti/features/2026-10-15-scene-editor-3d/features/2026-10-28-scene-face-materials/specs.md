## creative/scene: ADD 面编辑与面级材质分配

摄影师可以在场景里选中物件的一部分面，把它们指定到一个材质槽，再给这个槽配材质，比如只把方块的正面换成砖墙。面编辑只给面分配材质，不移动、旋转、缩放面。指定一次是场景的一条修订，配材质是另一条，两者分别撤销。

### Scenario: 进出面编辑
- GIVEN 摄影师选中了一个基础体或模型实例
- WHEN 按 Tab
- THEN 进入面编辑，状态栏显示「面编辑」和物件名，其他物件不可选；再按 Tab 回到物件模式

### Scenario: 不能面编辑的物件
- GIVEN 摄影师选中的是灯光、摄像机、分组、体积物件或锁定的物件
- WHEN 按 Tab
- THEN 不进入面编辑，状态栏说明原因

### Scenario: 选面
- GIVEN 摄影师在方块上进入了面编辑
- WHEN 在方块的一面上单击
- THEN 选中这一整面（两个三角形），选中的面着色显示；Shift + 单击把它去掉

### Scenario: 其他选择方式
- GIVEN 摄影师在面编辑中
- WHEN 框选、按 A / Alt + A、Ctrl + I、L / Ctrl + L，或用「选择」菜单的扩选、缩选
- THEN 结果与 Blender 的面选择模式一致；框选只选看得见的面

### Scenario: 指定到新槽位再配材质
- GIVEN 摄影师选中了方块的正面
- WHEN 在材质栏点「+ 新槽位」，在新槽位上点「指定」，再给它选砖墙材质
- THEN 指定后场景多一条修订，正面暂时沿用原来的材质；配上材质后只有正面变成砖墙，场景再多一条修订；选区保留，可以接着指定给下一个槽位

### Scenario: 撤销与重新打开
- GIVEN 摄影师刚给新槽位指定了面并配了材质
- WHEN 按两次 Cmd+Z，再重做两次，然后重新打开场景
- THEN 第一次撤掉材质，第二次撤掉指定；重做后恢复；重新打开时槽位和材质与关闭前一致

### Scenario: 共用模型只改这一个
- GIVEN 两个实例共用同一个模型
- WHEN 摄影师在其中一个上指定面，在询问里选「只改这个」
- THEN 只有这个实例换成带新分配的模型，另一个实例不变；选「所有实例」时两个一起变

### Scenario: 选中槽位的面
- GIVEN 物件已有几个槽位
- WHEN 摄影师在面编辑里点某个槽位的「选择」或「取消选择」
- THEN 这个槽位的面加入选区或从选区去掉

### Scenario: 分配太碎
- GIVEN 摄影师选了大量不相连的零散三角形
- WHEN 点「指定」，而分配超出上限，或物件的槽位会超过 32 个
- THEN 不保存，提示「面分配太碎，请在模型代码里划分槽位」或槽位太多；场景不变

### Scenario: 各种带材质的画面划分一致
- GIVEN 一个物件有面分配，新槽位配了材质
- WHEN 摄影师在「材质预览」「最终渲染」里看它，导出它的材质光照图，或助手截取它的材质光照截图
- THEN 这些画面里槽位的划分相同；白模、线稿和线框不区分槽位

### Scenario: 改参数时保留分配
- GIVEN 拱门、方块或代码模型上有面分配
- WHEN 摄影师只改不影响网格结构的参数，比如拱门的厚、方块的宽、模型的高度
- THEN 面分配保留

### Scenario: 改参数改了网格结构
- GIVEN 拱门上有面分配
- WHEN 摄影师改了门洞宽
- THEN 这个基础体的面分配在同一次修改里清空，提示「参数改变了面的划分，这个基础体的面分配已清空，撤销可以找回」

### Scenario: 模型只作废变了的网格
- GIVEN 代码模型的底座和柱身上都有面分配
- WHEN 摄影师把柱身从圆的改成方的
- THEN 柱身的分配作废，底座的保留；提示哪个槽位作废了多少个三角形，撤销可以找回

### Scenario: 改代码后对不上的网格
- GIVEN 代码模型里有两个同名、同结构的网格，各有面分配
- WHEN 摄影师改代码，交换了这两个网格的创建顺序，或让一个没有索引的网格的三角形换了顺序
- THEN 这些网格的分配作废并提示，不会落到另一个网格上

### Scenario: 助手读到分配出来的槽位
- GIVEN 场景里的物件有面分配
- WHEN 助手读取场景，或用 `write_model` 替换了一个有面分配的模型，或用 `edit_scene` 改了基础体参数
- THEN 助手看到的槽位包括面分配出来的槽位，标明来源和三角形数；替换模型、改参数后的结果说明分配保留和作废了多少；同一次基础体修改由编辑器和助手来做，保留还是清空的结果相同

### Scenario: 不合规的分配被拒绝
- GIVEN 有人提交的面分配区间重叠、未排序、超出上限，或有效槽位超过 32 个
- WHEN 场景命令到达服务端
- THEN 返回 `validation_failed`，场景不变；引用其他账号的模型修订时返回 `creative_model_unavailable`

## creative/library: ADD 模型资产带面分配

存进资产库的模型带着它的面分配，资产库里看到的划分和场景里一致。放进别的场景后再改分配，只改那个场景。

### Scenario: 存入带面分配的模型
- GIVEN 场景里的模型实例有面分配，分配出来的槽位配了材质
- WHEN 摄影师把它存入资产库
- THEN 资产带上面分配和这些槽位的材质；卡片缩略图按面分配显示材质

### Scenario: 不进场景直接查看
- GIVEN 资产库里有带面分配的模型
- WHEN 摄影师不打开任何场景，直接在资产库打开它的查看浮窗
- THEN 「材质」模式按面分配显示；信息里的材质槽包括面分配出来的槽位及所配材质

### Scenario: 放进另一个场景再改
- GIVEN 带面分配的模型已存入资产库
- WHEN 摄影师把它放进另一个场景，在那里重新指定一部分面
- THEN 放入时的划分与资产一致；改动只影响这个场景，原场景和资产库里的资产不变
