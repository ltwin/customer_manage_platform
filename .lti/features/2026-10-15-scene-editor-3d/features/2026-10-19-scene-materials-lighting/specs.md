## creative/scene: ADD 四种显示模式

编辑视图参照 Blender 的视口着色，提供线框、白模、材质预览、最终渲染四种显示模式。白模与白模导出一致，最终渲染与材质光照导出一致。显示模式是本机的查看状态，按场景记住，不写进场景，也不算一步编辑。

### Scenario: 切换显示模式
- GIVEN 场景里有分配了材质的物件和一盏投射阴影的点光
- WHEN 摄影师按 `Z`，在弹出的菜单里依次选线框、白模、材质预览、最终渲染
- THEN 线框只显示物件的轮廓边，能看到被挡住的物件，框选时被挡住的物件也会选中，点击仍选中最前面的表面；白模是统一的浅灰材质，灯光不影响画面；材质预览显示材质，光照是固定的中性室内光；最终渲染显示材质，点光照亮周围并投下阴影

### Scenario: 材质预览不受打光影响
- GIVEN 摄影师在材质预览模式下
- WHEN 删除场景里全部灯光，或改变太阳方向
- THEN 画面不变

### Scenario: 线框切换
- GIVEN 摄影师在最终渲染模式下
- WHEN 按 `Shift + Z`
- THEN 切到线框；再按一次回到最终渲染

### Scenario: 显示模式记在本机
- GIVEN 摄影师把场景切到最终渲染后离开
- WHEN 重开这个场景
- THEN 仍是最终渲染；Cmd+Z 不会撤销显示模式的切换；同一场景在另一个标签页里的显示模式不受影响

### Scenario: 第一次打开按场景的建议方式
- GIVEN 本机从没打开过这个场景，助手把场景的显示方式设成了 `lit`
- WHEN 摄影师打开场景
- THEN 以最终渲染显示

## creative/scene: ADD 按槽位分配材质

物件的每个材质槽位可以分配一种材质：原理化 BSDF，或带图案的程序化预设（石砖、木纹、大理石等）。基础体只有一个槽位，模型的槽位由几何代码划分。程序化预设按真实尺寸铺在物件表面，不依赖模型 UV，物件缩放时不拉伸。材质在材质预览、最终渲染和材质光照导出里显示。改动静默保存，Cmd+Z 可以撤销。

### Scenario: 给方块铺石砖
- GIVEN 场景里有一个 1 m 见方的方块
- WHEN 摄影师给它的槽位选「石砖」，再把方块沿 X 放大到 4 倍
- THEN 砖块大小不变，铺满更长的面，没有拉伸

### Scenario: 原理化 BSDF
- GIVEN 摄影师给一个球体的槽位选了原理化 BSDF
- WHEN 把金属度设为 1、糙度设为 0.2
- THEN 最终渲染里表面像抛光金属，映出天空

### Scenario: 半透明
- GIVEN 一块原理化 BSDF 的玻璃板立在一根柱子前
- WHEN 把 Alpha 设为 0.3
- THEN 能透过玻璃板看到柱子，玻璃板表面没有环境光遮蔽的阴影

### Scenario: 多选一起换材质
- GIVEN 选中了 5 根共用同一模型的柱子
- WHEN 给 `stone` 槽位选一种材质
- THEN 5 根柱子的 `stone` 槽位都换成它，只产生一个修订，一次 Cmd+Z 全部撤回

### Scenario: 预设转为原理化
- GIVEN 一个槽位用的是「漆面」预设
- WHEN 点「转为原理化」
- THEN 槽位改用原理化 BSDF，颜色、糙度、金属度沿用原来的值，画面看起来基本不变，可以继续调其他参数

### Scenario: 没有指定材质时按提示
- GIVEN 一个模型的槽位带提示 `wood`，没有分配材质
- WHEN 切到材质预览
- THEN 这个槽位显示为木纹；带不认识的提示的槽位显示模型代码里写的颜色，基础体显示中性浅灰

### Scenario: 不认识的材质
- GIVEN 场景里有一个槽位的材质是本版本不认识的预设
- WHEN 打开场景
- THEN 这个槽位显示中性灰，属性栏提示「未知材质」；其他编辑照常

## creative/scene: ADD 复制材质

材质可以从一个物件复制到其他物件，参照 Blender 的「关联材质」；单个槽位的材质也可以复制、粘贴，包括跨场景。

### Scenario: 复制到选中物件
- GIVEN 选中了两个模型和一个方块，活动物件是一根槽位为 `stone`、`trim` 的柱子
- WHEN 执行「复制材质到选中物件」
- THEN 有同名槽位的模型得到相同的材质，没有同名槽位的不变；只产生一个修订，一次 Cmd+Z 撤回

### Scenario: 单槽位的物件复制给全部槽位
- GIVEN 活动物件是只有一个槽位的方块，另一个选中的模型有 3 个槽位
- WHEN 执行「复制材质到选中物件」
- THEN 模型的 3 个槽位都换成方块的材质

### Scenario: 跨场景粘贴
- GIVEN 摄影师在一个场景里对某个槽位「复制材质」
- WHEN 到另一个场景的物件槽位上「粘贴材质」
- THEN 材质和参数相同，可以撤销

## creative/scene: ADD 编辑灯光与环境

摄影师可以添加平行光、点光、聚光，编辑它们的颜色、强度、阴影和光锥；没有选中物件时可以编辑天空、环境光、雾和曝光补偿。灯光和曝光补偿只在最终渲染和材质光照导出里生效；太阳方向、天空、环境光和雾在白模里也生效。改动静默保存，可以撤销。

### Scenario: 加一盏聚光
- GIVEN 摄影师在最终渲染模式下
- WHEN 用 Shift + A 加一盏聚光，把光锥角调到 30°，打开「投射阴影」
- THEN 光照范围和图标的光锥一致，物件在地面投下阴影；存储的光锥角为 π/12 弧度

### Scenario: 换灯光类型
- GIVEN 一盏聚光
- WHEN 把类型改成点光
- THEN 光锥角和柔化消失，颜色、强度、阴影设置保留

### Scenario: 白模里灯光不生效
- GIVEN 摄影师在白模模式下选中一盏灯
- WHEN 查看属性栏
- THEN 提示灯光在最终渲染模式下生效

### Scenario: 调太阳高度
- GIVEN 没有选中物件，天空是程序化天空
- WHEN 在「环境」里把太阳高度从 35° 调到 5°
- THEN 白模和最终渲染里影子都变长，天空变成黄昏色调；Cmd+Z 回到 35°

### Scenario: 调曝光补偿
- GIVEN 一个只有两盏壁灯的室内场景，最终渲染偏暗
- WHEN 没有选中物件时把「曝光补偿」调到 +2
- THEN 最终渲染变亮；白模不变；Cmd+Z 回到 0

### Scenario: 纯色天空和雾
- GIVEN 没有选中物件
- WHEN 把天空改成纯色，打开雾并设置起止距离
- THEN 背景和雾按设置显示，导出图一致

## creative/scene: ADD 手动编组

摄影师可以编组、取消编组、设置和清除父级，也可以在物件列表里拖动调整层级和顺序。这些操作都保持物件在画面中的位置，每个操作是一次修改、一步撤销，撤销后回到原来的父级、顺序和变换。

### Scenario: 编组
- GIVEN 选中了 3 个分属不同父级的物件
- WHEN 按 Ctrl + G
- THEN 出现一个新分组，3 个物件挂在它下面，画面中的位置不变；只产生一个修订
- WHEN 按 Cmd+Z
- THEN 分组消失，3 个物件回到原来的父级、顺序和变换

### Scenario: 取消编组
- GIVEN 选中一个旋转过、缩放过的分组
- WHEN 按 Ctrl + Alt + G
- THEN 分组被删除，子物件挂回它原来的父级，画面中的位置不变

### Scenario: 设置父级
- GIVEN 选中了两个物件，活动物件是一个空物体
- WHEN 按 Ctrl + P
- THEN 另一个物件挂到空物体下，位置不变；之后移动空物体，它跟着移动

### Scenario: 父级只能是分组
- GIVEN 选中了两个物件，活动物件是一个方块
- WHEN 按 Ctrl + P
- THEN 提示只能挂到分组或空物体下，场景不变

### Scenario: 清除父级
- GIVEN 选中一个挂在旋转过的分组里的物件
- WHEN 按 Alt + P
- THEN 物件挂回根，位置不变

### Scenario: 在物件列表里拖动
- GIVEN 物件列表里有一个分组和一个根下的物件
- WHEN 把物件拖到分组上
- THEN 物件挂进分组，画面中不动；拖到两行之间时，物件挂到那一行的父级下并排在该位置

### Scenario: 编组时助手改了其中一个物件
- GIVEN 摄影师选中 3 个物件准备编组，助手在此期间改了其中一个物件的位置
- WHEN 摄影师按 Ctrl + G
- THEN 编组按现有的冲突规则处理，不会出现物件跳位或丢失

## creative/scene: ADD 助手配材质和打光

助手可以给物件分配材质、加灯光、调天空和雾，用材质光照回看画面，也可以编组和改挂物件。材质的可选项来自与编辑器同一份目录；写错时工具直接说明原因并列出可用项，不改场景。

### Scenario: 请助手布置黄昏
- GIVEN 摄影师请助手「把这个场景改成黄昏、墙用石砖、窗户用彩色玻璃、加两盏暖色壁灯」
- WHEN 助手完成这一轮
- THEN 场景里写入了黄昏的程序化天空、墙的石砖材质、窗户的原理化 BSDF 透射材质和两盏暖色点光；助手至少用一次材质光照回看

### Scenario: 写了不存在的材质
- GIVEN 助手给一个槽位写了目录里没有的预设，或参数超出范围
- WHEN 提交修改
- THEN 修改被拒绝，场景不变，助手得到原因和可用的预设或参数范围

### Scenario: 没有内置 HDRI
- GIVEN 助手把天空写成 HDRI
- WHEN 提交修改
- THEN 修改被拒绝，助手得到「暂无内置 HDRI，请用程序化天空或纯色」

### Scenario: 助手编组
- GIVEN 场景里有 4 根散放的柱子
- WHEN 助手把它们编进一个分组，再整体移动分组
- THEN 编组时柱子在画面中不动，之后随分组一起移动

### Scenario: 助手用材质光照回看
- GIVEN 助手打完光
- WHEN 用材质光照方式回看某台摄像机
- THEN 截图与编辑器最终渲染模式下这台摄像机的画面一致

## creative/scene: MODIFY 导出分镜到画布

摄影师或助手可以把场景按摄像机导出成图，落成画布上的图片节点。导出方式有白模（`clay`）、线稿和材质光照（`lit`）；每张图按摄像机画幅出图，长边 2048。白模与编辑器的白模一致，材质光照与编辑器的最终渲染一致。图片节点记录来源场景、修订、摄像机和导出方式。

### Scenario: 导出 3 台摄像机
- GIVEN 场景里有 3 台摄像机
- WHEN 摄影师在编辑视图里点「导出」，选全部摄像机和白模、线稿两种方式
- THEN 画布上场景节点右侧出现 6 个图片节点，每台摄像机一行、白模和线稿各一列；在画布上撤销一次，6 个节点一起移除

### Scenario: 导出材质光照
- GIVEN 场景里有 3 台摄像机，摄影师在最终渲染模式下
- WHEN 打开「导出」
- THEN 白模、线稿、材质光照默认都勾选；导出后得到 3 行 3 列 9 个节点，材质光照图与相机视图里最终渲染的画面一致，摄像机打开景深时同样虚化

### Scenario: 白模模式下默认不带材质光照
- GIVEN 摄影师在白模模式下
- WHEN 打开「导出」
- THEN 默认只勾选白模和线稿，可以手动勾选材质光照

### Scenario: 先保存再导出
- GIVEN 摄影师刚移动了一个物件，修改还没保存完
- WHEN 点「导出」
- THEN 先完成保存，再按保存后的场景出图；导出图记录的修订包含这次移动

### Scenario: 再次导出不叠在旧图上
- GIVEN 场景节点右侧已经有一组导出图
- WHEN 再导出一次
- THEN 新的一组排在旧图下方，不重叠，旧图保留

### Scenario: 不能导出时说明原因
- GIVEN 场景里没有摄像机，或选择的组合超过 48 张图
- WHEN 打开导出
- THEN 「导出」不可用，分别提示先添加摄像机、分次导出

### Scenario: 提交时断网不重复
- GIVEN 摄影师点了导出，图片已经上传，提交时网络中断，而服务端其实已经建好节点
- WHEN 页面重试提交
- THEN 拿到的是同一组节点，画布上不会出现第二组

### Scenario: 助手导出
- GIVEN 摄影师请助手导出分镜，只开着画布页
- WHEN 助手调用导出
- THEN 画布页在后台完成导出，任务完成时图片出现在这次对话所在画布的场景节点旁；助手得到每张图的节点、摄像机和方式；助手可以要求材质光照图，不指定时导出白模和线稿

### Scenario: 助手知道导出图怎么拍的
- GIVEN 一台对焦在人物上、光圈 f/1.8、打开景深的摄像机已导出白模和线稿
- WHEN 助手读取画布，准备拿这两张图做参考重绘
- THEN 两个导出图节点都给出来源：哪台摄像机、哪种导出方式、导出时的焦距、景深开关、光圈、对焦距离和对焦物件「人物」，以及场景之后是否改过；助手按此在白模的重绘提示词里写明对焦在人物上、焦外虚化，线稿的提示词要求全清晰

### Scenario: 导出中途换页面不重复
- GIVEN 执行助手导出的页面已经出完图，但在完成任务前被关闭
- WHEN 另一个页面接手这个任务
- THEN 画布上只出现接手页面导出的一组节点；助手照常得到结果

### Scenario: 助手导出时场景节点已被移走
- GIVEN 助手的导出任务正在执行
- WHEN 摄影师在任务完成前把场景节点从画布上删掉
- THEN 一个节点也不建，助手得到失败原因

## creative/scene: MODIFY 导出图提示场景已更新

导出之后场景被修改，并且修改会改变这张图时，画布上的导出图显示「场景已更新」；改回原样后不再显示。只是提示，不改图片。哪些修改算数按导出方式区分：线稿只看几何和这台摄像机，白模另看环境和景深，材质光照再看灯光和材质。

### Scenario: 几何变化让导出图过时
- GIVEN 画布上有某台摄像机的白模图和线稿
- WHEN 摄影师移动了场景里的一根柱子
- THEN 两张图都显示「场景已更新」

### Scenario: 改挂分组也算几何变化
- GIVEN 画布上有某台摄像机的白模图和线稿
- WHEN 助手在同一次修改里把两根柱子移进一个旋转过的分组，并新增了一台摄像机
- THEN 两张图都显示「场景已更新」，即使柱子在画面中的位置没变

### Scenario: 改回原样不再提示
- GIVEN 导出后摄影师移动了一根柱子，导出图显示「场景已更新」
- WHEN 把柱子移回原位
- THEN 导出图不再显示「场景已更新」

### Scenario: 摄像机被删除
- GIVEN 画布上有某台摄像机的导出图
- WHEN 摄影师删除了这台摄像机
- THEN 导出图显示「场景已更新」

### Scenario: 环境不影响线稿
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图
- WHEN 摄影师改了太阳高度
- THEN 白模图和材质光照图显示「场景已更新」，线稿不显示

### Scenario: 灯光和材质只影响材质光照图
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图
- WHEN 摄影师改了一盏灯的颜色，或换了一个槽位的材质
- THEN 只有材质光照图显示「场景已更新」

### Scenario: 曝光只影响材质光照图
- GIVEN 画布上有某台摄像机的白模图、线稿和材质光照图
- WHEN 摄影师调了曝光补偿
- THEN 只有材质光照图显示「场景已更新」；调回原值后不再显示

### Scenario: 景深参数不影响线稿
- GIVEN 一台打开了景深的摄像机，画布上有它的白模图、线稿和材质光照图
- WHEN 摄影师改了光圈，或移动了对焦物件
- THEN 白模图和材质光照图显示「场景已更新」，线稿不显示；景深关闭时改光圈，三张图都不显示

### Scenario: 不影响画面的修改不提示
- GIVEN 画布上有某台摄像机的白模图和线稿
- WHEN 只新加、删除或调了另一台摄像机，加了或删除一盏灯光，改了场景标题、显示模式、曝光补偿，或者某个槽位的材质
- THEN 导出图不显示「场景已更新」

### Scenario: 换了图或场景没了就不再提示
- GIVEN 一张导出图之后场景有过几何修改
- WHEN 摄影师换掉了这个节点的图片内容，或场景已被删除
- THEN 不显示「场景已更新」
