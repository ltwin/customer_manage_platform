## creative/scene: ADD 材质贴图

原理化 BSDF 的槽位可以配五种贴图：基础色、法线、糙度、金属度、AO，与 Blender 原理化 BSDF 的同名输入相同。图片来自资产库、场景所在的画布，或者当场上传（上传的图片进资产库，以后还能再用）。基础色按 sRGB 读，其余按线性读；糙度、金属度、AO 可以选读哪个通道。

- **映射**：五张贴图共用一种映射。缺省是三平面投影，按设定的米尺寸平铺，物件缩放时贴图不跟着拉伸；也可以选模型 UV，按重复次数平铺。旋转和法线强度两种映射都能调。
- **透明**：不透明、透明裁切或半透明混合。透明裁切按基础色贴图的透明通道乘不透明度挖空，阈值可调，投下的影子同样挖空；半透明混合时透明度随贴图变化。
- **生效范围**：材质预览、最终渲染、`render_view`、`lit` 导出、屏幕外反射和探针 GI 都体现贴图；白模和线稿与以前一样不看材质。
- **场景持有图片**：场景引用的图片不会因为原图从画布或资产库删掉而失效，场景的所有修订都不再引用它之后才按现有规则回收。一个场景最多引用 64 张不同的图片。
- **等图片**：视口先按材质参数画，图片到了再重绘；离屏出图等图片加载完才渲染，有图片加载失败时这张图失败并写明是哪张。
- 配贴图、换映射、改透明方式都是普通的场景修改，静默保存，可以撤销；复制材质会连同贴图、映射和透明方式一起复制。

### Scenario: 给方块配一张基础色贴图
- GIVEN 一个原理化材质的方块
- WHEN 在属性栏的材质槽里点基础色的「选择」，从资产库选一张图片
- THEN 方块按三平面投影显示这张图，每 1 米一块；Cmd+Z 撤销后回到没有贴图的样子

### Scenario: 从画布选图或当场上传
- GIVEN 一个在画布上打开的场景
- WHEN 在选图框里切到「画布」选一张画布上的图片，或者切到「上传」选一个本机文件
- THEN 图片配到槽位上；上传的图片同时出现在资产库里

### Scenario: 缩放物件，贴图尺寸不变
- GIVEN 一个配了三平面贴图的方块
- WHEN 把方块放大两倍
- THEN 贴图块的大小不变，方块上的块数变多

### Scenario: 模型没有 UV
- GIVEN 一个不带 UV 的代码模型
- WHEN 把它的槽位映射方式改成「模型 UV」
- THEN 面板提示「这个模型没有 UV，按三平面显示」，视口按三平面投影显示，不出错图

### Scenario: 树叶面片挖空
- GIVEN 一个面片，基础色贴图带透明通道
- WHEN 透明方式选「透明裁切」
- THEN 透明的部分被挖空，地上的影子也有同样的镂空；从镜面反射里看也是挖空的

### Scenario: 没有贴图时选透明裁切
- GIVEN 一个没有基础色贴图的槽位
- WHEN 透明方式选「透明裁切」
- THEN 面板提示「没有透明贴图，裁切只看不透明度」

### Scenario: 原图删掉之后
- GIVEN 场景里一个槽位用了画布上的一张图片
- WHEN 摄影师把这张图片从画布和资产库都删掉
- THEN 场景照常显示这张贴图，再打开也一样

### Scenario: 图片不可用
- GIVEN 场景里一张贴图的图片已经不能读取
- WHEN 打开场景
- THEN 那个槽位的贴图旁显示「图片不可用」，悬停说明原因；渲染按没有这张贴图处理，其他贴图照常

### Scenario: 导出时有图片加载失败
- GIVEN 一个带贴图的场景，其中一张图片加载失败
- WHEN 导出 `lit` 图或执行 `render_view`
- THEN 这张图失败，原因写明是哪张图片，不出缺贴图的图

## creative/scene: ADD 表面阴影上限

普通表面最多同时用 8 张阴影贴图：投影的平行光占 4 张，聚光、点光、面光各占 1 张。按固定顺序选：先是天空的太阳，再按物件列表的顺序选打开了投影的灯，放得下就选。落选的灯照常照亮，只是不投影。选取与视角无关，拖动视角或灯光不改变结果；调整物件列表的顺序可以决定哪盏灯投影。隐藏的灯不占名额。

### Scenario: 投影灯太多
- GIVEN 场景里有太阳和四盏打开投影的聚光灯，还用了几套贴图
- WHEN 再打开一盏平行光的投影
- THEN 画面正常，不黑屏；放不下的灯在属性面板的「投影」旁显示「阴影超出上限」，悬停说明规则

## creative/scene: ADD 助手配贴图

助手读取场景时能看到每个槽位的贴图（图片 ID 和尺寸）、映射方式和透明方式，以及模型没有 UV、灯光阴影超出上限等提示。助手可以用账号里的图片或材质资产给槽位配贴图，写入后能用 `render_view` 回看。

### Scenario: 助手读场景
- GIVEN 一个槽位选了 UV 映射、模型却没有 UV 的场景，还有一盏阴影超出上限的灯
- WHEN 助手读取场景
- THEN 结果里列出这个槽位的贴图、映射和透明方式，标明它按三平面显示；那盏灯标为阴影超出上限

### Scenario: 助手引用不能用的图片
- GIVEN 助手在给槽位配贴图
- WHEN 引用了不存在、属于其他账号或者不是图片的内容
- THEN 修改被拒绝，结果写明是哪个贴图字段、哪张图片；场景不变

### Scenario: 原图删了，助手经材质资产仍能用
- GIVEN 一个材质资产的贴图原图已从画布和资产库删掉
- WHEN 助手读取这个材质资产，把它写到场景的槽位上
- THEN 写入成功，`render_view` 能看到贴图；材质资产或图片被撤销授权后，写入被拒绝

## creative/library: ADD 材质资产

资产库可以存放材质：一个槽位的材质参数、贴图、映射和透明方式，带一张材质球缩略图。材质资产与其他资产一样可以分组、打标签、评分、进回收站；它只能用到 3D 场景的槽位上，不能放到画布上。用到槽位时复制一份，之后改槽位不影响资产，改资产也不影响用过它的场景。

### Scenario: 存为材质资产
- GIVEN 在画布上打开的场景里，一个槽位配了材质和贴图
- WHEN 在这个槽位上点「存为材质资产…」，确认名称后存入
- THEN 资产库出现一项材质资产，卡片是这个材质的材质球；同样的材质再存一次只追加归类，不新建

### Scenario: 槽位没有指定材质
- GIVEN 一个按提示或默认材质显示的槽位
- WHEN 查看它的「存为材质资产…」
- THEN 按钮不可用，悬停提示先给这个槽位指定材质

### Scenario: 用到另一个场景
- GIVEN 资产库里有一个材质资产
- WHEN 在另一个场景的资产面板切到「材质」，把它拖到视图里的物件上、属性栏的槽位上，或者在槽位上点「材质资产…」选它
- THEN 那个槽位换成这个材质，画面与原槽位一致；Cmd+Z 撤销；之后修改原来的槽位，资产和这个场景都不变

### Scenario: 资产库里浏览和查看
- GIVEN 资产库里有图片、模型和材质
- WHEN 在类型筛选里选「材质」，再打开一个材质
- THEN 只列出材质，卡片带「材质」角标；查看浮窗在材质球上显示它，可以拖动旋转，右侧列出材质、贴图、映射和透明方式；没有「放入项目…」和「放入画布」

### Scenario: 原图删掉之后
- GIVEN 一个材质资产用了一张图片
- WHEN 这张图片从画布和资产库删掉
- THEN 材质资产和用了它的场景照常显示；材质资产彻底删除之后，不再被任何场景或资产引用的图片才被回收

### Scenario: 助手查找材质
- GIVEN 资产库里有几个材质
- WHEN 助手按类型「材质」查找资产
- THEN 每个结果带标题、预设、贴图种类与图片 ID、映射方式和透明方式；读取材质时得到完整的槽位和缩略图
