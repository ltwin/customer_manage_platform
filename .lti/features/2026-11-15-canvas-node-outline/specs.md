## creative/canvas: ADD 节点树

画布左侧面板有「画布」标签，按分组嵌套列出当前画布的全部节点，顶层和组内都按创建时间倒序（新建的在前），可按标题搜索，按节点类型多选筛选。节点树与画布选中双向同步：在树里点一个节点，画布选中它并把视口带到它；在画布上选中的节点在树里高亮。

### Scenario: 按分组嵌套列出
- GIVEN 画布上有 3 个顶层图片节点和 1 个内含 2 个文本节点的分组
- WHEN 摄影师打开节点树
- THEN 顶层是 3 个图片节点和该分组，分组下是 2 个文本节点，底部显示「共 6 节点」

### Scenario: 新建的在前
- GIVEN 摄影师先后建了图片 A、文本 B、图片 C
- WHEN 打开节点树
- THEN 顺序是 C、B、A；移动节点或调整层叠不改变顺序；删除 B 再撤销后 B 仍在 C 与 A 之间

### Scenario: 按标题搜索
- GIVEN 画布上标题含「晨光」的节点两个，正文含「晨光」但标题不含的文本节点一个，另有 10 个无关节点
- WHEN 摄影师在节点树搜索「晨光」
- THEN 只列出两个标题命中的节点及其所在分组，计数为「2 / 共 13 节点」

### Scenario: 按类型筛选保留分组路径
- GIVEN 画布上有图片和文本节点，部分图片在分组里
- WHEN 摄影师只勾选「图片」
- THEN 只列出图片节点，所在分组作为路径展开显示，分组不计入命中数

### Scenario: 点击定位
- GIVEN 某节点不在当前视口内
- WHEN 摄影师在节点树里点击它
- THEN 画布选中该节点并平移视口使其居中；节点大于视口时缩小到能完整放下

### Scenario: 画布选中反映到树
- GIVEN 节点树已打开
- WHEN 摄影师在画布上框选 2 个节点
- THEN 节点树中这 2 行高亮，并滚动到第一行可见

### Scenario: 在树里重命名可撤销
- GIVEN 画布可编辑
- WHEN 摄影师在节点树双击某节点标题改名并回车，再按 Cmd/Ctrl+Z
- THEN 改名后画布上的标题同步更新，撤销后恢复原名

### Scenario: 无命中
- GIVEN 搜索词在画布上没有任何匹配
- WHEN 摄影师输入它
- THEN 节点树显示「没有匹配的节点」和「清除筛选」，点击后恢复完整列表
