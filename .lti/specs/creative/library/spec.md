## 资产库里的模型

资产库可以存放 3D 模型。模型和其他资产一样可以分组、打标签、评分、进回收站；它只能放进 3D 场景，不能放到画布上。

### Scenario: 浏览与筛选
- GIVEN 资产库里有图片和模型
- WHEN 摄影师在类型筛选里选「模型」
- THEN 只列出模型，每张卡片显示带材质的模型缩略图

### Scenario: 查看浮窗里转着看
- GIVEN 摄影师在资产库页或画布的资产抽屉里
- WHEN 打开一个模型
- THEN 查看浮窗显示 3D 预览，可以拖动旋转、滚轮缩放，在「白模」和「材质」之间切换，材质与存入时场景里配的一致；右侧显示尺寸、面数、材质槽及所配材质和参数；「下载」得到 `.glb` 文件

### Scenario: 没打开模型时不加载 3D 引擎
- GIVEN 摄影师打开资产库页或画布页
- WHEN 浏览包括模型在内的卡片，但没有打开模型的查看浮窗、也没有进入场景
- THEN 页面不加载 3D 引擎

### Scenario: 模型不能放到画布上
- GIVEN 画布的资产抽屉里有模型
- WHEN 摄影师查看它的菜单，或把它拖到画布上
- THEN 菜单里没有「放入画布」「填充」「选参考」；拖到画布上不新建节点，提示「模型只能放进 3D 场景」；资产库页的「放入项目…」也不包含模型

### Scenario: 助手查找模型时看到要点
- GIVEN 资产库里有几个模型
- WHEN 助手按类型「模型」查找资产
- THEN 每个结果带模型的名称、尺寸（米）、挂载方式、面数、材质槽、参数名和所配材质，助手不用逐个读取就能初步挑选

### Scenario: 助手读取模型
- GIVEN 助手查到了一个模型
- WHEN 助手读取这个模型
- THEN 助手拿到完整的模型信息（尺寸、挂载方式、面数、材质槽与所配材质、部件、挂点、参数定义与当前值）并看到它的缩略图；拿不到生成代码

### Scenario: 当前模型不能看图
- GIVEN 当前对话用的模型不能看图，或摄影师没有允许图片预览
- WHEN 助手读取一个模型资产
- THEN 助手只拿到模型信息，并被告知没有附缩略图的原因；读取不失败

### Scenario: 助手把模型往画布上放
- GIVEN 助手搜到了资产库里的模型
- WHEN 助手试图把它放进画布节点
- THEN 被拒绝，错误说明模型只能放进 3D 场景、应改用 `edit_scene`；画布不变

## 模型资产带面分配

存进资产库的模型带着它的面分配，资产库里看到的划分和场景里一致。放进别的场景后再改分配，只改那个场景。

### Scenario: 存入带面分配的模型
- GIVEN 场景里的模型实例有面分配，分配出来的槽位配了材质
- WHEN 摄影师把它存入资产库
- THEN 资产带上面分配和这些槽位的材质；卡片缩略图按面分配显示材质

### Scenario: 不进场景直接查看
- GIVEN 资产库里有带面分配的模型
- WHEN 摄影师不打开任何场景，直接在资产库打开它的查看浮窗
- THEN 「材质」模式按面分配显示；信息里的材质槽包括面分配出来的槽位及所配材质

### Scenario: 放进另一个场景再改
- GIVEN 带面分配的模型已存入资产库
- WHEN 摄影师把它放进另一个场景，在那里重新指定一部分面
- THEN 放入时的划分与资产一致；改动只影响这个场景，原场景和资产库里的资产不变

## 材质资产

资产库可以存放材质：一个槽位的材质参数、贴图、映射和透明方式，带一张材质球缩略图。材质资产与其他资产一样可以分组、打标签、评分、进回收站；它只能用到 3D 场景的槽位上，不能放到画布上。用到槽位时复制一份，之后改槽位不影响资产，改资产也不影响用过它的场景。

### Scenario: 存为材质资产
- GIVEN 在画布上打开的场景里，一个槽位配了材质和贴图
- WHEN 在这个槽位上点「存为材质资产…」，确认名称后存入
- THEN 资产库出现一项材质资产，卡片是这个材质的材质球；同样的材质再存一次只追加归类，不新建

### Scenario: 槽位没有指定材质
- GIVEN 一个按提示或默认材质显示的槽位
- WHEN 查看它的「存为材质资产…」
- THEN 按钮不可用，悬停提示先给这个槽位指定材质

### Scenario: 用到另一个场景
- GIVEN 资产库里有一个材质资产
- WHEN 在另一个场景的资产面板切到「材质」，把它拖到视图里的物件上、属性栏的槽位上，或者在槽位上点「材质资产…」选它
- THEN 那个槽位换成这个材质，画面与原槽位一致；Cmd+Z 撤销；之后修改原来的槽位，资产和这个场景都不变

### Scenario: 资产库里浏览和查看
- GIVEN 资产库里有图片、模型和材质
- WHEN 在类型筛选里选「材质」，再打开一个材质
- THEN 只列出材质，卡片带「材质」角标；查看浮窗在材质球上显示它，可以拖动旋转，右侧列出材质、贴图、映射和透明方式；没有「放入项目…」和「放入画布」

### Scenario: 原图删掉之后
- GIVEN 一个材质资产用了一张图片
- WHEN 这张图片从画布和资产库删掉
- THEN 材质资产和用了它的场景照常显示；材质资产彻底删除之后，不再被任何场景或资产引用的图片才被回收

### Scenario: 助手查找材质
- GIVEN 资产库里有几个材质
- WHEN 助手按类型「材质」查找资产
- THEN 每个结果带标题、预设、贴图种类与图片 ID、映射方式和透明方式；读取材质时得到完整的槽位和缩略图
