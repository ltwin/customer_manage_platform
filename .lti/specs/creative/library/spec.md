## 资产库里的模型

资产库可以存放 3D 模型。模型和其他资产一样可以分组、打标签、评分、进回收站；它只能放进 3D 场景，不能放到画布上。

### Scenario: 浏览与筛选
- GIVEN 资产库里有图片和模型
- WHEN 摄影师在类型筛选里选「模型」
- THEN 只列出模型，每张卡片显示带材质的模型缩略图

### Scenario: 查看浮窗里转着看
- GIVEN 摄影师在资产库页或画布的资产抽屉里
- WHEN 打开一个模型
- THEN 查看浮窗显示 3D 预览，可以拖动旋转、滚轮缩放，在「白模」和「材质」之间切换，材质与存入时场景里配的一致；右侧显示尺寸、面数、材质槽及所配材质和参数；「下载」得到 `.glb` 文件

### Scenario: 没打开模型时不加载 3D 引擎
- GIVEN 摄影师打开资产库页或画布页
- WHEN 浏览包括模型在内的卡片，但没有打开模型的查看浮窗、也没有进入场景
- THEN 页面不加载 3D 引擎

### Scenario: 模型不能放到画布上
- GIVEN 画布的资产抽屉里有模型
- WHEN 摄影师查看它的菜单，或把它拖到画布上
- THEN 菜单里没有「放入画布」「填充」「选参考」；拖到画布上不新建节点，提示「模型只能放进 3D 场景」；资产库页的「放入项目…」也不包含模型

### Scenario: 助手查找模型时看到要点
- GIVEN 资产库里有几个模型
- WHEN 助手按类型「模型」查找资产
- THEN 每个结果带模型的名称、尺寸（米）、挂载方式、面数、材质槽、参数名和所配材质，助手不用逐个读取就能初步挑选

### Scenario: 助手读取模型
- GIVEN 助手查到了一个模型
- WHEN 助手读取这个模型
- THEN 助手拿到完整的模型信息（尺寸、挂载方式、面数、材质槽与所配材质、部件、挂点、参数定义与当前值）并看到它的缩略图；拿不到生成代码

### Scenario: 当前模型不能看图
- GIVEN 当前对话用的模型不能看图，或摄影师没有允许图片预览
- WHEN 助手读取一个模型资产
- THEN 助手只拿到模型信息，并被告知没有附缩略图的原因；读取不失败

### Scenario: 助手把模型往画布上放
- GIVEN 助手搜到了资产库里的模型
- WHEN 助手试图把它放进画布节点
- THEN 被拒绝，错误说明模型只能放进 3D 场景、应改用 `edit_scene`；画布不变
