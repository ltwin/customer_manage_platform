## 停止运行

助手运行时，输入框为空则发送按钮就是停止按钮；输入框有内容时按钮是发送，消息加入排队（见「消息排队与插队」）。点一次停止就停：面板立刻显示已停止，同一个对话可以马上发下一条消息。正在进行的模型请求会被中断；已经产生的费用由后台继续核实并入账，摄影师不需要等待，也看不到核实过程。已经交给生成服务的生成会跑完并计费，还没发出的生成会被撤回。

### Scenario: 运行中点停止
- GIVEN 助手正在输出回答，输入框为空
- WHEN 摄影师点击输入框右下角的停止按钮
- THEN 输出立刻停住、不再增长，并标为「已停止」，按钮变回发送；停止完成后显示已保存的内容（可能比点击时多出很短的一段）；可以马上发下一条消息

### Scenario: 等待补充时停止
- GIVEN 助手停下来等摄影师补充信息，输入框为空
- WHEN 摄影师点击停止按钮
- THEN 这次运行结束；如果在输入框里写了内容，按钮会变成「补充并继续」

### Scenario: 刚发出就停
- GIVEN 摄影师刚点了发送，消息已出现在对话里，但服务端还没建好这次运行
- WHEN 摄影师看向输入框
- THEN 按钮已经是停止，状态栏显示「正在处理」；此时点停止，立刻显示已停止，运行建好后随即被取消

### Scenario: 停止请求失败
- GIVEN 网络断开
- WHEN 摄影师点击停止
- THEN 面板先显示已停止，请求失败后恢复为运行中，并提示停止没有成功；再点一次可以重试

### Scenario: 停止后的费用
- GIVEN 停止时模型请求正在输出
- WHEN 后台随后核实了这次请求的用量
- THEN 费用照常入账，运行仍是已停止；面板上不出现费用核实的提示

## 消息排队与插队

助手运行时可以继续写消息。消息默认排队，显示在输入框上方，这一轮成功结束后按顺序一轮发一条；运行被停止、失败或中途出错时队列暂停，由摄影师点「继续发送」。对排队消息点「插队」，它会连同 @ 引用和附件送进正在运行的这一轮（含 Skill 或场景引用的消息只能排队），在下一次调用模型前送达，不打断当前的工具调用；如果插队在模型输出最终回答的过程中到达，同一个运行答完后再跑一轮来回应它；最终回答已经完整给出后，这一轮不再接收插队，消息作为下一轮发出。插队被接收不等于被读到：运行在送达前结束时，这条消息标明助手没有读到。附带的素材由账号级的发送前说明覆盖，只需属于本账号且可用。排队只保存在当前浏览器标签页。

### Scenario: 运行中写的消息排队
- GIVEN 助手正在运行
- WHEN 摄影师在输入框写下消息并按回车
- THEN 消息立刻进入输入框上方的队列，运行不受影响；这一轮正常结束后，它作为下一轮自动发出

### Scenario: 多条排队消息依次发出
- GIVEN 队列里有多条消息
- WHEN 当前这一轮正常结束
- THEN 只发出队首一条；那一轮结束后再发下一条

### Scenario: 停止或出错后队列暂停
- GIVEN 队列非空
- WHEN 这一轮被停止、失败或中途出错
- THEN 不自动发出任何消息，队列显示「继续发送」，点击后发出队首一条

### Scenario: 插队纠偏
- GIVEN 助手正在执行工具，队列里有一条消息
- WHEN 摄影师点这条消息的「插队」
- THEN 消息立刻出现在这一轮的对话中；当前工具做完后，模型带着这条消息继续

### Scenario: 插队时模型正在给出最终回答
- GIVEN 模型正在输出最终回答
- WHEN 插队的消息被接收
- THEN 回答完成后，同一个运行再回应一次这条消息，之后才结束

### Scenario: 最终回答已经给出
- GIVEN 最终回答已经完整给出，运行正在收尾
- WHEN 摄影师点「插队」
- THEN 插队被拒，消息回到队首，这一轮结束后作为下一轮发出

### Scenario: 插队没被读到
- GIVEN 插队已被接收，模型还没读到
- WHEN 摄影师点停止，或运行出错
- THEN 运行照常结束，这条消息留在对话里，标明助手没有读到这条

### Scenario: 插队时运行已经结束
- GIVEN 摄影师点「插队」的同时，运行恰好结束
- WHEN 服务端拒绝插队
- THEN 消息回到队首，按队列规则处理，不丢失也不重复

### Scenario: 带图片插队
- GIVEN 排队消息带上传的图片或 @ 引用的本账号素材，本轮模型支持图片输入
- WHEN 摄影师点「插队」
- THEN 模型下一次调用时能看到这条文字和图片，不需要再次确认外发

### Scenario: 有些引用只能排队
- GIVEN 排队消息选了 Skill、含场景引用，或带图片而本轮模型不支持图片
- WHEN 摄影师看这条消息
- THEN 「插队」置灰并说明原因，这条消息只能等下一轮

### Scenario: 刷新后队列还在
- GIVEN 队列非空
- WHEN 刷新页面后回到该对话
- THEN 队列原样还在；其他标签页看不到它

### Scenario: 排队消息发出时场景已不可用
- GIVEN 队首消息引用的场景已不可用
- WHEN 助手尝试发送这条消息
- THEN 队列暂停。摄影师可以点「重新选择引用」，在输入框为空时把原草稿移回输入框并修改引用

## 发送前说明与外发同意

第一次使用助手时，发送前会弹出「发送前说明」。它说明哪些内容会发给平台签约的模型服务商、后台任务完成后助手可能自动回复并计费，并让摄影师选择是否允许助手检索素材库。摄影师同意后，同意按账号记在服务端，之后换对话、换浏览器或换设备都不再询问，直到说明有变化或摄影师撤回。附带和 @ 引用的内容不需要逐条授权，只要属于本账号、当前可用并且允许展示；图片只在模型能看图时发送。摄影师可以在助手面板的「外发说明」里查看同意、修改素材库选择或撤回。撤回和说明有变化的效果相同：不能再开始新的回复，进行中的回复在下一次调用模型前停下，下次发送时重新询问；已经发出的内容无法召回。

### Scenario: 第一次发送
- GIVEN 账号从未同意过发送前说明
- WHEN 摄影师在画布助手里发送第一条消息
- THEN 弹出发送前说明；同意后消息发出，取消则消息留在输入框里

### Scenario: 换浏览器不再询问
- GIVEN 账号已经同意过当前版本的说明
- WHEN 摄影师在另一台电脑上打开创意空间并发送消息
- THEN 消息直接发出，不再弹出说明

### Scenario: 附带图片不需要逐张授权
- GIVEN 账号已经同意，所选模型能看图
- WHEN 摄影师附带两张自己的图片发送
- THEN 助手读到这两张图片，没有额外的确认

### Scenario: 不允许检索素材库
- GIVEN 摄影师同意时取消了「允许助手检索我的素材库」
- WHEN 摄影师让助手找一张素材库里的图
- THEN 助手不能检索素材库，只能使用画布和本对话里的内容

### Scenario: 撤回同意
- GIVEN 助手正在回复
- WHEN 摄影师在「外发说明」里撤回同意
- THEN 当前的工具调用完成后，回复在下一次调用模型前停下；下次发送时重新弹出说明

### Scenario: 说明有变化
- GIVEN 账号同意的是旧版本说明
- WHEN 平台更新了说明，摄影师再次发送
- THEN 先弹出新版说明，同意后才发送

## 耗时工具的等待与后台运行

助手调用生成、图片压缩、场景建模、回看截图、导出分镜这类耗时工具时，默认等到结果再继续。等待期间释放会话槽位，等待时长受任务自身执行时限和运行的 6 小时上限约束。除回看截图外，助手也可以选择后台运行：工具立即返回，助手接着做别的事，任务完成时结果作为一条通知回到对话里。前台等待中的工具卡片有「转后台」按钮，摄影师点击后助手不再等它。后台任务独立于运行：停止对话不会停止后台任务，要停止就在任务卡片上取消。场景建模和导出分镜需要保持创意空间页面打开。后台任务完成时如果对话空闲，助手会自动开一轮新回复来处理结果，按用量计费；以下情况只写完成提示、不自动开始，等摄影师下次发消息时一并送达：发起任务的那一轮被停止或失败、摄影师没发消息期间已连续自动开始 5 轮、外发同意已撤回或说明已变化、积分不足、助手在等摄影师补充；项目已归档时不写提示。

### Scenario: 等到生成完成
- GIVEN 助手调用生成，没有选择后台
- WHEN 生成用了几分钟才完成
- THEN 助手拿到生成结果后才继续，回答里说的是最终结果，而不是「还在生成」

### Scenario: 助手选择后台生成
- GIVEN 助手要生成一张图，同时还有别的事要做
- WHEN 助手以后台方式调用生成
- THEN 工具卡片显示为后台任务，助手立即接着做别的事；生成完成时，对话里出现一行完成提示，助手在当前这一轮或新的一轮里读到结果

### Scenario: 摄影师让助手不再等
- GIVEN 助手正在等一个耗时较长的生成
- WHEN 摄影师点工具卡片上的「转后台」
- THEN 卡片立刻变为后台任务，助手不再等它，接着往下做；生成完成时结果作为通知回到对话

### Scenario: 对话空闲时后台任务完成
- GIVEN 这一轮已经结束，还有一个后台生成在进行
- WHEN 生成完成
- THEN 对话里出现完成提示，助手随即自动开始新的一轮来处理结果；同一模型和主 Skill 版本的任务在合并窗口内只开一轮，不同配置依次开轮

### Scenario: 连续自动回复有上限
- GIVEN 摄影师没有发消息，助手已经连续自动开始了 5 轮，第 5 轮里又以后台方式发起了生成
- WHEN 这个生成在对话空闲时完成
- THEN 对话里出现完成提示，但助手不会再自动开始；摄影师下次发消息时，助手会一并读到这条结果，连续计数从头算

### Scenario: 停止对话不停止后台任务
- GIVEN 有后台生成在进行
- WHEN 摄影师点停止
- THEN 助手停下，后台生成继续，完成时照常出现完成提示，但助手不会自动开始；摄影师下次发消息时，助手会一并读到这条结果

### Scenario: 取消后台任务
- GIVEN 有后台生成在进行
- WHEN 摄影师在任务卡片上点「取消」
- THEN 生成被取消，卡片显示已取消，助手收到「已取消」的通知

### Scenario: 积分不足时不自动开始
- GIVEN 账号积分不足以开始新的一轮
- WHEN 后台任务在对话空闲时完成
- THEN 对话里照常出现完成提示，但助手不会自动开始；摄影师下次发消息时，助手会一并读到这条结果

### Scenario: 停止先于前台压缩采用
- GIVEN 助手的前台压缩已编码，候选结果尚未采用
- WHEN 摄影师先停止来源运行
- THEN 候选被丢弃，画布保留原图

### Scenario: 快速压缩先转后台
- GIVEN 压缩已编码，工具任务尚未发布结果
- WHEN 摄影师先完成转后台操作
- THEN 原工具得到转后台结果，压缩结束后对话收到一条完成通知

### Scenario: 来源运行交付部分内容后失败
- GIVEN 来源运行已交付部分内容，随后以带错误码的 `partial` 结束
- WHEN 后台任务在对话空闲时完成
- THEN 对话出现完成通知，摄影师下次发消息时一并送达

### Scenario: 唤醒等待锁时通知已送达
- GIVEN 唤醒正等待锁，候选通知仍待送达
- WHEN 摄影师的运行先送达该通知，之后唤醒取得锁
- THEN 这条通知不会创建新运行或预留积分

## 预览历史消息的引用

摄影师可以在对话历史里悬停或聚焦素材、场景和 Skill 的引用标签，打开预览小窗。素材预览读发送时引用的内容修订；场景小窗显示发送时保存的名单；Skill 小窗显示发送时使用的版本。

### Scenario: 素材改版或来源被删除
- GIVEN 历史消息引用了一份素材，随后画布节点换了内容或素材库条目被删除
- WHEN 摄影师打开历史引用的预览
- THEN 原修订仍可展示时，小窗展示发送时的内容；无法读取时，小窗提示「素材暂不可预览」，标签仍保留
