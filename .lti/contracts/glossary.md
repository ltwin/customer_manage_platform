# 领域语言

本项目术语的唯一 canonical 归宿。change 与 epic 的设计必须沿用这里的词;
出现新词、重载词或相邻概念边界不清时,先在此定义再动手。

## 外部助手

- 定义：在创意空间以外运行、经 MCP 调用创意空间工具的 AI 助手；首批宿主为 ChatGPT、Codex CLI、Claude Code、Claude 桌面端（含网页）。
- 不是：内置创意助手（界面上的「助手」）；不是摄影师本人。
- 边界场景：创作者在 Claude Code 里让它给画布加节点，是外部助手的写入；在创意空间助手面板里提同样的要求，是助手的写入。
- 拼写：代码 `external_agent`；界面显示宿主名「Claude」「Claude Code」「Codex」「ChatGPT」，泛称「外部助手」。

## 外部助手连接

- 定义：账号对某个外部助手客户端的一次 OAuth 授权，是外部助手在平台上的身份；署名、任务归属、断开都以它为单位。
- 不是：一次对话或一次工具调用；不是 OAuth 客户端（同一个客户端被两个账号授权，是两个连接）。
- 边界场景：同一账号在两台电脑上各授权一次 Claude Code，是两个连接，可以分别断开。
- 拼写：代码 `external_connection_id`，ID 前缀 `cxcon_`；界面「外部助手连接」。

## 分镜

- 定义：3D 场景时间线上的一个标记，记着帧号和绑定的摄像机；渲染这个分镜，就是按这一帧求值整个场景，再用这台摄像机出图。
- 不是：策划文档里的「镜头」（策划镜头引用分镜，可以引用一个主分镜和几个备选分镜）；也不是摄像机（多个分镜可以绑定同一台摄像机）。
- 边界场景：同一瞬间从两个机位拍，是相邻两帧上的两个分镜，绑定不同的摄像机；主体换了动作，是另一帧上的分镜。一个场景里的帧号不重复。
- 拼写：代码 `marker`，ID 前缀 `smk_`；界面「分镜」；字段 `scene.timeline.markers[]`、`marker_id`。

## 关键帧通道

- 定义：物件的一个可动画属性在各帧上的关键帧序列。属性有通道时，它在每一帧的值由通道求出；没有通道时取基础值，所有帧共用。
- 不是：物件在某一帧的整份快照；不是形态键（形态键是网格的顶点形变，本项目尚未支持）。
- 边界场景：主体在分镜 2 往前走了一步，是主体 `transform.position` 通道上第 2 帧的关键帧；挪动没有通道的桌子，改的是桌子的基础值，所有分镜里的桌子都变。
- 拼写：代码 `channel`、`keyframe`；字段 `objects[].animation.<path>.keys[]`；界面「关键帧」。

## 角色卡

- 定义：一个虚构角色可复用的视觉身份，存在资产库里。由 1–4 张参考图和一段外貌描述组成，可以附上所属 IP、作品和来源备注，生成图片时作为稳定参考。有版本，修改即产生新版本。
- 不是：一张普通图片资产（角色卡引用图片，自己不是图片）；不是策划文档里的「人设」（策划的人设以后引用角色卡）；不是真人（只支持虚构角色）；不是造型（同一角色换装是另一张角色卡）。
- 边界场景：同一角色的常服和战斗服是两张角色卡，用「版本说明」区分（「芙宁娜 · 常服」「芙宁娜 · 泳装」），不是一张卡下的两个造型。
- 拼写：代码 `character`；资产 `kind = "character"`；节点 `core.character`；界面「角色卡」；字段 `views`（界面「参考图」）、`sources`（界面「原始素材」）、`appearance`（界面「外貌描述」）、`ip`（界面「所属 IP」）、`work`（界面「作品」）、`variant`（界面「版本说明」）、`aliases`（界面「别名」）。

## 角色 IP

- 定义：角色所属的知识产权系列，如「原神」「Fate」「崩坏」。用于按系列查找、筛选角色卡。可以来自内置目录，也可以是账号自己输入的名字（例如摄影师自己的原创系列）。
- 不是：作品。一个 IP 可以有多部作品（Fate 下有 stay night、Zero、FGO），同名角色在不同作品里设定可能不同，靠「作品」区分；IP 和作品相同时（原神）不重复填作品。也不是账号里的一条可管理记录：首版没有 IP 管理页，账号自建的 IP 就是角色卡里用过的名字。
- 边界场景：「FGO 里的阿尔托莉雅，第三灵基」= IP「Fate」、作品「Fate/Grand Order」（「FGO」是它的作品别名）、版本说明「第三灵基」。「原神」「Genshin」「Genshin Impact」都匹配内置目录里的同一个 IP。
- 拼写：代码与载荷 `ip`（`{name, key?}`），内置目录的稳定标识 `key`（如 `genshin-impact`）；界面「所属 IP」。

## 素体

- 定义：平台内置的人形角色模型，目前一男一女，所有账号都能放进场景，不能修改；场景里的实例可以缩放、换材质，以后可以摆姿态。
- 不是：账号资产（不在「我的」资产库里，不能评分、打标签、进回收站）；不是人片（人片是 `cg-composite` 的平面照片物件）。
- 边界场景：摄影师把女素体放进场景后换了皮肤材质，改的是这个实例的 `material_slots`，素体本身不变；其他场景里的女素体不受影响。
- 拼写：代码 `builtin model`，条目 ID `body_female@1`、`body_male@1`；字段 `objects[].model.builtin`；界面「素体」「女素体」「男素体」。

## 标准人形骨骼

- 定义：平台定义的一组人形骨骼名和骨骼链，参照 VRM 1.0 humanoid，共 55 根（含 30 根手指骨）。人形角色的姿态按标准骨骼存储和换算，任何映射过的人形角色都能套用。
- 不是：某个模型自带的骨架（那是骨架摘要）；不是骨骼的显示名。
- 边界场景：一个 Mixamo 角色的 `mixamorig:LeftArm` 映射到标准骨骼 `leftUpperArm`；一个没有 `upperChest` 的角色仍是人形，它缺的骨骼的旋转传给子骨骼。
- 拼写：代码 `humanoid`、标准骨骼名用 VRM 1.0 的 camelCase（`leftUpperArm`）；字段 `model.rig.humanoid`；界面「人形骨骼」。

## 外发同意

- 定义：账号对「发送前说明」某个版本的同意。它决定本账号的内容能否发给平台签约的模型服务商，以及助手能否检索素材库。同意按账号记录，与对话、浏览器和设备无关。
- 边界：外发同意不是逐资产授权。具体内容能否外发，还要看它是否属于本账号、当前可用、允许展示，以及是否在读取范围内（当前画布、本对话、勾选时的素材库）。外部助手连接用自己的 OAuth 授权，不使用外发同意。
- 失效：说明版本升级或摄影师撤回，效果相同。失效后不能开始新的回复，进行中的回复在下一次调用模型前停下。
