# 领域语言

本项目术语的唯一 canonical 归宿。change 与 epic 的设计必须沿用这里的词;
出现新词、重载词或相邻概念边界不清时,先在此定义再动手。

## 外部助手

- 定义：在创意空间以外运行、经 MCP 调用创意空间工具的 AI 助手；首批宿主为 ChatGPT、Codex CLI、Claude Code、Claude 桌面端（含网页）。
- 不是：内置创意助手（界面上的「助手」）；不是摄影师本人。
- 边界场景：创作者在 Claude Code 里让它给画布加节点，是外部助手的写入；在创意空间助手面板里提同样的要求，是助手的写入。
- 拼写：代码 `external_agent`；界面显示宿主名「Claude」「Claude Code」「Codex」「ChatGPT」，泛称「外部助手」。

## 外部助手连接

- 定义：账号对某个外部助手客户端的一次 OAuth 授权，是外部助手在平台上的身份；署名、任务归属、断开都以它为单位。
- 不是：一次对话或一次工具调用；不是 OAuth 客户端（同一个客户端被两个账号授权，是两个连接）。
- 边界场景：同一账号在两台电脑上各授权一次 Claude Code，是两个连接，可以分别断开。
- 拼写：代码 `external_connection_id`，ID 前缀 `cxcon_`；界面「外部助手连接」。

## 分镜

- 定义：3D 场景时间线上的一个标记，记着帧号和绑定的摄像机；渲染这个分镜，就是按这一帧求值整个场景，再用这台摄像机出图。
- 不是：策划文档里的「镜头」（策划镜头引用分镜，可以引用一个主分镜和几个备选分镜）；也不是摄像机（多个分镜可以绑定同一台摄像机）。
- 边界场景：同一瞬间从两个机位拍，是相邻两帧上的两个分镜，绑定不同的摄像机；主体换了动作，是另一帧上的分镜。一个场景里的帧号不重复。
- 拼写：代码 `marker`，ID 前缀 `smk_`；界面「分镜」；字段 `scene.timeline.markers[]`、`marker_id`。

## 关键帧通道

- 定义：物件的一个可动画属性在各帧上的关键帧序列。属性有通道时，它在每一帧的值由通道求出；没有通道时取基础值，所有帧共用。
- 不是：物件在某一帧的整份快照；不是形态键（形态键是网格的顶点形变，本项目尚未支持）。
- 边界场景：主体在分镜 2 往前走了一步，是主体 `transform.position` 通道上第 2 帧的关键帧；挪动没有通道的桌子，改的是桌子的基础值，所有分镜里的桌子都变。
- 拼写：代码 `channel`、`keyframe`；字段 `objects[].animation.<path>.keys[]`；界面「关键帧」。
