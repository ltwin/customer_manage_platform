## creative/agent-run: MODIFY 停止运行

助手运行时，输入框为空则发送按钮就是停止按钮；输入框有内容时按钮是发送，消息加入排队（见「消息排队与插队」）。点一次停止就停：面板立刻显示已停止，同一个对话可以马上发下一条消息。正在进行的模型请求会被中断；已经产生的费用由后台继续核实并入账，摄影师不需要等待，也看不到核实过程。已经交给生成服务的生成会跑完并计费，还没发出的生成会被撤回。

### Scenario: 运行中点停止
- GIVEN 助手正在输出回答，输入框为空
- WHEN 摄影师点击输入框右下角的停止按钮
- THEN 输出立刻停住、不再增长，并标为「已停止」，按钮变回发送；停止完成后显示已保存的内容（可能比点击时多出很短的一段）；可以马上发下一条消息

### Scenario: 等待补充时停止
- GIVEN 助手停下来等摄影师补充信息，输入框为空
- WHEN 摄影师点击停止按钮
- THEN 这次运行结束；如果在输入框里写了内容，按钮会变成「补充并继续」

### Scenario: 刚发出就停
- GIVEN 摄影师刚点了发送，消息已出现在对话里，但服务端还没建好这次运行
- WHEN 摄影师看向输入框
- THEN 按钮已经是停止，状态栏显示「正在处理」；此时点停止，立刻显示已停止，运行建好后随即被取消

### Scenario: 停止请求失败
- GIVEN 网络断开
- WHEN 摄影师点击停止
- THEN 面板先显示已停止，请求失败后恢复为运行中，并提示停止没有成功；再点一次可以重试

### Scenario: 停止后的费用
- GIVEN 停止时模型请求正在输出
- WHEN 后台随后核实了这次请求的用量
- THEN 费用照常入账，运行仍是已停止；面板上不出现费用核实的提示

## creative/agent-run: ADD 消息排队与插队

助手运行时可以继续写消息。消息默认排队，显示在输入框上方，这一轮成功结束后按顺序一轮发一条；运行被停止、失败或中途出错时队列暂停，由摄影师点「继续发送」。对排队消息点「插队」，它会连同 @ 引用和附件送进正在运行的这一轮（选了 Skill 的消息除外），在下一次调用模型前送达，不打断当前的工具调用；如果插队在模型输出最终回答的过程中到达，同一个运行答完后再跑一轮来回应它；最终回答已经完整给出后，这一轮不再接收插队，消息作为下一轮发出。插队被接收不等于被读到：运行在送达前结束时，这条消息标明助手没有读到。附带的素材由账号级的发送前说明覆盖，只需属于本账号且可用。排队只保存在当前浏览器标签页。

### Scenario: 运行中写的消息排队
- GIVEN 助手正在运行
- WHEN 摄影师在输入框写下消息并按回车
- THEN 消息立刻进入输入框上方的队列，运行不受影响；这一轮正常结束后，它作为下一轮自动发出

### Scenario: 多条排队消息依次发出
- GIVEN 队列里有多条消息
- WHEN 当前这一轮正常结束
- THEN 只发出队首一条；那一轮结束后再发下一条

### Scenario: 停止或出错后队列暂停
- GIVEN 队列非空
- WHEN 这一轮被停止、失败或中途出错
- THEN 不自动发出任何消息，队列显示「继续发送」，点击后发出队首一条

### Scenario: 插队纠偏
- GIVEN 助手正在执行工具，队列里有一条消息
- WHEN 摄影师点这条消息的「插队」
- THEN 消息立刻出现在这一轮的对话中；当前工具做完后，模型带着这条消息继续

### Scenario: 插队时模型正在给出最终回答
- GIVEN 模型正在输出最终回答
- WHEN 插队的消息被接收
- THEN 回答完成后，同一个运行再回应一次这条消息，之后才结束

### Scenario: 最终回答已经给出
- GIVEN 最终回答已经完整给出，运行正在收尾
- WHEN 摄影师点「插队」
- THEN 插队被拒，消息回到队首，这一轮结束后作为下一轮发出

### Scenario: 插队没被读到
- GIVEN 插队已被接收，模型还没读到
- WHEN 摄影师点停止，或运行出错
- THEN 运行照常结束，这条消息留在对话里，标明助手没有读到这条

### Scenario: 插队时运行已经结束
- GIVEN 摄影师点「插队」的同时，运行恰好结束
- WHEN 服务端拒绝插队
- THEN 消息回到队首，按队列规则处理，不丢失也不重复

### Scenario: 带图片插队
- GIVEN 排队消息带上传的图片或 @ 引用的本账号素材，本轮模型支持图片输入
- WHEN 摄影师点「插队」
- THEN 模型下一次调用时能看到这条文字和图片，不需要再次确认外发

### Scenario: 选了 Skill 的消息只能排队
- GIVEN 排队消息选了 Skill，或带图片而本轮模型不支持图片
- WHEN 摄影师看这条消息
- THEN 「插队」置灰并说明原因，这条消息只能等下一轮

### Scenario: 刷新后队列还在
- GIVEN 队列非空
- WHEN 刷新页面后回到该对话
- THEN 队列原样还在；其他标签页看不到它
