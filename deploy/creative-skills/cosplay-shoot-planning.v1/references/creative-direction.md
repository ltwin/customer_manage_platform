# 创意方向：怎么找参考，做到和别人不一样

好创意靠两件事：知道别人通常怎么拍，再找到这个角色身上没被拍过、但又站得住的东西。

## 第一步：摸清常见拍法

先搜这个角色已有的 cos 正片，例如「<角色> cos 正片」「<角色> cosplay」「<character> cosplay photography」。小红书、微博、LOFTER 等站点读不到时如实说明，用能读到的。

从中总结 3–5 条**常见拍法**，每条写清场景、构图、动作和色调（例如「原作主城背景、全身仰拍、武器指向镜头、高饱和主色」）。这份清单就是要避开的东西，写进策划，供摄影师判断。

社交平台常常读不到，读到的作品太少时：说明读到了多少；可以按经验列出这类角色常见的拍法，但要标「经验判断，未逐张核实」，不要说成检索结果。

## 第二步：找差异点

差异不能脱离角色：视觉锚点要保住，差异要服务角色的内核（性格、处境、主题）。每个方向至少用两种下面的手段：

1. **换时间点**：拍角色故事里少有人拍的时刻，如战前、战后、日常、回忆、结局之后。
2. **转译场景**：把原作场景转成现实里能拍、能搭或能合成的对应物，并让它带上新的意思（例如原作里的「王城大殿」转成「人走空后的大殿一角」）。
3. **换情绪**：与常见拍法的情绪形成反差，但要能在原作里找到依据（常拍高傲，就拍高傲背后的孤独）。
4. **换光影与色彩**：换光源逻辑或色彩脚本，比如从高调平光换成单一硬光、从高饱和换成低饱和单色。
5. **换镜头语言**：换视角、景别和构图，如极低机位、大面积留白、前景遮挡、镜面或水面反射。
6. **跨领域找参考**：从电影剧照、绘画、时装大片、概念设计（ArtStation、Pinterest、电影截图）借视觉语言，而不是只看同一角色的 cos 作品。这是拉开差距最有效的一条。

## 第三步：按拍摄条件筛

用基本信息里的条件过一遍：拍摄形式（棚拍 / 外景 / 合成）、地点、时长、预算、人数、交付要求。

- 合成片的场景主要靠后期，前期在无影棚里拍，要考虑后期是否接得住（光位、透视、接触阴影）。
- 外景要考虑天气、时段和场地是否允许（如能不能洒水、能不能用烟）。
- 执行难度按「低 / 中 / 高」写，并写清主要难在哪（服装、道具、场景、灯光、后期工作量）。

## 写成什么样

给 2–3 个方向，三个方向之间要有真正的区别，不要是同一个想法的三个变体。每个方向：

```
### 方向 A · <名字>：<一句话概念>
- 概念：拍什么、想让人感受到什么
- 场景：在哪里拍、画面里有什么
- 光影：主光从哪来、环境光、有没有特殊光效
- 色彩脚本：冷暖倾向与情绪基调
- 与常见作品的差别：对照常见拍法，具体避开了哪几条、换成了什么
- 执行难度：低 / 中 / 高，主要难点
- 参考：1–3 个链接（优先跨领域的参考），说明各参考什么
```

方向里不要自己重新分配交付张数，交付固定按 2+4+3（2 张全身主视觉、4 张半身动态、3 张特写）；可以写这个方向的主视觉大概是什么画面。

摄影师已经给了风格要求时，三个方向都围绕这个风格展开，在风格之内拉开差别。

最后停下来问摄影师：选哪个方向，或者怎么混合（例如「A 的场景 + B 的光影」）。摄影师选之前，不要往下做情绪板和后面的阶段。
