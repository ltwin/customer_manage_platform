# IP 拆解

目标是拍摄用得上的角色理解，不是百科复述。每一条都要回答：拍的时候怎么体现、准备时要注意什么。

## 先认清是谁

动手搜之前，确认作品、角色和版本：
- 同名角色（不同作品里同名、同一系列的不同化身）。
- 多个皮肤、形态、时期（常服 / 战斗服 / 泳装 / 黑化 / 少年期）。

只有外观不同（服装、发型、配色、道具）才算拍摄要选的版本；只是能力、阵营、战斗机制上的区分，不算版本，不要拿来问摄影师。

摄影师没说清、而不同版本拍出来差别很大时，先问，给出候选让摄影师选。只有一个合理版本时直接用，在回复里写明按哪个版本做。

## 去哪查

可信度从高到低：
1. 官方：官网、官方账号发布的设定与立绘、游戏内或原著文本、官方设定集。
2. 社区资料站：萌娘百科、BWIKI、灰机 wiki、Fandom 等，用来找线索和定位官方出处。
3. 二创与讨论：只用来了解大家怎么理解这个角色，不当事实引用。

检索时同时试中文名、原文名（日文、英文）和常见别称，例如「<角色> 设定」「<角色> 立绘」「<角色> 萌娘百科」「<character> concept art」「<キャラ名> 設定画」。

至少读两类来源：一页官方或作品内文本，一页社区资料站（中文作品优先萌娘百科、BWIKI、灰机 wiki）的角色条目，资料站条目通常写全了外观、服装和形态。缺什么再补搜，不要一次读一大堆页面。只写读到的内容，不用记忆补细节；记忆里有、但这次没读到来源的，写进「资料缺口」让摄影师核对。

## 拆哪些维度

**视觉锚点：提炼角色的核心识别符号**
- 角色亮点：一眼认出这个角色的 3–5 个符号（发型发色、标志服饰或配饰、武器道具、瞳色与妆面特征、主配色）。按重要性排序，写清哪几个绝对不能丢。
- 动作参考：标志性姿势、技能或战斗动作、立绘里的姿态、表情习惯。写成摄影师能直接引导 coser 做的动作。
- 角色元素：象征物、元素属性、纹样、材质（金属、丝绸、皮革、半透明材料）。

**世界观对齐：确定美术与资产的调性**
- 美术调性：赛博、废土、唯美古风、哥特、日常校园……写清具体指什么（年代感、材质、色彩倾向），不要只贴标签。
- 场景元素：角色相关的地点、标志性建筑或环境、道具陈设，以及能在现实中找到或搭出来的对应物。

**还原难点**
- 服装、道具、妆面里容易做错或难做的地方（比例、材质、发光部件、大型道具），会进准备清单。

## 写成什么样

一句话概括（不超过 80 字），写最能抓住这个角色的几个关键词。正文按小标题组织：

```
### 视觉锚点
### 动作参考
### 角色元素
### 世界观与美术调性
### 场景元素
### 还原难点
### 资料缺口
```

- 每条事实后面附来源链接；没有来源的写「推断」。
- 「资料缺口」列出查不到或互相矛盾的项，说明需要摄影师补什么（设定图、某套衣服的背面、道具细节）。没有缺口就不写这一节。

## 特殊情况

- **冷门角色**：资料少时不要拿同作品其他角色或相似角色的资料来补。能确认的写上，其余全部列为缺口，请摄影师提供设定图或资料链接。
- **原创角色（OC）**：资料来自摄影师。没有设定图时先要设定图，再拆解。
- **多角色、CP、团体**：每个角色单独拆，最后补一节「人物关系」：互动方式、身高与体型差、常见站位，供构图用。
