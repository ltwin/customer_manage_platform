# 创意空间 v6 工作台 PRD

## 0. 文档说明

- **目的**：把 v6 原型验证过的交互写成可逐条核对的需求，作为正式工作台差距分析和后续开发的依据。
- **权威关系**：产品边界、数据语义和真实性要求以[创意空间基础框架需求](../../../.codestable/requirements/creative-canvas-foundation.md)（下称「基础需求」，编号 LIB / CAN / AG / FLOW）为准。本文只规定 v6 的交互与界面行为，两者冲突时以基础需求为准，冲突记录在 §11。
- **数值**：表中的尺寸、间距、时长是原型取值，视觉走查后可以微调；标「硬约束」的除外。
- **原型模拟**：假生成、本地存储、固定剧本等原型模拟不是需求。生产要求见 §10。
- **编号**：SH 外框、CV 画布、VR 版本、GN 生成输入框、AL 资产库、AS 助手、UF 端到端流程、NF 非功能。这些前缀与基础需求不重号，「对应」列给出映射。
- **优先级**：P0 首期必须；P1 首期应有，可以在 P0 之后补齐；P2 后续或可选。
- **与原型不同**：标「按此为准」的条目是本文对原型行为的修正，汇总见 §11.2。
- **术语**：遵循 `CONTEXT.md`。
  - 资产：摄影师主动收入个人库的内容。
  - 节点：内容在画布上的一次呈现。
  - 资产分组与画布节点组是两个概念，不混用。

## 1. 产品概述

### 1.1 定位

摄影师在一张无限画布上组合文字、图片、视频，用连线表达参考关系，并直接在节点上生成内容。助手可以代为读画布、建节点、写提示词、发起生成。资产库是跨项目的个人素材来源。

### 1.2 设计原则

1. **画布优先**：默认只露出工具轨、项目名和缩放条，资产库与助手默认收起，按需打开。
2. **近黑中性**：层级靠亮度和细线区分。白色是唯一的主操作色，琥珀色只表示「运行中」。不用玻璃模糊，不用衬线字体。
3. **连线即参考**：连线决定参考集合，`@` 只在句子里点名其中某一个。连线本身不会自动执行。
4. **下游只认主版本**：预览某个版本不影响下游。主版本可以固定，也可以跟随最新。
5. **助手过程可见、改动可撤**：
   - 每一次画布操作都写在对话里，可以定位到对应节点。
   - 消耗点数或覆盖已有内容之前先确认。
   - 一整轮的改动可以一次撤销。

### 1.3 范围

**范围内**：外框、画布（文字 / 图片 / 视频 / 音频 / 链接节点与组）、版本与主版本、节点生成输入框、资产库抽屉、助手面板。链接与音频节点在 v6 原型中没有设计，本文直接给出需求（§3.13，2026-10-04 拍板）。

**范围外**（本文不定义）：
- 3D 节点。（策划摘要节点 2026-10-15 纳入范围，见需求清单 V6-079。）
- 多画布、实时协作。
- 资产库整理模式、回收站界面。
- 计费规则与充值。

## 7. 助手面板（AS）

### 7.1 回复的组成

一轮回复是一串**有序的块**，按发生顺序追加。块分两类，视觉权重不同：

- **过程块**：思考、计划、工具调用。灰色细行，高 28px，默认收起，不抢正文的注意力。
- **结论块**：正文、提问、确认、提示词改动、本轮改动。以卡片呈现，需要摄影师操作的卡片用白色细框标出。

| 块 | 运行中 | 结束后 | 交互 |
|---|---|---|---|
| 思考 | 标题「思考中」带流光；下方单行滚动显示最新一句 | 「已思考 N 秒」，默认收起 | 点击展开或收起全文 |
| 计划 | 步骤清单，标出当前步骤；右上角显示进度 n/N | 已完成的步骤划线；被跳过的步骤单独标记 | 只读 |
| 工具调用 | 转圈图标 + 动词 + 对象（如「新建节点 2/4 个分镜」）；生成类显示进度条 | 显示类型图标和耗时；被停止的显示「已停止」，失败的显示原因 | 有详情时可展开；悬停高亮相关节点，点击定位到节点 |
| 正文 | 流式输出，末尾有光标 | Markdown：段落、列表、粗体、行内代码 | 可选中复制 |
| 提问 | 题卡 | 折叠为「已回答 / 已跳过 / 已停止」，下方列出每题答案 | 见 AS-20 |
| 确认 | 消耗点数的清单卡 | 「已确认生成 N 张 · X 点」或「已取消」 | 见 AS-30 |
| 提示词改动 | diff 卡 | 「已应用 / 未应用」 | 见 AS-31 |
| 本轮改动 | 汇总卡 | 可变为「已撤销」 | 见 AS-40 |

## 8. 端到端流程（UF）

这些流程用于走查和集成验收。真实性要求以基础需求 FLOW-01–10 为准。

| 编号 | 流程 | 关键断言 |
|---|---|---|
| UF-01 | 不用助手：新建文本节点 → 上传两张参考图 → 拖线连接到新建的图片节点 → 写提示词并 `@` 一张参考 → 生成 2 张 → 设为主版本 → 关闭后重开 | 草稿、主版本、连线、视口全部保持；下游节点引用的是主版本 |
| UF-02 | 从资产库按分组和两个标签找到素材 → 多选放入画布 → 撤销 | 整批一次撤销；本画布视图和「已在画布」勾同步更新 |
| UF-03 | 在节点 `@` 中选择「从资产库添加参考」→ 选 2 项 → 确认 | 新节点竖排放在目标节点左侧，已连线并按顺序引用；整个操作只算一次撤销 |
| UF-04 | 助手：「拆 4 个分镜并生成草图」→ 回答 3 题（含 1 道多选）→ 观察画布上逐个新建节点和连线 → 确认生成 → 整理成组 → 撤销本轮 | 每一步都能在对话中定位到对应节点；生成扣费与确认金额一致；撤销后画布恢复原样，点数不退回 |
| UF-05 | 助手运行到提问阶段时按 Esc | 没有产生任何画布改动；记录显示「已停止，未回答」 |
| UF-06 | 助手改写提示词：先放弃一次，再应用一次；运行期间排队一条消息 | 放弃时节点不变；应用后节点写入新内容；排队的消息在本轮结束后自动执行 |
| UF-07 | 切到「自动执行」后让助手生成 | 不出现确认卡；本轮改动卡仍然出现，并可以撤销 |
| UF-08 | 收起助手面板，让它在后台运行到需要回答的步骤 | 按钮出现白点并弹出 toast；点「查看」后焦点落在第一个选项上 |
| UF-09 | 新建链接节点并连到图片节点 → 生成；再拖入一段音频，放大节点后播放 | 链接以「标题 + 描述 + 地址」发送，不抓取网页；音频可以播放，手动尺寸在刷新后保持 |
| UF-10 | 让助手把画布上已有的 3 张参考图打成一组；运行期间手动改其中一张的标题；然后撤销本轮 | 组被解散，节点位置恢复；改过标题的那张先被列出，确认后保留新标题 |
| UF-11 | 把节点拖出它所在的组框 | 节点仍属于原组，组框随之撑大；解组后重新打组才会改变归属 |

## 12. 差距分析建议用法

逐条对照正式工作台，每条记一个状态：

- **已实现**：行为与验收要点一致，有测试或走查证据。
- **部分实现**：需写明缺了哪一项验收要点。
- **未实现**。
- **不采纳**：需写明理由，并回到本文 §11 登记。

建议按「外框 / 画布 → 版本 → 生成输入框 → 资产库 → 助手」的顺序核对，与 v6 迁移的六个阶段对应。助手（AS）相关条目大多需要服务端运行协议支撑，请对照[Agent API 事件](modules/agent-api-events.md)和[Harness](modules/harness.md)，确认哪些块已经有对应的事件类型。
