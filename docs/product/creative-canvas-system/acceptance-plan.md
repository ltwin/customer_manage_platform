## 2. 10条贯穿验收

每条FLOW在同一候选版本运行；数据集可以重置但要记录seed/迁移版本。至少两个隔离账号，A账号至少两个窗口；任何跨账号读取/写入/下载/SSE泄漏都阻断验收，不以任务成功率平均抵消。

| 场景 | 首次联合验收 | 必备证据 |
|---|---|---|
| FLOW-01 人工闭环 | FND-05 | 真实前端/DB/媒体：新项目→图文导入→连线打组修改→关闭重开，一致且无CRM前提 |
| FLOW-02 跨项目复用 | FND-05 | 内容修订/资产/节点身份与对象计数；一处编辑分叉，移除节点不改其他项目/库 |
| FLOW-03 检索到画布 | FND-05 | 分组/多标签条件与响应ID/count一致，多选真实拖入可整体撤销，无项目同样可整理 |
| FLOW-04 Agent闭环 | FND-08/09 | 真实获准模型与Skill版本、检索结果、命令回执、实际节点、消息/费用；无结果如实说明 |
| FLOW-05 并发与恢复 | FND-08 | 人工修改后Agent旧读集冲突；取消/断流/重试/COMMIT unknown，证明无重复与迟到写入 |
| FLOW-06 回收与保留 | FND-10 | 库根/节点/附件/消息/运行/命令引用、到期和物理清理的测试存储证据；被引用媒体仍可读 |
| FLOW-07 专业节点边界 | FND-04 | 开发/测试独立文档adapter及真实存储；摘要最大化/还原/删除/重新引用，通用核心无镜头/订单语义 |
| FLOW-08 隔离与双窗口 | 各FND项+FND-12 | A/B账号资产/节点/任务/下载/SSE/操作回执越权拒绝；同账号冲突可见；媒体错误可诊断 |
| FLOW-09 能力与故障降级 | FND-08/09 | 不支持媒体/上下文过大/模型不可用：草稿保留、原因明确；人工库和画布持续可用 |
| FLOW-10 节点生成与版本 | FND-13/08/10 | 四类每类两次真实生成，Prompt草稿、媒体播放/下载、历史预览/采用/重开，Agent同入口，取消/冲突与长期保留 |

首次联合验收不是整体验收完成；FND-12在完整schema/Worker/开关配置下复跑全部FLOW，加入FND-11迁移后的同类场景，以及“部分复制→放弃→旧域修改→旧基线清理中断/恢复→再次迁移”的全链；验证新域已有编辑/采用时自动退役被拒绝。


## 3. 性能与真实模型证据

性能预算沿需求原值：资产10,000条/100组/200标签，服务端检索p95≤500ms、首批端到端p95≤1s；画布200节点/300边/3层组，10分钟交互帧间隔p95≤33ms、无连续1秒主线程卡死；普通小编辑停止后2秒内得到保存结果。上传、媒体处理和模型调用单独计时，不将它们混入普通编辑保存指标。

FND-01记录基准设备CPU/内存、浏览器精确版本、视口/缩放、网络RTT/带宽、后端/DB/Worker资源；使用实际目标浏览器与部署级配置在FND-12复验。资产数据包含图文/音视频、标签稀疏/密集、多层分组、回收项和短中文关键词；只灌英文长词不算中文检索预算验证。记录SQL执行计划、至少100次混合查询样本与p95计算口径，冷启动单列。不能减少结果/丢弃字段来让性能达标。

画布使用缩略图和懒加载，录制连续平移/缩放/组拖动/文字编辑轨迹及Performance数据；媒体类型分布、解码策略明确。测试原型或空白卡性能不算成品通过；至少覆盖目标桌面浏览器，并在另一受支持桌面浏览器做手势/媒体兼容验证。移动端验证项目找回、阅读、预览和基本文字编辑，不要求桌面等价复杂拖拽。

真实模型使用FND-06锁定的目录/价格/Skill/限制版本及获准素材，固定八类基本案例：纯对话、检索并添加参考、结果不足、生成方向文字、指定文字修改、整理选区、明确提案采纳、图片输入与音视频元信息说明。每例连续三次记录完整结果/回执/耗时/用量，预期的部分结果或拒绝可以是正确结果，不能伪造成功；核心任务断言逐次通过，不能挑一次成功隐藏其他失败。模型自然语言质量另给摄影师观察意见，不把措辞一致当通过标准。

模拟适配测试覆盖非法参数/工具碎片/超时/unknown/费用更正等难稳定制造的失败，真实调用证明供应商接通与模型实际能力，两者缺一不可。费用测试预算在PRE-06先获准，未获准不发付费请求；需要增加批次时先明确新增费用范围。此小样本只证明固定验收案例，不宣称统计意义的普遍成功率。

## 4. 证据记录与结论

每条证据记录：FND与需求/FLOW、候选HEAD/工作区或构建摘要、环境/账号匿名ID、数据seed、配置/模型/Skill版本、执行步骤、期望/实际、原始日志/截图/trace、结果pass/fail/not_run、限制与复现命令。需要恢复时额外记录数据库恢复点、对象版本清单和RPO/RTO；供应商调用额外记request/attempt/measurement身份及未知结算。

证据写入所属任务文档或项目已有测试产物目录，由work链接，不新建第三套状态台账；不保存凭证/签名URL或无关私有素材正文。自动检查、浏览器观察、真实环境测试分别标识，所有not_run必须可见。

- 子项工程完成：对应出口全部有证据，blocking清零，important已处理或获明确接受；按影响面门禁通过。未完成前置项不能用“后续补齐”把当前项标done。
- 全部工程验收：25需求/10FLOW和性能/隔离/恢复通过，完整版本的make check通过，目标环境部署候选可复现。单纯SQL探针全部绿不满足。
- 发布资格：进一步满足[migration-release](migration-release.md)的目标环境、账号范围、恢复、监测和授权；实际发布结果另记。工程通过不等于已经上线。
- 产品试用：建议2–3名摄影师用各自素材体验FLOW-01/03/04，记录能否独立完成、卡点与后续使用意愿；人数建议不是隐藏的工程门禁。未开展则明确“产品试用未完成”，最终产品接受由摄影师明确确认，不把旧实拍样本借来算新系统通过。

发生数据丢失、跨账号泄漏、重复收费请求、取消后新写入、引用中媒体误删或无法恢复时停止相应writer，修复并重新验证受影响链；不能以缩小样本或关闭断言处理。其余质量反馈按实际影响安排后续，但不得把首期核心能力移动到后续后仍标全部完成。


Eino接入补充：FND-12覆盖框架checkpoint前后崩溃、同参数多轮工具身份、摘要/卸载授权与来源保真、辅助模型费用、旧runtime/serializer/Skill版本恢复、opaque状态清理与媒体根。Eino八项小样实验是适配依据，不填作真实应用FLOW通过；正式入口证据责任见[Eino接入](eino-adoption.md)。


AG-03工具化追加验收：同一节点用界面和Agent编辑得到一致领域结果；读取未获准范围被拒绝；内部text-compose从创建到执行生成真实修订，重复操作复用execution，未注册/未配置动作明确失败；已知运行中的节点执行让父Agent queued有界等待，子任务不重复抢slot；父取消、到期或目标变化不产生迟到覆盖；执行输入/产物持续受引用保护。首期FND-13生产生成类executor必须复用同契约，不用内部fixture假称生成能力已开放。

FND-07/08节点执行竞态：在输出保存后、发布前暂停，触发父查询/取消/到期，验证pending继续等待、取消或超期禁止发布；发布仅在父queued/running及slot归属匹配时提交。FND-08验证发布→继续编辑→整组撤销；发布后插入人工修改应产生真实冲突；重复消费发布回执不得重复效果、推进或回退读集，也不得重复归组。

首期生成验收详见[node-generation](node-generation.md#6-开发与验收)。模型调用必须记录实际供应商/版本、输入/输出格式、参数、费用与执行/版本ID；旧八类Agent评估继续保留，新增四类生成及组Prompt验收不被旧样本替代。人工Prompt独立于聊天；真实生成成功但媒体未落库不得算通过。

新增闭合验证：FND-04实际生成DTO及草稿/状态/版本存储契约（内部执行器），FND-13复用同一模型交付真实生成，不重复造基础schema；FND-08组Prompt提交重开停止与删组/解组竞态；FND-13/12停止独立生成后无新收费派发、迟到不自动采用、维护核算/候选仍可恢复、历史仍可读，重开开关不恢复旧发布资格。

关闭node_generate/generation_apply后验证人工导入/替换/复制/采用旧版仍可用，显式保存ready候选用新人工operation且去重；旧任务自动登记/采用仍拒绝。未落库候选不可采用，伪造人工actor或取消后的Agent不能绕过守卫；再关闭全局writer时上述人工写入一并拒绝。

历史登记/采用分离验收：生成期间人工修改内容或选旧版，成功结果在任务/发布资格仍有效时进入未采用历史，当前内容/采用指针不变；该历史不随执行载荷期限清理。登记效果与Agent变更组一致，未发生的内容采用不推进读集；重复回执不重复历史。取消/节点删除/生成停用等资格失效时则只留execution候选，不登记历史。
