# 创意空间 v6 · 画布重设计原型

从仓库根目录运行 `python3 -m http.server 8771 --bind 127.0.0.1`，打开 <http://127.0.0.1:8771/docs/prototypes/creative-workspace/v6/>。不依赖前后端，数据存在 `localStorage`（项目菜单 → 重置示例数据）。

方向：对齐 TapNow 类画布工具。近黑中性界面，层级靠亮度和细线；白色是唯一主操作色，琥珀只表示「运行中」；全部无衬线，不用玻璃模糊。

- 节点：标题在卡片外上方，卡片只装内容；选中为白色描边，端口 `+` 仅在悬停/选中时出现。
- 尺寸：新建的图片/视频节点默认 1:1，空节点可在比例 chip 里改画幅。有内容后宽度不变，高度跟随当前显示内容的真实长宽比，生成、上传、切换预览版本都会自动更新。
- 连线：指针靠近端口 48px 内就显出 `+` 并轻微吸向指针；拖线在空白处松手时，18px 内最近的可连节点也会吸附，预览线变实并落白点。拖到空白处松手会弹出添加菜单，虚线留在原处；选了节点，新节点的端口正好落在虚线终点并变成实线，取消则虚线消失。选中节点、组或连线时，相关连线沿数据流向走一道慢速白光；运行中仍是琥珀虚线。双击连线直接断开，可撤销。
- 视口：平移缩放位置按画布记住，重新打开回到原处；滚轮移动视口时收起菜单。视频节点悬停即预览。选中节点的端口可 Tab 聚焦、Enter 打开添加菜单；触屏端口常驻。
- 生成：选中图片/视频节点，输入框吸附在节点下方。模型与比例/数量为 chip，右侧显示点数和白色圆形生成键，Enter 生成。结果追加为版本，节点内缩略图条切换。
- 引用：连线决定参考集合，`@` 只在句子里点名其中一个。`@` 列表只有当前节点已连接的上游（可输入过滤），另有「从资产库添加参考」会放入素材、连线并引用。句子里的引用是缩略图 chip，悬停放大并注明发送编号，Backspace 整体删除；点输入框上方参考行里的某一项也能插入。连上但没 `@` 的参考照样发送，作为整体参考。发送时 chip 换成 `[图1]` 这类占位词，附件按编号排序，再附一段规则说明占位词含义（原型把请求打到 console）。断开连线会同时去掉句子里对它的引用。
- 主版本：下游节点参考的永远是上游的主版本。默认自动选用最新生成的一版；在版本条（或全屏里）选定某一张「设为主版本」后就固定下来，之后再生成新版本也不会被替换，新结果只进入预览，需要时可以点「改为跟随最新」恢复自动。点缩略图只是预览，不影响下游，取消选中后回到主版本。如果上游在下游生成之后换了主版本，下游输入框里的参考会标「已更新」，提示重新生成会用新图。
- 工具条：选中节点上方出现，图片节点提供重绘/扩图/高清/生成视频（派生新下游节点），多选可合并为参考生成。
- 添加节点：工具轨 `+`、双击空白、右键、拖出端口到空白处，共用同一菜单；T/I/O 快捷键。
- 文字：双击文字节点或按 Enter 直接在卡片内编辑，点空白处保存；双击标题重命名。
- 分组：多选或框选后 ⌘G 打组（工具条、右键菜单同样可用），⇧⌘G 解组。可以嵌套；拖动组标题会带着整组移动，单独移动组内节点时边框自动伸缩。组内空白处可以继续框选；框选时要完整框住组才会选中它。复制组会连同内部连线一起复制，删除组会连同子节点一起删除，这些操作都能撤销。示例画布自带一个「参考素材」组。
- 资产库：抽屉默认按分组平铺，每组一段等大方格，第六格「+N」进组；分组可嵌套，父组包含子组内容，一份素材可在多个组。顶部固定视图：全部 / 最近使用 / 本画布（这张画布用过的）/ 最爱 / 未归类。进组后是面包屑加保持比例的瀑布流，子组以 chip 列在最上面。类型分段、标签（按分类列出，「同时满足 / 满足任一」可切换）、排序三件筛选；有关键词或标签时平铺变成一张结果网格，空结果可清除条件或扩大到全部。已在画布上的素材右下角有小勾，点一下定位到节点。悬停放大在抽屉右侧，空格快速查看、方向键翻看。⌘ / Shift 点击多选，整批拖入或「放入画布」横排摆开，一次撤销。从 `@` 进入时点击即选择，可多选，确认后竖排放在目标左侧、连线并依次引用。画布节点拖到分组标题上松手即存入该组，节点留在原处；右键「存入资产库…」可选分组，重复存入只追加归类。分组栏在平铺顶部：「新建分组」就地输入名称，Enter 确认、Esc 取消，同层不能重名；组标题的「…」或右键可重命名、新建子分组（最多两层）、删除。删除分组只去掉归类，素材仍在库里，子组升到上一级，toast 里可以撤销。整理模式（分组树拖拽、批量归类、检查器、回收站）尚未做。
- 填充空节点：空的图片/视频节点里点「上传」或工具条「上传」，选的图直接填进这个节点；点「资产库」进入选图模式，只列图片，点一张即填入。也可以把资产库的一张图或本地文件拖到空节点上。已有内容的节点不会被覆盖，拖上去照常新建节点。填入后标题换成文件名或资产名，高度按图片比例更新，可撤销。
- 外框：资产库默认收起；项目名菜单收纳改名/归档；撤销、缩放、适应、小地图合并在左下。
- 助手（`agent.mjs`）：一轮回复是一串有序的块。过程（思考、计划、工具调用）压低成细行，结论（正文、提问、确认、改动）是卡片；结束后过程收成一行「已处理 N 秒 · M 次操作」，点开可回看。
  - 思考：运行中流光标题，下面滚动显示最新一句；结束写「已思考 N 秒」，默认收起。
  - 工具调用就是对画布的操作（读取 / 新建 / 连接 / 生成 / 整理成组）。悬停工具行或任意节点 chip，画布上对应节点高亮、其余变暗；点击定位。助手正在处理的节点带琥珀描边和「助手」标签，生成进度同时显示在节点和工具行上，结果缩略图挂在工具行下面。
  - 提问：卡片内逐题回答，支持图片选项、画幅示意、多选，数字键直选，也可以直接在输入框里写答案；可跳过，由助手按默认处理。
  - 确认：消耗点数的生成先列清单和总价，可勾选「本对话内不再询问」；改写提示词先给 diff，应用后才写入节点。输入框的执行模式 chip 可切到「自动执行」，跳过这两类确认。
  - 本轮改动：列出新增节点、连线、改写的提示词和点数，可「在画布上查看」或「撤销本轮」（已消耗点数不退）；整轮只记一个撤销快照，⌘Z 也能一次撤掉。
  - 控制：底部状态条显示当前步骤和耗时，Esc 或「停止」随时中止，已做的改动仍会汇总。运行中继续输入会排队，本轮结束后自动发送。面板收起时，工具栏「助手」按钮带状态点（琥珀 = 运行中，白 = 等你回答），需要回答或完成时 toast 提示。
  - 上下文：默认跟随画布选中，也可以 `@` 手动添加或移除；对话列表收进标题菜单，外发授权首次确认一次。
  - 原型没有真实模型，按关键词走固定剧本：拆分镜并生成草图、给镜头 02 写提示词、整理拍摄清单，以及它们的追问。

## 首页（`home.html`）

打开 <http://127.0.0.1:8771/docs/prototypes/creative-workspace/v6/home.html>，`#projects` 是完整项目列表，左侧「资产库」进入独立的资产库页。数据只在内存里，刷新即回到示例。2026-10-11 参考 LibTV（登录后首页与项目页）和 Buzzy 做了这一版：保留 LibTV「新建 + 最近项目」在首屏的工作台结构，借用 Buzzy「一句话直接开始」的输入框，不做营销 banner、社区作品流和促销。

- 外框：左侧应用侧栏（`side.mjs` / `side.css`），首页、项目页和资产库共用同一个。从上到下是导航（首页 / 项目 / 资产库）、「最近打开」、返回 CRM 和账号余额。替换掉现在的营销式大标题和三处重复的「新建项目」。
  - 展开 216px 显示全称，折叠 56px 只剩图标；点品牌右侧的按钮切换，折叠与否记在本机，换页面保持不变（owner 2026-10-11 要求两个页面统一）。图标在两种状态下位置不变。
  - 折叠后悬停或聚焦图标，名字显示在右侧；最近项目只剩缩略图，运行中的带琥珀点，等你确认的带白点。
  - 以后导航加条目，「最近打开」整体往下挤，放不下就在自己的区域里滚动（owner 拍板保留这一栏）。
  - 窗口在 761–1100px 之间自动折叠，不显示切换按钮；手机上收成顶栏，只留品牌和三个入口。
- 一句话开始：首屏中央是输入框，可以加参考图（上传、拖入、从资产库选），选 Skill 和模型。按 Enter 会新建项目、把这句话交给助手，项目卡立即出现在「继续创作」第一位，并标上运行中。「空白画布」是次要入口。输入框下面是摄影场景 chip（婚纱外景策划、棚拍布光、品牌情绪板、写真分镜、客片扩图），点一下就填入示例文字并切换 Skill。
- 继续创作：最近 4 个项目放在首屏。封面是这张画布的缩影，按节点位置画出图片、文字块、空节点和连线，空项目显示「空白画布」，不再用首字母加色块的假封面。进行中的状态沿用画布的语义：琥珀点表示助手运行中或生成中，白点表示等你确认。只用左上角的状态标签，卡片不加琥珀描边，几个项目同时在跑时不至于整排发黄。问候语分开写「N 个项目在运行，M 个等你确认」。
- 从模板开始：每个模板是一张带好参考组、分镜和说明的画布。点击会复制一份成新项目，卡片上列出模板里包含的内容。
- 资产库 · 最近添加：一行等高原比例缩略图，悬停「+ 参考」会放进上面的输入框。首页因此也是资产库的入口。
- 开始创作：一句话发送、「空白画布」、点模板都会建好项目后直接进入画布，不停在首页等人点 toast。
- 项目页：当前 / 已归档（不叫「进行中」，免得和运行中撞词）、搜索、排序（最近编辑 / 最早编辑 / 名称）。新建只放在右上角一处，网格里不再放占位卡。卡片「⋯」菜单有打开、就地重命名、复制项目、归档（有任务在跑时不能归档），已归档的项目可以恢复；归档和恢复都能在 toast 里撤销。

落地时需要后端补的：项目列表要带封面摘要（节点版式、前几张媒体的缩略图、节点数）和进行中状态（运行中的助手 run、生成任务、等待确认）；「一句话开始」要能一次完成建项目 + 建对话 + 发出首条消息；模板需要一份「复制画布」的能力，可以和 V6-050 复制项目共用。

## 资产库（`assets.html`）

打开 <http://127.0.0.1:8771/docs/prototypes/creative-workspace/v6/assets.html>，首页左侧「资产库」也会进入这里。资产库是独立页面，不再借用某个项目的画布。方向是 Eagle 式的素材管理：左边整理，中间浏览，右边看详情。2026-10-11 参考了 LibTV 的资产页（生成历史 / 个人资产库 / 主体库），只借用了「生成结果自动归档」这一点，整理能力都是我们自己的。

- 布局：应用侧栏（和首页同一个，可折叠）+ 资料库树 + 浏览区 + 检查器。检查器可以收起；浏览区变窄时先收掉缩放滑杆、筛选折行；窄屏只保留浏览区，检查器开关也一起隐藏，侧栏变成顶栏。
- 资料库树：
  - 固定视图：全部、未归类、最爱、最近添加、生成记录、回收站。
  - 智能分组：按颜色、画幅、标签保存的条件，新导入的素材符合条件会自动出现。
  - 分组：最多两层，计数包含子组，一份素材可以同时在多个组。右键可以重命名、新建子分组、删除；删除只去掉归类，可以撤销。
  - 标签：按分类（风格 / 场景 / 光线 / 用途）列出，点一下就加入筛选。
  - 底部显示用量。
- 浏览：
  - 类型分段带数量，颜色、画幅、标签三个筛选，标签可选「同时满足 / 满足任一」。生效的条件以 pill 列出，可以「存为智能分组」。
  - 排序、瀑布流 / 方格切换、缩略图大小滑块。进入分组后显示面包屑和子分组 chip。
  - 文字、链接、音频各有自己的卡片样式，不用通用图标代替。
  - 换视图时筛选条件会清空。
- 颜色是真实计算的：每张图缩小后取 5 个主色，有彩色按色相和明度匹配，中性色按色度匹配，避免用暖色找出黑白照片。检查器里点主色也能直接找相近的颜色。
- 选择与整理：
  - 选择：单击选中，⌘ 加选，Shift 连选，在空白处拖动框选，⌘A 全选，Esc 取消。
  - 移动和整理：把素材拖到左侧分组上即可归入。多选时操作在检查器里；检查器收起或屏幕放不下时，下方改为出现批量条（归入分组、打标签、评分、最爱、放入项目、回收站），两处不同时出现。右键菜单包含同样的操作，进入分组后还有「移出这个分组」。
- 检查器：
  - 单选：大图、可编辑的标题和备注、主色、分组与标签 chip（可以就地增删，也可以新建标签）、属性。下方是「放入项目…」、最爱、下载和移到回收站。
  - 多选：叠放的预览；只属于部分素材的分组和标签显示为半透明。
- 评分（owner 2026-10-11 要求）：
  - 五星制，最小单位半颗星：点星星左半边是半星，右半边是整星，再点一次当前分数就清零；悬停时预览，方向键每次 ±0.5。
  - 选中素材后按数字键 1–5 打整星，0 清除；多选时批量评分，可以在 toast 里撤销。
  - 缩略图下方只放标题和只读星级，尺寸、类型在检查器里看；文字、链接、音频卡片本身写着标题，下方不再重复。检查器、批量条、右键菜单和查看浮窗里都可以改分。
  - 筛选有「5 星 / 4.5 星以上 / 4 星以上 / 3 星以上 / 未评分」，排序可以按评分；智能分组也能用评分做条件，示例是「精选 · 4.5 星以上」。
  - 星星用白色，琥珀仍只表示运行中。
- 查看浮窗（`viewer.mjs` / `viewer.css`，参考 LibTV）：左边看或播放，右边是信息面板。资产库、生成记录、以后的画布节点和助手结果共用这一个组件。
  - 打开方式：双击、空格或 Enter，或者点缩略图悬停时的放大按钮。单击仍然是选中，保持 Eagle 式的整理手感。
  - 画幅：图片和视频按原比例完整显示（竖图不裁切）；铺不满的两侧用同一张图的模糊放大填充（owner 2026-10-11 要求，参考 LibTV）。这是 v6「不用玻璃模糊」的唯一例外，模糊来自内容本身，不是界面皮肤。
  - 缩放（owner 2026-10-11）：图片已经按画幅放到最大，所以不提供点击放大。只用鼠标滚轮和触控板双指捏合缩放（1×–8×），以指针为中心；放大后拖动或两指滑动平移，边缘不会被拖出视野。底部显示比例，点一下还原，翻到下一项自动复位。
  - 左侧：视频和音频有播放、进度和时长控制，空格播放或暂停；文字按阅读排版显示；链接显示预览，并提供「打开网址」。方向键翻看，Esc 关闭。
  - 右侧：类型与尺寸、可编辑的标题、星级、添加时间与大小。生成得到的素材还有「生成信息」：提示词（可复制，可展开）、模型、比例、分辨率和参考图。下面是分组、标签和备注，底部是放入项目、下载和删除；删除后浮窗里可以直接恢复。
  - 生成记录在浮窗里显示创建时间、来源项目和生成信息，操作是存入资产库、新建画布添加、下载和删除记录。
- 导入：
  - 入口：导入菜单可以上传文件、添加链接、新建文字；也可以把文件拖进浏览区，导入到当前分组。
  - 粘贴：⌘V 粘贴文件、网址或文字。
  - 重名：标题相同的素材会跳过，并在 toast 里说明。
- 生成记录（owner 2026-10-11 确认要做）：参考 LibTV 的「生成历史」。每次生成的结果按日期自动列在这里，但不算资产库内容，也不会自己分组，点「存入资产库…」并选择分组后才进库。检查器里显示提示词和模型。
- 回收站：显示剩余天数，可以恢复或永久删除；顶部一条提示写明 30 天自动清除，旁边是「清空回收站」。永久删除前会确认，并说明画布里已有的节点不受影响。
- 遵守内容归属约定：资产库不记录、也不展示素材是否已经放进画布或哪个项目用过它；「放入项目」是一次性的复制。

落地时需要后端补的（owner 2026-10-11：这是一块需要先拆需求、写设计的大任务）：
- 素材主色和画幅。可以在上传或生成时计算后入库，供筛选用。
- 素材评分（0–5，步长 0.5），以及按评分筛选、排序和批量评分。
- 生成得到的素材保留自己的生成信息（提示词、模型、比例、分辨率、参考），这是素材自身的来源记录，不记录画布或节点关系。
- 智能分组的存储。
- 生成记录的跨画布列表（按账号列出生成结果），以及「存入资产库」。
- 导入时按内容哈希查重。原型只按标题判断，真实实现应该比对内容。

生成、下载均为模拟，没有真实模型调用。影像复用 v4 素材，图标复用 v5 的 Lucide 导出。

## 拍摄策划节点（`plan.html`）

打开 <http://127.0.0.1:8771/docs/prototypes/creative-workspace/v6/plan.html>。数据只在内存里，刷新即回到示例。2026-10-15 按 V6-079 design（`.codestable/features/2026-10-15-shoot-plan-document/`）做的视觉原型，示例内容是一份 cosplay 合成片策划，图片沿用 v4 示例影像占位。

- 画布卡片：标题在卡片外上方；卡片上半是封面拼图（优先 KV 分镜，其次情绪板参考），下半是类型、方案名、作品 · 角色、创意方向一句话、各章状态点、「已规划 x/9 · 分镜图 y/9」（已规划要求动作、构图、光线齐全；分镜图要有图且不过时）和当前版本号。空策划显示「打开」和「让助手起草」。选中后上方出现工具条：打开策划、重命名、更多（从画布移除可撤销，策划本身保留）。
- 策划类型：工具轨「+」新建时先选类型。首版只有 Cosplay 拍摄，婚纱外景、人像写真、商业产品标「即将推出」。类型就是模板，决定章节、参考分组和镜头分组；编辑视图顶栏显示「Cosplay 拍摄 · 模板 v1」。
- 最大化编辑视图：双击卡片从卡片位置展开，Esc 或左上角还原。顶栏是类型、保存状态（已保存 · #版本 / 保存中 / 未保存 · 内容在本机，重试中）、历史版本、助手、更多（导出 PDF、复制为新方案标「后续」，移入回收站）。
  - 左栏目录按阶段分组（前期策划 / 准备 / 拍摄 / 后期 / 交付），每章一个状态点：空、草稿、已确认、确认后有修改、本次不适用；底部是确认进度和图例。滚动时目录跟随。窗口窄于 1100px 时左栏收起，顶栏出现「目录 · 当前章节名」按钮，点开是带状态的章节菜单。
  - 封面：类型、可直接改的方案名、作品 · 角色 · 拍摄形式、创意方向一句话，右侧是分镜联系表。下面是基本信息表格；选「合成」时地点默认填「无影棚」。空白策划不显示分镜联系表，首屏是基本信息和「根据这些信息起草方向」。
  - 章节：编号、标题、状态、确认按钮（确认绑定当时的版本，之后有人改动就变成「确认后有修改」并提示重新确认）、本次不适用开关。「确认后有修改」时点「看改动」，在这一章下方展开自确认以来的差异：一句话逐字对比，正文按段落对齐（未改动的折叠，改了的标出字差别），参考图列出增删；可「看过了，重新确认」或「恢复到确认时的内容」，历史版本退到第二层。下面是一句话概括、所见即所得正文和参考图组。正文聚焦时出现格式条（加粗、斜体、小标题、列表、待办、引用块、链接、引用参考）；输入 `@` 或点「引用参考」插入参考 chip，chip 绑定引用 ID，编号随参考顺序计算，悬停预览大图；删除参考后正文里显示「引用已删除」，不会指向下一张。粘贴表格转成列表并提示，粘贴图片提示改用「添加参考图」。
  - 视觉设定（情绪板之后、准备清单之前）：人设与场景两组卡片。人设是三视图（正 / 侧 / 背），由助手基于搜集到的或摄影师提供的角色资料生成，策划阶段没有定妆照；场景是一张主场景图加由它派生的角度。每张设定卡有状态与确认、「N 个镜头使用」、说明和生成依据（引用 chip）；设定改过后提示有几张分镜基于旧设定。
  - 准备清单是可勾选的待办列表，按妆造 / 服装与道具 / 场地与灯具 / 拍摄素材分组。
  - 分镜与交付：按主视觉 KV、半身、特写分组并显示目标数（2+4+3）。每个镜头是一张卡片：左边分镜图（风格标签：草图 / 灰度 / 写实），右边标题、景别、动作 / 表情 / 构图 / 光线 / 备注和参考缩略图；没有分镜图时可「添加分镜图」或「生成」。镜头标题下是关联的设定 chip（可增减），没有关联时显示「未关联设定」；分镜基于的设定版本已过时，图上显示「设定已更新 · 重新生成」；必填字段没填的镜头标「待补 构图、光线」。顶部是「已规划 / 分镜图可用 / 基于旧设定」三个数，右侧切换逐张卡片和紧凑总览（2+4+3 一屏排开，空位显示「待补」，点一格回到卡片并定位）。「补齐镜头方案」只让助手写文字；「生成分镜图」进入选择：默认勾上没有图和基于旧设定的镜头，底部操作条选风格后「交给助手」，助手先给出生成前确认卡（每格的设定与参考、模型 gpt-image-2.5-sunburst · 2K · high、预计积分），确认后逐格生成。
- 添加参考图：每个参考图组都有「添加参考图」，弹出选择器，分「当前画布」和「资产库」两页，可搜索、多选并按顺序编号，底部选择放入哪个分组。分镜位是单选。
- 助手面板：画布工具轨「✦」和编辑视图顶栏「✦」打开的是同一个助手，共用一份面板状态（当前会话、输入框草稿、运行状态、开合）。画布上聊到一半双击打开策划，对话和草稿接着出现在编辑视图右栏；关闭策划回到画布，面板仍停在同一个会话。打开策划不切换会话：当前会话不是这份策划的工作会话时，面板顶部提示「这份策划之前在『X』里讨论 · 切过去」；面板还没有会话时直接进入工作会话。从策划里发消息、或消息带了策划标签，这个会话就成为它的工作会话。画布面板的 `@` 可以选画布上的策划；对话里的标签在画布上点击会打开策划并定位。「请助手修改」入口只起草消息、带上这一处的 `@` 标签，摄影师补一句要求再发：章节头「✦」与章节菜单（输入框留空，提示示例要求）、正文或镜头字段里选中一段文字后浮出的「请助手修改这段」（标签带摘录）、参考图菜单「请助手按这张图修改」（标签带图号）、镜头菜单、视觉设定。不默认挂 Skill：会话里第一次碰策划时，助手自己加载配套的 Cosplay 拍摄策划 Skill（过程里显示「加载 Skill」），之后几轮不再重复加载；摄影师仍可在 `@` 菜单里手动带上。助手写完后，回复下方出现「本轮改了 N 处」：每处有状态（待确认 / 已确认 / 待看 / 看过了 / 已恢复）和「看改动」，点开定位到策划里那一处，展开「本轮之前 → 现在」，可确认、看过了或「恢复这一处」。与历史版本抽屉共用右栏。
- 历史版本：右侧抽屉列出每个版本是谁（你 / 助手 + 对话名）、何时、改了哪些部分；可预览（只读）和恢复（生成新版本）。
