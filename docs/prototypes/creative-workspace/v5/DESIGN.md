# 夜间创作台

2026-09-08 owner 指定：暗色基调、液态玻璃、左侧工具与资产、中央通用画布、右侧 Agent。现有资产管理与搜索迁入侧栏；策划通过特殊节点呈现。后续纠正优先：**策划展开是该节点的最大化状态，不是从侧栏进入的独立子页面。**

## Overview

主体是摄影师正在创作的内容。深石墨工作面保持中性，清晰影像不叠玻璃滤镜；玻璃只用于工具轨、侧栏、浮层与节点最大化外壳。签名元素是烟色玻璃的细亮边缘，以及节点与展开视图之间连续的内容身份。避免强霓虹、彩色光污染和大面积营销标题。

## Colors

唯一运行时权威是 `tokens.css :root`。背景、表面、正文、次要文字、主要动作、动作文字和危险色分别映射 `--bg / --surface / --ink / --muted / --accent / --accent-ink / --danger`。原生资产侧栏的 `asset-shelf.css` 直接消费同一变量；生产 CRM 与独立 v4 的默认品牌不变。

鼠尾草色只强调当前工具、参考连接与主要动作；少量暖金标记策划、发布信息。状态同时有图标与文字。颜色不代替节点类型、订单状态或权限说明。

## Typography

宋体只承担项目意图、短文字节点和策划标题；操作、正文与元信息使用清楚的中文无衬线。世界坐标中的文字随画布缩放，工具和最大化视图保持界面字号。标题再长也不能遮住节点菜单、最大化或还原按钮。

## Layout

桌面：54px 浮动工具轨，318px 可收起的资产侧栏，弹性画布，308px Agent。资产管理可展开到 720px，也可拖动边缘调整宽度；达到 500px 后同时显示分组树。窄栏通过当前位置展开分组导航。素材采用按元信息定位的瀑布流，保持纵向滚动与原始比例。

策划节点显示摘要、状态、分镜数和关联订单；节点头部提供最大化按钮。最大化占据中央工作面，保留项目工具和 Agent，标题栏提供“还原节点”。不设置独立的策划导航。移除摘要后，从新建节点菜单的“引用已有策划”放回画布。

1200px 以下，资产侧栏覆盖画布而不继续挤压它；950px 以下，两侧辅助面板按需展开；620px 以下，工具轨缩窄，辅助面板使用余下宽度，策划分镜改为纵向图文。画布本身是二维工作面，手机可缩放/定位，现场模式使用独立的大图与触控操作。

## Elevation & Depth

交互玻璃由透色、28px 背景模糊、克制内高光与投影组成；不支持模糊时回退可读实色。浮层不改变画布或素材卡的位置。无动画也能完成全部核心操作，减少动态偏好关闭过渡。

## Shapes

控制器 10px、辅助面板 20px；节点 13px，影像保持自己的比例。边缘高光表现材质，不用厚重描边模拟装饰玻璃。鼠标点击不保留浏览器默认方形轮廓，键盘保留清楚的柔和焦点。

## Components

画布菜单、弹窗、表单和通知由 `ui.mjs` 统一管理。个人资产界面以 v5 原生模块呈现，分组树替代大封面集合页；只复用 v4 标签与回收站的纯数据规则。首次将旧 v5 侧栏数据复制到新数据库，不覆盖旧页面数据。

## Do's and Don'ts

- 从节点最大化策划，保留还原路径与画布视口。
- 区分本次任务参考订单、策划发布目标及现场使用版本。
- 所有模型、RAG、交易和 3D 未实现能力明确标注；不把示例回复伪装成真实生成。
- 原图、画布节点、策划镜头和发布快照的生命周期分开。
- 不在项目层增加客户、订单或档期归属。

## 选择反馈

节点工具条位于选区上方，以同一烟色玻璃呈现并跟随移动。框选使用细鼠尾草描边与低透明填充。Agent 上下文紧邻输入框；图片附件采用可移除缩略图。LLM 选择独占输入框下方的轻量行，与 Skill、附件和发送动作保持层级。

媒体预览以近黑半透明遮罩隔离画布，保留原始比例；不展示标题栏与提示文字，仅在右上角保留圆形玻璃关闭按钮。媒体工具条提供双斜角放大与下载图标，节点点击仍承担选择。

节点两侧采用圆形加号，悬停出现、选中常驻；触达区域延伸到节点边缘，避免移动到加号途中消失。拖动连线使用现有鼠尾草色细线，终点菜单复用烟色玻璃菜单。

加号在邻近范围即显现，并以轻微阻尼位移回应鼠标；感应与位移范围采用屏幕像素，维持不同缩放下的一致手感。连线固定在节点边缘中心，加号吸附独立于连线；减少动态偏好停用吸附位移。

选区关联线使用适度提亮的鼠尾草底线，叠加一小段柔光沿参考方向移动，周期 2.8 秒；未选中的无关线保持低对比度。减少动态偏好下使用静态高亮。

## 2026-09-09 · 原生画布资产侧栏

- 高频路径为找素材、放入画布、将可复用的节点内容存回个人库。画布上传与生成不自动进入长期资产库。
- 分组是多重引用，标签是跨组属性；我的最爱与未归类不可删除。删除普通分组保留素材，子组提升一层。
- 搜索范围可见。搜索建议区分标签与分组，标签组合默认交集，可切换并集，浮层内显示实时数量。
- 侧栏卡片单击选择、修饰键多选、空格预览；右下角菜单常驻，预览与添加在悬停/选中时显现。
- 文件导入直接入库，按文件显示状态与重试；文字/链接分别使用专属字段。标签就地新建，不出现第二层选标签弹窗。
- 玻璃承载面板与工具，不覆盖图片本身。窄屏保留工具轨，资产侧栏右侧距离视口 12px。

## 画布分组（2026-09-09）

- 多选或框选至少两个节点后，工具栏与右键菜单提供打组，快捷键为 ⌘/Ctrl G。分组可嵌套、重命名、复制、移除。
- 用浅鼠尾草描边与极淡背景围住节点；组标题栏负责选择和拖动，背景透传，组内空白仍可框选。分组不显示输入输出加号。
- 子节点相对父组定位。渲染、连线、工具栏、小地图和命中检测使用统一世界坐标。组内节点调整后边框自适应，不改变兄弟节点的世界位置。
- 解组只移除容器，保留位置与连线。移除整组则同时移除子节点，但保留独立策划文档及资产原件；所有操作可撤销。
- 同时选中父组及子节点时，只移动最上层的选中对象，避免重复位移。框选完整包住组才选中组边框，小范围框选可单选组内节点。
