## 导航与状态

- 项目主工作面始终为画布。策划的 `#node=…&mode=maximized&tab=…` 是节点展开状态，不是左侧子页面。还原不重新适配画布，不修改坐标、连线或缩放。
- 策划没有独立顶部/侧栏导航。删除摘要节点后，可以在新建节点菜单选择“引用已有策划”，定位或重建摘要入口。
- 资产库为非模态辅助侧栏，允许边检索边看画布；可展开宽度，关闭后保留原生侧栏的查询、标签与滚动；展开管理仍留在画布内。资产编辑统一使用 ui.mjs 模态。
- 最大化时收起资产侧栏，回到画布时恢复原来的展开状态。Agent 与策划同时可用。小屏两侧辅助面板互斥。
- 视口位置使用本标签页的 sessionStorage，不争用内容修订号。画布内容、策划与会话使用 IndexedDB；刷新后继续。存储失败保留恢复副本并显示错误，不假装保存成功。
- undo/redo 仅恢复画布节点与连线，不回滚订单发布、策划文档或现场记录。

## 内容与业务边界

- 图片/文字/视频/音频是通用节点；3D 节点可摆放，但场景编辑明确禁用。
- 连线表达参考图片/文本等输入。悬停或选中时显示左右加号；点击或拖到空白处创建并连接节点，拖到已有节点直接连接；不自动执行生成。风格参考和不同视频模式的详细设计未在本轮冻结。
- 策划节点引用独立文档。镜头图像直接保存素材引用/快照；删画布图片不删镜头，删摘要不删策划。
- 本次 Skill 可选参考虚构订单。产物默认未发布，发布动作另选目标并默认带出任务来源。项目不产生 CRM 关联。
- 订单跳转落到虚构 CRM 详情预览；不访问真实订单、不发送客户消息、不改变真实状态。订单入口显示发布快照，工作版本修改不覆盖它。
- 现场演示固定一版策划，保存已拍标记与当前镜头。工作版本更新后明确提示版本不同；不静默替换现场依据。
- 公共市场使用原型示例素材；免费示例可收藏，付费/关注获取明确未开放。知识包只演示条目与摘要，不声称完成多模态 RAG。

## 表单与恢复

- 新建/编辑使用 app-owned dialog，禁用原生校验气泡。错误保留输入并提供文字提示；重复提交由共享提交状态拦截。
- 关闭存在改动的表单先询问是否放弃，默认可继续编辑。普通只读预览与搜索不弹丢弃确认。
- 图片选择在编辑弹窗内展开，避免二级选择模态；分镜与图片节点共用上传校验。图片支持 JPG/PNG/WebP、5 MB，音视频参考支持指定格式、12 MB。
- 原生资产库用分组树、紧凑瀑布流与实时检索替代 v4 嵌入页。首次复制旧侧栏数据到 `creative-canvas-library-v5`，以后独立提交；保留 revision 冲突保护。
- 移除父子 iframe 消息桥。市场收藏通过原生存储接口等待事务提交成功。

## 当前限制

没有真实 Agent、生成模型、RAG、交易、3D 编辑器、云同步、多账号权限或生产离线保证。原型的本地事务与快照验证不能替代这些系统的设计、开发和测试。

## 2026-09-08 选择与 Agent 交互修订

- 默认选择工具：左键从空白处拖动绘制选择框，框与节点相交即选中；Shift/Cmd/Ctrl 可追加框选或切换点击选择。左键拖动节点移动所选节点。
- 中键、空格加拖动以及 H 手形工具平移画布，平移保留当前选择。空白点击清空选择。
- 工具条锚定选中节点（多选时为整体包围盒）上方，随节点位移、画布平移、缩放和尺寸变化重定位；靠近视口边缘时避让。
- Agent 引用与当前画布选择实时同步，取消选择即移除引用；引用卡的移除动作也取消对应节点选择。同步不抢输入焦点、不强制打开已收起的侧栏。
- Agent 加号只选择图片附件：JPG/PNG/WebP、单张最多 5 MB、每条消息最多 6 张；支持预览、移除和仅图片发送。发送成功清理本次附件，失败保留草稿；不自动写入资产库或新建节点。
- 输入区下方提供独立 LLM 菜单，演示自动选择、GPT、Gemini、Claude 系列占位，所选值记录在消息中。本轮不指定具体版本、不接入推理服务，也不声称不同选项有真实生成效果。

## 媒体放大预览

单选且已加载来源的图片/视频节点，在跟随工具条显示双斜角箭头按钮。节点图片本身使用普通选择光标。预览按原比例完整展示媒体，视频提供播放控件；Esc、右上角关闭或点击媒体外侧空白均退出，保留画布视口与选择，并将焦点还给触发按钮。预览视频时暂停节点视频，关闭后停止预览并回传播放位置，不自动恢复播放。空媒体节点、文字节点和多选不显示放大按钮。

预览进一步简化为媒体与右上角关闭按钮，标题仅作为无障碍名称保留。单选有来源的图片、视频或音频节点时，工具条提供下载按钮，按节点名称及媒体格式生成文件名；下载期间阻止重复点击，读取失败提供提示。下载不修改节点或资产。

## 加号连接交互（2026-09-09）

- 鼠标悬停节点时显示左右圆形加号，移开隐藏；选中节点后保持显示，取消选择且移出鼠标后隐藏。键盘聚焦加号时也显示；触屏保留可点入口。
- 左侧添加上游参考，右侧添加下游节点。点击加号打开节点类型菜单；拖动时显示临时连线，松开到空白处在终点打开菜单。
- 选择类型时在终点创建节点并建立参考边，两者作为同一次画布事务，可一次撤销。关闭菜单、Esc、取消拖动或拖出工作面均清理临时状态。
- 拖到已有节点直接建立对应方向参考边，自连、重复连线由原有领域守卫拒绝。
- 策划节点继续使用独立文档，当前不提供连线加号，也不出现在参考连线创建菜单；其入口仍在全局新建节点菜单。

## 加号邻近吸附（2026-09-09）

加号静止中心约 48 个屏幕像素内即可触发显示，无需先进入节点。吸附位移以屏幕像素计算，目标最大约 12px，通过弹簧与阻尼逐帧跟随，移开后回到原位；减少动态偏好下保留邻近显示但关闭位移。拖线或菜单展开时固定源加号位置，避免追逐鼠标导致起点漂移。触屏沿用显式加号，不加入悬停吸附。

临时连线与已有连线均固定锚定节点左/右边缘中心，与加号吸附位移完全独立。移动节点时更新锚点；点击默认终点与节点边缘中心同高，拖拽终点保持鼠标松开位置。

纠正（2026-09-09）：加号仅为创建和拖线的交互入口，位置与边中心接近，但不是连线端点。其悬停、吸附、回弹不驱动任何连线重绘。

## 选中节点的连线反馈

选中节点时，高亮所有直接相连的入边与出边；多选取关联边并集，其他边保持原样。短段流光始终沿参考源 → 使用方移动：入边流向选中节点、出边流向下游，不因选择哪端而反转。取消选择后关闭流光和高亮。流光不接受鼠标事件，不改变节点边缘中心锚点；减少动态偏好下只保留静态高亮。

## 原生资产库操作契约（2026-09-09）

- 同一素材允许多个分组；嵌套分组展示各自直接归类的素材，父组不隐式汇总子组。拖动分组顶部为同层排序，拖到中部为嵌套；拒绝循环。
- 搜索名称/描述/正文/标签；当前范围与条件可见，切换分组保留筛选。搜索建议可直接选择标签或分组。
- 库内选择不改变 Agent 引用；画布新增后选中节点，沿用 Agent 自动引用。库内快捷键不误删画布节点。
- 多素材一次入画布为一次历史操作，落点为首个节点左上角，后续按网格排布。素材链接入画布成为含原地址的文字节点。
- 上传到画布仅创建节点；上传到库入库，并加入当前普通分组。文字/链接创建、单素材编辑可直接选分组及标签，就地创建标签。批量整理追加归类与标签。
- 分组删除保留素材；素材回收站恢复原有喜爱和仍存在的分组。彻底删除保留画布中的内容快照。保留周期 7/30/90 天或不自动清理。
- 节点工具栏“存入个人资产库”只对有内容的文字与媒体显示，策划和 3D 不伪装成普通素材。

## 画布分组契约（2026-09-09）

- 画布组使用 `type: group` 的布局容器节点；`parentId` 标识所属组，节点 x/y 相对父组。资产库分组不参与画布层级。
- 打组自动计算边框，节点世界位置不变；同父级所选节点在原父组内成组，跨父级所选节点在画布根层成组。支持嵌套，拒绝父子循环。
- 拖动/方向键只移动选中对象的根集合，子节点通过父组位移跟随。组内单个节点可独立移动，边框调整补偿子坐标，不带偏兄弟节点。
- 解组保留当前世界位置、节点 ID、连线和策划关系；复制整组复制后代与内部连线，策划节点继续引用同一独立文档；移除组级联移除后代和受影响连线，独立文档保留。
- 组本身不允许参考连线。选中组时高亮子树关联的边，连线仍锚定具体节点的边缘中心。
- 打组、解组、整组拖动与复制各为一次撤销历史操作；刷新保留 parentId 与相对坐标。
