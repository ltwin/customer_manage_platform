# 创意空间 v5 · 夜间创作台

本地入口：[打开画布原型](http://127.0.0.1:8770/docs/prototypes/creative-workspace/v5/)。从仓库根目录运行 `python3 -m http.server 8770 --bind 127.0.0.1` 即可，不依赖前后端服务。

这版将画布设为主体，左侧工具与资产侧栏、右侧 Agent。暗色与液态玻璃替换 v4 的浅色视觉。**策划详情是策划节点的最大化视图**：点击节点右上角最大化，或“展开策划”；点击“还原节点”回到原视口。没有单独的策划导航页。

## 可以体验

1. 新建图片/文字/视频/音频/3D/策划节点；拖动、键盘调整、平移缩放、参考连线、复制、移除、撤销/重做、小地图与节点搜索。框选/多选后可打组（⌘/Ctrl G），拖标题带动子节点，解组（⌘/Ctrl Shift G）保持位置；支持嵌套与整组复制。
2. 原生个人资产侧栏：分组树、可拉宽管理、实时标签检索、搜索建议、类型与排序、批量归类、文字/链接专属表单、文件导入进度、回收站。多选素材可一起拖入画布，节点工具栏可存回个人库。
3. 公共市场浏览/搜索示例，收藏免费示例到个人库。付费与关注获取明确未开放。
4. 最大化策划节点，编辑六类内容；分镜可以新建、移除、选择/替换/上传参考图。关联订单显示在策划中，可进入虚构订单详情查看发布版本。
5. Agent 演示上下文引用、对话、拍摄策划 Skill 的可选参考订单、可编辑示例产物。产物保持未发布，发布与进入现场是后续独立动作。
6. 现场模式保存已拍镜头和当前位置；使用固定方案版本，工作版本更新不会自动覆盖现场。

## 数据与实现范围

- v4 默认数据不变；v5 画布使用 `creative-canvas-prototype-v5`，个人库使用 `creative-canvas-library-v5`，首次自动复制旧侧栏 `creative-canvas-assets-v5` 的数据，之后独立保存。视口按标签页记忆。
- 资产界面由 v5 原生模块构成，不再嵌入 v4 页面。保留 v4 的标签与回收站纯数据规则；不保留独立资产页导航。
- 节点、策划文档、发布快照和现场快照分别建模。移除节点不删除文档，重新引用可从“新建节点 → 引用已有策划”完成。
- 原型使用预置回复和示例策划，没有真实生成、知识检索、模型费用、CRM 数据连接或市场交易。
- 视频/音频节点可选择本地小文件；3D 场景编辑标为暂未开发。没有用静态占位冒充已完成的 3D 或 AI 能力。
- 导出画布 JSON 副本用于保留本地数据；策划可导出 Markdown。JSON 导入恢复与 PDF 排版不在本轮。

视觉依据见 [DESIGN.md](DESIGN.md)，行为归属见 [UX-CONTRACT.md](UX-CONTRACT.md)，浏览器观察见 [SOURCES.md](SOURCES.md)，验证结果见 [QA.md](QA.md)。

## 原生资产库验证

运行 `node docs/prototypes/creative-workspace/v5/asset-store.check.mjs` 验证分组防环、多重归类、标签与回收站规则；原有 `check.mjs` 继续验证画布与策划边界。

原型文件导入每次最多 50 份；图片限制 5 MB，视频/音频限制 12 MB。文件保存到当前浏览器。到期回收站在打开资产库时清理。智能分组、市场正式授权/交易、向量检索均未实现。

画布分组数据与资产库分组独立。节点保存 `parentId` 和相对父组的坐标；分组不成为参考输入。运行 `node docs/prototypes/creative-workspace/v5/canvas-groups.check.mjs` 验证层级与世界坐标规则。
