把攒下来的参考，理成现场能用的一张清单

一个空间对应一次拍摄。图片一次拖进来、聊天一次贴进来，在灵感墙上排个顺序、分个组，挑出要拍的画面，现场对着参考图拍。没有表单、没有状态、没有价格。

界面上固定的红线

走查中不得被「顺手」突破
没有必填。新建空间不弹表单；标题、关联、备忘都是之后可选的事，不填不是残缺态。
形态不弱于收藏夹。默认视图是图片网格，不是文本列表；文字卡和链接卡与图片同尺寸并排。
要拍的画面由自己挑。卡片不会自动变成拍摄项；做成之后与来源脱钩，来源变了也不跟着变。
备忘只是给自己的一张纸。没有必需项、截止时间、负责人、提醒，不阻断任何操作，不显示完成度。
关联只用来跳转和认出来。对订单、客户、档期、价格零写；关联对象没了，空间内容不受影响。
没有 AI、画布、检索、知识库入口或占位按钮。视频不能拖入，会被明确拒绝。
