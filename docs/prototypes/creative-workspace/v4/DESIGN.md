# 玻璃创作室

本目录是自包含的中文产品原型。2026-09-07 owner 指定自适应长宽比卡片、Pinterest 式瀑布流、懒加载/空白预占位和优雅艺术气质的液态玻璃 UI。此方向只在 v4 原型验证，不自动改生产「暗房」品牌或业务行为。

唯一运行时颜色与材质来源为 `studio.css :root`：以上背景、正文、次要文字、主动作、表面分别映射 `--bg / --ink / --muted / --accent / --paper`；标题/正文映射 `--serif / --sans`。本文件是意图记录，不生成第二套 token。层叠玻璃的高光、blur/saturate、深浅内阴影只用于侧栏、筛选栏、搜索和弹层，照片不叠滤镜。

标题用克制的宋体，照片旁的元信息用小而清楚的无衬线。桌面浮动窄轨导航、中央宽浏览区；手机转底部玻璃导航与双列素材。艺术气质来自照片、留白与字形，不使用大营销 Hero、虚构收藏量、市场占位或无效 AI 入口。

主导航收敛为素材／集合／项目；我的最爱与未归类在集合页固定置顶，以小型玻璃标识区分系统身份。普通集合沿用同样的影像拼贴封面；仅包含文字时以文字预览代替误导性的空白新增符号。集合内的管理动作使用文字按钮，删除确认明确保留素材与其他引用。

项目在 `project.css` 中消费同一套 token，采用独立工作台布局：意图与照片对照、现场条件、策划章节、分镜与现场大图。项目列表呈现创作摘要而非普通集合拼贴。owner 本次允许原型先表达完整形态，因此画布标注“布局预览”，AI/导出等明确禁用并解释暂未开发；这是原型展示规则，不代表正式产品已有这些能力。

## 布局与素材

每张图片先按真实宽高布局，使用最短列分配；桌面列间距 20px，手机 12px，元信息区域分别 62px/57px。每张卡按原图比例完整显示，不统一裁成竖图。容器宽度变化才重排；图片加载、错误与重试不改变位置。文字卡的比例属于排版容器；详情始终保留全文。

素材为 12 张有出处的 Unsplash 示例影像与演示笔记；图片保存在 assets，运行时无需访问图片外网。来源与尺寸见 photos.json。页面标题是演示收藏文案，不代表照片的实际作者或自有授权。

## 动态与降级

静态空白卡预占位，加载中的轻微明暗移动只表示加载；解码后淡入。减少动态模式移除移动与渐入，保留静态灰底和 aria-busy。玻璃不支持时使用可读实色；不依赖动画才能完成任务。

## 验证

`check.mjs` 验证几何和图片清单；`qa.mjs` 做真实浏览器走查与截图。截图、失败注入和布局测量结果在 QA.md 记录。生产 API、模型能力、真实账号和云端同步不在本原型证据范围内。

分镜编辑沿用同一玻璃弹窗，文字下方放置保持原比例的参考图预览与选择/上传/移除操作。素材选择在弹窗内展开，优先展示本项目图片；手机为双列缩略图。分镜表的编辑与移除并列为独立操作区，移除使用克制的危险色与具名确认。

收集弹窗用图片／文字／链接三个互斥入口表达创建意图。图片队列将缩略图、标题、描述、标签、来源放在同一张浅玻璃卡片内；文字与链接各有独立字段和解释，不展示混合输入区。底部固定当前类型的保存动作，错误留在其上方；沿用共享危险确认与手机弹窗滚动。

回收站位于素材库内的次级入口，沿用玻璃材质但使用稳定列表，突出素材名、移入时间、剩余时间和恢复动作。彻底删除用克制危险色及二次确认；自动清理设定与本地执行边界放在列表上方，手机控制区换行而不挤压操作。

素材卡右下角以常驻三点按钮代替装饰图标；浅玻璃菜单统一图标与文字间距，危险动作分隔置底。详情底部四项水平对齐，垃圾桶与最爱为同尺寸圆形图标按钮，默认克制，悬停/聚焦显示危险色；手机缩小间距保持同排。

标签设计参考 Eagle 的分组、组名搜索和就地选择方式，继续使用本原型浅雾灰绿的玻璃材质。管理弹窗左侧为分组、右侧为带使用数量的标签列表；名称/颜色/分组在独立小弹窗编辑。颜色以小圆点和明确名称共同呈现，不以大面积高饱和填充干扰素材。创建字段显示已选标签与「选择或新建标签」，多选器分组可折叠。素材筛选用可移除标签芯片和明确的 all/any 中文文案。手机管理分组改为顶部横向列表，标签行保留编辑/删除动作。

Owner 后续修订：标签选择不使用二级模态。筛选采用锚定下拉（手机就地展开），选中后立即刷新结果；匹配数量放在面板头部，让每次选择都有反馈。创建和详情的选择器在原字段旁展开，标签新建也在面板内完成；管理页的独立编辑表单不变。保留名称和颜色的细小标记，让素材结果继续是主要视觉内容。

Owner 浏览区修订：移除无管理入口的固定题材分类，以「素材类型 + 标签」分担筛选职责。工具栏收敛为一个轻玻璃容器，左筛选、右排序与显示；管理动作放在结果数量旁，空标签行不占空间。桌面保持单行，手机两条紧凑控制行并保留排序。选中标签才出现条件行。视频为未来禁用项，素材分组不在本次提前实现。

类型与排序控件不使用原生弹出菜单；两者共享小型玻璃选项面板、行图标与勾选标记。触发按钮与选项圆角保持一致；鼠标选择后不留焦点方框，键盘焦点仍用柔和绿线明确提示，不能以全局移除 outline 换取外观。

自建集合沿用素材卡片右下角三点菜单，删除为分隔后的危险动作。系统集合不展示管理菜单。卡片主入口与菜单为两个相邻按钮，保持大面积封面可点，并为菜单留出标题/说明空间。
