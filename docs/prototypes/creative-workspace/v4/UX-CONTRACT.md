# v4 原型交互归属

范围是独立本地原型，产品来源为 `.codestable/epics/creative-workspace-system.md` 的 M1 以及 owner 本次视觉指示。生产共享组件不被重写；原型使用一个 studio.js 统一不同视图的弹窗、通知、存储与选择行为。界面语言简体中文。

图像 loading/load/error 都使用相同宽高槽位；只有临近视口的图片设置 src。错误卡片原位重试，12 秒未加载给出重试入口；不会靠图片解码重排。慢速设置只供体验加载状态，默认关闭。

搜索是本地同步检索，输入法组合期间不改变结果；提交查询、素材类型、排序、尺寸和视图在 URL hash 保留，刷新可恢复。大图使用原生 dialog，Escape、焦点圈定、背景 inert 和返回触发控件；上一张/下一张有按钮与键盘路径。未保存笔记、导入和新建名称关闭前使用统一放弃确认，继续编辑保留输入。

收藏、集合、项目和图片导入保存在当前浏览器 IndexedDB。提交以本地 revision 校验后原子写入，失败保留输入，跨标签页不覆盖更新。导入文件每次最多 50 张、每张 5MB，类型 JPEG/PNG/WebP；单个错误在队列/表单说明，可移除后重试。没有上传服务器，也不判断上传图片属于什么题材或有什么生成授权。

主导航只有素材、集合、项目。集合页固定置顶「我的最爱」系统集合，不可删除或重命名，但素材可随时加入/移出；未归类是自动视图，不提供手动增删成员。未归类只检查普通集合关系，最爱与项目使用不影响归类。普通集合支持重命名/删除，删除确认明确只删集合，初始焦点落在“保留集合”。素材离开最后一个普通集合后回到未归类，收藏文件、其他集合和项目引用保留。

集合与项目成员去重；同一素材可加入多处，原素材不移动。旧 favorites 存储直接作为系统集合成员使用，旧 view=saved 深链兼容到集合下的我的最爱。系统入口的保护由 collections.mjs 操作守卫承担，不仅隐藏按钮。本原型提供浏览器素材回收与彻底删除，不提供服务器或仓库文件物理删除、市场发布、Agent、画布、付费或真正的拍摄执行。本地数据可用于走查，不计入 pilot 真实证据。

## 项目完整形态的原型例外

owner 已明确允许原型先展示后期形态。项目的概览／参考／策划／画布／现场由 `projects.mjs` 承接，存储仍经 studio.js 的唯一 commit/IndexedDB 路径；弹窗仍使用统一打开/关闭、焦点循环和未保存确认。项目内页由 URL 的 pane/section 恢复视图，默认概览；参考页仍用原瀑布流。主导航中的集合与素材职责不变。

项目专属参考说明写入项目文档的 referenceNotes，不修改全局素材 note。分镜明确采纳为快照，策划和现场共用相同本地拍摄项；现场操作追加演示执行事件，修改/撤销不删除此前演示事件。道具核对共享同一清单，保存后保持当前备忘展开状态与焦点。新项目无默认方案，只有具名示例项目有预置手写内容。

当前画布是布局预览，节点可跳到同一项目内容；不可拖拽/连线或保存布局。AI、PDF、CRM 接入和专业布光图是禁用入口，并在按钮旁显示原因。此处的“可操作”只表示本地原型，不表示后端交付。表格中的旧非目标“画布/真正执行”指正式能力，这些布局与本地操作不构成正式实现。

## 分镜移除与配图

- 分镜表每行提供编辑与移除；移除前展示画面名称并确认。移除只从当前方案中取下分镜，原素材与项目参考不变，拍摄事件保留，移除时的分镜快照留在 `document.removedShots` 中。概览、画布数量和现场模式均使用剩余分镜；最后一个移除后回到可创建的空状态。
- 手写与编辑共用图片编辑器，可从素材库按名称/标签选择（项目参考优先），或上传 JPG/PNG/WebP（≤5 MB）；预览保持图片比例，可替换或移除图片，也允许纯文字分镜。
- 图片和文字都是草稿，取消/关闭不导入素材。保存时将新上传图片、项目引用与分镜快照一并写入同一个本地事务；已有图片只增加缺少的项目引用，不重复创建素材。替换图片不覆盖原素材，也不重置分镜的现场状态。
- 图片解码与保存期间阻止关闭和重复提交；失败保留输入，存储冲突不产生半份修改。搜索词不算内容更改，图片单独改变也受未保存提醒保护。

## 按类型创建素材

- 图片／文字／链接是创建表单的载体类型，与未来「风格参考／知识库」用途分类分离；每次保存仅创建所选类型。
- 图片允许多选，每张独立填写标题（默认文件名）、描述、可多选或新建的标签、来源网址。后面三项可空。说明落在该图片的 `description` 字段，独立于个人收藏笔记 `note` 及项目参考意图；详情可查看，搜索包含描述和来源。采纳为分镜时可使用描述作为初始文字快照。
- 文字要求标题与正文，支持可选标签；整篇正文是一份素材，换行和内嵌链接不触发拆分或自动识别。链接要求 HTTP(S) 网址，标题、参考说明与标签可选；标题留空使用域名，不抓网页。图源网址同样只接受 HTTP(S)。
- 类型切换沿用统一未保存确认，说明具体将丢弃哪类草稿；继续编辑保留全部内容，确认放弃才清空。拖入图片遇到另一类型的草稿时采用相同规则。关闭确认恢复普通关闭文案。
- 批量图片先校验、再解码、最后原子提交素材和项目引用；解码/存储失败不产生半份导入，保留草稿可重试。保存时禁止编辑、切类型、关闭和再次加图。移除队列成员不改其余图片字段；预览对象 URL 在移除或关闭后释放。
- 图片输入限制为 JPEG/PNG/WebP、单张 ≤5MB、最多 50 张；保存按钮说明将创建的类型与图片数量，并固定在弹窗底部。保留当前原型「本地原子整批保存」边界，不将它声称为 Epic 未来服务端逐项上传/重试能力。

## 素材回收站

- 默认保留 30 天，设置可选 7/30/90 天或不自动清理；年龄从移入时间起算，修改时长不重置年龄，恢复后再次移入重新计时。旧存储缺省按 30 天处理，无需清空数据。
- `state.assets` 是可用素材，`state.trash` 保留素材完整快照、移入时间及原最爱/集合/项目关系。移入时原子移除可用素材及这些关系；所有普通浏览、搜索、数量、参考和图片选择器天然排除回收站。移入前提示素材名称、数量及使用集合/项目数量。
- 恢复原子还原素材及仍存在的目标关系，跳过已删除的集合/项目，不创建同名替代目标。已有项目文档保持不变，示例项目在首次涉及素材删除时先固化默认分镜快照。
- 彻底删除仅针对回收站记录，删除对应素材参考笔记；已经采纳的分镜/媒体快照、移除分镜历史与执行事件继续保留。单项、批量与清空都经过统一具名不可恢复确认。失败保留回收站内容，采用共享 revision 校验，不能覆盖其他页更新。
- 自动清理在页面打开、回到前台及每分钟执行；弹窗打开、恢复/删除中、保留时长有未保存选择时暂缓。关闭页面时不运行。先计算到期记录，仅有变化才提交；缩短保留时长时确认到期数量，设置与清理一次提交。
- 本地原型不调用生产媒体 API，不删除原型目录中的演示 JPEG；上传素材所占数据若被已采纳快照继续引用，不会因删除素材而破坏分镜。

## 卡片快捷菜单与详情操作栏

- 每张素材卡右下角常驻三点按钮，位于图片外的标题信息区；图文/链接共用，不依赖悬停。按钮具备名称、菜单关联和展开状态，点击不打开详情或切换批量选择。
- `card-menu.mjs` 维护唯一菜单浮层：查看详情、加入/移出最爱、加入集合、加入项目、移入回收站。动作复用原有详情、最爱、目标选择及回收确认，不创建第二条写入路径。危险操作与日常动作有分隔。
- 浮层放在卡片外以避开 transform/contain 裁切，不影响瀑布流几何；空间不足时向上展开，并避开手机底部导航。点击外部、页面滚动、尺寸变化、重新渲染时关闭。
- Enter/Space 或上下方向键可从按钮打开；菜单支持上下/Home/End，Escape 返回触发按钮，Tab 关闭并继续页面焦点顺序。
- 详情底栏固定顺序为加入项目、加入集合、最爱、垃圾桶。垃圾桶只显示图标，通过 aria-label/title 说明移入回收站，沿用未保存笔记保护和移入确认；320px 下四项保持同排。

## 标签身份、分类与颜色

- `tagCatalog` 保存标签固定 ID、全库唯一名称、颜色枚举、可空的单个 `groupId`；`tagGroups` 保存一级分组。名称 1–40 字符，首尾空白/NFC/大小写归一后判重；系统「全部标签」「未分组」保留，不作为可编辑分组。
- `asset.tagIds` 是关联权威，`asset.tags` 是兼容旧视图/搜索的名称镜像。每次统一 commit 前刷新镜像；第一次载入将旧自由文本标签迁移到稳定 ID，包含回收站素材，重复打开不产生新身份。
- 改名保持 ID，颜色与分组变更同步所有使用处；颜色仅辅助识别，始终展示名称。默认鼠尾草，可选雾蓝/紫藤/蔷薇/琥珀/珊瑚/青绿/石墨。使用计数排除回收站，删除标签的影响确认包含回收站。删除分组不删标签，删除标签不删素材；恢复回收素材不会复活已删除标签。
- collector 调用统一选择器，按每张图片/文字/链接分别存选择草稿。内联新标签暂存到当前草稿，保存所选素材时合并必要的新定义并一次提交；取消、切类型或移除最后使用该草稿标签的图片不会留下无用途定义。详情编辑也复用选择器和原子存储。
- 多选器在当前字段下拉/就地展开，支持搜索名称/组名、折叠分组、已选移除、面板内创建；同名已有标签直接选择，不提供制造重复标签的快捷动作。标签管理的编辑弹窗沿用未保存提醒与焦点圈定；素材选择器不创建第二层模态，逐次更新草稿或素材，关闭面板无需确认，未保存保护由所属素材表单承担。提交失败保留输入，revision 冲突不写入素材或新标签的任意一半。
- URL 的 tags 存固定 ID，tagMode 为 all/any；默认同时包含，空选择不筛选。对当前可见素材范围叠加关键词/类型/集合/项目筛选，回收站不进入普通检索。已删除标签的旧 URL 显示可清除的失效条件，不扩大为全部结果。收集成功清除标签筛选以显示新素材。
- 本轮只有私有原型标签管理，不建设公共标签目录、知识本体、AI 自动标注或同义词合并；正式 API 与迁移设计在 Epic 后续子项中处理。

### 标签即时反馈（owner 后续修订）

- 素材库过滤使用非模态下拉面板，保持当前结果可观察；勾选、取消立即同步筛选芯片、匹配数量和瀑布流，无「应用筛选」步骤。URL replace 保存实时条件；「收起」或 Escape 只关闭面板，不撤销筛选。
- 桌面筛选面板锚定按钮、浮在结果侧边；手机就地展开，匹配数量放在面板头部，避免底部导航遮住反馈。素材创建/详情在标签字段旁展开，不再叠加标签选择或新建弹窗。已选状态实时显示在原字段里，新建标签直接在面板内填写名称/颜色/分组。
- 创建素材时改变的是草稿，仍随素材一次提交；详情里选择标签即保存。保存失败保留错误并回退本次选择，避免显示未保存成功的关联；异步写入时保护所属对话框免受并行修改。面板中的纯搜索文本不算素材更改；搜索 Enter 不提交素材，新建名称 Enter 只创建并选中标签。
- 点击外部、Escape 或收起关闭面板，焦点可回到触发按钮。没有锁住背景或新增模态焦点圈，原素材弹窗继续拥有自己的键盘边界。共享面板在关闭后回到页面根节点，避免创建类型切换或文件队列重绘销毁它。
- 当前结果由本地数据即时计算，本轮不建设后端缓存、索引服务或接口。

## 浏览筛选的职责与排布

- 不再提供固定题材分类入口。载体类型由实际 kind 决定，主题/用途依靠账号标签；未来素材分组与既有集合关系需另行对齐，不借旧 category 枚举冒充管理能力。
- 单一玻璃工具栏承载类型选择、标签选择、排序、批量选择和显示设置。管理标签/回收站属于库管理动作，位于数量栏右侧；选中标签及 all/any 条件独立一行，无条件时整行隐藏。
- 标签下拉仍为非模态即时筛选：挂在统一工具栏，桌面浮层不推挤卡片；手机就地展开，展开时工具栏退出吸顶以免遮挡整个视口。排序在手机仍可操作，图文信息保持原始比例。
- mediaType 支持 all/image/text/link；视频入口禁用并标暂未开放。旧文字/链接 category 只做读取兼容，题材 category 不再参与匹配或搜索；新 URL 只写 mediaType。清除全部筛选同时清除类型/标签/关键词/方向条件，单独清除标签则保留类型。

## 类型/排序菜单与焦点

- 素材类型与排序由 glass-select.mjs 渲染共同的非模态列表：图标、当前项勾选、禁用视频标记、玻璃表面与圆角，不调用系统下拉弹出层。隐藏的原生 select 只保留既有 value/change 契约，不能接收指针或键盘焦点；可见按钮具有名称、展开状态和 listbox 关联。
- 指针打开时保持触发按钮焦点，选择/收起后的 :focus-visible 为 false，outline 为 none；不全局禁用焦点。键盘操作支持方向键/Home/End、Enter、Escape、Tab，跳过禁用项；返回触发按钮时保留 2px 鼠尾草色圆角焦点。
- 选择后复用现有过滤/排序与 URL 同步；Escape/外部点击只关闭。列表固定定位到触发点，边缘自动收拢/向上展开，手机避开底部导航。滚动、尺寸变化、重新渲染关闭陈旧菜单；打开类型/排序时关闭已有标签/卡片菜单。

## 自建集合外层菜单

- 集合卡片采用 article 包含主入口按钮与独立三点按钮，避免按钮嵌套，点击菜单不触发进入集合。仅普通集合显示菜单，系统集合/自动视图没有菜单；操作仍经过 ordinaryCollection 身份守卫。
- card-menu.mjs 复用素材菜单的视觉、定位和键盘行为，按目标生成打开集合、重命名、删除集合。集合名称/删除表单复用详情入口处理函数，不创建第二套保存逻辑。外层改名留在列表，删除后即使 URL 不变也刷新列表。删除集合不移素材入回收站、不清除最爱或项目关联。
- 滚动关闭以触发点实际位移为准，避免滚动定位后迟到的同位置事件导致刚打开的菜单闪退。真实页面滚动/尺寸变化仍关闭菜单。删除完成焦点回到新建集合，取消返回触发按钮。
