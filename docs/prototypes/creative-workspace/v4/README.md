# 创意空间 v4 · 玻璃创作室

这是创意空间的可交互设计原型，覆盖资产层与项目工作台的整体形态；保留 v3，不替换生产页面。视觉采用浅雾灰绿、宋体标题、浮动液态玻璃导航/工具栏，素材卡片完整保留图片比例。

## 打开

在仓库根目录启动静态服务：

```sh
python3 -m http.server 8770 --bind 127.0.0.1
```

访问 [创意空间 v4](http://127.0.0.1:8770/docs/prototypes/creative-workspace/v4/)。原型使用模块、JSON 和 IndexedDB，需要 HTTP 打开，不支持直接双击 file:// 文件。

## 可以体验

- 素材原始比例瀑布流：横幅、竖幅和文字混排，手机双列；图片提前分配空间，进入视口附近再请求，加载失败原位重试。
- 搜索标题、正文、标签与收藏笔记；支持中文输入法、清除搜索、方向筛选、尺寸切换与排序，查询和所在集合/项目随地址保存。
- 大图详情、上一张/下一张、收藏笔记、我的最爱和多处引用。关闭详情回到原浏览位置，未保存输入有继续编辑选项。
- 主导航为素材／集合／项目。集合页固定展示不可删除的「我的最爱」与自动「未归类」，心选旧数据与旧地址兼容保留。
- 新建集合或项目；普通集合可重命名、删除，单张/批量素材可移入、移出。删除集合不删素材，也不影响其他集合、我的最爱或项目。未归类只看是否有普通集合归属，与最爱标记及项目使用无关。
- 收集时先选图片、文字或链接：图片逐张填写标题/描述/标签/来源，文字整篇保存，链接单独填写网址/标题/说明/标签。图片每张 ≤5MB、每次 ≤50 张。导入、笔记和关系保存在当前浏览器 IndexedDB，刷新保留。
- 左下角设置或页尾「原型说明」可开启慢速图片加载演示；关闭说明后即可看到空白卡预占位。

## 项目工作台

[打开示例项目](http://127.0.0.1:8770/docs/prototypes/creative-workspace/v4/#view=projects&group=p-sea)。项目列表展示本次创作意图、参考与分镜数量；进入项目默认打开概览，和长期收藏集合分开。

| 视图 | 原型中能做什么 | 尚未实现的能力 |
|---|---|---|
| 项目概览 | 编辑本次意图、场地/时间/器材条件，查看参考和方案摘要 | CRM 数据关联、Agent 推敲方案 |
| 参考素材 | 查看本项目的参考；写独立于素材收藏笔记的“本次参考什么”；选择参考创建分镜；导入直接加入项目且保留全库素材 | 业务 API 与媒体上传 |
| 拍摄策划 | 手动编辑风格、分镜、场地、布光、道具、后期；手写新分镜；核对道具清单 | PDF 导出、专业布光图编辑 |
| 创作画布 | 浏览参考/意图/方案/分镜的布局关系；节点可跳到已有编辑与策划视图 | 拖拽、缩放、连线、自动排布与布局保存；均标注为布局预览或暂未开发 |
| 现场模式 | 读取同一分镜内容，逐项查看、已拍/跳过/撤销、查看并核对备忘；结果在本地追加记录 | 真实拍摄执行服务、云端同步 |

两个具名示例项目预置手写演示内容，不是 Agent 生成，也不代表实际已开展拍摄。新建项目保持空白。分镜从参考复制内容，之后独立编辑；采纳和现场结果都只作用于浏览器中的原型数据。

## 原型边界

不连接生产 API 或摄影师真实业务账号；数据仅留在此浏览器/来源地址，清理站点存储会清除。没有云同步、真实上传进度、真实 Agent、可编辑画布、市场或付费能力，也没有已验证的素材使用许可。尚未开发的能力使用禁用按钮与可见原因说明，不提供假的成功反馈。不会把新导入的图片自动判成某种题材或自有版权。

种子集共 16 条：12 张来自 Unsplash 的参考影像、3 条演示手记、1 条链接。图片下载为保留比例的 850px 宽 JPEG，启动原型后不再依赖外部图床；原作者/来源页面见 `photos.json` 与 [来源清单](SOURCES.md)。收藏标题和标签为示意文案，不冒充图片实际作者或授权。

### 分镜配图与移除

在「项目 → 拍摄策划 → 分镜表」中，每行提供「编辑 / 移除」。手写分镜和编辑窗口都可从素材库选图、上传图片、替换或移除参考图；保存后会同步到项目概览及现场模式。移除分镜保留原素材、项目参考和已有拍摄记录。图片与文字一起保存，取消不会导入素材。

专项浏览器验证：`node docs/prototypes/creative-workspace/v4/shots.qa.mjs`（在仓库根目录运行，预览服务默认 8770）。

### 按类型收集素材

「收集灵感」一次只保存所选类型。图片的描述属于图片本身，不会额外生成文字卡；文字正文保留换行及其中的链接，不按行拆分；链接仅保存指定网址，不自动抓网页。切换类型前如有草稿，需选择继续编辑或放弃当前内容。图片标题默认取文件名，其余补充信息可跳过；链接标题留空时使用网站域名。

表单由 `collector.mjs` 管理，仍使用统一 IndexedDB 提交、弹窗和未保存提醒。专项验证：`node docs/prototypes/creative-workspace/v4/collector.qa.mjs`。

### 素材回收站

素材详情或批量选择后可「移入回收站」；入口位于素材库数量栏，也可直接访问 `#view=trash`。支持单个/批量恢复、彻底删除和清空。默认保留 30 天，可改为 7 天、90 天或不自动清理；缩短时长前显示立即到期数量并确认。

恢复时找回原来的最爱及仍存在的集合/项目关系；删除期间不出现在正常浏览、搜索和参考选择中。已采纳的分镜快照与执行记录独立保留。当前仅清除浏览器中的素材数据，不删除随原型发布的演示图片文件，也没有服务器后台任务：打开页面、回到页面或使用期间的定时检查清理到期素材。

验证：`node docs/prototypes/creative-workspace/v4/recycle.check.mjs` 和 `node docs/prototypes/creative-workspace/v4/recycle.qa.mjs`。

素材卡右下角的三点菜单可直接查看、标记最爱、加入集合/项目或移入回收站。详情底部用垃圾桶图标与其他操作并排；原有确认和恢复机制保留。菜单键盘、窄屏及动作验证：`node docs/prototypes/creative-workspace/v4/card-menu.qa.mjs`。

### 标签管理与筛选

素材库分类栏下方可打开「管理标签」：新建/编辑名称、选择八种颜色、归入分组；分组可创建、重命名、删除。点击管理列表中的标签可查看关联素材。已有标签会自动纳入管理，名称去除首尾空白、统一 Unicode NFC 后不区分大小写去重；旧素材及回收站里的关系都保留。

创建图片、文字或链接时，标签改为字段旁展开的多选面板，不另开弹窗。支持按标签名/组名搜索、折叠分组，也可以直接新建并选中标签；新标签与素材同时保存，取消素材创建不产生空标签。素材详情的「编辑标签」可以维护已有素材的关联。

「标签筛选」勾选或取消后立即更新结果与匹配数量，无需点击应用；支持多选，默认同时包含，可切换为包含任意一个；能与关键词、素材类型、集合/项目范围组合，地址保存标签 ID 和匹配模式，刷新后保留。改名不破坏关联和当前筛选。删除分组只让标签回到未分组；删除标签会在确认后移除包含回收站在内的素材关联，不删除素材。

验证：`node docs/prototypes/creative-workspace/v4/tags.check.mjs`、`node docs/prototypes/creative-workspace/v4/tags.qa.mjs`。

即时标签交互验证：`node docs/prototypes/creative-workspace/v4/tag-live.qa.mjs`。素材创建中的已选标签实时反映到草稿，新标签在面板内创建；详情标签即时保存。收起选择面板不会撤销筛选或清空已选标签。

### 素材浏览工具栏

移除固定的「人像／空间／色彩／风景」分类。统一工具栏左侧提供「全部类型／图片／文字／链接」和标签筛选，右侧提供排序、批量选择、显示设置；视频保留为「暂未开放」禁用项，不表示已有上传/播放能力。仅在有选中标签时展示条件行；管理标签与回收站统一位于结果数量栏右侧。

类型按素材真实 `kind` 筛选，与标签自由组合。新的地址参数为 `mediaType`；旧 category=文字/链接兼容到相应类型，旧题材分类不再隐式过滤，新操作不继续写 category。历史素材 category 字段仅保留兼容，不作为 UI 分类或类型依据。更细的素材分组以后另行设计。

工具栏与旧链接兼容验证：`node docs/prototypes/creative-workspace/v4/browse-toolbar.qa.mjs`。

素材类型与排序现使用统一玻璃下拉菜单，带图标、已选勾选及禁用说明。鼠标点击不残留方框，键盘导航保留圆角焦点。验证：`node docs/prototypes/creative-workspace/v4/glass-select.qa.mjs`。

自建集合卡片右下角提供三点菜单，可打开、重命名、删除集合；系统「我的最爱／未归类」不显示管理菜单。快捷重命名留在集合列表，删除确认与详情内操作共用，所有素材及其他引用保留。验证：`node docs/prototypes/creative-workspace/v4/collection-menu.qa.mjs`。
