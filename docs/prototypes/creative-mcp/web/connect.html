    须知

    • 生成按你自己的规则扣点，外部助手的对话本身不扣点。
    • 建模、回看、导出分镜需要一个打开的创意空间页面，外部助手会给你链接。
    • 外部助手的改动署名为宿主名，可以在历史里回退；你的 ⌘Z 只撤自己的改动。
    • 外部助手看不到客户、订单、日程等经营数据。
