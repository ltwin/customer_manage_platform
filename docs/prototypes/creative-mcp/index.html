走查时请特别看

  • 终端里结果只露前 3–4 行：每个工具结果的第一行是不是结论。
  • 图形界面里点了卡片按钮后，外部助手这一轮不会说话，靠「卡片动作日志」里的上下文知道发生了什么。
  • 「等待页面」：卡片按钮、终端里的链接、打开后的横幅，这三处说的是不是同一件事。
  • 授权页的「能做 / 不能做」够不够让创作者放心点「允许」。
  • 宿主自带的许可提示和菜单名称都是近似的，等活原型在真宿主里核实。
