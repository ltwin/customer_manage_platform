plan-business-feedback经营草稿 tab 的复杂度事实与两份 typed draft
creative-planning-v1-hardening无独立界面：界面用用户语言表述，stale / 409 / fail-closed 等契约细节统一收进各页「评审注释」虚线框
界面上被固定下来的红线
H1 策划是辅助工具：任何列表与详情都不出现「缺策划」提示，没有策划的订单、档期与报价零阻塞；内部观测指标不进摄影师界面。
H2 协作与定价解耦：两个客户页均无价格、成本、工时与草稿字段；经营草稿 tab 明确标注仅摄影师可见。
H3 首版不依赖 AI：摄取只做结构化切分，纯链接保留为未解析候选，不抓取、不 OCR，无任何模型入口。
H4 不自动触达客户：认领项提醒收件人固定为账号所有者，昵称永不成为投递地址。
H5 原作素材仅展示：official / fan / screenshot 的生成参考选项在界面上直接禁用并给出原因。

静态原型，无后端。交互均为前端演示，用于评审信息架构与关键状态；数据为示例内容。页面里的虚线框「评审注释 · 正式产品不显示」承载工程契约说明，只面向评审。原版备份见 ../backup/planning-v1/。
