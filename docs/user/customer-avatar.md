# 客户头像

## 概述

客户头像是可选的视觉标识，帮助在同名、昵称相近时更快认出客户。未设置或图片暂时加载失败时，界面会显示昵称的**首个完整字符**（含 emoji）加色块，而不是空白。

头像**不在 30 秒建档时要求填写**；建档完成后再到客户详情里设置即可。

## 设置与替换

1. 打开客户详情。
2. 无头像时点 **设置头像**；已有头像时点 **替换头像**。
3. 选择本机图片。支持 **JPEG / PNG / WebP**，体积不宜过大（服务端上限约 5 MiB）。
4. 保存成功后详情与列表会显示新头像。

说明：

- 服务端会自动校正方向、去掉元数据，并缩放到适合展示的尺寸；**不会保留原图**。
- 不支持 GIF、SVG、HEIC，也不提供裁剪编辑器。

## 移除头像

1. 在客户详情点 **移除头像**。
2. 成功后回到首字 fallback，按钮恢复为「设置头像」。

**已合并（merged）的客户**：档案其它字段只读，但若仍有头像，可使用带隐私清理含义的 **移除头像**，用于清掉当前展示图。合并操作本身不会自动迁移、继承或删除任一方头像。

**已归档（archived）的客户**：仍可设置、替换或移除头像。

## 在哪里会看到头像

| 位置 | 行为 |
|---|---|
| 客户列表 | 缩略图或首字 |
| 客户详情 | 大号头像 + 设置/替换/移除 |
| 转介绍选择介绍人 | 候选行显示头像、昵称、短 UID、状态 |
| 合并客户时选择来源 | 同上 |
| 新建订单 / 新建档期选客户 | 同上；未来档期默认只搜在跟进客户 |
| 订单/档期上已固定的客户摘要 | 只读头像 + 名称，不是可搜索选择框 |

## 常见问题

**为什么上传失败？**  
检查格式是否为 JPEG/PNG/WebP、文件是否损坏或过大。若提示版本冲突，刷新详情后重试（有人同时改过头像）。

**移除后旧备份里还有图吗？**  
在线移除只清理当前系统里的展示与活动存储。历史备份若包含该头像，恢复备份时可能再次出现；运维侧有独立保留与销毁策略，界面不承诺「跨所有备份彻底擦除」。

**为什么有的选择列表看不到已合并客户？**  
新建转介绍、合并来源、新订单、未来档期的候选默认不包含已合并客户，避免误选。
