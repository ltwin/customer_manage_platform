# 创意工作台

正式一级入口 `/creative`，由主导航「创意空间」进入，展示已有项目与新建项目。选择卡片进入 `/creative/canvases/:canvasID`，个人资产库为 `/creative/library`；画布可返回首页。正常登录且已激活的账号直接使用，不需要白名单、试用登记或命令行开通。`/creative/capabilities` 只描述当前产品已实现能力，历史账号能力表不再控制访问；未完成的媒体/Agent能力不冒充可用。

## 视觉与交互

正式页面采用v5原型的暗色与液态玻璃：全屏画布、轻量项目栏、悬浮工具栏、可收起个人资产库和内容编辑面板。此路由有自己的主题，与CRM共用登录会话；从左上角返回仪表盘。颜色和材质由 `frontend/src/creative-canvas/editor/workspace.css` 统一拥有，语义与设计意图见根DESIGN和UX-CONTRACT。

正常保存静默进行，无保存中/确认中/同步成功提示或成功Toast。只有未提交正文草稿、离线、错误或需人工恢复时出现提示。资产库不依赖项目；文字/链接可拖入不同画布，编辑其中一个节点不会修改原资产或其他节点。

## 保存与内容边界

内容不可变修订；新建内容必须在同一事务建立资产/节点合法引用根。共享内容第一次编辑分叉，继续编辑追加修订。已有来源声明不能通过编辑扩大用途。链接只保存URL，不抓取网页。

新增节点检查topology_revision，移动检查placement_revision，正文检查data_revision和当前内容修订。操作效果和回执同事务提交；列表游标绑定账号和查询条件，预览最多2000字符，编辑前按修订ID读取全文。

IndexedDB按账号/标签页保存草稿与完整命令，节点草稿还包含画布/节点身份。请求正文、版本和operation_id先落盘再发送；每个会话同一时刻只有一个在途请求。未知结果查询原回执或原样重试，不换key。离开时关闭队列并排空本机写入，再释放Web Lock，迟到回执不能覆盖新会话。画布编辑本身不等待这个请求槽：见下文「本机 outbox」。

冲突通过共享确认框展示服务器版本，明确确认后重新应用。离线同步中断仍可编辑已加载节点的本机草稿，但禁止提交；联网重开可恢复草稿。账号切换阻止旧请求重发，认证过期沿共享续期机制处理。归档项目只读并可恢复。

## 本机 outbox（2026-09-11）

画布命令（新增/删除/缩放/改名/内容/连线/撤销/重做）不再走 `perform`+`refresh` 的阻塞路径，而是进入 journal 的 `outbox`：`SaveQueue.stageIntent` 先落盘并立即返回，`projectCanvas` 把未确认的意图与回执画到快照上（新增节点、删除、移动、缩放、标题、内容、连线/断开可本机投影；打组、解组、复制也立即投影；版本类效果等快照），编辑器不再置 loading、不再每次重拉快照。发送由 WorkspacePage 的效果驱动：250ms 静默后按序把队首意图变成一笔 batch/undo/redo 请求，读集取自投影视图（含尚未进快照的回执版本），仅本机存在的节点与 `pending:` 临时边不进读集；这些节点的位置意图等其创建回执后再发。连续 move/resize 合并进尚未发出的队尾；撤销队尾未发出的编辑直接本机取消并保留在 redo 栈，已发出的走服务端 undo。回执到达后立即拉一次快照，快照 revision 追上后 `pruneOutbox` 清理已确认意图。被拒绝（版本冲突/校验/权限）时该意图及其后同画布意图一并撤回投影，画布编辑禁用直到人工「放弃被拒绝的请求」；未知结果仍走原回执查询恢复。拖动位置也走同一 outbox（`stageMoves` 只对选区根生成 `move_node`，落点不变不入队），上文「拖动同步优化」的独立 positions 路径已合并移除；旧 journal 中未同步的 positions 在加载时转成 move 意图重放。docs 与 `creative-save-queue.test.ts` 的 outbox 用例覆盖投影/合并/本机取消/拒绝撤回/重载续发/本机节点位置延后。


### 画布交互补齐（2026-09-11）

撤销/重做在画布挂载期间监听窗口键盘事件，支持 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z 与 Ctrl+Y；按钮或页面焦点不影响操作，输入框、可编辑文本与对话框保留原生键盘语义。撤销按钮沿用现有入口。队尾取消按意图类型匹配，重做不会误删待发送的普通编辑。

打组/解组的本地投影沿用服务端的共同祖先、组边距和相对坐标规则；复制保留选区子树及内部引用边。新组与副本先用 `pending:` 编号显示和选中，收到回执后用 created_ids/id_mapping 替换身份，同时重写后续待发送命令及本机 redo 中的节点引用。复制版本、输入和布局最终以服务器快照为准，因此后续命令等快照追上后再发，但本地操作可继续显示。回执刷新只读画布，不再重载资产库；若已有快照请求在途，会补拉一次。

回归验证：`creative-save-queue.test.ts` 覆盖本地结构投影、身份替换、依赖顺序、冲突回退与队尾取消；`node frontend/scripts/creative-canvas-interaction.e2e.mjs` 在 Vite 开发服务上使用隔离的模拟 API 验证真实浏览器焦点、快捷键和无网络响应时的即时显示（可通过 CREATIVE_EDITOR_URL 指定前端地址）。


## 画布 SSE 同步（2026-09-11）

画布常态同步改为 `GET /api/v1/creative/canvases/:id/events` 的 SSE，移除前端五秒定时读取。写操作继续通过带幂等键的 POST commands，打组、复制与撤销沿用本地 outbox 投影。SSE 发送失效通知后读取权威快照，不直接重放节点补丁；命令回执后的立即读取继续保留，以便尽快清理 outbox。若快照读取失败，会退避重试；认证/权限/不存在错误停止重试。

数据库迁移 `0042_creative_canvas_events` 给画布、节点、边、输入、变更、提示词、版本及执行表安装提交后通知。项目、文档、内容可用性和账号状态变化按账号失效。相同事务的相同通知由 PostgreSQL 合并；内存订阅通道容量为 1，合并慢消费者的重复失效。每个 Store 按需建立一个独立 LISTEN 连接，所有页面共享，不占用业务连接池中的连接；HTTP shutdown 先停止监听并关闭订阅流，Store.Close 也会取消并等待监听结束。数据库断线采用退避重连，LISTEN 生效后强制通知所有订阅者重读，避免初次订阅和恢复时漏更新；空闲监听仅探测数据库连接存活，不查询画布。

前端使用带 Authorization 的 fetch 消费 SSE，复用既有登录续期，凭证不进入 URL。页面隐藏、断网、切换画布或卸载时取消流，可见/联网时重新连接；重新订阅的首个 invalidate 补拉最新快照。服务器每 20 秒发送注释心跳，每条流最长 5 分钟；前端 60 秒收不到字节时重连，失败采用 1～30 秒退避与抖动。事件发送前重新检查 token、账号能力和画布归属；权限失效发送 unavailable 并断开。设置 no-cache/no-transform、X-Accel-Buffering: no 和单次写入期限。

验证包含真实 PostgreSQL 的提交/回滚、账号与画布隔离、仅执行状态变化、监听断开恢复；真实 HTTP 流的认证、外部连接写入通知、权限撤销；前端分帧解析、心跳、重连补拉、终止错误及卸载取消。浏览器脚本 `node frontend/scripts/creative-canvas-interaction.e2e.mjs` 使用模拟 API/SSE 验证空闲不轮询、远端通知更新节点，并回归 Ctrl/Cmd 撤销重做、即时分组和连续复制。

启用需要后端运行包含 0042 迁移的新版本；仅前端热更新不足以提供 SSE。当前仍按变化拉取完整快照，高频大量变更下的增量推送可另行演进，本轮不宣称已经完成生产性能基准。

## 媒体空态与上传校验（2026-09-11）

节点文件选择器按服务端 media-capabilities 与节点类型生成 accept（MIME 与扩展名）。上传前统一校验扩展名、声明 MIME、目标节点类型、大小及非空；允许常见 MIME 别名，MIME 缺失或为 application/octet-stream 时根据扩展名判断。跨类型、扩展名与 MIME 冲突、未支持格式直接提示且不发起上传，提示不阻塞画布或重新选文件。素材导入与画布拖入复用同一分类规则。当前服务端支持 JPG/JPEG、PNG、WebP；MP4/M4V、WebM；MP3、WAV。后端继续识别实际文件内容并验证节点绑定类型，前端校验不替代内容校验。
